Local Dango adaptations replace module discovery, menus, font loading/search,
translation, persisted preferences and undo image storage. View transforms,
the credited brush stabilizer, color conversions and throttle are replaced
with Dango implementations; the upstream third-party snippets are excluded.
Uncertain upstream SVG icons and all image/font assets are excluded.

This subset excludes upstream imagefilters (including the Huxtable header),
vintage, glfx, color-thief, GIF, Hermite, pica, file imports/exports, remote
services, web fonts, service workers, telemetry, print and cloud operations.
Only the files listed in manifest.json form the shipped resource set.
AlertifyJS is replaced by Dango notifications; none of its code is shipped.
The esbuild build tool and its platform binary are build-time only (MIT).
Playwright-core is test-time only (Apache-2.0); no browser binaries downloaded.
