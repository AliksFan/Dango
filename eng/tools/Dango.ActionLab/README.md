# 动作按钮实验窗口

状态：隔离实验实现，工程与原生动态检查单独记录；真实前台操作与用户审美审核待完成。仅供本轮 14 个动作评审，不接入正式产品启动、情绪／性格或自动行为。

## 本轮合同

用户已选定 8 个身体动作与 6 个眼神／短移动动作，并授权实现单人、单只团子的按钮实验窗口。幅度、节奏与衔接是本轮可调整的实验参数，不构成新的产品设计基线。

| 动作 | 执行路径与审核重点 |
|---|---|
| 抖身 | 原生顶点有界牵引；短促高频、小幅、衰减收尾 |
| 摇摆 | 同一物理牵引路径的低频缓动；与抖身节奏明显不同 |
| 舒展 | 先轻微收拢，再纵向伸展，松手回稳 |
| 伏低 | 纵向压低，保持片刻，松手回稳 |
| 歪身探看 | 向所选侧轻倾，配合注视后回正 |
| 轻靠 | 按钮模拟所选侧的抚摸接触，物理牵引轻靠后收回；不声称已接入真实抚摸 |
| 短后缩 | 短促收拢／短退，停住观察 |
| 蓄力轻跳 | 压低蓄力，单次跳跃请求；必须观测真实离地与稳定落地才结束 |
| 慢眨 | 复用 `Blink`，闭合／停留／睁开为 180／80／260 ms |
| 眯眼 | 复用 `SetEyes`，进入／停留／恢复 |
| 注视后移开 | 复用 `SetGaze`，先注视所选侧，再移开并恢复 |
| 回头看 | 先沿所选方向看，再回看反侧；本轮表示二维脸部回看，不新增三维转身 |
| 挪近一点后停住 | 原生水平驱动，以真实核心位移反馈减速／停住 |
| 短退后观察 | 沿所选方向的反侧短退，停住观察 |

控制器只接收一个按钮动作，不排队；忙中拒绝重复触发。方向只影响本轮有方向的动作。移动前检查可用空间，执行中保留原生地面和实体侧墙。停止动作释放本轮驱动与占用的眼通道，物理继续收稳；最小化取消动作并暂停，恢复后不补播隐藏时间。故障显示真实原因并停止，允许重建本实验的内存场景。

## 复用与新增边界

- 复用 `StackedDangoSceneRuntime`、`DesktopPhysicsScene`、连续带房间原生模块、现有轮廓／眼／帽渲染及附件意图。原有公开 `Tick`／`Step` 路径保持，新增内部单步驱动边界仅供隔离消费者使用，不保存输入。
- `QuietIdleController`、`ShortWanderController` 和 `IdleDozeController` 是自动待机调度，不作为本轮按钮编排器。实验运行时关闭其调度，不读取正式设置或存档。
- 新增 `DangoActionController`，将有限动作时序与实际物理观测分离；新增 `ActionLabSession` 作为 UI／验证共用的唯一推进路径。
- 不新增依赖，不改原生求解器和已有 ABI／默认行为，不替换已保护 DLL。新增每实例可选的实验跳速倍率导出：默认 1，只有本实验运行时设为 0.4，在实际施加跳跃冲量时生效，动量与能量记录同时计算；旧模块缺失能力会明确失败。牵引是现有原生弹簧力，不移动贴图，不重设核心坐标，不冻结身体或制造空中支撑。
- 场景只存在进程内；无账号、网络、数据库、真实持久数据、托盘或日常实例锁。重建只替换本实验拥有的内存世界。

## 界面规则

采用 [桌面界面规范 v0.1](../../../docs/desktop-ui-design-v0.1.md)（2026-10-10，第 2–6 节）：共同调色资源和按钮模板、暖白背景、细线图标＋短文字、40 DIP 按钮、中文提示与辅助名称、固定状态和恢复入口。两组按钮与预览同时可见；窗口下限 940 × 700 DIP，无需滚动。

页面差异：这里没有保存／应用／取消草稿或页面导航；“重新开始”只重建本实验的内存场景。第 4.3 节针对控制中心的方向键焦点规则不适用：本实验没有键盘团子控制，保留标准按钮焦点以支持 Tab／Enter，所有键盘作用域均限本窗口。高对比复用共享语义调色，无装饰性滚动或转场；动作本身是评审内容，不以系统减少动画设置静默省略它们。

## 构建与运行

在仓库根目录执行：

```powershell
dotnet build eng/tools/Dango.ActionLab/Dango.ActionLab.csproj -c Release
& ./eng/tools/Dango.ActionLab/bin/Release/net10.0-windows/Dango.ActionLab.exe
```

启动可见窗口需要当前用户的屏幕使用授权。运行不更新日常安装；关闭窗口即释放本实验世界。工程检查遇到仓库既有 `NU1903` 时，记录原失败；本轮可用命令级 `-p:NuGetAudit=false` 继续编译，不修改依赖或项目审计策略。

无前台占用的集成检查（必须指定尚不存在的新目录）：

```powershell
& ./eng/tools/Dango.ActionLab/bin/Release/net10.0-windows/Dango.ActionLab.exe --verify ./artifacts/action-lab/check-01
```

该入口使用隐藏 HWND，按实际按钮事件执行 14 动作的左右两向，推进同一原生物理与 WPF 渲染链，写入数值结果和本实验截图。验证取消、暂停、恢复、接地、真实位移、形变与跳跃起落；每次原生 tick 对应一次受控单步。它证明有限确定性步进和隐藏渲染，不能证明可见窗口真实点击、墙钟节奏、所有 DPI／高对比组合、自然度或审美。

1. Release 构建及动作控制器针对性测试通过。
