# 圆形自然态与材料小样

2026-10-09。范围：用户同意继续验证“所有团子的自然形状为圆形，落地形态由物性产生”。本轮交付独立 Windows 单团子对照小样，生产捏脸、设置、物理默认值和 DLL 均不切换。完整材料模型、多人配置、持久化和生产接入尚未获本轮验证。

## 模型和操作

- 左侧：当前 `DangoPhysicsDefaults.Current` 原参数。
- 右侧：关闭 `TopInwardForce` 和 `GroundDeformationStrength`；保留现有径向／外围弹簧、面积保持、防交叉与地面接触。两侧分别拥有独立单体物理世界，不表示共享世界或多人同步。
- 所有参数都用于真实 native 模拟。拖动抓取节点，松开后移除拖动力；同时跳跃、持续下压、正常下落和高处自由落体均使用真实物理输入。
- 高处自由落体使用 `Add(0, 8)`；地面不移动、不关闭重力，镜头只改变显示原点。
- 大小 80%～120%：实际静止长度、节点半径及排斥距离随尺寸缩放，面积下限和质量随尺寸平方缩放。恒定二维密度是小样假设，不制定生产重量或跳跃规则。
- 柔软度 0～100：映射两组弹簧频率；0、50、100 分别为现有频率的 1.2、1、0.55 倍。既有长度与角度硬限制保留。
- 晃动抑制 0～100：两组弹簧阻尼比 0.5～2.0，默认 90 对应原值 1.85。它改变恢复过程，不宣称数值越高越快回圆。
- 参数修改是草稿；“应用参数并下落”显式重建两个对照世界。暂停／失焦清空输入，错误停止并显示诊断，只能显式重新下落。

身体复用生产 `DangoStreamGeometryFactory` 的轮廓校验和样条，抵消其 X/Y 映射系数后按同一物理单位长度显示；不经过 presentation adapter 的尺寸归一化。眼睛仅是小样装饰，不证明生产捏脸挂点兼容。

## 预先固定的验收

1. 小／中／大 × 软／中／硬共九组，检查所有帧成功、16 节点、有限坐标、面积和速度安全；正常下落 10 秒内接地，末 2 秒速度小于 0.03，核心与宽高漂移小于 0.003，轮廓穿地容差 0.002。
2. 高处自由飞行连续后 1 秒径向差不超过 4%、宽高比偏差不超过 4%、几何圆度至少 0.975。圆心通过最小二乘拟合；节点分布不均不能被误当作非圆。
3. 九组都用实际拖动力先产生至少 10% 径向差；松开后 1.5 秒内恢复近圆并维持至少 0.3 秒，全程无接触。禁止把重新生成的圆形当作恢复。
4. 尺寸实际直径比例达到 0.8／1.2，容差 0.01；软硬端点的落地宽高比差至少 0.03或高度差至少自然直径的 3%；阻尼端点实际恢复轨迹径向差最大差至少 0.01。
5. 圆度纯指标测试接受不均匀采样的圆，并拒绝横向放大 20% 的椭圆。这两份是明确标注的合成度量夹具，不冒充物理模拟。
6. 默认候选连续 36,000 帧（10 分钟模拟时间），健康、接地及末段漂移通过。加速运行不等于 10 分钟真实桌面运行。

本轮不声称全滑块组合、极端鼠标操作、长期真实桌面、多体接触或用户人工验收已通过。

本轮实际结果：Release 构建零警告、零错误；最终自动门禁 32/32。九组实际拖动后回圆约 0.10～0.32 秒；同尺寸软硬端点的落地宽高比约 1.07／1.30；默认 36,000 帧通过接地停稳和漂移门禁。已打开真实窗口，通过 UI Automation 验证三滑块、未应用草稿提示、应用按钮和应用后实际形态变化，并查看真实帧离屏快照。自动操作不作为用户手感验收。

## 运行

按 `docs/phase-1-physics-module.md` 在新隔离目录构建当前 native 模块。本小样不调用会替换正式 DLL 的 `build-box2d.ps1`，没有新依赖。

```powershell
pwsh -NoProfile -File eng/run-material-sample.ps1 -NativeModulePath <isolated-module.dll>
dotnet artifacts/round-material/app/Dango.MaterialSample.dll <isolated-module.dll> --verify artifacts/round-material/verification-final.json
dotnet artifacts/round-material/app/Dango.MaterialSample.dll <isolated-module.dll> --snapshot artifacts/round-material/comparison.png
```

`--verify` 写完整结果，任一必过项失败则退出 1；`--snapshot` 渲染真实落地帧，并且绘制失败不能生成成功快照。

## 探索失败与后续边界

首轮错误地把旧默认顶部内收当成必然不圆的负例；实际旧默认也满足 4% 的“近圆”门禁。保留原报告，不收紧圆形阈值以拒绝旧模型，改用明确的圆／椭圆度量正反例。

曾试验面积保持强度 1.8～7.8 的“饱满程度”滑块，其端点落地面积差未达到预设 1%，因此此功能退出当前交付，保留失败记录，不降低门槛。现有面积保持仍是旧单向径向压力，不是已经改造的守恒材料模型；后续应独立评估面积梯度约束及参数效果，再决定是否开放。

过程报告位于忽略目录 `artifacts/round-material/verification-first.json`、`verification-v2.json`；最终状态以 `verification-final.json` 和本轮人工评审为准。正式基线、native 二进制和产品文档的已验收事实保持原样。
