# 独立物理实验室

## 当前实验：整体连续闭合带

2026-10-16 已开始[完整外观与身体标定](../../../docs/planning/2026-10-16-belt-calibration-and-appearance.md)，当前优先校准身体，眼睛和配饰只作被动观察。`--belt` 默认打开身体D，可切换F、原外围和校正前实验；选择后点击应用。D/F使用独立v2模块、正式默认眼睛与明确标注的内置测试搭配；眼睛/配饰运动参数未做标定，不写日常设置。`--saved-appearance`可显式切为日常只读快照；`--smoke`始终用虚构夹具。

独立批测：`--belt-calibration`保留默认兼容性及有限弹性灵敏度，`--belt-candidates`跑A/B/C静态组合，`--belt-refinement`跑D/E/F静态探针，`--belt-dynamics`跑旧half和阻尼D/F的走停、回弹及跳跃。每次单独运行，所有结果保留；完成批测不代表形态/手感通过。静态后两入口读取最近的同模块 `calibration-results.json` 并验证模块哈希。会话目录加随机后缀，防止同毫秒启动覆盖清单。

**跳跃事实更正：** 前轮把“Space不变”误接成仅核心0.42冲量，实际旧half默认整身各增加7.7m/s起跳速度。D/F通过可选能力恢复实际原地面规则，冷却及W/S仲裁保留，不通过加硬或任意调高冲量补偿。校正前模式仍保留弱跳行为供历史对照。下文早期“原核心冲量”等表述以本更正为准。

用户已废弃下文的弹性弧段候选。本轮新外圈使用自己的周期 Fourier 变形坐标（K=8，核心加整圈共36自由度），16个旧骨架位置成为无质量塑形附着点，不再各自碰撞。默认保留短骨架塑形；整圈承担真实接地。数值模型仍是有限维近似，不能保证静置与受力形状自动等同原版。

- `--belt` 打开新窗口，仅提供“连续闭合带”和“原外围半侧驱动”对照；默认短骨架开、步态关、显示平滑关。
- `--belt --smoke` 显示真实WPF窗口，跑窗口内路由输入、真实原生物理、截图检查后退出。不是OS键鼠或人工观感验收。
- `--belt-experiments` 先记录默认材质静置轮廓，再跑旧Core、旧半区与新圈半区的同输入走停、W/S、Space；短骨架关闭仅做静置对照。新圈Core驱动未实现，不伪装成已有模式。
- `--arcs`、`--arc-experiments`、`--region-point`明确拒绝；旧候选源码与失败数据保留为历史。

新原生目标 `dango_physics_lab_belt` 与 `dango_physics_lab_belt_tests`，开关 `DANGO_PHYSICS_LAB_BELT=ON`；输出单独放 `artifacts/physics-lab/belt-native/Release/`。WPF输出 `artifacts/physics-lab/app-belt/`。不运行会复制正式DLL的构建脚本。

区域驱动按当前真实曲线的包围范围划分：A左半、D右半、W/S均上半，沿材料区间共同受力，合力预算保持；不是给16个附着点分力。Space仍作用于原核心质量，沿用冷却及接受帧W/S仲裁。新模型仅单体平地；没有平台/家具/球/多人接入。X边界越界明确失败并整帧回滚，不伪装成旧侧墙。

窗口直接绘制256个真实曲线采样点，不再从16点插值。蓝十字来自连续质量积分的真实COM，灰线是同材质原版300帧落稳参考，橙点为核心/无质量塑形附着点，红箭头为区域合力位置。材料修改后显式应用；失焦、文本输入、拖动、菜单和重置清玩法输入。最近1200帧诊断可导出，文字内容不保存。

计划：[连续闭合带实验](../../../docs/planning/2026-10-15-continuous-belt-lab.md)。模型安全、静置外形、减抖、输入、人工验收分别判定；退出0不表示效果通过。

## 历史：已废弃的弹性弧段与半侧共同施力

用户于2026-10-15批准：外围弧段真实参与弯曲受力和碰撞，内部径向骨架先保留；A/D对应侧外侧1/2，W/S均上侧1/2向上／向下，区域按实际质量共同受力，总力预算保持，Space沿用原跳跃。单节点入口已取消；下文旧1/3及单节点记录仅为历史。

新原生开关 `DANGO_PHYSICS_LAB_ARCS=ON`，三个独立目标 `dango_physics_lab_arcs`、`dango_physics_lab_half`、`dango_physics_lab_half_envelope`，输出 `artifacts/physics-lab/arc-native/Release/`。WPF输出单独使用 `artifacts/physics-lab/app-arcs/`，不覆盖旧观察窗口加载的文件。

- `--arcs`：弹性弧段＋半侧区域共同施力，默认关闭显示平滑。
- `--regions`：原外围＋半侧共同施力，作为相同输入对照。
- 不带参数：原Core驱动／离散接地；可在下拉框选择弹性弧段和施力方式后显式应用。
- `--smooth`：另行开启既有显示滤波；判断弧段真实改善时保持关闭。
- `--arc-experiments`：默认材料的旧Core／旧外围半侧／弧段Core／弧段半侧四组走停及W/S/Space对照。安全与抖动、速度、形状代价分别记录；结果不表示用户观感通过。
- `--region-point`明确拒绝；本轮半侧模块也拒绝原生单节点模式。

同一周期二次B样条用于显示、伸长／曲率能量和多点接地。自然态为原有16节点的近圆形样条，并非严格数学圆；弧段可弯曲、伸长和回弹。原外围距离弹簧和角度规则被替换，受力形状须重新比较。新模型仅支持单体平地，平台／球／家具及多体明确拒绝。

界面显示真实伸长能、弯曲能、阻尼功率和有效接触数；原始骨架、真实质心与施力节点可叠加。绿色单标记为最低点诊断，不代表只有一个支撑点。故障暂停，需显式重置。实验方案见[本轮计划](../../../docs/planning/2026-10-15-elastic-arc-lab.md)。

本轮默认四组批测全部安全通过，但弧段未减少行走抖动；效果失败记录与窗口状态见[验证结果](../../../docs/verification/2026-10-15-elastic-arc-lab.md)。不作为产品采纳或人工验收通过。

`Dango.PhysicsLab` 是本地单体物理实验窗口。直接调用项目原生物理算法；原有步态、睡眠、自主走与产品宿主均不运行。它不修改外观文件、用户设置或正式 DLL，不构成正式界面、桌宠或多人验收。

## 运行

先单独构建 CMake 目标 `dango_physics_lab` 到 `artifacts/physics-lab/native/Release/`，再构建本项目到 `artifacts/physics-lab/app/`。不使用会复制正式 DLL 的构建脚本。模块需具有 Lab capability 1；旧模块明确拒绝实验调用，但原有接口继续可用。

窗口自动从仓库内查找该模块。`--smoke` 显示真实 WPF 窗口并运行路由事件检查、生成截图后退出；这是自动检查，不代替真实键盘与人工验收。`--experiments` 使用同一物理接口跑确定性实验并退出，不打开窗口。输出均在新建的 `artifacts/physics-lab/sessions/` 会话目录，记录模块哈希与步长。

## 操作

- A/D 移动；W 拉伸、向上看；S 原下压力、向下看；Space 单次跳跃。
- 相反键中性但保持活动；W+S 同按立即撤销旧拉伸力；普通 W 松开按批准的 0.20 秒释放。
- F 只在左侧开关附近放置／移除真实平台；长按不重复，远处无动作。侧栏按钮可直接操作平台。
- 鼠标拖动团子；拖动、窗口失活、文字输入、菜单与重建都会清玩法状态，恢复时需重新按键。
- 鼠标点按钮／滑块或 Tab 聚焦后，WASD/Space 继续控制团子；按钮用 Enter／鼠标执行。文字框保留输入，文字不保存、不导出。
- 修改参数后点“应用参数并重置”，或点“从同一起点回放”；参数并不在拖滑块时悄悄改变物理世界。

## 物理对照

1. 核心单点：原驱动基线。
2. 全身按实际质量：相同总力按各物体真实质量分配。
3. 按高度偏置：改变全身节点的上下施力权重。
4. 移动合力作用高度：在当前核心到上／下轮廓节点的区间选择目标高度，由最近上下两个真实物体线性分摊水平力；偏置0回到核心单点。它改变力矩，不保证稳定。

各模式保留总力、材料、核心速度限幅、重力与小步。基础摩擦设零只改变配置摩擦；原算法的空闲摩擦覆盖与接地制动仍保留，不能据此排除全部摩擦来源。

地面统一为 world X ∈ [-256,256]，远边有实际墙。固定回放须离地面两侧边缘至少2 world；批测逐帧检查该条件。视觉纵向相机固定，只在必要时横向跟随，不抵消真实Y运动。显示放大为120 DIP/world；指标统一按72 DIP/world换算，清单记录两者。默认曲线分别去均值，量程固定±2 DIP，不用自动缩放隐藏候选间差异。保留最近1200个紧凑样本，导出不包含界面／桌面／文字输入内容。

本工具眼睛是输入方向反馈，轮廓来自物理；未接产品面部通道、配饰、多人或混合体型休眠。W/S 幅度和驱动观感仍须按原门槛分别判断，机制安全检查通过不代表这些效果通过。

## 连续接地隔离候选

另构建 CMake 目标 `dango_physics_lab_envelope` 到 `artifacts/physics-lab/envelope-native/Release/`。这个目标独立替换地面约束，不复制正式模块。机制与32字段诊断合同见[原生说明](../../native/box2d/dango_lab_envelope.md)。

窗口左侧“真实接地模型”可选离散圆节点或连续轮廓包络，再点“应用参数并重置”或“从同一起点回放”才应用；每次切换清理输入并重建世界。`--envelope` 直接打开连续候选。候选仅支持单体平地，平台按钮禁用，F 明确提示限制；平台、球、家具和多体入口在原生层拒绝。基线的 F 操作保留。两种模型的原有步态均关闭。

曲线接地使用与绘图相同的二次 B 样条解析极值，保留16节点骨架、材料、质量、施力与步长，地面的 Box2D 碰撞遮罩关闭以避免重复冲量。绿色标记表示候选选中的最低接地点。`Grounded` 只表示间隙不超过0.035 world，不能当成有正支撑冲量；原始 Box2D 地面接触数另计且必须为0。多个分离最低点等高时，接触身份与 Jacobian 仍可能切换。

窗口图表显示真实曲线高度／真实质心Y；导出新增 `ExactCurveHeight`，保留旧 `ContourHeight` 控制点跨度，不能将两者混用。导出仍最多1200帧；另附接地修正、骨架修正、法向／摩擦冲量及能量／动量／力矩台账。故障会暂停，需显式重置，不自动退回基线。

`--ground-experiments` 跑默认材质、核心驱动的同输入 A/B；0.5 Hz至Nyquist（含端点）的全频带、原0.5～5 Hz频带及原始去均值RMS分别保留，禁止用频率迁移冒充改善。自动进程退出0表示安全检查通过；改善与速度／形态代价须另外读取JSON中的 `QuantitativeImprovementTarget`、`SpeedAndShapeCostPassed`。

本轮连续候选**未改善抖动，不采纳为产品实现**。实际数据与自动／人工验证边界见[验证记录](../../../docs/verification/2026-10-15-physics-lab.md)。

## 显示平滑与方向外侧1/3实验

独立 CMake 开关 `DANGO_PHYSICS_LAB_REGIONS=ON`，目标 `dango_physics_lab_regions` 与 `dango_physics_lab_regions_envelope`，输出到 `artifacts/physics-lab/region-native/Release/`。旧模式0～3保留；新模式通过可选能力导出识别，旧DLL明确拒绝新模式，不静默换算法。

- `--smooth`：原核心驱动，只开启显示平滑，便于先看单独显示变化。
- `--regions`：区域共同受力＋显示平滑；`--region-point`：区域中心最近单节点＋显示平滑。可与 `--envelope`组合，但连续接地仍是已保留的失败候选。
- 窗口上方平滑开关立即改变显示，不清玩法按键、不重建或推进物理。施力／身体／接地选择仍需固定操作区的“应用参数并重置”或回放才生效。
- 区域边界取当前真实绘制曲线的解析包围盒：A左外侧1/3、D右外侧1/3，W和S均取上外侧1/3。只在16个轮廓节点中选取，核心排除；区域共同模式按实际质量分力，单点模式选离区域中心最近的节点，同距按稳定编号。
- A/D、S总力预算不变。W新模式使用原拉伸预算上限、0.15秒进入／0.20秒释放，但改为向上净外力；S向下且立即撤掉W尾力。Space仍为原跳跃核心冲量，接受帧暂停W/S。红圈是最后小步实际施力节点，红箭头表示施力；新驱动可能改变速度与形变，不能等同于只显示平滑。

显示候选以0.060秒时间常数低通轮廓／核心相对真实世界脚底的Y；X、水平响应与物理帧不变，曲线最低点跟随当前原始曲线最低点。原始骨架与真实质心作为诊断保留；可叠加原始轮廓。Space请求后保持旁路，待冷却时长及实际接地／竖向稳定后再恢复；离地与拖动旁路，失焦／暂停／重建清历史。它会引入显示滞后，不能保证每个瞬时局部轮廓完全不变。

图表并列原始高度、显示高度与原始质心，导出另含显示记录和区域施力诊断，仍各最多1200帧。`--region-experiments`在默认材料上回放原核心／区域／单点三模式，并对同一物理轨迹分别计算原始与平滑显示指标。安全通过与显示改善、驱动速度／形态代价分开读取，退出0不等于产品或观感验收通过。

实际验证与已知差异见[显示与方向区域实验记录](../../../docs/verification/2026-10-15-display-region-lab.md)。
