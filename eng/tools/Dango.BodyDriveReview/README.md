# 身体驱动效果对照

真实产品门廊与原 Runtime，只使用本工作树 D0 冻结的两个 review 模块及新建虚构设置目录，不修改日常设置、正式DLL或原F5窗口。

向构建后的程序传入两个参数：C0或C1，以及当前仓库 artifacts/body-drive/ 下尚不存在的新会话目录。C0是核心单点驱动，C1是按质量分配的观察候选；程序核对D0模块哈希。每份程序独立运行，可左右摆放比较。

点击场景后A/D移动，Space跳跃，S下压。F2在同一驱动下切换原物理轮廓与主动步态叠加，标题标明当前状态；默认步态开启，关闭只用于定位。W/S新体态、F交互和焦点修复尚未接入，不能用这个入口验收它们。C1已有数值端点退化，用户也已否决两版观感，不作为已通过方案。

查看器保留项目现有窗口／托盘退出方式。started.json只证明宿主Ready、可见和模块身份，不代表人工验收通过。
