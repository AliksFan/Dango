# Phase 1 团子视觉基准候选

> 状态：Approved for AP-004 — A 方向极简版，不代表运行时或正式美术验收
>
> 日期：2026-09-02

## 1. 用途

本轮只选择一套用于 Phase 1 占位动画的视觉方向。它需要支持动作和桌面体验验证，但不冻结正式团子造型、最终画风或商品化美术标准。

选择结果将约束 AP-004 的 `Idle`、`Landing` 和 `ClimbUp` 三类动作样本；未经选择，不扩展完整动作包。

## 2. 共同硬约束

- 单只虚构团子，软萌、圆润、治愈，正面略带三分之四朝向。
- 主体没有脚、腿、爪、手臂或脚状凸起；底部是一条连续、平滑的圆弧。
- 透明背景，完整轮廓不裁切；禁止体积光、明暗面、高光、渐变和材质纹理。
- 身体底色、眼睛和帽子在视觉上完全可拆分，不能烘焙成一张固定角色；当前不制作嘴或腮红。
- 身体采用可替换纯色；本轮只验证换色友好性，不确定正式颜色数量和色板。
- 眼睛属于表情/动画层，不进入首版捏脸预设；需要与身体分层，但不展示可选眼型列表。
- 帽子作为头部配饰独立替换；本轮展示少量示例，不确定正式帽子数量。
- 完全不使用接触影或地面阴影；落地点由语义锚点、主体底部接触和动作形变表达。
- 缩小到 160 × 120 逻辑画布时，脸和轮廓仍可读。
- 不含文字、水印、背景、场景道具、复杂服装或高频细节。
- 不使用现有动漫、游戏、桌宠或商业角色的辨识性特征。
- 不使用拟真毛发、渐变、高光、投射光、复杂阴影或会妨碍透明边缘处理的纹理。
- 不用底部两个凸起暗示站立，不通过四肢表达移动、攀爬或落地。

## 3. 三个候选方向

### A：无描边柔圆

- 无外描边，以干净纯色轮廓表达轻微压扁的糯米团体积。
- 五官由最少几何形状组成，整体最安静、最柔和。
- 优先验证换色后的轮廓稳定性和极简陪伴感。

### B：统一细描边

- 使用等粗、圆角、深色细描边，内部全部为纯色。
- 五官和帽子沿用同一线条语言，小尺寸识别最稳定。
- 优先验证动作轮廓、帽子挂点和不同身体颜色的兼容性。

### C：粗描边贴纸

- 使用略粗的统一深色描边和更概括的圆角几何形。
- 纯色块、极少线条，缩小后最像清晰桌面贴纸。
- 优先验证强轮廓下的表情替换和挤压拉伸可读性。

## 4. 选择标准

按以下顺序评估：

1. 小尺寸轮廓和脸是否清楚；
2. 是否自然支持压缩、拉伸、爬边和落地形变；
3. 身体换色和帽子替换是否无需重画主体，表情眼睛是否能独立播放；
4. 长期驻留桌面时是否安静，不持续抢注意力；
5. AI 草稿中的不一致能否以合理成本人工修整；
6. 是否完全符合纯色、无光影、无渐变；
7. 是否没有明显现有 IP 联想。

## 5. 当前验收边界

用户选择的是占位视觉方向，不是正式美术验收。选择后仍需人工修整、透明导出检查、三类动作样本、WPF 播放和真实桌面验收。简单捏脸在本分支只形成资产兼容要求，不实现 UI、保存、授权或多人同步。

## 6. 用户选择

- 已选择 A“无描边柔圆”的主体轮廓与极简气质。
- 眼睛从捏脸预设中移除，归入表情/动画层。
- 首版预生产只保留身体纯色和帽子两个可配置类别。
- 当前 A 生成图仍含渐变、光晕和非透明背景，只作为方向参考；必须经定向修正后才能成为候选。
