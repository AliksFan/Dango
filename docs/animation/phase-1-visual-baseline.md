# Phase 1 团子视觉基准候选

> 状态：Draft — 等待 AP-003 用户选择
>
> 日期：2026-09-02

## 1. 用途

本轮只选择一套用于 Phase 1 占位动画的视觉方向。它需要支持动作和桌面体验验证，但不冻结正式团子造型、最终画风或商品化美术标准。

选择结果将约束 AP-004 的 `Idle`、`Landing` 和 `ClimbUp` 三类动作样本；未经选择，不扩展完整动作包。

## 2. 共同硬约束

- 单只虚构团子，软萌、圆润、治愈，正面略带三分之四朝向。
- 透明背景，完整轮廓不裁切，角色下方保留独立感明确的柔和椭圆阴影。
- 身体、脸、腮红、阴影和一个简单配饰在视觉上容易拆分。
- 缩小到 160 × 120 逻辑画布时，脸和轮廓仍可读。
- 不含文字、水印、背景、场景道具、复杂服装或高频细节。
- 不使用现有动漫、游戏、桌宠或商业角色的辨识性特征。
- 不使用拟真毛发、复杂渐变高光或会妨碍透明边缘处理的纹理。

## 3. 三个候选方向

### A：暖糯手绘

- 奶油米白主体，细而柔和的深棕轮廓。
- 轻微压扁的糯米团体积，克制的粉色腮红。
- 一个可移除的小叶片配饰。
- 优先表达温暖、陪伴和手绘柔软感。

### B：清爽图形

- 淡薄荷色主体，较清晰的圆角深色轮廓。
- 大块纯色、极少明暗层次，轮廓在小尺寸最清楚。
- 一个可移除的迷你圆帽配饰。
- 优先表达资产拆分、动画维护和桌面可读性。

### C：柔和水粉

- 淡薰衣草色主体，极轻的铅笔感边缘和克制水粉颗粒。
- 更明显的软垫体积，但不使用毛发或复杂纸张背景。
- 一个可移除的四瓣小花配饰。
- 优先表达治愈感、柔软体积和轻微手作气质。

## 4. 选择标准

按以下顺序评估：

1. 小尺寸轮廓和脸是否清楚；
2. 是否自然支持压缩、拉伸、爬边和落地形变；
3. 身体、脸、腮红、阴影和配饰是否容易分层；
4. 长期驻留桌面时是否安静，不持续抢注意力；
5. AI 草稿中的不一致能否以合理成本人工修整；
6. 是否没有明显现有 IP 联想。

## 5. 当前验收边界

用户选择的是占位视觉方向，不是正式美术验收。选择后仍需人工修整、透明导出检查、三类动作样本、WPF 播放和真实桌面验收。
