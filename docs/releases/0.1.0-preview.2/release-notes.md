# Dango v0.1.0-preview.2

Windows x64 本地单人预览版。本次递增预览编号，便于区分新旧安装包；本地打包不代表对外发布。

## 本次更新

- 首页提供三个固定团子栏位，分别保留名字、外观和穿戴配置。
- 配饰使用统一图像／图层与多组骨架编辑器，支持草稿、撤销、保存和真实团子模拟。
- 桌宠房间与显示设置采用当前 main 已整合的实现。
- 修复只有旧配饰库时首页初始化失败、栏位和编辑入口被禁用的问题。

## 使用与存档

完整解压 `Dango-v0.1.0-preview.2-win-x64.zip` 后运行 `Start-Dango.cmd`，或运行 `app/Dango.Desktop.exe`。程序自带 .NET 运行时，不需账号或服务器。详细使用方式见 `README.zh-CN.txt`。

数据默认位于 `%LOCALAPPDATA%\Dango`，独立于程序目录。旧配饰库原文件与图片保留，本版不载入旧柔性效果；可在换装中创建新配饰。已有 schema1 团子目录按已批准规则先备份再升级；任意旧版不保证能读取新版存档。

## 已知限制

- 仅提供本地单人功能；好友联机、账号云同步及跨设备同步未交付。
- 当前版本的全量长期运行、Windows 10、多屏／不同 DPI 与完整性能矩阵未全面验证；保留既有历史保存异常的未解决边界。
- 尚无代码签名、自动更新或正式安装向导。内部日常安装更新的一次授权覆盖必要且可恢复的管理工具升级。
