# Dango v0.1.0-preview.1

Windows x64 本地单人体验版。本文件是随本地候选包准备的发行说明，对外发布时间以正式下载页为准。

## 可以体验

- 团子连续身体控制及本地桌宠模式。
- 捏脸、内置配饰及自定义图片配饰，应用后本地保存。
- 最多3间本地普通房、每房家具及本机位置／镜头恢复。
- 首页、捏脸、配饰页共享布局与控制中心焦点规则。
- 设置页反馈QQ：2085475782。

## 下载和使用

计划分发文件为`Dango-v0.1.0-preview.1-win-x64.zip`。完整解压后双击`Start-Dango.cmd`，或运行`app/Dango.Desktop.exe`。程序自带.NET运行时，不需另外安装.NET；不需账号或服务器。

请同时阅读`README.zh-CN.txt`。本地数据默认位于`%LOCALAPPDATA%\Dango`，独立于解压目录。更新前先退出并备份完整数据目录，新旧程序使用不同解压目录；不承诺所有旧版都可读取新存档。

## 已知限制

- 本版仅提供本地单人功能；好友联机、账号云同步及跨设备同步未交付。
- 600秒连续观察尚未完成，桌宠真实鼠标与空白穿透等体验仍待补验；短时和后台验证不代表全天稳定性。
- Windows 10、多屏／不同DPI和完整性能组合尚未完整验收。
- 历史Schema1保存异常未定位到根因。遇到保存失败，请保留原文件并反馈，不把“未复现”理解为已修复。
- 本预览包尚未做代码签名；暂无自动更新和正式安装向导。
