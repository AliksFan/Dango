# 快速甩动冻结修复

> 阶段收尾：用户在本修复交付后明确要求结束单体阶段，另开任务开始碰撞测试。保留现有形状和输入机制作为基线；此确认不扩展为未执行场景的全覆盖验证，也不授权合并或推送。

用户已确认顶部内收力版本形状满意，随后反馈快速甩动后完全不动、WASD 无效，必须重新生成。用户批准正常超速时限速并继续模拟，仅保留异常冻结保护。

## 根因与复现

真实 native 单体连续变向拖动，在内收力 0.5、1 两档均于第 986 帧返回 -87 并锁存。只在诊断测试中把速度门槛从 12 改为 30，同一帧测得有限节点速度 12.212440，并正常推进，确认是超速而非非有限数值导致该次故障。正式参数未提高。

旧实现只在输出时检查速度，任何节点超过最大速度便释放 world 并冻结最后合法帧。此前固定目标拖动测试没有覆盖反复甩动积累速度；本次保留能失败的连续轨迹回归。

## 修复

- 每个原生小步完成约束求解后，检查核心及全部节点速度。存在非有限速度仍返回 -87。
- 仅当最大速度超过现有上限时，全部速度乘同一个正比例系数，使最大值回到上限以内；留 0.001% 数值安全余量。只耗散能量、不改位置，且保持相对速度约束方向，不逐节点截断。
- 未超速时不改速度；输出校验和角度、长度、面积、自交异常保护全部保留。没有自动重生或放宽几何门槛。
- 诊断增加锁存状态及最后原生错误码，重新生成时清零。渲染、当前形状、默认参数、抓取节点和输入语义不变，ABI 仍为 13。

## 验证

两档各 6,000 帧反复变向拖动，逐帧检查有限速度上限、90°～180°、无自交、无回退或锁存；随后松手运行 600 帧，再向右施力验证位移超过 3 像素，排除冻结取样。

原生直接检查超速缩放、方向比例、核心与节点统一缩放、位置不变和低于上限时不修改；另保留三档各 36,000 帧长度/地面/角度/漂移门禁。未将加速测试称为真实桌面连续观察。最终全量及替换结果另记。
