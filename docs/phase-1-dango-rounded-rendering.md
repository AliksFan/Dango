# 圆滑身体渲染试验

> 2026-09-17 整理说明：本文保留对应单体设计/渲染轮次的范围、参数与当时验收状态；后续单/双/三体模块及桌面接入已获各自人工认可，见[模块说明](phase-1-physics-module.md)。旧候选参数不自动恢复，未记录的逐项人工检查不补填。

用户提供顶部柔软度和顶部圆润度均为 1 的截图，认为渲染也可以优化；已确认允许身体曲线贴近骨架而不必穿过每个节点。物理机制、参数默认值及骨架拓扑不变。

## 已核实问题与实现

原身体使用穿过每个节点的 Catmull–Rom 转三次 Bézier，仍保留节点布局导致的局部尖顶。身体坐标映射为 `(width/2 + x*width*0.45, height*0.55 - y*height*0.483333…)`，骨架却使用 `(width/2 + x*width/2, height/2 - y*height/2)`，所以骨架与身体错位。

本次保留身体原尺寸、偏移及附件布局，骨架调用身体相同的映射函数（核心点也统一映射）。骨架仍绘制真实 16 节点、16 径向直线和 16 外围直线，不对骨架平滑，不修改表现帧或物理世界。

身体改用闭合二次 B 样条：从相邻节点中点出发，以当前节点为控制点，连到下一相邻边中点。每段曲线在其控制三角形内，相邻段的一阶切线连续；对当前凸轮廓不会向骨架外鼓出，因此不会因插值过冲产生新增穿地。视觉皮肤会略微向内收，不声称改变了物理接触位置。整体下宽上窄的节点结构保留，不冒充已经把团子改成椭圆。

## 验证

新渲染结构测试在修改前失败，修改后验证二次曲线类型、顶部不再穿过尖节点，以及 16 节点参考椭圆的面积保持至少 95%、顶部收缩小于 2 像素。逐段采样检查曲线在凸骨架内，闭合接缝和各段切线连续；向量比较允许 1e-10 浮点容差，最初的精确比较因约 1e-14 的舍入误差失败。

STA 测试运行真实原生单体 600 帧（两项顶部参数为 1），使用真实 `DeformableDangoVisual` 和 WPF 离屏渲染生成 `artifacts/render-rounding/comparison.png`：上排是旧/新身体，下排是旧/新骨架叠加。已人工查看该输出，身体拐点更柔和、骨架位置对齐，眼睛和帽子未见新增明显错位。该图是测试绘制，不是用户桌面验收，也未启动独立预览窗口。

运行时代码只改 `DangoStreamGeometryFactory` 和 `DeformableDangoVisual`，另增加渲染测试及本文档。native DLL、ABI、参数、输入、宿主和附件跟随机制没有修改。

更新重启会按既有规则恢复参数默认值；用户复验需将顶部柔软度、顶部圆润度重新设为截图中的 1。默认值本身不为此次渲染试验更改。
