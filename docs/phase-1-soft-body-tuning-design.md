# Dango Phase 1 落地果冻感调参台设计

> 状态：Approved
>
> 批准日期：2026-09-03
>
> 所属任务：P2D-005 — WPF 动态轮廓与分层挂点

## 1. 目标

先在普通 WPF 窗口中把单团子的落地轮廓调准，再接入 WorkerW。预览动作固定为“空中圆形 → 正常落地 → 极小回弹且几乎不离地 → 底部压平、下半部外鼓的扁圆常态”。用户提供的图片只作为轮廓参考；团子继续使用 A 方向的极简纯色视觉，不加入脚、嘴、腮红、描边、阴影、渐变或光照。

## 2. 真实物理边界

- 轮廓由 Box2D 动态节点、径向弹簧、轮廓弹簧和地面接触产生，不能在渲染后伪造压扁。
- 调参台可以安全重建预览世界；节点数、子步、节点半径等拓扑参数变更必须重建。
- 调参状态机只服务于预览，不进入 Core 正式动作状态机；P2D-006 才接正式动作语义。
- WPF 视觉只消费表现帧，不直接持有或步进物理世界。

## 3. 参数面板

| 分组 | 参数 |
|---|---|
| 常态轮廓 | 宽度、高度、顶部圆度、下半部鼓度、底部平坦度、接地压缩量 |
| 落地动作 | 下落高度、撞击速度、最大压缩、横向扩张、回弹强度、离地上限、稳定时间 |
| 果冻材质 | 径向弹性、轮廓弹性、径向阻尼、轮廓阻尼、整体阻尼、节点质量 |
| 地面接触 | 地面高度、节点半径、摩擦力、弹性系数、接触柔软度 |
| 模拟质量 | 12/16 节点、2/4 子步、固定步长、核心跟随速度 |
| 眼睛与帽子 | 跟随比例、位置偏移、帽子旋转幅度、帽子阻尼 |
| 安全限制 | 最大形变、最大质心偏移、最大速度、最小轮廓面积 |

连续参数提供滑块和数字输入，并以短防抖更新。窗口同时提供重新下落、暂停、慢动作、空中/落地常态对比、节点与弹簧辅助线、恢复默认值、JSON 保存/加载、实时指标和临时隐藏眼睛/帽子的轮廓模式。JSON 必须拒绝未知字段和越界值。

## 4. 预览状态与验收

```text
Reset / AirCircle
  -> Falling
  -> ContactCompression
  -> TinyRebound
  -> GroundedRest
```

自动验收覆盖参数范围、JSON 往返与严格解析、UI 控件完整性、物理世界重建边界和原有轮廓安全约束。实时预审必须确认空中近圆、落地后宽大于高、底部接近水平、常态不恢复成圆、回弹不明显离地。用户人工确认轮廓之前，P2D-005 保持未完成且不提交。

## 5. 明确排除

- WorkerW、正式动作状态机、双团子接触、网络同步与 P2D-006。
- 嘴、腮红、脚、四肢、描边、阴影、渐变、纹理和光照。
- 推送、合并、部署和 P2D-005 完成声明。

## 6. 调参台可用性修订

用户预审后确认首屏参数过多、含义不清，且低影响参数干扰轮廓判断。首屏因此只保留常态轮廓、落地动作、三项主要材质、接触软硬以及 12/16 节点和 2/4 子步选择；每项显示“增大后的效果”。眼睛/帽子细节、底层接触材料、固定步长和安全阈值继续由预设保存并受校验，但不作为首轮视觉调参项。节点数与子步改为离散选择，不允许滑块产生非法中间值。

## 7. 后续移交：团子 DIY

用户确认身体数值调节本身具有趣味性，批准将其登记为正式团子 DIY 的后续工作。本调参台仍是 P2D-005 诊断工具，不直接成为产品界面；Phase 4 需要另行完成面向普通用户的命名、预设、组合约束、持久化、同步、降级和验收设计。

移交范围以团子自身为主：宽高、顶部圆度、下半部鼓度、底部平坦度、常态压缩、恢复弹性、轮廓弹性和整体阻尼。地面、碰撞半径、节点/子步、固定步长和熔断阈值不开放。动作高度与撞击速度是否作为“动作性格”是待设计问题，不在本次决定中预先承诺。
