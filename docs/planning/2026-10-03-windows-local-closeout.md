# Windows 本地体验收口设计与实施计划

> 2026-10-03 用户确认本对话设计与实施顺序；实施基线 `codex/team-integration@0bdf5c1`。
> 状态：实施与隔离包检查已完成，用户确认首轮 150% 屏幕条件下的单机候选人工验收通过；同屏第二缩放 100% 的实包自动检查已通过，人工观感及恢复 150% 待确认。自动差异等未验证项见[本轮验证记录](../verification/2026-10-03-windows-local-closeout.md)，不标记完整收口门禁完成。日常安装更新、合并 main 和推送分别另行确认。

## 目标和边界

交付可从本地快捷方式启动、可安全更新与回退的单机首页候选。首页真实团子、编辑面板、S/空格动作、W 门廊、设置、托盘和三档物理像素目标沿用已确认行为。未进入正式房间时桌面宿主保持隐藏。门廊没有正式房门；外观未实现的应用/创作仅明确标示预览或未开发。

本批无需服务器、数据库或外部服务，不接 Phase 2A 样本。登录、正式房间、联网、跨屏 DPI、热插拔及既有延期专项不纳入本批完成结论。

## 已核实问题与决策

旧 Schema 4 读取器使用严格未知字段拒绝，旧控制中心尺寸下限为 820×560。整合候选写 Schema 5、selectedPreset 及 960×540/480×800 几何；仅改 schema 数字或增加可选字段都不能使旧版本正常回退。

主 `settings.json` 写严格 Schema 4 的既有字段和旧安全几何。产品窗口尺寸由独立 `settings.window-preset.json` 的 Schema 1/selectedPreset 决定；每个隔离 settings 路径使用同目录同文件名前缀的 sidecar。旧版忽略该文件，旧版保存主设置后新版仍恢复独立预设。Schema 1–3 和本地实验 Schema 5 可读取；转换原主文件之前先保留其原始字节备份。主文件的未来格式/损坏保护沿用；sidecar 损坏只降级预设并保护原 sidecar，其余有效偏好可保存，恢复时先备份。

两文件分别原子写入，先预设、后主设置；主设置失败时可以已保存预设，但界面不得声称全部保存成功。重试不重复宿主动作。产品切换预设不再把临时 DPI 适配几何写进旧字段。

发布/安装采用版本化兼容表：旧五源哈希不变，新受控源哈希经本批验证后固定。两 DLL、许可、包完整清单及源哈希仍 fail-closed。已装管理工具差异仍阻断普通应用更新；一次性显式迁移核验旧工具、owner/state、已装包、停止状态与锁，staging 新工具并记录恢复 journal。应用回退保留兼容管理器。所有迁移/恢复先在隔离根验证；不读写真实用户设置。

原生预检要求显式模块路径、已批准 SHA、必需导出/ABI、旧 DLL 指纹与许可。缺失或不符在创建发布输出前失败；不自动下载、重编译或替换受保护 DLL。原生二进制不进入 Git。

## 批次与文件所有权

1. L0：冻结候选、旧安装与模块指纹；写失败型设置/契约测试。主代理负责本文件、设置源码和 .NET 测试。
2. L1：设置主文件/sidecar、迁移、失败和重试；目标为 ControlCenterWindowSettingsStore、ApplicationSettingsSession、ControlCenterWindow、DangoApplicationHost 及对应测试。
3. L2：契约兼容表、显式工具迁移及发布预检；独立安装代理负责 local-install 模块、Manage/install/test/迁移脚本。主代理接发布和预检，待 L1 后固化新源哈希。
4. L3：Release/self-contained 构建；在独立输出及隔离安装根验证真实 A→B→A、StageOnly、快捷方式/单实例与失败保护。
5. L4：真实 Windows 检查当前屏幕三档、A/D/S/空格/W、设置失败提示、托盘恢复、退出；按工作流补同一屏幕两种缩放或分辨率。用户人工验收后另行决定日常安装更新。

各批通过受影响验证后才继续。无模块来源、回退读取失败、安装保护失败或新实时故障时停止相关交付。

## 可失败验收

- B 保存各预设后，主文件字段集、Schema、几何仍能被旧 A 读取；A 改旧偏好后回 B，旧偏好和新预设均保留。
- 损坏/未来 sidecar 保持原字节，主偏好仍有效；恢复前备份，失败不伪报成功。Schema 5 转换保留原主文件。
- 缺模块、错 SHA/导出/ABI、受控源改动、篡改包、许可缺失均拒绝。预检失败不创建 package；安装失败不切换状态或覆盖用户快捷方式。
- 隔离 A/B/A 的 StageOnly/激活/回退不写用户设置，运行中拒绝切换；迁移失败或中断可恢复原管理工具，旧包仍可校验和回退。PS5.1/pwsh 都执行。
- 真实冷启动显示首页与成功物理帧；原生不可用时明确错误。重复启动一个实例，未入房间桌面不显示，关闭到托盘可恢复，正常退出无本次进程残留。
- 受影响自动门禁不得有失败或意外跳过。完整 Desktop/Physics 与旧 DLL 缺导出历史失败分别记录，不以局部通过或中止代替全量通过。

证据按静态、集成、实时、人工和 Git 交付记录。隔离测试使用虚构设置；日志只保存版本、文件指纹、技术状态和本次 PID，不记录真实设置内容、窗口内容或凭据。

真实新包启动通过显式 `--local-install-acceptance-settings` 参数使用带 `.dango-local-install-acceptance.json` 所有权标记的虚构设置目录，保持普通 Product 模式和单实例。参数不得指向日常设置根、包目录或其祖先，不使用重解析点；安装管理器仅允许新契约包透传该参数，普通/验收/不同验收目录的实例不能互相冒充。旧 A 不支持此参数，由独立 probe 加载真实旧程序集的设置读取/写入代码验证回退语义；旧 A 的普通冷启动留待日常更新授权后人工检查。
