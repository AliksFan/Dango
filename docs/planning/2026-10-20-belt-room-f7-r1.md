# F7-1R1：接触修复与要求取舍

日期：2026-10-20。用户明确要求“按照计划修复”，并重点评估不必要要求；本轮据此修订工程合同并实施、后台验证和本地提交。原 F7-1 的提交 `c24fe1f`、FAIL 结论及 `artifacts/belt-room-f7/` 原证据保留。R1 新证据只写 `artifacts/belt-room-f7-r1/`，不把新标准回写为旧标准通过。

本合同在新候选运行前写定。用户随后进一步明确：即使必要门槛，也不一定在本阶段修。范围据此收敛为连续身体与单个平台、地面的基础接触修复；横墙安排到产品房间接入前，不作为本轮交付门。不接产品房间，不包含球、多体、家具保存、休眠或 UI。主入口为[原实施记录](../verification/2026-10-20-belt-room-f7.md)。

## 1. 有证据的根因

- 原程序在位置求解前要求 free prediction 获得完整证书，阈值附近的未决区间直接锁故障，接触尚未处理就退出。
- 两处静置失败的独立 Decimal 60 位导数区间分析得到真实最小 gap：配置1为 `-1.06239123439e-7m`，配置3为 `-9.99948249598e-8m`；旧门是 `-1e-7m`。后者未越门，仍被 Taylor 包围余量与深度限制误拒绝。两处均为静态证书，不是角点根隔离问题。
- 原 `-705` 分别涉及扫掠角切入但末端已安全、32轮未收敛，以及默认体型的速度迭代残差；不能靠只调静态容差宣布全部修复。

诊断脚本和50／60位交叉结果保存在新证据 `reference/`；它们只证明上述两个保存状态，不代替新候选验证。

| `1e-7m` 穿透门、`2e-9m` 投影余量 | 调整为下节有尺度依据的几何预算。旧门仅为工程选择，远小于显示分辨率；贴着门槛求解放大数值拒绝。 |

| 几何未决必须永久锁死 | 候选阶段取消；最终状态仍不确定或真实物理门失败时完整回滚并锁存，保留安全帧。当前没有经过验证的恢复操作，不额外引入自动重试／恢复系统。 |
| 全状态原子提交、错误输入不损坏状态、保存／回滚真实性 | 保留。它们是结果正确性要求；本轮不扩大到存档实现。 |

## 3. 冻结的 R1 合同

- ABI 1、能力15和frame布局不变；接触模型更新为 `belt-solid-aabb-r1-v1`，托管绑定同时校验。原身体仍为 `continuous-belt-v1`／`C455-F-v1`。
- 几何允许穿透 `5e-4m`，位置校正目标正 clearance `1e-4m`，接触激活距离 `1e-3m`。按1m＝72 Room逻辑单位，分别为 **0.036、0.0072、0.072** 逻辑单位；这是几何数值预算，不是身体缩放。未来实际最大镜头仍须人工观感验证。
- 位置每子步最多32轮，每轮任一广义坐标改动最多`.01m`；速度最多300轮，target `2e-8m/s`、最终残差 `2e-6m/s`，接触动能不增容差 `1e-9*(1+before)`。当前证据尚不足以更改速度／能量门，先修流形与收敛。
- 外物证书262144 cells/frame、theta深度20／time16；原身体shape guard预算131072不变。保留原材料、受力、4子步及`0.0166666f`；候选定位与最终证明分开，所有位置调整通过原形状／材料保护。
- 无平台时仍精确调用原单体路径；无接触基线须与旧模块一致。横向bounds当前仅保留guard拒绝，不宣称实体墙；实际房间开放前再实现墙接触。平台侧面／底面不能取得顶面支撑资格。
- 接触求解可改变候选定位、流形去冗余和投影顺序，不改变最终防穿、形状、能量及完整回滚结果；最终不确定仍明确失败。平台撤除同帧失去支撑。

1. native先修候选／证明排序、几何余量及已定位的扫掠witness错误；绑定同步模型。保留旧失败重放入口，新增R1实际DLL重放入口。不为本轮同时扩展横墙或改写速度求解架构。
2. **本轮交付门**：安全合同、默认体型基本落台／站稳／撤支撑与侧面／底面接触，以及两处原静置误拒的回归。默认离边／跳台／拖压优先修明确bug；复杂未过项列入静态接触产品准入前补齐，不阻止本轮独立修复交付。
3. 九配置站台／撤支撑与六动作矩阵作诊断；按实际接触、位置和支撑变化确认动作，未发生不算通过。九配置全动作不作本轮强制全绿门；已能定位下一阶段问题时可结束扩展扫描，不反复调门刷矩阵。若有必要局部修正，只重验受影响项。
4. 验证完整回滚、禁接触／坏回滚负控、托管真实DLL边界；独立几何参考审查新候选关键状态。只重复受影响的原身体无接触对照。未过能力仍禁止进入产品，但不阻止与其无关的room owner、球／多体独立研究。
5. 保留每项通过、失败、未触发和未验证；记录运行成本。更新当前入口，创建本地提交。未获授权不合main、推送、替换生产DLL或操作真实日常数据。

R1自动门通过也不等于产品房间、前台输入、人工观感、整个F7或Windows／多人验收通过。无UI改动，桌面规范v0.1第2～6节没有新增页面差异或例外。
