# 配饰统一编辑器与骨架柔性实施计划

日期：2026-10-23。状态：设计方向已获用户确认；用户在后续实施对话授权执行，E0 已实施工程候选，性能预算尚待冻结，E1–E5 尚未开始。本轮 60Hz 对照目标不是已批准的硬验收线；实际证据与澄清见 [E0 记录](../verification/2026-10-23-accessory-editor-rig-e0.md)。

依据：[本轮设计](2026-10-23-accessory-editor-and-rig-design.md)、[桌面界面规范 v0.1](../desktop-ui-design-v0.1.md)第 2–6 节、[开发流程](../development-workflow-v0.1.md)第 13 节。
实施须在后续明确授权的阶段内开展。本计划不把依赖可用性、性能预算、数值稳定性或人工效果写成已验证。

## 1. 目标、边界与完成标准

目标是将正式产品的简单图片编辑窗口替换为本地 miniPaint＋WPF WebView2 统一编辑器，并接入刚性与骨架柔性两种配饰。
统一编辑图片、连接点、单条无分叉链中心线及全部配饰参数；包括重力的参数随配饰保存。
同一张整图自动生成骨节和蒙皮，无需用户拆分图片。首期支持自然跟随与静止曲线。
AI 自动抠图、主动摇尾、分叉骨架、布料和 3D 后置；不实现旧柔性效果兼容或转换。

完成标准同时包括：

- 普通启动可进入编辑器，正式 build／publish 包包含所需本地资源和许可材料。
- PNG／JPG 不透明源可进入编辑；成品规范化为静态透明 PNG，工程仍可重新编辑。
- 手动抠图／魔棒／橡皮／恢复、简单绘图／填充／文字／基础图层、裁剪／旋转／翻转／撤销重做可用。
- 编辑结果以工程＋成品 PNG＋骨架／参数作为一份草稿返回；外层应用才持久化，取消恢复保存值。
- 两条正式运行链遵守各自推进 owner；刚性和骨架柔性都可佩戴、重开并自然跟随。
- 旧简单窗口和旧应变场柔性生产消费者退出，旧格式保护与失败恢复有真实结果；Windows 实测和人工验收完成。

上述完成标准尚未达成。文档完成、构建通过或独立实验通过均不构成整个阶段验收。
现有用户持久库不得删除、清空或静默覆盖；不支持的旧格式保留原文件并明确提示。
本轮无数据库、云服务、付费资源、远端推送、安装或部署操作。

## 2. 模块与文件所有权

以下路径以仓库根目录为起点，是已核对的当前接线位置；新增类型和目录在实施中按职责命名，不视为已有实现。

| 所有权单元 | 当前目标文件／目录 | 职责与边界 |
|---|---|---|

| 统一编辑器 | `Accessories/AccessoryEditorPanel.cs`、`AccessoryImageEditorWindow.cs`、新增 WebView2 宿主／本地资源／桥接合同 | 图片与 rig 编辑、会话生命周期、宿主输入隔离；旧窗口由此替换 |
| 共享配饰计算 | `Accessories/AccessoryMotionSolver.cs`、`AccessoryMeshVisual.cs`、`AccessoryBodyMapper.cs` | rig／蒙皮／求解与只读显示结果；不得成为身体物理 owner |

若以后分工，先确定文件所有权与集成顺序：数据合同先行，编辑器与求解可在合同稳定后分开，正式接线最后集成。
两条 runtime owner 不合并；共享的是数据、求解和输出合同，不能抽成一个新总 owner。

## 3. 增量与门禁

### E0 — 依赖、许可与工程预算（工程候选已实施，性能预算待冻结）

目标模块：桌面项目依赖、本地 miniPaint 资源、WebView2 宿主初始化、构建／发布输入，以及候选链式求解／蒙皮的无窗口机制验证。

预期行为：

- 核对 miniPaint 上游版本／提交、许可证、所含字体／图标／第三方包及再分发要求；记录实际需要的能力与裁剪内容。
- 核对 WebView2 SDK／Runtime 支持、目标架构、运行时分发方式与缺失时恢复路径；不能假定用户机器已安装。
- 确定本地资源来源、版本锁定、资源校验、许可证随包位置及离线运行方式；编辑器不得依赖 CDN 或线上脚本。
- 列明桥接消息大小、工程／PNG 大小、像素／图层上限、骨节／网格规模、加载时间／内存及求解耗时预算。
- 数值预算涵盖时间步、暂停恢复、长帧、迭代／约束、阻尼／重力范围与稳定性；给出测量设备和样本。
- 用最小无窗口机制验证固定骨长、初始曲线恢复、权重和静止图重建，冻结可执行算法与预算；它只支撑后续合同，不是另做展示窗口，也不代替 E3／E5 正式实现与验收。
- 初始化或资源损坏时显示真实原因，可重试或取消并保留草稿；旧编辑器不得作为隐形 fallback。

关键失败反例：开发机可用而离线发布包缺资源；缺 Runtime 时空白且丢稿；大图／消息阻塞 UI；许可清单漏传递依赖。
退出条件：版本、许可证、分发方案和预算有证据记录，初始化失败可恢复；会改变获批方向的发现先更新设计再实施。冻结设计 C3／C6 后续验证所需的算法与资源边界。
依赖／风险：无前置增量；官方资料和开源资源需核对，具体版本、预算及下载尚未确认或执行。
外部资源：仅后续授权内所需公开文档和依赖获取；不引入数据库、云端或收费服务。

### E1 — 可编辑工程与一次草稿结果（未开始）

目标模块：`AccessoryConfiguration`、`AccessoryImageAsset`、`AccessorySettingsSession`、`AccessorySettingsStore`。

预期行为：

- 以版本化合同保存编辑工程、规范化 PNG、连接点、rig、蒙皮生成输入及全部配饰参数；工程与成品需可追溯对应。
- 新 Schema2 使用独立版本化清单，具体命名以本轮设计为准；Schema1 原文件留原位且明确未载入，新库仅经用户显式应用建立。
- 明确图片像素／工程画布／归一化坐标与身体根部坐标转换；裁剪、旋转、翻转后连接点和中心线仍指向正确内容。
- 子编辑确认时，工程／PNG／rig 整体校验后返回外层草稿，不写正式库；任一失败不得留下半份可应用结果，未完成新建草稿按下述规则保留。
- 保留新建合同：选图成功即建立未应用创作草稿；不透明源可作为未完成草稿进入编辑器。模态取消保留进入前的新草稿项，外层取消才撤销。
- 未完成草稿可重开编辑；透明度、尺寸和导出校验未满足时禁止整套应用，不能因允许编辑不透明源而放宽成品合同。
- 为 source／project 单独设预算；不能绕过现有成品合计 128,000,000 像素／256 MiB 预算，候选图层／节点等上限在 E0 测量后冻结。
- 外层应用用现有集中存储边界扩展提交；先准备完整资产再原子提交引用，失败保留原保存值与可重试草稿。
- 重开恢复图层及可编辑内容；复制的后续编辑互不污染。取消子编辑、取消外层、关闭和保存失败分别定义状态。
- 删除独立双重确认，仅删除目标，不提交其它输入；取消删除不提交输入缓冲。
- 识别并保护不支持的旧柔性／未知版本；未来版本或损坏的新清单同样保护。不加载为空库后覆盖，不提供旧柔性兼容、转换、自动骨架或搬迁阶段。

关键失败反例：PNG 已换但工程仍旧；子编辑确认直接落盘；模态取消误删新建草稿；不完整成品可整套应用；删一件带入另一件未应用参数；未知版本被重写。
退出条件：针对提交各失败位置、取消、重开、复制、独立删除和旧格式保护的反例测试通过，支持格式与保护边界有记录，对应设计 C2／C5。
依赖／风险：依赖 E0 的数据和消息预算；多资产提交及并发外部改动须保留已有保护，不以删除持久文件补救。
外部资源：本地隔离虚构素材与临时目录，无数据库／云端。

### E2 — 正式统一编辑器、手动图片编辑与连接点（未开始）

目标模块：新 WebView2 宿主／本地 miniPaint 适配、`AccessoryEditorPanel`、旧 `AccessoryImageEditorWindow` 入口、主题资源。

预期行为：

- 正式入口初始化本地编辑器并恢复工程；导入 PNG／JPG，包括未抠图源；解码、方向与透明度规范化须可验证。
- 接入第 1 节所列手动工具；恢复与撤销重做恢复实际像素／图层，不能只重置界面选中态。
- 在同一工程坐标内编辑连接点，图片变换同步更新坐标；保留全部配饰参数编辑入口，重力不留在外层独立保存。
- 桥接只接受当前会话的受支持消息，校验版本、来源、长度和数值；拒绝过期回调、外部导航与任意本地文件访问。
- 关闭／重开／渲染进程退出／加载失败可取消或重试；宿主销毁释放事件、资源和未完成请求，不污染下一会话。
- 按界面规范第 2–6 节统一暖白、细棕强调、图标短文字、常驻细条与固定操作区；Web 内容也遵循同一规则。
- 画布滚轮缩放、文本／图层／参数输入各自消费事件；编辑期间不误触团子动作，模态／菜单和外层焦点规则不冲突。

关键失败反例：画布缩放同时滚动外层；文字输入触发团子；重开后旧消息提交新草稿；初始化失败自动落回旧窗口。
退出条件：手动编辑→确认子编辑→外层取消／应用→重开完整验证；图片／点变换和桥接负例通过，真实输入及视觉项另记结果，对应设计 C1／C2／C5／C6。
依赖／风险：依赖 E0、E1；miniPaint 原有功能需按产品合同适配，不能仅以工具栏存在宣称可用。
外部资源：随包本地依赖；不上传源图片，不调用 AI／云端抠图。

### E3 — 中心线、骨节、蒙皮与跟随参数（未开始）

目标模块：统一编辑器 rig 工具、新骨架／蒙皮合同、`AccessoryMotionSolver` 与 `AccessoryMeshVisual` 的受影响实现。

预期行为：

- 单个身体根部连接、单条无分叉中心线可编辑；校验有限数、重复／退化点、零长度、合法顺序和预算上限。
- 根据同一整图和中心线生成骨节及蒙皮；用户无须分图，权重归一化且静止状态能重建原图形状。
- 刚性与骨架柔性明确选择；柔性参数包括重力、阻尼、回正与弯曲控制，范围和单位按 E0 记录执行。
- 自然跟随身体根部变换并保持静止曲线；暂停／恢复、重置、跳变和无有效帧采用明确策略。
- 无碰撞、无对身体反作用；不把配饰边界加入身体命中／拖动范围，不在浏览器新增物理 timer。
- 求解接受 owner 的单次推进与只读刷新；相同帧重复刷新不能增加时间、速度或步数。

关键失败反例：零长骨节生成 NaN；蒙皮接缝／静止图扭曲；重力不同步保存；长暂停恢复爆炸；刷 UI 导致额外摆动。
退出条件：静止重建、连接不漂移、权重／有限值、长帧／暂停和重复刷新反例通过，对应设计 C2／C3；自然效果与可编辑性仍需 E5 人工验收。
依赖／风险：依赖 E0–E2；算法和预算未验证，若需改变单链范围或添加回作用，必须先回到设计审批。
外部资源：本地虚构静态 PNG 样本；无训练、云端或第三方实时服务。

### E4 — 双运行链正式接线与旧路退役（未开始）

目标模块：`BeltBodyAppearancePresenter`、`AccessorySceneController`、`StackedDangoSceneRuntime.Accessories`、`AccessoryHostBinding`、`ProductHomeView.Accessories`。

预期行为：

- 首页／编辑链和房间／桌面宠物链分别消费同一配饰合同；共享求解与帧输出，各自由既有 owner 推进。
- 外层草稿预览、应用、取消、失败、切页和桌面宠物交接均消费真实会话状态；不能只更新某一宿主。
- 遵守线程、FIFO、暂停屏障及销毁合同；`Refresh` 和重复绘制只投影，不推进。
- 同步完成下表旧路退役，正式消费者无隐藏旧编辑器或旧应变场分支；不支持数据保留保护提示。

| 退役对象 | 处理与证据 |
|---|---|
| `AccessoryImageEditorWindow` 简单窗口及 `OpenImageEditor` 旧入口 | 正式调用替换后删除生产旧路；失败恢复转入新宿主，不切回旧窗口 |
| 旧整图弯曲／应变场求解及旧柔性分支 | 核对 `AccessoryMotionSolver` 和两条运行链全部消费者；保留所需刚性公共行为，移除被替代路径 |
| 旧外层独立参数写入路径 | 将统一编辑器拥有的全量参数收口至同一结果；避免两处参数源互相覆盖 |
| 专属旧路测试／资源／实验入口 | 明确归属并移除失效生产依赖；历史证据保留，不为旧效果继续增加兼容测试 |
| 旧格式持久文件 | 保留原文件并明确不支持／保护状态；不执行自动转换、清空或批量删除 |

关键失败反例：编辑链正常而桌宠仍跑旧柔性；同一帧两个 owner 推进；截图刷新改变姿态；新编辑器失败回到旧窗口。
退出条件：普通产品入口和两条运行链均有接线证据；旧路检索无生产消费者，刷新／交接／暂停生命周期反例通过，对应设计 C4／C5。
依赖／风险：依赖 E1–E3；退役不等于删除用户数据，历史测试证据也不得改写为新实现已通过。
外部资源：隔离本地配置和虚构配饰；无数据库／云端／付费资源。

### E5 — 发布包、Windows 实测与人工验收（未开始）

目标模块：正式桌面项目、受影响发布脚本、配饰／渲染／宿主测试与用户验收记录。

预期行为与验证：

- 按改动选择现有 `AccessoryStorageTests`、`AccessoryDeletionTests`、`AccessoryImageTests`、`AccessoryEditorTests` 等业务门禁，新增能检出新失败反例的测试。
- 依据实际接线选择 `AccessoryRuntimeOutputEquivalenceTests`、`AccessoryDesktopHandoffTests`、`BeltBodyAppearancePresenterTests`、`DesktopPetAccessoryIntegrationTests`；旧求解测试不机械全跑或照抄。
- 执行正式 build 和 publish，检查本地资源、WebView2 分发输入、版本及许可证；用普通启动走真实入口，独立实验窗口不代替产品交付。
- 验证离线编辑、缺 Runtime／初始化失败、进程退出、取消与保存失败；使用隔离配置重启产品核对工程、PNG、rig、参数对应。
- Windows 实测最小正式窗口／横向／纵向、受支持 DPI／高对比／减少动画、真实画布缩放／拖动／文本／焦点及失败恢复。
- 人工核对手动抠图和恢复、图层重开、点／中心线操作、刚性与自然柔性观感；构建和数值测试不代替人工效果结论。

关键失败反例：源码启动成功但 publish 缺脚本；后台被暂停却计入稳定运行；只测实验预览；静态截图掩盖真实输入错误。
退出条件：设计 C1–C6 的自动门禁、包验证、真实运行和人工验收分别有记录；未执行项明确列为未验证，不提前标记阶段已验收。
依赖／风险：依赖 E0–E4；需要屏幕的测试先说明目的、占用方式与预计时长并获准，等待期间继续无屏幕工作。
外部资源：仅本地隔离测试；不授权替换日常安装、保护 DLL、删除持久库、推送、部署或启动付费资源。

## 4. 交付记录与停止条件
