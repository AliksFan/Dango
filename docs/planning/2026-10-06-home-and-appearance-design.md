# 首页与自身外观编辑：当前已确认设计

> 交付状态补充：以下 Git 和 104 项测试描述保留原候选设计归档时的快照。用户随后授权只合捏脸；普通房依赖剥离后的实际 main 状态及新验证见[独立整合记录](../verification/2026-10-06-face-only-local-main-integration.md)，不由原设计人工确认推定普通房验收。

日期：2026-10-06。状态：**已实现的本地 Windows 候选已获用户人工观感确认**。用户在三侧入口、镜像展开和纵向保存区修订后回复“通过，记录各种没有在文档中提到的设计”。本页汇总此前在对话中逐次确认的最终设计，实施基线为 `codex/appearance-face-design@da6b8b2`。

本页是当前首页／捏脸／换装入口与布局的设计依据；[10 月 1 日首页方案](2026-10-01-home-ui-fidelity.md)及早期布局验证保留历史含义。自身参数、保存合同分别见[捏脸设计](2026-10-05-dango-face-design.md)和[实施计划](2026-10-05-dango-face-implementation-plan.md)。实际结果与未验证项见[最新验收记录](../verification/2026-10-05-home-icons-and-ground-shadow.md)。本次通过不代表整个 Windows 产品、完整 F5 专项或多人阶段已验收，也不授权合并、推送或日常安装。

## 1. 自身捏脸与换装的边界

- 捏脸只编辑团子自身：身体 RGB、眼睛 RGB，以及双眼统一的大小、椭圆度、高度、眼距。左右眼不分别编辑；嘴巴、真实身体大小／形状／柔软度、绘制和上传留在后续范围。
- 帽子、服装和配饰属于独立换装部分。捏脸默认／取消不改变帽子。帽子[选择设计](2026-10-05-hat-selection-design.md)仍为单独候选；本次只确认换装入口、预览位置和面板动效，不等于换装内容已经开发或帽子候选已批准。
- 预览使用同一活动团子、同一 Runtime 和唯一帧驱动。调参数只更新请求，不额外推进物理、不重建实体；基础长相与注视、眨眼、困倦、睡眠等逐帧动态表现分开。

## 2. 首页入口与品牌

首页保持近白暖灰、棕色细强调和少字留白，入口围绕团子排列：

| 位置 | 按键与图标 | 行为 |
|---|---|---|
| 团子上方 | W＋门 | 复用现有门廊入口；进入房间的导航意图由门图标表达，当前动作先进入门廊 |
| 团子左侧 | A＋T 恤 | 展开左侧换装面板 |
| 团子右侧 | D＋团子 | 展开右侧捏脸面板 |

用户明确选择入口放在团子左右两侧，替代原先下方两个按钮的排列。W 位于完整跳跃弧线之上；A／D 与实际身体和帽子轮廓保持净空。点击图标与对应游戏快捷键进入同一操作路径，不能借 W 入口添加新的房间准入或多人能力。

三个字母使用一致的 **22×22 DIP 键帽**，圆角 4 DIP、边框 1 DIP，字母居中，与图标相隔 8 DIP。字母和边框继承按钮前景色，覆盖选中及高对比状态。键帽明确表示键盘操作，省去原先占空间的底部快捷说明和重复首页文字。

捏脸展开时，顶部 Dango 品牌文字替换为团子图标；首页及换装保持文字品牌。两种品牌使用相同高度，避免切换或窄窗口导航换行改变内容原点。导航、真实通知和收起入口保留。

## 3. 镜像展开与输入

| 状态 | 横向参数区 | 团子及固定预览工具 | 参数面板动画 |
|---|---|---|---|
| 首页 | 隐藏 | 居中 | 无 |
| 捏脸 | 右侧 | 左侧 | 从右向左进入，`+X → 0`；向右退出 |
| 换装 | 左侧 | 右侧 | 从左向右进入，`-X → 0`；向左退出 |

编辑时三个首页入口全部隐藏并停止接受点击。顶部导航固定，预览只作横向转场，三态不改变团子尺寸和接地高度。动画约 440 ms；关闭立即禁止退出面板接受输入，但保留该面板所在列直到动画完成。快速切换以最后一次请求为准，系统减少动画时即时到位。

入口激活或编辑关闭后，焦点回到团子舞台继续游戏操作。参数、调色盘和预览工具获得焦点时，由自身消费操作，不能同时触发移动、跳跃或 W 进门。临时比较、隐藏和关闭的清理遵守整套草稿取消合同。

## 4. 图标工具与保存区

捏脸态不显示“捏脸”标题，标题行不占空间，释放参数区高度；共享标题控件仍供换装使用。局部页签和动态比较改用图标，保持团子原尺寸：

| 分组 | 从上到下或从左到右 | 位置 |
|---|---|---|
| 参数页签 | 调色盘／眼睛 | 团子左侧竖栏 |
| 动态比较 | 眨眼／睡眠 | 团子右侧对应竖栏 |
| 草稿操作 | 回转箭头（恢复默认）／X（取消）／勾（应用） | 团子预览区右下，同排排列 |

工具和草稿操作均为 **32×32 DIP**，图标 20×20 DIP，同组间距 8 DIP；竖栏与正常预览约隔 6 DIP。参数面板镜像不交换团子两侧的工具竖栏。睡眠比较激活后，月亮改为太阳／醒来，提示和辅助名称同步变化；比较状态不保存，也不改变自动睡眠行为。

图标保留中文 Tooltip 和辅助名称，提示延迟 250 ms。横向保存区使用预览列宽度，图标行靠该列右下。应用保留强调背景、边框及待保存状态；真实保存反馈和受保护文件的恢复入口继续可达，不能用图标替换掩盖写失败或文件保护状态。

### 4.1 纵向窗口

纵向时参数停靠在预览下方，在 `OptionsBody` 内独立滚动。固定预览工具只占上方 `PresenceStageRow`，不跨入参数行。

恢复默认／取消／应用归属于**团子的右下方**：保存组与团子预览同宽、使用同一水平锚点，位于阴影下方；不能固定到整个页面的右下角。上部按真实反馈和恢复入口的测量高度预留空间，删除原先额外强制的 300 DIP 整页高度和底部保存占位。长参数列表的滚动不会带走保存按钮，所有按钮须完整处于所属窗口可见边界内。

## 5. 共用接地高度与阴影

同一窗口尺寸下，首页、捏脸和换装使用相同正常预览尺寸与接地基线，不因展开面板轻微下移，也不缩小团子来迁就按钮；跨窗口尺寸仍按可见视口响应布局。团子放低到实际身体下缘贴合阴影的位置，接触点为阴影中心上方约 1 DIP；独立帽子与身体一起移动。

三态共用固定地面的柔边椭圆阴影，落地宽度为预览宽度的 0.62、高度为 0.045、透明度为 0.17。相对当前预览的地面中心在跳跃时保持稳定；随同一成功帧的实际 Native 跳跃高度，阴影缩窄、变薄、变淡，落地恢复。落地帧用实际身体轮廓下缘校准表现偏移，腾空时缓存落地偏移再叠加既有跳跃投影，不能通过改变物理高度来伪造贴地。

故障、停止、设置和门廊不显示首页阴影。阴影不接收输入、不保存、不上传，也不增加计时器或帧 owner。本项是首页表现层投影，独立于历史纯色团子资产规则；不据此给身体资产加入纹理、渐变或额外装饰。

## 6. 四滑块、默认与保存语义

| 控制 | 合法范围／默认／UI 步长 | 方向与映射 |
|---|---|---|
| 大小 | 70～140／100／1 | 左小右大；相对旧眼睛直径统一缩放 |
| 椭圆度 | -100～100／0／1 | 左横、中圆、右竖；短轴倍率 `1 - abs(value)/200`，长轴不变 |
| 高度 | 32～66／51／1 | 左高右低；以旧中心为锚点，双眼同步上下移动 |
| 眼距 | 12～34／24.5／0.5 | 左近右远；以旧中心距离为锚点，双眼对称调节 |

保留现有 Windows 默认长相，四项默认执行旧完整求解分支。高度／眼距是相对旧锚点的控制单位，不能当成实际身体比例；公式和安全边界以实施计划为准。安全退让可以暂时调整显示，不反写用户请求、滑块或已保存参数。

同一草稿包含两色和四项眼睛参数。选色、拖滑块、切页签及表情比较只预览；恢复默认只改草稿；只有显式应用成功才原子写入 Schema 3。取消、关闭、离开首页或隐藏回滚整套未应用自身外观并清理临时比较。黑色、同色及低对比选择合法，不自动修正。

Schema 1／2 只读补默认布局，显式应用成功才升级；坏文件和未来版本受保护，恢复须先显式备份。写失败保留原文件、最近保存值和可重试草稿。示意页面状态和验收窗口内的个人选色均不是新的产品默认；帽子保持独立保存边界，多人外观协议未在本轮扩展。

## 7. 选择理由与验收边界

| 已确认选择 | 被替代的方案 | 原因与结果 |
|---|---|---|
| 键帽加图标、三侧入口 | 底部文字说明及两个下方按钮 | 直接表达按键，把空间留给团子与参数 |
| 捏脸右进、换装左进 | 两类参数都在右侧、同向转场 | 入口位置与面板来源对应，关闭保持原列避免跳动 |
| 两侧竖栏图标、去标题 | 文字工具组和重复“捏脸”标题 | 节省空间并保留原团子尺寸；提示与辅助名称承接文字含义 |
| 保存锚定预览右下 | 保存固定整页右下、参数强撑页面高度 | 纵向按钮可见且靠近操作对象，参数单独滚动 |
| 共用贴影基线 | 首页和编辑态分别居中、身体悬在阴影上 | 切换稳定，跳跃顶空和实际地面关系可验证 |
| 旧 Windows 默认校准、整套显式保存 | 直接采用 HTML 比例或切页自动保存 | 默认身份稳定，取消／失败／升级具有明确边界 |

本轮用户通过的是当前 Windows 候选的自身捏脸与三态布局观感。最新受影响回归 104/104、零跳过，隔离 Release 构建 0 警告／0 错误；真实 150% 系统缩放下横向和纵向窗口已核对。真实 100%／125% 系统缩放、其它显示器及完整阶段专项仍未验证。原生轨迹、像素、重启与磁盘失败证据分别查阅验证记录，不由这次人工确认推定新增结果。交付仍限本地任务分支，未合并 main、推送、更新日常安装或部署。
