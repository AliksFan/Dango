# 官方圆球隔离技术试验计划

日期：2026-10-09。设计基线：`1cd81cc`。用户已通过[圆球设计](2026-10-09-official-round-ball-design.md)，并明确授权“持续推进直到需要人工协助/验收”。本计划冻结隔离试验范围、夹具与停止门禁，按该授权实施；它不代表试验已运行或通过。

## 范围与隔离

先证明 [ADR 0006](../adr/0006-native-round-ball-display-metric.md)的 `q=diag(4/3,1)p`、native 球三个自由度与原团子共同子步可行，再进入完整单人窗口。试验不改团子参数、原 42 槽帧或 ABI 1 签名，不实现正式房间、软皮球、直接拖球、球面起跳、平台组合或多人。

实施从含本计划的本地提交建立独立 Worktree／`codex/round-ball-admission` 分支；设计与已接受平台分支保持原样。所有输出进入新的 `artifacts/furniture/round-ball-<RunName>/`，不覆盖既有产物，不停止已打开的用户验收窗口。沿用固定 Box2D 3.1.1／C17／.NET 10，不新增依赖、服务、端口、数据库或云资源。

算法负责人独占 world、球求解辅助文件与 CMake；测试负责人修改新测试入口和独立 oracle；probe 负责人只改新纯数据消费者。跨文件接线顺序由集成负责人协调，不能同时修改 world 或同一共享函数。测试专用故障入口只编入独立 native 测试可执行文件，不作为正常模块运行时开关。

本阶段用内部球定义／状态验证合同，正式球 ABI 与托管 API 在准入后冻结。正常候选仍能通过原导出执行无球回归；独立测试 target 可调用内部试验入口，不能把绕过正常 Step 的完整 rig 结果记为集成通过。

## 固定时间与参数

外层 `dt=1/60` 秒，沿用当前模块 `max(ceil(dt×960), SubStepCount)` 的真实小步路径，名义为 16 个子步；不能改成 bridge 配置的 4 步。原测试禁阻尼路径使用 240，只有明确标注的解析夹具可使用，不代替正式真实 rig。

原参数保持 `core_mass=.12`、16 节点各 `.015`、总质量 `.36`、重力 `9.8`、原地面 `-.72` 与参数版本 1。球初始试验值为 `m=.09`、`r=.4`、二维圆盘惯量 `I=.0072`；地面／团子摩擦 `.45/.35`，回弹 `.25/.15`，回弹阈值为闭合速度至少 `.5`。球线速度上限 12、角速度上限 40，超界锁存，不用截断掩盖失败。

只加入一种地面滚动耗散：滚动阻力系数 `.02`，力矩上限 `c_r m g r`，方向反向于有效滚动，不能越过零点注入反向能量。自由飞行的线性／角阻尼先为 0。解析无外力试验明确关闭重力、摩擦、回弹与滚动阻力。native 睡眠需连续 `.5` 秒满足地面稳定接触、线速度不超过 `.02`、角速度不超过 `.05`、接触误差不超过 `.001`，并无待处理碰撞／控制扰动；睡眠停止球积分，仍检查可能唤醒的团子接触。

这些值在开工前固定为试验起点。失败后保留原证据并定位，调整候选须记录理由及新批次，不能修改 oracle 或放宽已批准的接触／守恒／资源门槛。需要改变已批准玩法、原团子参数或架构边界时才请求用户决定。

## 解析与几何夹具

| 编号 | 固定输入与断言 |
|---|---|
| A1 投影 | DIP 原点 `(320,240)`、原世界点 `(1.2,.7)`、q 点 `(1.6,.7)`；`s=1/.5` 的屏幕期望分别 `(416,198)/(368,219)`。DPI 倍率 `1/1.25/1.5` 只转换最终像素，纯 double 投影／逆映射误差至多 `1e-10` |
| A2 正圆与角度 | 球心为 A1 的 q 点、r=.4；八向 `kπ/4` 的 DIP 半径为 `24/12`。角度 `0、π/2、π、−π/2、2π+.2`，WPF 角度 `−θ×180/π`；位置相同角度不同及反向组合都需成立 |
| A3 原样条 | 从只读基线冻结静止、下压、非对称拖动公开帧；独立二次 B 样条按每段至少 64 点重建。公开帧已含外扩，不重复外扩。两种 s／三种 DPI 下旧投影与新投影一致，离屏 double 差至多 `1e-10`；这不替代真实呈现 1 DIP 门禁 |
| A4 接触几何 | native 合法真实 rig 的未归一化轮廓，以及经同一显示轮廓函数处理的 test-only 强形变 17 点几何夹具（唯一最大点归一化与分支边界）；覆盖八向及每段内部最近点。独立稠密曲线 oracle 不调用被测最近点 helper，最大间距误差至多 `.001` q 单位 |
| A5 导数 | 平滑分支用中心差分 `h=2^-10` 与 `2^-11`；每个 core／节点自由度与解析导数误差至多 `5e-4+2e-3×|期望|`。归一化最大点须唯一且离并列／阈值至少 `.02`；非光滑边界用单侧分支检查，不套中心差分假定 |
| A6 反作用与功 | 单个解析点体 mD=.36、球 mB=.09，`T=diag(4/3,1)`；法向为四轴及 `(.6,.8)` 的四符号镜像，初速 `vD=T⁻¹n`、球速度／角速度 0，切向 `t=(-ny,nx)`。核对 `ΔP_D+TᵀΔP_B=0`、球心法向转矩 0、切向 `Δω=τ/I`。能量为原 p 中点体动能＋q 中球平移动能＋旋转动能；不得用 q 中普通总动量替代 |
| A7 接触耦合 | 斜向 A6 的法／切有效逆质量矩阵为 `[[14.6666666667,-1.0370370370],[-1.0370370370,37.4938271605]]`；同时满足回弹法向目标与库仑摩擦界。不能单解一次法向再切向而漏重解法向 |
| A8 回弹阈值 | 闭合速度 `.499999/.5/.500001`，地面回弹目标分别 `0/.125/.12500025`，团子接触分别 `0/.075/.07500015`；同一次持续接触不重复注能 |

A6／A7 使用一接触的无外力解析夹具，测试摩擦 `0/.35/1`、回弹 `0/.15/1` 的交叉组合，另增加点体速度 `(3,0)` 的斜向滑动用例。求解后相对速度、冲量与独立 double 的两自由度接触解比较，绝对误差至多 `1e-6` 加相对 `1e-5`；反作用向量范数至多 `1e-6`，法／切速度残差至多 `1e-6`，能量误差至多 `1e-7+1e-5×|期望|`。真实团子有弹簧、阻尼及控制，不适用这条全场景无外力守恒断言。

数值锚点：A6 横向 `μ=e=0` 时 `Jn=.0623076923077`，点体速度 `(.519230769231,0)`，球速度 `(.692307692308,0)`。A7 在法向 `(.6,.8)`、原 A6 初速、`μ=.35/e=0` 下，`Jn=.0683154211447`、`Jt=.00188952761810`、球角速度 `−.104973756561`，用于独立核对耦合解。

地面滚动解析夹具另固定球初速 `(1,−1)`、角速度 0、`e=0`：法向冲量 `.09`。`μ=.45` 时 `vx=2/3`、`ω=−5/3`、`vx+rω=0`；`μ=.10` 时 `vx=.9`、`ω=−.5`、滑动速度 `.7`；`μ=0` 保持 `vx=1/ω=0`。按上述解析容差检查，960 次无外力静置接触的额外冲量至多 `1e-6`、能量增长至多 `1e-7`；有重力真实场景的持续支撑冲量不要求为零。

## 真实集成与停止门禁

几何夹具分类说明：原 `radial_max=.68×1.22=.8296`，加节点外扩 `.045` 后仍不超过 `.8746`，小于显示归一化阈值 `.98`。A4／A5 的归一化与边界覆盖因此属于 test-only 几何分支验证，不声称合法稳定 rig 已进入该分支。原参数、导数误差门槛及真实集成约束不变。

真实场景通过正常 world Step 和原有有界控制进入目标，不在生产模块暴露任意冲量／坐标改写入口。测试特定初态仅用隔离 fixture，并单独标注。

| 编号 | 实际场景与要求 |
|---|---|
| I1 正常接触 | 左／右推动、球落地、八向接近及团子与地面夹球；每场至少 900 步，所有状态有限，原团子形变／速度边界不变，接触穿入或静止悬空最多 `1/30` q 单位 |
| I2 高速 | 球左右与斜向真实速度至少 8、不超过 12，另有原团子最大合法输入与球反向接近；记录实际相对速度及真实接触帧，不能未碰到就通过，不越过实体或锁存故障 |
| I3 滚动／滑动 | 地面低速无滑动区间核对 `vq.x+rω≈0`；μ=0 对照保持真实滑动。中心法向撞击不凭空自转，位移与角度分别来自状态 |
| I4 球面起跳 | 证明球顶接触且原地面接触为 0，团子接地标志仍假；点按与持续 Space 均无额外起跳冲量。原地面起跳对照保持 |
| I5 真休眠 | 球以地面静止初态开始，10 秒内进入真实 native 休眠；维持 30 秒，积分计数不增加，活动团子仍正常推进；再次有效接触唤醒并运动，无穿透或旧冲量累积 |
| I6 安全快照 | 场景修订＋步号联合标识；成功创建、移除、Reset 更新整组快照。第 4 个真实子步后破坏真实球状态或几何触发故障；球、团子及接触诊断共同冻结。覆盖创建后首步、移除后、Reset 后故障，不丢新球、不恢复旧 ID |
| I7 生命周期 | 100 次创建／冲突拒绝／移除／重新添加／Reset／销毁，ID 单调不复活，失败不部分改状态；球与平台互斥，多团子创建球及有球增第二团子拒绝。native 所有者／分配最终归零 |
| I8 原路径 | 未启用球时 1／2／3 团子各 900 步与只读已接受模块完整帧零容差一致；重跑平台 41 项、既有 world／capacity／bounds、旧模块能力保护及历史三体对照，0 失败、0 跳过 |
| I9 投影边界 | 离屏 probe 只接收不可变同版本快照，不持有 world／Step。重复读取、往返改 s／DPI／原点／覆盖层均不改变快照、ID、步号或角度；该检查不推定真实 HWND 通过 |

至少四种隔离错误变体必须触发对应行为断言失败：禁用球接触、漏团子反作用、导数漏 `Tᵀ`、球顶误授起跳。斜向耦合和伪滚动／伪休眠也由针对性错误夹具击穿。MissingExport、未到达接触及测试启动失败都不能计为行为反例。
