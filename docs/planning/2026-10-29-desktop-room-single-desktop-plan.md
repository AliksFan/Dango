# 桌宠房真实桌面与单一虚拟桌面实施计划

日期：2026-10-29。依据：[已批准设计](2026-10-29-desktop-room-single-desktop-design.md)。用户先授权实施，随后对 R3 明确“通过，合并到main”，已完成本轮人工验收及本地 main 快进集成；不包含推送、安装更新和数据清理。首版与 R2 人工反馈未通过的历史保留；R3 已修正同步鼠标消息内 COM 查询导致的永久输入失活，鼠标不要求桌面焦点、不接管方向键。定向后台／离屏回归 111 项通过，代码已纳入 `main@5bde536`，见[最新修订验证与集成](../verification/2026-10-29-desktop-room-focus-independent-input.md)。

| 增量 | 文件／职责 | 行为与验证 |
|---|---|---|
| 移除房间壁纸 | `DesktopPetRoomHost`、`DesktopPetDangoWindow`、`LocalRoomSceneView` | 场景校验挂在现有透明团子窗口；桌宠不创建 WorkerW，不绘制背景；同一映射、单 owner、新健康帧继续成立。迁移原双表面测试，保留普通房背景回归 |
| 虚拟桌面归属 | 新增 `DesktopPetVirtualDesktop` 宿主边界 | 公开 Windows COM 接口及自有 owner 管理归属；检测当前桌面、迁移／失败，内部标识不落盘。纯逻辑测试先覆盖失败与生命周期；真实工具窗、Win＋Tab、任务栏需屏幕验证 |
| 暂停与恢复 | `LocalRoomSceneDriver`、桌宠宿主及应用导航／设置 | 切桌面释放手势并暂停，不补播；手动隐藏保持归属；切回新健康帧恢复。普通退出释放窗口及归属资源，旧代际回调无效 |
| 显示大小（追加批准） | 设置页、独立偏好会话、共享映射及帧驱动 | 50%–200% 整数百分比、即时预览、本机原子保存及失败重试；同一投影缩放身体／配饰／命中，活动边界适配且不修改物理身体参数。离屏验证倍率、逆变换、地面及文件保护 |
| 验证迁移与报告 | 桌宠相关既有测试、定向新增测试、验证记录 | 先构建与不显示窗口的测试，再执行获准的真实桌面／输入验证；记录不能执行项及所有残留资源，不以静态门禁替代人工验收 |

不新增依赖、账号、服务、数据库或付费资源。按开发工作流第 13 节集中装配新宿主，并同步退役桌宠旧壁纸消费者与故障字段；普通房壁纸路径继续属于普通房。

主 Agent 负责生产宿主／视图／驱动／导航与串行构建，虚拟桌面子任务只拥有新增独立模块及对应测试，测试迁移子任务只拥有指定既有桌宠测试文件。并行编辑不重叠，所有需屏幕的运行均由主 Agent 统一协调。
