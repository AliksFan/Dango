# 官方静态平台：第一批小样实施计划

日期：2026-10-09。状态：用户已通过[静态平台与独立单人验收窗口设计](2026-10-09-official-furniture-design.md)，并明确授权“开始实施”F0–F4 本地实现、隔离构建／测试和启动单人验收窗口。编码、native／托管自动门禁与本机真实输入检查已完成，规定的运行观察通过；原造型比例回归已修复，用户于 2026-10-09 对修正后的 r6 窗口回复“通过”，本批独立单人小样已验收。既有性能门禁和未执行的专项检查保留，详见[验证记录](../verification/2026-10-09-static-platform-prototype.md)。

## 目标与工作区

交付一件官方静态平台和一个独立 Windows 单人验收窗口。团子能碰到平台、落在顶面、站稳、起跳和走下边缘；侧面及底面接触不能授予跳跃资格。图片资源与碰撞矩形分别定义，窗口只提交真实输入和绘制 native 成功状态。

本批不制作玩家家具编辑器、不导入玩家 PNG、不提供任意参数面板；不接入正式普通房／桌宠房、布局持久化、账号、服务端或多人。不实现圆球、蹦床、窗帘，不改变配饰行为和既有身体参数。

设计基线为 `9ab37af`，计划文档已提交在 `codex/furniture-and-accessory-design`。获实施授权后，检查已有附件，从含本计划的 `a34b097` 建立独立实施 Worktree 与 `codex/static-platform-prototype` 分支。物理接线、托管 API 与集成由同一负责人顺序修改；窗口和测试按明确文件所有权并行。

仅使用固定 Box2D 3.1.1 来源、现有 C17／.NET 10／WPF 能力，不新增依赖。候选 native、应用、日志和 TRX 写到新的 `artifacts/furniture/<RunName>/` 下，不重建既有物理对照目录，不运行会复制正式 DLL 的 `build-box2d.ps1`。本轮核实受保护 `src/Dango.Desktop/runtimes/win-x64/native/dango_box2d.dll` 的 SHA-256 为 `6712D66ECEF9588123CAFCD868455080598B5B58711A698FB8AF022A0CDA191A`，实施前后复核。

## 最小合同

- 世界坐标继续 X 向右、Y 向上；平台是无旋转的实心轴对齐矩形，顶面可站立，侧面和底面阻挡，不是单向穿透平台。
- 平台定义为中心坐标、宽高及固定摩擦值；外观纹理、画布留白和绘制偏移由窗口的官方资源定义，不参与碰撞。首批世界最多一件平台；测试可移除后在不同坐标重新创建，不提供玩家摆放功能。
- 建议新增 `DangoStaticPlatformDefinition` 与 `SetStaticPlatform`／`ClearStaticPlatform`，只有一个可选平台槽，不提前建设通用家具 ID／注册表。重复设置同一定义幂等；已有平台时不同定义明确拒绝。重置保留定义、重建物理状态，释放世界时一并释放。
- 托管和 native 都拒绝非有限值、float 转换溢出、非正尺寸、越界坐标、第二件平台和创建时与已有团子轮廓相交。矩形端点限制在 ±1024，宽高为 0.1～16，摩擦为 0～1.5，回弹固定为 0。失败不改变现有对象、团子 ID 或有效帧。
- 保留 ABI 1 的现有函数签名、6 槽输入与 42 槽身体帧，平台使用可选扩展导出。旧 DLL 能继续运行无家具场景；请求平台能力时缺少导出必须明确失败，不能绘制一张可见但不碰撞的图片冒充成功。
- `GroundContactCount` 保留原地面语义；是否平台支撑／接触法线／间隙使用独立只读诊断合同。家具启用场景的 `IsGrounded` 与动作判定反映当前有效支撑，不能只修改输出标志而不影响下一次 native 输入。
- 无平台时水平原点平移保持原路径与原重置锚点语义，不统一修改 anchors。首批独立窗口不需要原点滚动；有平台时 `TranslateHorizontal` 明确拒绝并保持状态不变，清除平台后恢复既有能力。局部地面边界调整不得销毁平台，相关调用先完成全部校验，失败时无部分场景更新。

## F0 — 冻结反例与无家具对照

目标：`tests/Dango.Physics.Tests/StaticPlatformTests.cs`、独立几何测量辅助文件，以及候选构建／运行记录。

1. 先定位当前 main 使用的真实模块对照，记录来源提交、文件哈希、配置和输入序列；当前设计 Worktree 没有 `artifacts/` 对照产物，不把现有源码或待构建候选当成已验二进制。
2. 保存 1／2／3 团子的无平台逐帧状态、ID、接触步数和错误码。包括移动、跳跃、下压、拖动、添加、移除、重置和局部边界；候选无家具路径要求与对照完全一致。
3. 建立显示轮廓测量 oracle：从公开身体帧按现有 WPF 外扩、缩放和二次 B 样条重建轮廓，以平台矩形测量实际接触；不能只检查核心或原始节点圆。
4. 冻结顶部落地、左右侧碰、底面顶撞、走下边缘、接缝／角点、高速接近、拖动释放、移除与错误输入场景。每个反例先证明到达目标位置和发生目标接触，避免未碰到平台却声称侧碰规则通过。

退出条件：对照可追溯，场景、时间范围和下方数值门槛固定。缺少真实对照时暂停依赖等价性的实现，不绕过旧失败、不放宽门槛。

## F1 — native 显示轮廓接触与支撑

目标：`eng/native/box2d/dango_physics_module.h`、`dango_collision_review.c`，新增独立平台接触辅助头；仅在证据要求时修改 `dango_display_contact.h` 或公共 self 原语。CMake 仅加入必要的候选／反例验证支持。

直接增加能与原始节点圆碰撞的 Box2D 矩形可能让团子提前停住、看起来悬空，不能作为充分实现。推荐由同一 native 世界登记静态矩形，并以既有显示轮廓和梯度构造平台接触，平台作为固定质量边界；任何代理不能同时以更大的 raw rig 再挡住团子。候选求解路径须先通过 F0 场景，不能用呈现层移动、隐藏凸包、第二 owner 或额外物理步修正显示。

平台接触需在每个既有子步与身体约束联合检查，位置修正后重新验证轮廓与约束。仅顶部有向支撑可接地：接触法线朝上分量至少 0.7，分离间隙至多 0.008 物理单位，核心相对静态平台的竖直速度严格小于 0.5 单位／秒；等于或超过 0.5 的向上运动不获得支撑，测试覆盖阈值两侧。侧碰／底碰只阻挡。支持状态贯穿输入前、约束与接触后、阻尼及帧读取；原 `read_frame`、约束和阻尼仅按地面判定的路径不能覆写平台结果。

跳跃继续采用原静态地面起跳速度和冷却，不使用团子间支撑的反作用分支，不把平台支撑当成另一只团子的槽位。起跳或离开顶部后及时失去支撑；平台不额外加力、不修改全局重力、柔软度、节点数或子步数。

创建成功后平台不动；移除、故障重置及世界销毁全部解除接触状态并释放资源。非有限值、速度／形变越界或接触不收敛锁存错误，返回最后安全帧，普通动作停止，只允许显式重置或退出。

退出条件：全部真实 native 平台门禁通过，并证明“关闭平台碰撞”及“将侧碰误作支撑”的隔离错误候选分别使落地与侧碰反例失败。反例开关只存在于测试构建，正常候选不得携带运行时绕过入口。

## F2 — 托管 API、兼容与资源门禁

目标：`src/Dango.Physics/DangoPhysicsWorld.cs`、新增纯数据平台合同，`tests/Dango.Physics.Tests/` 的平台与兼容测试，按需扩展 `PhysicsTestLibraries.cs`。

- 导出按需加载，保留无家具旧模块兼容；托管保持创建线程所有权和显式释放，不引用 WPF。
- 设置／清除与只读支撑诊断必须核对世界和团子 ID，不信任调用者自报状态；异常或 native 拒绝后托管与 native 定义一致。
- 验证重复设置／清除、冲突设置失败、重置保留定义、重复释放、跨线程访问、释放后访问、缺失平台导出、合法极值及既有团子身份回归。
- 运行现有 world／统一模块／边界／等价性相关回归；无家具世界仍保持原轨迹。平台缺少能力、native 故障和最后安全帧不能被包装成成功。

退出条件：F1／F2 自动结果与当前对照、历史失败分别记录，未执行项不计入通过。

## F3 — 独立真实验收窗口

目标：在 `eng/tools/Dango.JointReview/` 新增 `StaticPlatformSession.cs`、`StaticPlatformWindow.cs`、官方平台图像资源，在 `Program.cs` 增加独立 `--static-platform <DLL>` 入口；新增 `eng/run-static-platform-review.ps1` 与运行说明。不把原来仅支持 2／3 团子的 `CollisionWindow` 改成家具产品入口。

窗口只放一只团子和一件官方矮台，提供无平台对照、顶部／侧面／底面预设场景、重置、暂停及碰撞轮廓显示。场景切换重建验收世界，不修改用户产品设置。使用现有团子视觉和呈现适配，平台图片与物理矩形共用同一坐标变换；窗口缩放只改变显示，不重置或调节物理。

A／D 移动，S 下压，Space 使用原速度跳跃；鼠标真实拖动团子。按钮焦点和控件操作不穿透为动作；失焦、暂停、重置、丢失鼠标捕获和关闭清空输入。暂停／隐藏不推进，恢复不补跑挂起时间；每个固定步仅一次 native Step，绘制和调整窗口不推进。错误后显示最后安全状态和明确原因，禁止继续普通输入。

启动脚本明确候选 DLL 路径与新 RunName，仅构建隔离输出；运行前检查哈希和当前候选是否被打开，不覆盖运行中文件、不停止无关进程。关闭停止计时、解除事件与捕获并 Dispose。窗口是本批交付物，不用 ZIP 或静态截图代替人工操作。

## 冻结的候选验收门槛

这些门槛在开工前冻结，用于候选的失败判断，实际测量另记验证报告。不得因候选失败而降低数值；确需改变产品行为或门槛时先保留证据再评审。

| 门禁 | 场景与要求 |
|---|---|
| 无家具回归 | 固定只读旧模块与新增候选，在相同默认配置、输入和步序下，1／2／3 团子至少 900 步逐帧完全一致；新平台分支不运行于无家具路径，不能比较同一候选自身重复运行 |
| 固定步与安全 | 1/60 秒外层固定步；所有输出有限，默认面积不小于 0.42，最大节点／核心速度不超过 12＋1e-5；native 错误为 0 |
| 顶部支撑 | 正常落地最多给 120 步收稳，随后连续 1,800 步保持有效平台支撑且不掉落；末尾最大速度小于 0.03 |
| 接触质量 | 按公开绘制轮廓测量；标准 60 DIP／物理单位尺度下穿入或静止悬空最多 2 DIP，物理预算固定为 1/30 单位；不随实际窗口缩小而放宽 |
| 起跳与离开 | Space 产生真实向上运动，遵循原静态地面起跳和 450 ms 冷却；起跳或失去支撑后至多 2 个固定步清除平台支撑，持续侧碰和底碰不能触发额外跳跃 |
| 角点与高速 | 顶／侧／底、边缘、节点间隙，以及受现有 12 单位速度上限约束的接近与拖放，不越过矩形到另一侧、不卡死、不产生故障或异常面积 |
| 身份与生命周期 | 至少 100 次创建／移除／重置／世界释放循环，无旧 ID 复活、计数残留或 Box2D 分配残留；失败参数不改变前后有效状态 |
| 图像与碰撞 | 图像透明装饰区可与碰撞区不同；碰撞覆盖层对齐在当前 DPI 下误差不超过 1 DIP；各窗口尺度下物理状态不受绘制影响 |
| 真实输入 | 实际 HWND 检查焦点、松键、捕获与失焦；清输入后的下一步无残留控制，暂停不推进，关闭无该窗口残留进程／计时 owner |

2 DIP 接触预算是本小样的新门槛，不挪用团子间 3% 重叠规则。高速场景必须由真实有界输入或受控测试 fixture 到达速度并记录过程，不能只测静态几何。窗口先在本机实际 DPI 和一次调整尺寸下验收；100%／125%／150%、多屏、睡眠和其他硬件仅按实际执行记录。

自动门禁后进行至少 10 分钟真实窗口观察，记录新状态绘制频率、步进耗时、CPU／内存、峰值接触误差及 20 次暂停／隐藏恢复；无崩溃、锁存故障、接触超预算或随循环累积的资源残留。绘制更新计数不冒充显示合成 FPS。墙钟至少 600 秒，活动至少 560 秒（扣除 20 次计划的两秒暂停／隐藏）；额外最小化或暂停自然延长，状态和丢弃时间明确记录，不把暂停墙钟代替持续运行。性能数据独立于功能通过，既有性能红灯和长期／其他硬件未验证项不关闭。
