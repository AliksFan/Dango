# 身体材料接入捏脸：设计草案

日期：2026-10-10。状态：用户明确“设计通过”，本页单滑块物性方案及后续捏脸接入设计已批准；用户随后明确“开始”，[隔离小样实施计划](2026-10-10-landing-build-material-sample-plan.md)已获实施批准，L0～L2 已执行，完整验证进行中，生产接入尚未实施。用户明确“不改变骨架的初始形状”，随后要求“做一个落地时体型由胖到瘦的滑块，通过我们预设的比例调整这些物理特性”，并确认胖端更宽更扁、瘦端更窄更挺，柔软度继续独立调整。本稿撤回此前体型比例／上下饱满度改变自然几何的建议：所有体型共用圆形初始骨架及自然几何，只由预设材料参数改变受力后的形态。原圆形材料小样已获“手感验收通过”，轻微甩后慢形变暂留；[原小样结果](../verification/2026-10-10-round-material-drift-repair-result.md#2026-10-10-用户手感验收通过)及失败证据保持不变，不能由它推定新增参数组合通过。本页先验证隔离物性小样，再按通过后的首页／捏脸接入合同制定对应实施计划。

## 1. 用户可调内容

初始节点保持均匀圆环；同一身体大小下，体型和柔软度均不改变自然骨长、自然面积或自然角度。空中与落地外形由实际材料、重力和接触自然决定，不按离地／接地状态切换材料或施加回圆、压扁及扶正力。无载自然态保持圆形，飞行中的短暂变形、旋转和恢复随物理演化，不要求每帧严格圆形。滑块中点保持原认可参数映射与落地外形。

| 控制 | 范围／默认／步长 | 作用 |
|---|---|---|
| 身体大小 | 80%～120%／100%／1% | 实际骨架长度、节点半径等随尺寸变化，不只缩放图片 |
| 柔软度 | 0～100／50／1 | 沿用认可小样的径向／外围弹性映射，改变受压及落地形态 |
| 落地体型（候选） | 胖 0 ↔ 瘦 100／50／1 | 单滑块按预设比例联动现有材料参数；用户已确认胖端更宽更扁、瘦端较少铺开更挺，实际范围待小样验证 |

取消“晃动抑制”用户控制和拟保存字段，内部先固定已认可小样默认控制值 90，对应两组弹簧阻尼比 1.85。现有三种大小 × 三种柔软度的飞行／落地／恢复及三种拖甩轨迹已覆盖这个阻尼；长时证据仅覆盖默认大小与柔软度。暂不引入未经验证的柔软度→阻尼联动映射，也不宣称 1.85 已适合所有新增体型。新体型需要独立验证恢复、振荡及数值稳定；不合适时先报告原因并另定有限映射，不叠加额外反漂移力。

本批不添加独立重力、顶部／底部状态塑形力或骨架自由点编辑器。已有身体／眼睛颜色和四个眼睛参数保持独立；配饰的柔软度仍属于换装。

## 1.1 单滑块材料映射

先在现有隔离 DLL 与单团子物理小样中验证一份有限的预设映射，不直接接入正式捏脸。大小、柔软度、落地体型仍为三个用户控制；不向用户暴露径向／外围弹性、抗压或内部阻尼滑块。通过后再按下节预览与保存合同接入隔离首页候选。

第一候选以径向弹性为主要联动项，外围弹性及抗面积压缩强度作有限配合。沿用柔软度生成的径向／外围基值，再乘以体型对应的预设系数；面积强度从原 4.8 乘以对应系数。体型 50 时三项系数均为 1，所有大小与柔软度下均精确复用旧映射，不能只保留默认的一组参数。径向／外围“弹性”实为弹簧频率，系数不直接解释为等比例刚度；面积项仅抵抗低于自然面积的压缩，不能当作严格体积守恒。具体端点系数及插值表由后续有限校准计划在模拟前固定，当前没有已验证比例。

局部弯曲强度先固定原 1.7；质量、质量分布、重力、接触及摩擦、阻尼和伸缩／角度／凸性／最小面积保护在原三项候选中均不随体型变化。已有大小的恒定二维密度映射保留。顶部内压与主动落地横扩仍为 0，不增加区域／方向材料、新排斥力或新防漂移力。若三项联动无法产生可靠效果，保留失败并回到设计，不无界扫描或悄悄扩展到其它物性。

2026-10-11 用户要求两端“明显一档，仍保持团子感”后，三项材料预览未能明显增强胖端，复核发现宽度接近径向伸展上限；用户随后明确“通过，继续”，批准[有限范围增量](2026-10-11-landing-build-stronger-endpoint-preview.md#已批准的伸展范围增量)。该预览仅额外联动胖侧 `RadialMaximumRatio`：胖 0 为 1.30，至中点 50 线性回到原 1.22，瘦侧保持 1.22；自然几何及其余硬保护不变，中点仍逐字段等于旧配置。版本 `landing-build-v3-stretch-preview` 已通过默认胖端下落及一条原触发拖甩轨迹，实际观感待确认，完整新矩阵和长时未验证，尚未冻结为生产映射。原 B 停止记录及既有三项候选证据保留；本例外不授权扩大其它物性或替换正式 DLL。

体型与柔软度是不同的操作入口，但真实物理会耦合：柔软度也会影响落地宽高，体型也会影响恢复手感，不承诺严格独立。需要在同一大小和柔软度下比较胖／中／瘦，再覆盖大小与柔软度端点；有限映射不能让某一端静置时塌陷、停止或使体型方向反转。现有均匀、各向同性的圆形材料中，瘦端预期是较少受压铺开、趋近自然圆，不能承诺长期竖向细长的 OC 轮廓。

重要替代方案：保留多项高级物性滑块会增加操作负担，不采用；改变初始节点或自然骨长与用户要求冲突，撤回；仅改变显示宽高或接地时强制塑形不能证明材料效果，不采用。当前只承诺验证安全范围内的一维落地变化，未验证的极端、非凸或尖锐 OC 不作为本批支持承诺。

## 2. 面板与预览

在已确认的捏脸竖向图标页签增加“身体”页，参数面板内放置大小、柔软度和一个通过小样的落地体型滑块；既有调色盘和眼睛页保留。晃动抑制不进入界面。沿用横向右侧面板、纵向独立滚动、恢复默认／取消／应用靠团子右下的布局，不改变首页入口或换装方向。

首批身体参数采用小样已验证的批量预览：滑块只修改草稿，身体页内提供“预览身体并下落”，点击后用全部身体草稿创建新的单人预览物理世界并自然落地，显示已预览参数。颜色和眼睛仍即时预览，不重建物理。参数改动后必须明确显示身体预览尚未更新；不能将旧物理画面描述为新参数已生效。

这是对旧捏脸“参数不重建实体”合同的一项明确候选变更，仅限身体参数的显式预览、取消恢复和默认恢复。物理世界重建不由滑块每帧触发，不转移到正在运行的房间。预览继续由原 Runtime／唯一固定帧 owner 推进，不增加第二套帧驱动或用额外静态演出代替物理。

只有当前身体草稿已成功预览，才允许按现有勾按钮保存。成功预览标记绑定精确的身体控制快照和材料模型版本；身体再改立即失效，颜色或眼睛修改不使身体标记失效，旧成功预览不能放行新身体草稿的保存。取消、关闭、隐藏或离开首页回到最近保存的整套自身配置，并清理输入与临时比较。已预览的身体草稿需恢复时，在同一预览 owner 下显式回到已保存参数的落地状态，不能声称保持了原运动轨迹。身体未变更时，颜色／眼睛的保存与取消仍沿用原行为。

恢复默认先修改草稿，不写磁盘；身体变化仍需执行预览再保存。预览或保存失败保留最近已保存配置及可重试草稿，不显示成功。物理失败继续保持最后合法快照和错误状态，不能通过改变滑块自动消除故障；故障后的重建必须走显式恢复入口。

重建时新世界先完成创建及合法首帧验证，再交接给同一帧 owner，随后释放旧世界；准备阶段不推进旧世界或开启第二个驱动。失败不得把实际生效参数或成功预览标记切换到目标值，不写磁盘，保留最后合法状态并明确报错。取消恢复失败时不得显示已回到保存外观；保留保存值、草稿及实际生效状态的区分，提供显式恢复入口，离开编辑器也不能隐藏未完成的恢复。

## 3. 配置与旧数据

在自身外观配置中加入不可变的身体控制值，保存用户控制值，通过一份共享映射生成物理配置。小样与接入候选使用同一映射及同一材料模型版本，不将整份调试物理配置或 native 状态写入外观文件。

拟将独立 `appearance.json` 从 Schema 3 升为 Schema 4，保留原七个字段，新增 `bodySizePercent`、`bodySoftness` 及候选 `bodyLandingBuild`（0～100，默认 50）；只保存用户控制值，不保存联动后的物理系数、几何体型字段或 `bodySettling`。映射与内部阻尼归属于明确的材料模型版本，具体版本契约需在新小样通过后冻结。旧稿提出的 Schema 4 尚未实现或发布，不当作既有用户数据。不得写入主 `settings.json` 或配饰文件。范围、有限数值、重复／未知／缺失字段在存储边界再次校验，不依赖滑块约束。

Schema 1／2／3 只读时补身体大小 100、柔软度 50及中性体型，内部阻尼固定 1.85；保留原颜色及已有眼睛布局，尤其不能因当前版本升级到 4 而把 Schema 3 的四项眼睛参数当作旧版默认。仅显式应用成功后原子写入新版本；启动不自动改写用户文件。损坏或未来版本保留原文件，延续既有保护、显式备份后恢复及写失败可重试合同。

所有颜色、眼睛、默认和取消路径均须完整处理身体字段：局部颜色／眼睛修改保留其余字段，整套默认和取消按各自合同替换。当前源码多处用三参数构造外观对象，接入后必须覆盖这些路径，避免改眼色时把已保存体型或物性复位。眼睛与配饰依据实际轮廓布置，身体尺寸不能改变其保存参数的含义。

## 4. 实际接入边界

只读核对时，本分支与 `main@2acb532` 的生产捏脸／保存／物理适配源码相同。生产 `SetAppearance` 目前只改变颜色和眼睛；`DesktopPhysicsScene` 默认创建容量 3 的世界，物理配置只在世界创建时传入，`Add` 只有坐标，尚无运行中单实体物性更新 API。

本轮材料候选仍为模块 ABI 1，但候选创建要求容量 1、16 节点；正式 `dango_box2d.dll` 使用的是另一套 ABI 13。接入必须显式选择已验的独立候选 DLL、容量 1 和身体配置，不能只替换原文件或把模块 ABI 版本一致当作生产语义兼容。运行场景与原眼睛／配饰中性标定都会创建物理世界，两处均须采用明确配置并独立验证，不可遗漏标定入口。正式 DLL 保持受保护，所有候选构建、数据和启动入口均隔离。

本次体型只联动现有材料字段，不需要自然几何字段、新形状创建接口或 native ABI 扩展；撤回前稿的新 shape API 建议。小样与后续宿主必须核对实际加载的候选版本和完整配置，缺少指定模型时明确拒绝，不能加载旧正式模型后声称新参数已生效。不修改正式 ABI 13。

每次身体配置重建都重新取得该配置对应的中性可见宽度、地面偏移及眼睛／帽子／配饰基线，并与新世界一起原子交接；不能因附件控制器已存在就沿用旧尺寸或物性的缓存。临时标定由同一 Runtime 同步完成，在新活动世界接管前释放，不增加帧 owner；标定失败沿用前述重建失败合同，不发布部分更新的身体或装饰状态。

首批仅覆盖隔离单人首页、捏脸预览及重启恢复。普通房、桌宠房、多人、多体独立材料及云端同步不在本页范围。本批使用明确的首页／捏脸验收入口，不把新身体配置带入既有房间路径：候选入口若显示房间导航，进入动作需明确提示本候选尚未开放身体参数的房间接入，不能继续进入后静默用旧物理冒充参数已生效。正式入口行为不在本批变更范围。单人场景未通过前不开始房间接线。

生产轮廓当前保留旧 72:58 显示比例，并有大轮廓归一化路径；接入需采用与小样一致的两轴比例和真实尺寸补偿，同时复用原合法轮廓校验与二次样条。核对命中、拖动逆映射、地面、阴影、眼睛、芽和已佩戴配饰的实际轮廓挂点；不能为容纳 120% 团子而暗中缩小物理尺寸。装饰仍按原合同不向身体施加反作用。

小样采用恒定二维密度假设，质量随尺寸平方变化。本批候选保留该映射及已验输入供比较，不据此确定未来房间承重、跳跃或跨端公平规则。尺寸补偿和各项材料参数在实际 host 中必须重新验证，不能用小样通过替代宿主兼容。

## 5. 后续实施前需固定的验收

- 真实效果：80／100／120 大小的实际轮廓与命中按比例变化；落地体型 50 在所有已覆盖大小／柔软度下复用旧配置及回归。胖／中／瘦的初始节点、自然骨长、面积及角度在相同大小下完全一致，实际材料配置必须不同。固定大小／柔软度、释放条件及事前确定的采样窗口，体型 0／25／50／75／100 的原生静置轮廓宽高比须从胖到瘦降低，同时分别记录宽、高和面积，排除仅整体缩水。默认大小／柔软度须满足胖端宽高比至少为瘦端的 1.08 倍，中间不得出现超过 1% 的反向变化。具体采样时刻、重复姿态及其它组合门槛在后续计划中预先固定。忽略滑块、反向联动、只缩放图片、改自然几何或按接地状态切换材料的错误实现必须失败。柔软度须继续产生真实轨迹差异，并验证其多档组合，排除体型仅复制柔软度映射；全部候选保留无载圆形自然态，不要求运动中每帧圆形或抛掷后保持屏幕竖直朝向。
- 草稿边界：未执行身体预览不能宣称新物性生效或保存未预览身体；保存后重启恢复、取消／默认／隐藏／切页均符合上述合同；改颜色或眼睛不得丢失身体参数，改身体不得改变已保存配饰。
- 数据保护：Schema 1／2／3 的有限虚构配置迁移保持旧颜色和眼睛，未来／损坏／重复字段文件保护，原子写失败、备份失败和恢复失败均不覆盖原数据。只使用隔离外观文件，不操作用户实际设置。
- 运行边界：唯一帧 owner、旧世界释放、输入／拖动捕获清理及失败锁存；实际加载 DLL 与容量必须核对，不用假的 Runtime 或离屏截图替代交互。
- 宿主兼容：真实捏脸横向／纵向窗口、默认与大小端点的眼睛和配饰挂点、保存组可达及既有颜色／眼睛回归。当前分支缺少 main 后续上下文时，实施需从最新 main 建立独立 worktree，按必要源码拆分集成，不整体合入实验分支。
- 长时证据：继续保留原圆形默认的固定轨迹和 `<0.003` 原判定；已同意暂留的正向默认慢形变如实列为差异。新体型仍为同一圆形自然几何，需要独立静置及正向／镜像甩后静置证据，旋转中的世界宽高变化不能直接当作非刚性漂移，也不能在形状拟合时抹掉真实伸缩或放宽基本物理门槛。原例外不自动适用于新参数组合、宿主行为、停止、穿地或其它失败。新差异先报告，不修改原结果为通过。

本页设计及[单滑块物性小样计划](2026-10-10-landing-build-material-sample-plan.md)已获批准，隔离小样已开始实施；新小样通过后才制定捏脸接入的逐文件实施计划。本轮没有迁移设置或开始生产接线；正式 DLL 替换、main 合并、推送、日常安装和部署均尚未获本次授权。
