# 圆形材料：一维冗余反力候选

2026-10-10。**待用户批准，未实施；不扩大上一方案授权。** 上一[有限活动块候选](2026-10-10-round-material-contact-block-candidate.md)已按固定秩失败规则停止；[第 147 帧复核](../verification/2026-10-10-round-material-contact-block-result.md)证明该帧存在合法运动，但反力分配不唯一。

## 问题与选择

水平骨架边的长度 rate 与两个接触节点的横向 rate 精确依赖：`J55=J155−J156`。两点粘着时，周长上限并未增加一个独立速度条件；9 个反力坐标只有 8 个独立效果。把秩不足一概当作故障会拒绝这个可行状态。

建议只增加**一维、相容、合成冲量为零的冗余反力分配**。所有原物理行仍属于活动块并参加最终检查；矩阵秩门槛继续如实报告秩，不补对角线、不删周长约束、不把任意最小范数／自由坐标解直接当作物理解。

这种有限扩展比更换完整材料／接触架构小，直接对应已捕获原因。多维冗余通用优化或更换约束职责仍属另一设计；不在此轮混入。本方案也不解决已记录的模式循环，遇到其他未支持状态继续保存证据并停止。

## 固定范围与成本

1. 保留当前 17 体、全部 160 行、最多 16 个活动行、每小步最多 32 次模式裁定、原位置预算、材料／骨架／耗散／限速／圆形自然态与扁形门槛。用户参数仍是大小、柔软度、晃动抑制。
2. 保留一般完整 pivot、原 ID 平局、原 `λ=Dz` 缩放及 `128*n*DBL_EPSILON*||M||∞` 秩阈值。满秩路径保留现有算法。
3. 仅新增 `rank=n−1` 分支。每个模式一次因式消元、一次相容／零空间检查、一次至多 16 行区间求交和一次最终代表值选择，计入原 32 次裁定；不搜索 α 网格、不枚举更多模式、不嵌套第二个求解预算。
4. 秩缺口大于 1、右端不相容、零方向改变合成冲量、区间为空、非有限／残差失败、重复模式、容量／预算／末态失败全部锁存；不为这些失败更换算法或增加预算。报告为本固定候选不支持此状态，不能由当前模式的空区间或右端不相容推断所有模式／整个物理问题无解。

## 冗余分支

完整 pivot 保留 row／column permutation，明确报告数值秩。对于一维秩缺口，从同一消元系统取得一个特解 `zp` 和自由方向 `q`，以确定性原列 ID 选择自由坐标。回到物理单位：

`λp=D zp`，`k=D q`，`λ(α)=λp+αk`。

自由 z 坐标按原 column ID 固定，原始特解该坐标为 0、原始方向为 1，保存原始 pair。按现有精确身份约定形成有效 pair：RELEASED 的 λp=0、ZERO 的 λp=−T0，这两类的 k 分量均为 0；其他分量来自消元。将有效 k 规范为最大绝对分量 1，并由最低原 row ID 的非零分量确定正号，再形成有效 `zp=D⁻¹λp`、`q=D⁻¹k`，规范和 α 单位随同记录。q 属于缩放未知量，不能直接作为物理反力方向。

分别对原保存的归一矩阵重算有效 pair 的特解残差 `M zp−b` 和零方向残差 `M q`。每行使用固定 backward-error 门槛：`128*n*DBL_EPSILON*(Σ|Mij zj|+|bi|)`；齐次零方向去掉 b 项。尺度为零时要求残差恰好为零，不加入一般绝对值 floor。消元中的相容性判定不能替代这次原矩阵重算，也不能借原物理 rate 门槛容忍不相容右端。逐体纯反力检查也使用有效 k，不能只检查原始 pair 或最终 α 单点。

另以原几何梯度检查 k 是否仅重分配反力。对每个动态体 b，令 `g_b=W_b Σ J_ib k_i`、`s_b=W_b Σ ||J_ib k_i||`，要求 `||g_b||≤128*n*DBL_EPSILON*s_b`；s 为零时 g 必须为零。这里不用 float 舍入余量、速度 floor 或物理门槛。如果当前滑动非对称系统的零方向会改变速度，就属于本候选不支持的状态。

所有当前模式的累计反力要求转为 α 的线性约束，包括 ENABLED 的新增单边 λ≥0、RELEASED 的 λ=0、已有 receipt 加新增法向的预算，以及切向累计冲量的两侧 Coulomb 锥。滑动／ZERO 的等式仍保留在原矩阵和末态检查中；不把粘着切向独立夹紧。ZERO 的区间只包含其固定切向身份与物理累计锥，不额外强制 B=0；预算变化由后续单模式规则裁定。receipt 的测得余量保持原定义，不新增预算。

逐行按原 ID 对 α 区间求交，记录约束系数、上下界及导致空区间的行。零系数按精确 a==0 判定并检查常数，不用 epsilon 把小系数当作零。未受约束的端以独立无界 flag 记录；输入、系数、残差、实际 α／λ 非有限或有限端点计算溢出仍失败。选取区间内距离 α=0 最近的有限代表；若 0 合法则取 0，否则取最近有限端点。只选择一次；不做试探点、端点平移、clipping 修补或区间外容差扩张。选择后仍重算全部原方程、真实累计预算和原模式检查，浮点舍入造成端点违规则失败。

原 RELEASED=0 和 ZERO=−T0 的精确身份赋值约定保持。赋值后再次核原方程与完整末态，不能借身份赋值隐藏残差。预算 B=0 的 STICK／SLIDE 仍按原最低 row ID 规则切换到 ZERO；B>0 的 ZERO 切换到 STICK。每次只改变一个模式并计入原 32 次，检测重复。不能在冗余分支同时批量改变 N／T 模式。

实际速度始终由 `v=v0+WJᵀλ` 重建。即使数值零方向检查通过，也必须重新验证完整 double／float 160 行、当前模式、耗能、逐体账本、总动量／角动量，以及最终统一限速后的实际 float 模式。失败不写回，保留最后合法公开快照与错误锁存。

## 实施顺序与可失败验收

1. **只做数学夹具**：固定第 147 帧完整输入／receipt／矩阵，验证旧 rank 候选仍明确失败，新一维候选在固定成本内通过。独立重建 `J55−J155+J156=0`、反力可行区间、合成冲量不变和全部原末态门槛；第 29 帧满秩回归仍通过。
2. 覆盖特解符号错误但可通过一维分配修复、零点／区间端点／无界端、空区间、零系数矛盾、非零 T0、真实 receipt 余量、零预算切换、不同质量和滑动方程。明确拒绝 rhs 不相容、二维冗余、会改变速度的零方向、数值近退化、非有限及 float／cap 末态失败，输出保持。夹具无法成立就停止复核。
3. **独立审查通过才连接另一私有目标**，保留旧有限块失败候选及报告。默认无宏模块仍与认可模块逐帧一致，验证锁存／显式 reset；不替换正式或认可 DLL。
4. 执行原默认 36,000 帧、两向各 6,000 轨迹帧加同一世界 36,000 零输入帧。保留原 1,180 采样点、跨度<0.003、扁形／绘制／穿地／健康要求；任一提前故障或无样本均失败。
5. 长期项通过后才执行九组大小／软度、飞行回圆／松手恢复、新候选 35＋35，最后打开真实 WPF 对照窗口，等待用户验收扁形与拖甩手感。
6. 固定候选失败时，保存输入、原／缩放矩阵、秩／相容／零方向残差、α 区间及选值、全部模式／成本／末态，停止设计复核，不扫描维数、系数、容量或预算。

批准仅授权上述隔离顺序，持续推进至固定失败复核或人工验收。不授权生产捏脸／持久化集成、多人、正式 DLL／安装切换、合并 main、推送或部署。本固定帧的可行诊断不保证其他轨迹支持，更不证明原镜像漂移已修复。
