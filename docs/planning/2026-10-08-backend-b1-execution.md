# B1 邮箱账号实施与验收

状态：实施中，未验收。承接用户“继续”与邮箱后端首期批准设计。

## 范围与所有权

根分支负责共享输入与实体、模型迁移、注册事务、正式 HTTPS 入口和工具。邮件、会话密码、验收测试分别在独立 Worktree 实现，从共享合同提交开始，按依赖顺序集成。保持 Phase 2A 管道原型入口；正式模式不映射匿名 Hub。配饰不作为前置依赖，注册只接受外观 Schema 3。

## 先建立能失败的门禁

- 规范化邮箱、密码边界、七字段外观校验、256 位继续秘密、未知字段与重复字段拒绝。
- 邀请与继续秘密绑定；GET 不消费；旧代际、到期、用途混用和旧 generation 拒绝。
- 同一完成键竞争只产生一套账号／Pet／默认房／成员／归属；每个创建步骤故障均整体回滚；完成重试不改密码／外观，不发会话。
- 登录锁定、绝对过期、每次 Cookie 查库、本人会话撤销、禁用／恢复锁定、找回与改密原子撤销旧会话。
- HTTPS、Origin、框架 CSRF；所有写入均需要证明，无 Origin 不豁免；正式启动不迁移。
- 真实 PostgreSQL 独立连接 + 受控 loopback SMTP；有限重试、租约恢复、SMTP 接受后故障可能重复，证明最多消费一次；重启继续验证未过期证明。

## 数据操作边界

源码生成迁移和静态门禁先完成。真实 B1 迁移、虚构账号写入、外部测试密钥及受控 SMTP 所需目标另列精确操作计划，获得授权后执行。B0 数据保留，不重置／删除／还原，不访问既有 PostgreSQL 服务；真实 SMTP 和还原演练后置。结果分列自动门禁、实时行为、人工验收和 Git 状态。
