# 配饰编辑与佩戴界面交接合同

日期：2026-10-26；2026-10-28 按用户明确纠正更新右下三页、列表改名及侧栏对齐。状态：**已获本地实现授权，代码进展见验证记录，本版人工视觉验收待完成。**

配套：[机制与工具](2026-10-26-accessory-skeleton-mechanism-and-editing-design.md)、[实施入口与验收映射](2026-10-26-accessory-skeleton-implementation-plan.md)。共同规范：[桌面界面规范 v0.1](../desktop-ui-design-v0.1.md)，日期 2026-10-10，第 2–6 节；参数、滚动和动画尺寸仍按该规范区分视觉起点与实际验收。

## 1. 来源、优先级与页面职责

- 用户最新明确：右下分别为图层列表、骨架参数、图层参数三个竖向Tab；“全部显示图层”只指图层Tab，不改变骨架参数页面。删除底部参数栏；骨架参数中不提供组名编辑框，图层／组改名在列表双击或右键执行。上下侧栏在展开和收起时对齐。
- 用户已同意：右下使用“图层／骨架”页签、画布铺满而面板浮于其上、收起不改变缩放和位置、顶部按功能分组、提示移开恢复当前工具用法，以及暖白／棕强调。缩窄时先用图标节省空间，工具整组排成两／三行，并设最小窗口，不挤小控件。列表超出容量通过竖向滚动保证对象可达，图层组可收起；不新增独立骨架界面。
- 用户最新明确：拖根只移根；外层独立整体重力；伸缩 0–50%、默认 0%、对称。本文不能退回旧样板中的继承重力、整条链随根平移或 0–10% 范围。
- 本文补齐默认包括具体折叠初始状态、菜单展开形式、快捷键分配与组管理细节。这些有明确可执行值，来源是设计补齐，不冒称用户逐项指定；数值手感与命中尺寸在 S0／S1 校准，改变用户可见语义须记录差异。
- 旧交互 HTML 和用户参考图片仅作来源。旧 HTML 的操作、颜色、继承机制与独立骨架页面不作为实施依据；参考图只取紧凑排版，保留 Dango 暖白与细棕强调。

## 2. 内外层属性归属（UI-01）

| 所在位置 | 字段／功能 | 说明 |
| --- | --- | --- |
| 编辑器 | 配饰名称、图像像素、图层／组、P、各组 R/J、挂接引用、初始几何、绑定 | 名称可编辑；外层只显示名称与缩略图，不再维护第二个名称编辑入口 |
| 编辑器组属性 | 弯曲幅度、伸缩弹性、组重力、形变阻尼、形变恢复 | 一组一套，选组或其图层显示同一套；不受外层默认值控制 |
| 外层，与进入编辑器同级；编辑器预览模式共用同一份草稿 | 选择团子挂点 A、佩戴大小、基础角度、前／后显示层、连接强度、最大行程、整体转动设置、整体重力响应 | 属于当前团子的佩戴关系；预览修改在编辑器确认时一起返回外层草稿，外层应用才保存。预览不修改佩戴开关及配饰间排序，后两者仍由外层管理 |
| 视图／工具会话 | 缩放、平移、选区、工具、面板展开、续画起点、临时挂接、试摆动态姿态 | 不进入成品图，不作为持久佩戴或骨架定义保存 |

外层修改 A 的操作不修改 P；修改 P 不改变团子 A。挂点 A 在真实团子预览选择，不提供一对常驻 X/Y 滑条。P 与骨节在画布上修改，以方向键微调。

## 3. 外层排列与折叠（UI-02）

固定可达：进入编辑器、选择团子挂点、尺寸、基础角度、整体重力响应、叠放，以及既有草稿应用／取消／复位区。左侧只显示当前已选配饰的一张缩略图，名称显示在图片上方，预览不使用选中卡片边框或底色；右侧为缩短并竖排的“编辑配饰”和“团子上选支点”。此处不再列出多件配饰或滚动选择，切换配饰仍由配饰库负责；移除原大预览、名称框和佩戴复选。当前缩略图跟随草稿选中项更新，双击／右键仍可佩戴或取消佩戴。

创建新配饰直接打开 512×512 透明画布工程，不再先弹出选图对话框；取消编辑保留待完成草稿，外层取消恢复保存状态，只有完成有效编辑后才能应用。

默认收起的两组：

| 折叠组 | 展开后的内容 | 收起时摘要 |
| --- | --- | --- |
| 连接 | 连接强度、最大行程 | 使用同一参数格式显示“强度 100 · 行程 75%”等当前实际值 |
| 整体摆动 | 锁定整体转动、旋转阻尼、整体回正、限制摆角与最大摆角 | 锁定时显示“已锁定”；否则显示回正与当前摆角限制 |

这些摘要不另造第二套输入。锁定整体转动时，转动专属参数保留值并禁用，显示原因；整体重力对平移的部分仍生效。关闭摆角限制只禁用最大摆角输入，不把它重置或丢弃。

“显示位置”更名为**叠放**，同一行保留四个按钮，次序为：

| 按钮 | 行为与状态 |
| --- | --- |
| 团子前 | 与团子后二选一，持续显示选中态 |
| 团子后 | 同上，切换整件配饰所在身体前后层 |
| 上移 | 只在当前前／后区内移动一次；到顶禁用 |
| 下移 | 只在当前前／后区内移动一次；到底禁用 |

前／后切换保留既有对应位置规则；上下移不自动切换前后。删除单独归属对象操作，不混入四按钮；不再出现独立“同层顺序”面板。组骨架挂接和内部图层排序不会改变整件前／后设置。

## 4. 编辑器结构与初始状态（UI-03）

中心画布占主要面积，使用透明棋盘和适量外边距。名称位于轻量顶栏；撤销／重做、视图控制及编辑器确认／取消保持可达，不能随右侧滚动消失。

左侧为窄图标工具列，包括图片、图像调整、修改／绘制骨架，以及平移／缩放／画布扩展。恢复像素紧邻橡皮下方，其笔径归属顶部当前工具参数。工具悬停与键盘焦点显示中文名称和已有快捷键；左下单行显示用法，移开恢复当前工具用法。画笔等当前工具参数直接铺在顶部独立功能组，与顶部其他工具对齐；文字工具常驻字体、字号、加粗／斜体／下划线，颜色使用右上调色盘，删除线、描边、字距和行距收进“更多”图标；骨架工具不展示无关笔径、字体等输入。

右上调色盘短、右下对象面板较高，两块独立向右收起。画布工作区铺满，收起直接露出原被遮挡区域，不重新缩放或移动画布。透明棋盘只覆盖文档边界，与图案／骨架采用同一世界坐标变换；外侧留白用于平移和缩小查看，操作不改变工程、图片或撤销历史。

右下最右侧为“图层／骨架参数／图层参数”三个竖向图标Tab，分别切换右下内容；悬停显示名称，上／下方向键循环，Home／End到首／末项。图层Tab中六个动作和归属提示之外的全部高度均属于列表，不预留数值区。骨架参数保留组选择、根来源和数值；图层参数单独一页，不再占用列表空间。无底部参数栏。

两个右侧面板使用相同296px宽度与右边距，展开时左右边缘对齐；收起时统一保留40px工具列，按钮左缘一致。收起对象面板保留三个Tab，点击恢复对应页。短窗口的骨架基础／细调在原页面内切换，细调展开时显示“返回基础参数”，不搬走或隐藏整个参数页；普通高度仍直接展开细调。

| 区域 | 默认直接可见 | 默认折叠／按需显示 |
| --- | --- | --- |
| 右上调色盘 | 顶栏并排显示当前颜色、可编辑色值、调色／通道／色板三个图标；不再显示“调色盘”和“色值”重复标签 | 一次显示一页以保持紧凑，调色区域占满顶栏下的可用空间；复用 miniPaint 的真实颜色控件，不另造颜色模型 |
| 右下图层Tab | 可滚动的图层／组列表；新建层／新建组／复制／光栅化／下移／上移六按钮同排；显隐与行尾删除 | 整页用于对象列表，双击或右键名称重命名；不保留参数占位 |
| 右下图层参数Tab | 选中层的数值和组操作 | 复用原miniPaint控件，不复制模型，不搬到画布底部 |
| 右下骨架参数Tab | 组选择、根来源、弯曲／伸缩／重力与细调 | 移除组名编辑框，改名归属列表；小高度下在页内切换基础／细调，参数仍在右下 |
| 左侧工具 | 选中工具与工具切换；图像调整入口；平移／缩放／画布扩展一组；橡皮下方为恢复像素 | 各工具选项随工具显示；恢复笔径在当前工具参数中；图像调整弹出设置，非激活时收起 |
| 视图 | 缩放值、适合画布、100% | 透明画布扩展与平移／缩放同组，裁剪为独立工具，整图翻转和旋转位于图像调整；这些内容操作保留各自原有行为 |

组属性始终说明属于哪个组；选中未分组层不自动创建组。跨组多选显示活动组名，仅编辑该组属性，不能把一个滑块默认为批量写入所有组选中对象。

工程尺寸起点：默认原生窗口 1120×760 DIP、最小 800×640 DIP，浏览器外边距 8 DIP、原生动作 32×32 DIP。右侧两面板宽296px，保持六个32px按钮和8px间距同排并对齐。顶部各功能组可换两／三行，不拆组；短窗口左侧可排两列图标以保持全部工具可达。最终 DPI 与前台视觉仍需验收。

2026-10-27 用户进一步明确：移除原生整行标题栏及可见“编辑配饰”字样，最小化／最大化或还原／关闭三个按钮参照首页。共用首页窗口按钮模板，右上保留 132×38 DIP 原生按钮区域，不另占一整行。任务栏／辅助名称保留，不成为画布上可见标题。

P、R 和骨架线平时隐藏；进入任一骨架工具，或展开右下骨架参数页时，显示全部辅助结构，区分 P、各组 R/J、活动组与选择。仅打开参数页不切换图像工具，辅助线不拦截图像输入；离开／收起参数页后，显隐继续由骨架工具决定。辅助线绝不导出进图片。

## 5. 图层组管理补齐默认（UI-04）

本节来源为设计补齐，配套机制第 12 节记录理由：连续块简化遮挡顺序，显式重排避免透明图层在归组时偷偷变样。

- 一组一根一条链；组不嵌套。组可为空，根可无骨段；未分组层合法，跟随整件 P 姿态。
- 图层列表以文件夹组名和成员数量为父行；成员真实嵌套于组下，使用缩进、纵线与连接线，未分组层保留在列表根部。当前图层旁显示“组：组名 / 层名”或“未分组 / 层名”。这里只表达图像归组，不把骨架连接关系变成嵌套图层组。
- 点击组名保持图层页，以便查看成员；骨架工具或最右侧骨架图标进入骨架参数。组标题有独立展开／收起按钮，折叠只影响当前会话列表显示，不改变图像顺序、显隐、工程归属或撤销历史；图层列表竖向滚动，操作区和归属提示固定。
- 图层与组在列表双击或右键菜单重命名，共用中文输入对话框；按目标ID修改，支持取消、输入验证、IME与撤销／重做，不随当前活动组切换而改错对象。
- 新建组立即建 R；普通新建根初始位于 P，从骨节创建组则新 R 引用该骨节。只改活动组／选中根，不搬走已有图层或父链后缀。
- 多层归组仅接受连续区间；跨组或不连续选择拒绝并给原因。显式拖层进入组时显示插入线和最终顺序，作为一次可撤销动作；脱组移到原组相邻边界并预览结果。
- 拖动组标题或上下移会移动完整连续块，组内层随之移动；列表顺序同步实际绘制层级，不由骨架父子决定绘制前后。拖至组标题上沿可在组外插入，拖到标题主体则进入该组；拖动到列表上下边缘时自动滚动，可把图层或整组移到当前可见范围之外。空组可相对其他组排序并保留；现有工程格式不能表达空组与未分组图层之间的任意位置，操作被拒绝并提示先加入图层。
- 删除组保留图层、按原顺序脱组。若其他组引用其 R/J，拒绝删除并提示先改接／解除；不连带删除子组。删除图像内容另用图层删除，不由“删组”暗中执行。
- 图层与组的删除入口都使用同一垃圾桶图标并放在各自行最右侧；点击组行的垃圾桶只删除该行的组，不依赖当前活动组，也不必打开顶部菜单。保留同一可撤销命令与引用拒绝原因，退役原工具行删组入口。
- 组为空不清理骨架；删光普通节点保留 R；无图像的结构组可以驱动子组。只有根的有图像组刚性跟随其动态根姿态，不停在世界原位。

## 6. 紧凑滑条与动作图标（UI-05）

滑条用参考图的排版关系：左侧独立小图标；右侧上行左为短名称、右为**可编辑数值与单位**，下行是细轨道。去掉每个参数各自的厚卡片和大圆形色底，不复用参考图紫红主题。

沿用规范第 4.1 节起点：3 DIP 轨道、12 DIP 圆滑块、28 DIP 实际操作高度。仅缩小视觉密度，不缩小命中范围；滑条和数值直接跟手，无数值缓动。非法输入显示原因；数值／滑条／键盘进入同一草稿更新路径。参数实际单位和范围不同，不能全部改成百分数。

规范第 2、4 节继续适用：同族细线图标、圆角端点、语义颜色；纯图标按钮 32×32 DIP、图标 20×20 DIP，同组间距 8 DIP。编辑器按用户本次明确要求以纯图标为主；参数标签、实际值、单位、名称和错误继续保留文字。

以下给出功能与图标意象的完整分配，实施为可复用矢量图标，沿用项目同义图标；不引入一套表情或彩色位图。含义接近的动作通过辅助名称区分。

| 功能／属性 | 图标意象 |
| --- | --- |
| 名称／重命名、佩戴、进入编辑器 | 标签＋笔、勾选圆、方框＋笔 |
| 团子挂点 A、配饰根 P | 团子轮廓＋定位点、图像方框＋十字靶心 |
| 尺寸、基础角度、整体重力响应 | 双向尺寸箭头、弧形角标、整体轮廓＋向下箭头 |
| 连接、连接强度、最大行程 | 链环、链环＋短强度线、两端限位的双向箭头 |
| 整体摆动、锁转、旋转阻尼、整体回正、摆角限制 | 摆动弧、锁＋弧、弧＋减速线、回到竖线的弧箭头、两条边界射线 |
| 团子前／后、上移／下移 | 参考图的前后叠方框、上／下折角；不混用为图层透明度 |
| 图层／组、可见、透明度 | 单张层片／层片文件夹、眼睛、半填圆 |
| 创建／复制／删除、收起／展开 | 加号、重叠层片、垃圾桶、旋转折角 |
| 修改骨架、绘制骨架、根来源 | 骨节＋移动箭头、骨段＋加号、节点间链环 |
| 弯曲幅度、伸缩弹性、组重力 | 弯折骨段、骨段两端伸缩箭头、骨段＋向下箭头 |
| 形变阻尼、形变恢复、形变细调 | 振幅递减波、曲线返回虚线初始形、微调横杆 |
| 选择、画笔、橡皮、恢复像素 | 箭头指针、画笔、橡皮、笔尖＋回转箭头 |
| 魔棒、填充、文字、裁剪 | 魔棒、漆桶、T、交错裁剪角 |
| 图像调整、旋转／翻转、画布扩展 | 调节横杆、弧箭头／镜像轴、外扩边框 |
| 平移、缩放、适合画布、100% | 手掌、放大镜、四角框、1:1 |
| 撤销／重做、试摆、确认／取消／复位 | 左右回转箭头、播放／暂停、勾／X／回转箭头 |
| 挂接／解除挂接、插入骨节、选中所在骨架 | 链接／断链、线段中加点、骨架外选择框 |

菜单项复用对应图标，保留短动作文字。纯参数没有快捷键时不显示假键位；工具悬停及键盘焦点说明必须包含工具名与已分配快捷键。

## 7. 快捷键与输入归属（UI-06）

V/B/E/G/T/C/H/Z 等沿用常见图像编辑习惯；魔棒 W、P 及 Shift 组合是本产品分配，不能宣传为所有软件的行业标准。骨架 K／Shift+K 是本文补齐默认，两个工具不得占同一个键。

| 工具／动作 | 键位 | 范围 |
| --- | --- | --- |
| 选择／移动图像对象 | V | 图像工具；与骨架修改区别 |

## 8. 图像调整、画布与工具保留（UI-07）

Ctrl+C 按明确选择目标复制当前图层或图层组；魔棒像素选区存在时优先复制选区图片。图层组片段包含成员图层、内部骨架、参数及顺序，组外挂接在副本中解除并保留当前根位置；粘贴使用新标识，内部引用重新映射。Dango 内部 Ctrl+V 还原可编辑图层／图层组，整个粘贴仅一条撤销动作；系统剪贴板同时提供透明 PNG 供其他软件使用。文字、数值和对话框输入域优先处理原生复制粘贴；不轮询剪贴板。

显式粘贴图片（Ctrl+V）或将单张 PNG／JPEG 文件拖入画布，将图片新增为独立图层，保留现有图层、图层组与画布尺寸，并进入统一撤销历史；多文件明确拒绝，不部分插入。图片以画布中央为初始位置，超出画布时等比缩小显示；仍受图片与工程资源上限约束。文字／数值输入域和对话框继续使用自身粘贴行为；不主动读取、轮询或记录系统剪贴板。

实现底座沿用 [ADR 0007 决策第 1 项](../adr/0007-accessory-editor-and-rig.md) 的固定版本 miniPaint 本地定制资源及 WPF WebView2：优先复用已有 miniPaint 图片工具、图层、历史和集成，再按本合同定制 Dango UI。S0 几何样板不替代 miniPaint；正式 S5 接回现有编辑器，图片与骨架共用统一工程历史，不保留另一套独立图片编辑产品入口。

保留现有约定的手动绘图、橡皮／恢复像素、魔棒（原“去背景”）、填充、文字、图层、裁剪、旋转、翻转和撤销／重做。每项须有实际图像结果，不能用工具图标存在代替可用。

魔棒选区是临时像素遮罩，不改变图片或工程；橡皮、填充和恢复像素限定在选区内。当前画笔、文字、图层拖动和裁剪不支持像素遮罩，选区存在时阻止操作并提示先按 Esc 取消；整图变换也需先取消选区。像素删除进入统一撤销历史。

图像调整置于左侧工具列，点击展开的设置框紧贴入口右侧并让出工具栏，不保留多余空白。保留当前已提供的调整能力与参数，不据“图像调整”标题追加未设计的滤镜集合；调整影响当前明确对象或整图，执行前显示范围。整图旋转／翻转三个图标在图像调整菜单同排；裁剪是独立工具，透明画布扩展与平移／缩放同组；恢复像素位于橡皮下方，恢复笔径在当前工具参数。上述操作不常驻占据右侧属性。

| 操作 | 工程结果 |
| --- | --- |
| 视图缩放、平移、适合画布、100% | 只改变查看方式，不改图片尺寸、P、骨长或参数 |
| 透明画布扩展／裁剪 | 改变像素坐标系、尺寸或可见内容，作为可撤销工程操作 |
| 整图旋转、翻转、实际重采样 | 同步变换像素、P、所有组 R/J 和绑定输入；不重复施加佩戴大小／角度 |

不保留独立常驻“画布调整”面板。实际变换后若根／链超出合法边界，保留草稿与可撤销操作、标明需修正，阻止无效结果确认；不夹点、不拆挂接、不静默丢组。参数／几何变化更新试摆快照并拒绝旧输出；试摆不改初始几何。

## 9. 展开动画、滚动、焦点与提交（UI-08）

依据规范第 5、6 节：本编辑器两块右侧面板向右收起，采用约 180 ms 平移作为校准起点，可中断／反转，不改变画布查看姿态或抢焦点；减少动画时立即切换。实际滑条、节点拖动、指针和数值不加缓动。

本编辑器右下图层页以常驻细条滚动显示长列表，必要操作固定；最小高度下骨架基础／细调在页内切换，参数不搬家。其他仍可滚动的原生内容沿用共同规范。画布滚轮用于缩放；收起后不得留下透明输入遮挡层。

编辑器中“确认”回传完整定义草稿；外层“应用”才写正式存储。编辑器取消恢复打开前的全部编辑草稿，外层取消恢复保存值。编辑器确认按钮不设为会吞噬画布 Enter 的全局默认提交按钮；退出时若存在未完成临时操作，先处理该操作，再明确执行确认或取消。

选中、悬停、按下、键盘焦点和禁用均有可辨识状态；菜单、失败原因和确认不能只有颜色／图标。控制中心的团子焦点规则遵循规范第 4.3 节，独立编辑窗口保有画布与表单输入域；关闭菜单不能在后台抢前台焦点。

- 独立配饰编辑窗口打开的整个期间，暂停背后控制中心的团子owner与呈现，并清输入；确认、取消、异常退出后按控制中心当前可见／页面资格恢复。外层换装页自身仍保留预览；不暂停其他房间或进程，不新建第二个后台owner。
- 模拟场景的左右可视边缘使用显式启用的真实侧墙接触，持续碰壁后可以反向离开；不能把越界guard报错当作碰撞停止。默认身体／门廊的边界保护语义不随模拟功能改变。
- 预览空间直接用正式native身体和配饰求解／WPF绘制。中央WebView HWND按有效视口挖洞露出原生surface，不以放大288×160PNG代替；底层单场景只有一个物理推进者。该临时场景与外层团子位置隔离，不写存储；没有新增外部依赖、同步或用户数据迁移。
- 佩戴改变与图片／骨架使用同一miniPaint撤销栈，wear动作不触发像素导出；骨架／图像变化才更新完整有效预览定义。Native只接受完整13字段佩戴白名单，不允许改图片P、资产身份、佩戴开关、Order或其他配饰。确认返回完整项目与当前佩戴值，外层应用才保存；取消恢复打开前草稿。
