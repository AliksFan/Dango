# 后续双模式方向备忘

日期：2026-09-20
状态：仅记录用户确认的方向；具体设计以后开展，当前回到固定本地启动、更新与回退批次的收尾。

## 已确认的方向

- 岛的设计暂时搁置，不再作为近期下一功能的默认安排。
- 桌宠模式：每个房间最多两人，利用双方桌面的共同性和真实窗口产生互动。
- 房间模式：提供多人贴贴的独立活动空间，不与真实桌面互动；人数上限尚未确定。
- 桌宠模式的构想：双方界面大致静止一段时间后，扫描画面中的线条，包括窗口边缘、文字行等，选取合适线条作为两只团子的活动空间。OCR 或直接读取均是待评估手段，尚未选型。
- 同一个平台可以在双方映射到不同位置，不必重合，但位置差不能太大；容许偏差尚未量化。

## 留待以后设计

稳定时长、扫描及筛选方法、平台配对与失效处理、数据处理及同步边界、模式切换规则和详细验收标准均留待后续设计。讨论中提出的水平/垂直偏差 5% 只是助手建议，未获用户确认，不作为实现参数或验收门槛。

本记录不批准新功能实施，也不将旧基线中与上述方向冲突的桌面/房间耦合及岛安排继续视为当前要求。产品、服务端和阶段计划的系统性修订留待具体设计时进行。

当前批次进度以[固定启动、更新与回退计划](2026-09-20-local-launch-update-plan.md)及其验证记录为准。
