## 2. 当前代码事实

- `ProductHomeView.xaml` 的换装入口已有已认可的左侧面板，内容仍是禁用的帽子、皮肤和自己制作占位；本次替换其中配饰内容，不改捏脸参数。
- `StackedDangoSceneRuntime`、`DangoHatVisual` 与 `DangoHostFrameBinding` 当前处理一个旧帽标识。旧帽运动使用头冠轨道与固定素材根部；不能直接换成任意图片获得任意身体位置的单支点配饰。
- `DampedSpring`、`AttachmentStepClock` 和附件场景生命周期可复用。身体成功帧、实际运动差分、唯一帧驱动和暂停／恢复边界继续沿用；旧帽的头顶多点接触规则不套用到新单支点模型。
- `HatDeformationGeometry` 修改旧矢量帽子的 Path。仓库当前没有可直接复用的任意图片网格形变器；图片弯曲／拉伸需要新的渲染与求解路径。
- 自身 `appearance.json` 使用独立 Schema 3 且严格校验字段。配饰不混入该文件；主设置里的旧 `HatPresetId` 也不能直接写入新配饰 ID。
- 首页、Window、Wallpaper／overlay 与本地普通房使用多个画面接线点；一处预览成功不能证明全部可见宿主已接线。

以上为设计批准前的只读代码核对结果；本轮实现和实际验证另见实施验证记录。

## 3. 用户流程与图片编辑器

沿用 A／T 恤的“换装”入口，面板仍从左侧展开，当前同一只实时团子在右侧预览，尺寸、接地高度和阴影保持已认可规则。配饰是换装内容，不进入自身捏脸。

用户随后要求“ui方面和捏脸模块对齐”。换装保留左参数／右预览的镜像方向，改用捏脸相同的暖白资源、字体、滑条、32 DIP 线性动作图标和状态文字；顶部放预览说明与收起按钮，应用／取消／当前配饰复位固定在预览下方，不随参数列表滚动。参数按功能组织，图片弹窗也使用同一主题，不增加官方配饰分类或改变保存边界。

面板提供配饰库、已佩戴列表、导入、佩戴／摘下、复制和当前项编辑。每件都能命名；不提供官方类别、用途推断或分类专属参数。允许无配饰。复制共享不可变图片数据，但具有独立支点、尺寸、角度、运动参数和排序；修改一个副本不改变另一个。

导入后进入图片编辑视图：透明棋盘格、原图、图片支点标记、尺寸与基础角度控制。图片支点允许放在透明像素处，位置按原画布归一化保存；不按透明边缘偷偷裁图或挪动支点。团子附着位置在团子上选择，也提供归一化位置数值与复位，避免仅靠鼠标才能精确操作。

区分“画布缩放”和“配饰尺寸”：前者只方便查看、不改变佩戴结果；后者改变实际显示大小。旋转修改配饰基础角度，围绕图片支点进行。全部使用非破坏性参数，不反复重采样或覆盖源图。首版不增加裁剪、绘画、抠图、色相和分区材质编辑。

编辑器确认只把结果返回换装草稿，尚不写入正式配饰库。换装页显式“应用”才提交整套草稿；“取消”、离开换装、隐藏或关闭编辑区恢复最近已保存结果。编辑器内部取消只撤销该次编辑，保留进入编辑器之前的换装草稿。

图层选择为“团子后／团子前”，配合上移／下移调整组内顺序。前配饰覆盖整个团子图形，包括眼睛；不暗中抬高眼睛。以后若需要一件素材同时跨前后层，再独立设计多素材配饰；首版可通过两件配饰自行组合。

文字框、滑条、图片拖动、支点选择和弹窗消费自己的输入，不穿透触发团子移动、跳跃或导航。实际配饰图层不拦截桌面／场景命中；只有编辑状态的工具覆盖层可接收编辑输入。

## 4. 支点、形变与运动语义

### 4.1 两个坐标位置，一个连接

图片支点采用原画布的归一化坐标；身体附着位置采用团子显示局部坐标。缩放、旋转、DPI、相机平移、换宿主后，两者仍表达相同位置。身体映射使用当前有效完整身体帧；不把可变的原生节点数组编号直接作为长期身份。

低连接强度时，图片支点可在团子附着位置附近弹性偏移，因此不是任何强度下都要求两个点瞬时重合。固定连接模式要求两点重合；柔性连接要求偏移有界、不脱落，并能在运动结束后收敛到当前受力下的稳定平衡位置。重力非零时允许持续的弹性偏移与下垂；恢复原图或零偏移的门禁须关闭重力并撤除持续激励。图片内部变形仍以其单支点为根，不额外添加对团子的隐藏支点。

### 4.2 相互独立的用户参数

| 参数 | 用户感受到的结果 | 边界 |
|---|---|---|
| 柔软度 | 整图更易弯曲／拉伸并恢复，0 为刚性图片 | 统一材质；不提供分区笔刷，不无限拉长或翻折失稳 |
| 连接强度 | 支点紧跟或产生弹性位移 | 只影响连接，不代替图片柔软度；0 仍有安全最低连接 |
| 旋转阻尼 | 摆动更快衰减或持续更久 | 不宣称高阻尼等于锁定 |
| 朝向锁定 | 保持用户设置的基础角度，不因单点摆动转偏 | 锁定整体角度，内部柔软形变仍可发生 |
| 回正强度 | 偏转后更快／更慢回到基础角度 | 0 可不回正；与阻尼独立 |
| 最大摆角 | 相对基础角度限制整体摆动 | 可关闭限制；限制与锁定的优先级明确 |
| 重力影响 | 下垂程度，0 关闭重力 | 不改变团子的质量、速度或碰撞；不收集真实桌面数据 |

旋转锁定优先于摆角和回正；旋转未锁定时，回正、阻尼和摆角共同作用。角度始终使用有限数并处理周期，不因多次转动积累数值溢出。

整图统一柔软度可以让内部网格发生不同位移，从而产生真实的图片弯曲和拉伸；“不做局部分区编辑”不意味着只做整体缩放或整体摆动。它不需要用户先画权重，但需要工程上的网格、恢复约束和纹理映射。重力、实际团子运动和连接变化驱动表现；不使用按键触发的固定动画冒充响应。

### 4.3 技术候选及安全边界

优先使用现有 WPF 图片解码、变换与绘制能力，不提前引入渲染依赖。刚性模式直接使用图片变换；柔性模式先验证有界网格与纹理绘制。具体绘制方式、网格密度和系数映射在技术小样通过后记录，不把尚未测试的方案写为已批准技术。

所有配饰只读取身体状态，不创建碰撞体、修改 native 求解或施加反作用。配饰求解随唯一成功身体步推进，同一帧可被多个宿主只读消费；刷新草稿和切图不额外 Tick 身体，不新增物理世界。暂停、隐藏、失败、切换宿主、实体移除和代际变化都有明确清理／恢复规则，不能把长时间间隔一次积分成巨大冲击。

为响应稳定性设置引擎内部的位移、拉伸、速度、求解预算和资源边界，不把诊断数值全部开放给用户。推荐首版最多同时佩戴 8 件；列表可保存更多，图片惰性解码。上限属于本候选的资源策略，需技术小样验证；不得通过自动隐藏、忽略参数或静默降低柔软度来声称通过多件性能验收。

默认新导入配饰以刚性、紧连接、锁定朝向、无重力显示，保留图片造型；用户逐项打开柔软度、弹性、旋转和重力。提供当前配饰参数复位和整套换装取消，不通过“恢复默认”删除用户图片库。

## 5. 配饰数据与本地保存

新建独立、版本化的配饰清单与内部图片目录，沿用当前设置根目录解析；不提交个人绝对路径。设计语义区分不可变图片资产、可复用配饰参数和本地佩戴状态。当前 Schema 1 已分离图片资产，但 `AccessoryItem` 同时包含配饰参数与本地佩戴状态，没有独立的配饰定义／佩戴实例引用结构；副本通过独立条目 ID 和参数快照隔离。第二轮不改清单 Schema、不迁移现有数据，也不把当前实现描述为定义与实例已经拆开。图片资产共享，副本参数独立；没有官方类别字段。

清单记录稳定 ID、名称、图片资产 ID、原始尺寸、支点、基础变换、运动参数、佩戴状态和图层顺序。图片区块、颜色蒙版或身体贴合能力未来通过版本化扩展加入，首版不写无效占位参数。动态速度、当前网格形变和每帧坐标不持久化；重启从保存的基础配置开始。

首版建议导入静态透明 PNG，文件选择器默认 PNG 并保留全部文件过滤入口；非 PNG、损坏或多帧文件明确拒绝。候选图片边界为压缩文件不超过 16 MiB、最长边不超过 2048 像素、总像素不超过 4,194,304；在解码前后分别校验。超限明确提示重新准备图片，不静默裁剪或降低原图质量。全透明或完全无透明像素的图片给出明确不满足本期素材要求的错误。

导入不修改源文件。保存时复制并规范化为内部 PNG，去掉非必要元数据，只保存内部资产 ID 和相对资产引用，不保存／日志输出原文件路径；源图片移动或删除不影响重载。

提交顺序为：校验整套草稿 → 写入并验证新增不可变图片 → 原子替换正式清单 → 更新最近已保存状态。清单替换失败时原清单仍能重载，草稿可重试或取消；已写入但未被引用的内部图片不被当成已保存配饰，也不自动清理用户其他数据。新增文件、暂存文件与测试资源残留在验证记录中如实报告。

取消和编辑器确认均不写正式清单；通用窗口几何保存、延迟保存和退出保存不能偷偷提交换装草稿。单个图片损坏或丢失时仅隔离对应配饰并提示，保留其配置及其他配饰；不假装已完整恢复。编辑其他配饰后应用，仍须写回未修改的隔离项配置，不能把不可显示项过滤掉；恢复相应内部图片后应能再次读取。坏清单或未来版本受保护，不自动覆盖，恢复需单独明确操作并先备份。

## 6. 旧帽与各宿主兼容

推荐保留三种现有素材为无类别的内置配饰条目，使用统一选择／摘下／编辑流程；它们不是新的官方“帽子分类”。首次没有新配饰清单时，根据旧帽字段生成内存兼容配置，维持最近保存的旧外观；不在启动时自动迁移写盘。

显式应用后，新清单成为配饰显示依据，合法空佩戴列表表达“摘下全部”。旧 `HatPresetId` 保持既有兼容意义，不存新配饰 ID；新清单有效时不得再额外画一个旧帽。兼容模式与新配饰模式必须保证每件只显示一次。如何把旧矢量素材规范化为内部图片，在小样中确认；本候选不承诺完全复现旧帽专属轨道运动。

| 加载状态 | 显示与保存规则 |
|---|---|
| 新清单不存在 | 才使用旧帽的内存兼容配置；启动不写迁移 |
| 新清单有效，佩戴列表为空 | 显示无配饰，不回退旧帽 |
| 新清单有效，单图损坏／丢失 | 仅隔离该项，保留清单记录与其余有效配饰，不回退旧帽 |
| 新清单损坏／未来版本 | 保留原件并禁止普通应用覆盖；保留可用内存画面，首次无可用状态时只显示身体并提示未恢复，不伪装为清单缺失或回退旧帽 |

当前多团子画面存在“全部身体之后再画全部帽子”的旧规则。本次候选改为以每个团子为单位组合“后配饰 → 身体／脸 → 前配饰”，实体组沿用场景实体顺序；这是新的配饰遮挡合同，需要双团子交叠反例验证，不声称当前代码已具备。避免所有团子的前配饰无条件位于整个场景最前方。保持当前主要团子的稳定实体身份，不把其用户配置套到诊断生成的其他团子。

首页实时预览、门廊显示、Window、Wallpaper／overlay 和本地普通房的可见团子路径列入接线与验证。显示包围范围按配饰实际变换／形变更新，避免旧帽固定顶部余量裁图；该范围不改变身体碰撞或命中区域。

多人同步、服务器资产上传、云端持久化、审核、分享、手机显示和创作者市场不在本地阶段。本地成功不宣称远端客户端能够看见 DIY 配饰。

## 7. 可失败的验收

1. 两张不同透明 PNG 可导入、分别编辑、同时佩戴并独立保存；移动源文件后重启仍恢复原图与全部配置。复制一件后修改支点、角度或柔软度，原件不变。
2. 改图片尺寸、角度、画布缩放与 DPI 后，图片支点含义不变；刚性连接在团子移动、挤压、跳跃与换宿主时保持绑定。柔性连接允许不同有界偏移，不误用固定点重合门禁。
3. 同一身体输入下，柔软度 0 保持各纹理点相对距离，非零柔软度出现可测的相对位置变化；关闭重力并撤除激励后恢复，持续重力下收敛到稳定下垂形态。只有整体摆动的错误实现必须失败。
4. 同一身体输入下，低／高连接强度产生不同的弹性跟随；阻尼改变衰减、回正改变恢复、锁定保持基础角度、摆角限制有效。重力 0 与非零产生不同下垂，且没有添加身体支点或碰撞。
5. 前／后切换和组内排序真实改变遮挡；透明边缘没有底色、明显网格缝或重影。前配饰覆盖脸时不会被偷偷重排。双团子交叠时遵守实体组顺序，不把后方团子的前配饰置于前方团子之上。超出旧帽范围的图片在各宿主不被错误裁切。
6. 相同初始状态与身体命令下，是否佩戴配饰不改变 native 身体轨迹、碰撞结果、物理实体数和步数；换装预览不抢帧 owner。
7. 导入确认、取消、离开、隐藏、通用延迟保存及退出不泄漏草稿；显式应用才提交。图片写失败、清单替换失败、坏图、坏清单、未来版本均保留有效旧数据并准确报告结果。坏清单不伪装为缺失；修改另一件并应用后，隔离的坏图记录仍保留，修复测试图片后能重载。
8. 快速编辑／取消／换宿主后，过期回调不能重新装备已取消配饰；暂停、恢复与重启不产生虚假冲击。30／60／120 Hz 渲染消费同一身体驱动时运动结果保持一致。
9. 8 件配饰、极端但合法组合、较多透明边框及不连续图案的图片通过有界性和目标桌面性能检查。预算和机器条件在实现验证中明确记录，未通过时不悄悄降功能。
10. 各可见宿主分别记录真实运行、磁盘重启和人工观感；构建与单元测试不能代替这些证据。

## 8. 后续候选：配饰可以挂在另一件配饰上

用户于本轮补充并确认“配件的支点可以在配件上”指配饰之间挂接，例如 A 连接 B，B 再连接团子。这是明确登记的后续设想，首版仍只实现连接团子，不把它加入本轮自动／人工通过条件。

推荐后续把连接目标扩展为“团子附着点／另一佩戴实例的图片坐标点”。每件子配饰仍只有一个父连接，允许父配饰承载多件子配饰；资产 ID 不能代替佩戴实例 ID，否则同图副本会指错连接对象。首版保持连接目标模块边界和稳定实例 ID，不提前加入可用的父配饰选择 UI 或无效保存字段。

这是可行性建议，尚非获批实施设计：子配饰应读取父配饰本帧变形后的连接点，不能只跟随父图片未变形时的外框。需要按父到子顺序计算，禁止自连接和循环连接，对层级、总量及速度有预算；暂不引入碰撞或向父配饰施加反作用的双向耦合。

父配饰摘下、丢失或损坏后如何处理子配饰，子配饰的前后层是否独立，以及串联弹性和重力如何稳定，留待该功能的专门设计明确。不得自行选择悄悄删除子配饰、自动改挂团子或假装完整恢复。此候选不承诺兼容全部挂接组合，也不要求首版预先实现未启用的挂接求解器。

## 9. 建议、替代方案与后果

- 整图统一柔软度优于首版分区权重编辑：实现图片自身形变，又不要求提前建设绘画编辑器；代价是暂不能单独设置同一图里不同部位的软硬。
- 独立角度锁定／回正优于仅提高阻尼：阻尼不能保证角度保持；代价是增加少量明确参数与组合验证。
- 统一配饰优于官方类型分支：不按图片用途限制用户；单支点及无碰撞是所有图片共用的本期边界。
- 内部图片副本优于保存外部文件引用：可独立重载并移除原路径依赖；代价是本地存储与多文件提交协调。
- 独立清单优于扩展自身颜色文件或滥用旧帽 ID：保持捏脸和配饰取消／保存隔离；代价是兼容接线与资产管理模块。
- 身体多区域贴合、多素材层和分区染色保持后续独立设计；首版仅提供可扩展模块和版本边界，不声称单张图片加单支点已经兼容所有未来效果。

本轮用户已整体确认并授权本地实施。技术小样失败必须报告原因和建议，不替换柔软度需求、不放宽门禁。完成本地候选后仍须人工验收，Git 合并／推送／安装权限独立；第 8 节配饰间挂接继续为后续候选。

## 10. 实施中的技术选择

配饰使用独立的表现求解器，读取成功身体帧中实际闭合平滑轮廓及步态变换。身体归一化纵坐标选择当前轮廓的水平截面，横坐标在该截面内插值；不会把矩形角落当作身体表面。图片缩放保留完整透明画布，以最长边 64 DIP × 尺寸比例为显示尺度。

统一柔软度驱动连续弯曲／应变场，采样到 8 × 8 网格，并插入精确图片支点；连接与角度分别保持独立弹簧状态。该场取均匀画布材质和画布中心的近似，不解析透明图案的真实质量分布，也不进行多区域身体贴合。选这一方案是为了保持只有一个连接点、材料响应可测且有界；完整节点约束网络和局部材料绘制需要后续单独设计。

WPF 逐三角裁剪／叠画会在半透明接缝累积 Alpha，因此实现将每件配饰的所有三角光栅化到同一张预乘 Alpha 位图，每个像素保持一致覆盖后再由 WPF 绘制。宿主先在 UI 线程准备最多八件的绘制批次，再以最多八个 CPU 工作线程并行计算各件完整源纹理，最后在 UI 线程逐件上传新旧占用区域的并集；单件失败不会丢弃其他有效项。此方案避免每件图片重复建立并行屏障，以及反复上传未占用的透明容量。WPF 对象仍只在其创建线程访问；没有新增依赖或 native 求解入口。纯平移可复用纹理，真实形变和旋转必须重新采样，禁止用平移缓存测量代替软图案性能，不通过缩小源图、DPI、网格或柔软度满足门禁。

新增独立 `accessories.json` Schema 1、内容哈希 PNG、最多 16 项图片缓存，以及未应用导入 32M 像素／128 MiB PNG 的累计预算。磁盘提交结果与显示警告独立，源图路径不会写入清单；出现坏图时保留其配置和其他有效项。内置三图直接从既有作者几何生成透明 64 × 64 画布，支点为 `(0.5, 60/64)`，保持作者图案的名义尺寸。

配饰显示范围用于宿主画面和普通房显示边界。配饰不进入身体碰撞、命中或既有自动移动控制的计算，以维持同样身体输入下的 native 轨迹对照。真实系统 DPI、光栅性能、进程重启与各宿主的证据以专项验证记录为准；等效像素采样不代表切换了 Windows 系统 DPI。

同层同排序值按实例 ID 的 Ordinal 顺序消除歧义。宿主在实际 Children 顺序变化时重排现有 Visual，保留原排序值和纹理，避免跨层切换后因插入先后产生不同遮挡；重复消费相同画面不重排，也不推进身体或配饰求解。

## 11. 已确认的第二轮界面与操作修订

本节依据首版候选的用户反馈，已获本轮实施授权。候选实现和自动／实时检查见[第二轮验证](../verification/2026-10-08-accessory-ui-refinement.md)，人工验收尚未通过；A0–A4 的旧证据和未人工验收状态保留。本轮只调整本地换装体验，不实现分享、上传、云端、多人与配饰间挂接，不更改清单 Schema 或迁移现有库。

### 11.1 左侧分组与素材库

四个分组为“配饰库／图像与位置／柔性与连接／旋转与重力”。分组使用线性图标，在团子预览左侧竖排，参考捏脸的页签位置、尺寸、选中反馈及暖白主题；切换分组只改变当前可见内容，不丢失草稿、换选配饰或保存配置。参数仍在左、实时团子仍在右，复位／取消／应用保持归属预览且不随参数滚动。

配饰库改为每行四个素材图的网格；素材图使用完整透明画布，名称、当前选中与已佩戴状态可辨识。网格允许纵向滚动，不能把文字行或四张固定演示图当作完成。内置与导入素材采用同一选择规则；图片不可用时显示明确不可用状态，保留条目和配置。

### 11.2 创建入口及取消边界

把用户入口“导入 PNG”改为“创建新配饰”，第一步仍选择满足本期条件的静态透明 PNG，随后编辑图片支点／造型和全部配饰参数。该名称表示从图片创建可保存、可复用的配饰，不承诺绘画、裁剪、抠图或空白画布制作能力；选择器保留 PNG 默认过滤及全部文件入口，非法素材继续明确拒绝。

选择 PNG 成功后即新增换装草稿条目，再打开图片编辑模态窗口。图片编辑确认只返回该窗口的参数修改；模态取消仅撤销本次图像编辑，新条目与进入模态之前的换装草稿继续保留。外层取消、Esc 关闭换装或其他既有取消边界恢复最近已保存的整套配饰，包含撤销尚未应用的新条目与图片。沿用现有整套草稿事务，不新增独立创建事务，也不在模态确认时写入正式库。

### 11.3 保存参数与未来分享语义

用户确认配饰应保存一份可复用参数快照：名称、图像、图片支点与身体附着点、尺寸／基础角度等造型、默认前后图层，以及柔软度、连接强度、旋转阻尼、朝向锁定、回正强度、摆角限制／最大摆角和重力影响。当前 `AccessoryItem` 已保存这些字段，同时保存本机的 `IsEquipped` 与 `Order`；当前所选 `Layer` 兼任参数快照的默认图层和本地显示图层，尚无独立模板与穿搭实例。复制仍共享不可变图像、复制独立参数，修改副本不联动原条目。

未来若实施分享，分享内容应包含图像与上述参数快照，身体附着点作为建议的默认佩戴位置；当前已佩戴状态和组内排序属于接收者自己的本地穿搭，不随分享沿用。单独 PNG 不携带支点或物理参数，不能称为完整配饰分享。分享包格式、身份与版本、导入冲突以及定义／实例的独立结构需后续专门设计；本轮不提供分享按钮或文件导出，不提前写入无效分享字段，也不调整现有保存语义。

### 11.4 可操作的实时团子与自由地面

换装预览中的团子接受真实控制：A／D 左右移动、S 压扁、W／Space 跳跃，Esc 关闭换装、撤销未应用草稿并恢复保存值。W 与 Space 映射到同一既有跳跃动作，不增加上行／飞行语义，也不进入门廊或触发导航；两键同时按下时，松开其中一键不能误清仍由另一键保持的跳跃输入。动作使用成功身体帧和实际 native 轨迹，配饰据此响应，不能用固定动画或移动预览图替代控制。

预览场景为自由、无限的水平地面，没有左右侧壁或世界横向终点。镜头沿用普通房已认可的规则：水平跟随，低跳保留接地构图，身体越过画面中线后才垂直跟随，并保护实际绘制身体的下方边距。相机移动和预览范围调整不改变配饰支点含义，不新增身体或帧驱动 owner。实现采用 native 局部原点随移动滚动平移、宿主保持连续世界坐标的边界；地面继续有效，不能通过把有限侧壁挪远或扩大有限房间来声称无限。本轮已有双向越界、多次原点平移和真实 native 连续性检查，实际边界和证据见第二轮验证报告。

文字框、下拉和模态窗口消费自身键盘输入，不穿透触发团子或页面导航；按钮获得键盘焦点时 Space 保留标准按钮操作。滑条的箭头键／拖动、图库选择和支点工具的鼠标操作仍由自身消费，其他未用于控件编辑的 WASD／Space 进入预览控制。成功切换分组后将焦点返回预览。离开控制域、失焦、关闭编辑、取消和切换宿主清空控制意图，防止移动或跳跃卡住；模态 Esc 只执行模态自己的取消边界。

### 11.5 本轮可失败的验收

1. 四个分组图标实际位于团子左侧，切换显示各自内容；往返切换不改变未应用参数。素材超过四件时首行恰为四图、后续换行且可以滚动，选中与佩戴标记对应真实条目；文字列表、固定素材或每行数量错误的实现必须失败。
2. 从“创建新配饰”选择 PNG 后编辑两个支点、造型、默认图层和全部物理参数，应用并重启后恢复一致；选择器取消不创建条目，模态取消保留新草稿项但恢复该次图像编辑前的参数，外层取消／Esc 撤销新项且不写盘。改名后偷偷保存或改成独立创建事务的实现必须失败。
3. A／D 连续移动改变真实世界位置，S 和 W／Space 驱动实际身体；W 不导航，Esc 恢复保存。W＋Space 同时按下及交错松开不会提前清除另一个来源的跳跃意图。编辑名称、数值、下拉、图库、支点和模态时不穿透，失焦与关闭后没有残留输入。
4. 连续向左右移动跨过原有侧边界和多次局部原点滚动，世界位置与速度连续、地面碰撞持续有效，没有侧壁、横向钳制、回弹或越界停止；扩大有限房间的错误实现须由边界合同与运行轨迹共同识别。对照中 native 身体、求解步数和帧 owner 不增加，配饰不脱落或在原点平移时产生虚假冲击。
5. 低跳不启动垂直跟随，越过中线后开始跟随，下降与落地时实际身体仍有规定下方边距；水平移动、窗口缩放及切换分组后镜头与支点一致。构建或单帧截图不能替代连续运行证据。
6. 保留现有配饰、捏脸及宿主回归门禁，准确区分静态、集成、实时和用户人工验收。旧 A0–A4 记录、性能波动、Wallpaper 回归差异及未验证项继续保留；本轮用户未确认前不标记已验收，不合并 main、不推送、不更新日常安装、不替换正式 DLL。

## 12. 第三轮反馈修订

本节记录用户针对第二轮候选的修改要求，以及确认的低跳、参数端点和永久删除语义。与第 11 节不同之处以本节为准；第 11 节和旧验证记录保留为历史。本轮继续使用 Schema 1、本地草稿和显式应用，不实现分享或配饰间挂接。

### 12.1 图库与图标操作

隐藏内容区“配饰库”标题。创建、复制、删除改为团子右上侧竖排图标，沿用左侧分组的 32 DIP 图标按钮、8 DIP 间距和顶部对齐；显示可理解的工具提示和自动化名称。图库顶部独立显示已佩戴配饰，下方显示未佩戴配饰，两区每行四张图片。选中状态跨区唯一，素材缓存和惰性加载继续适用。

移除图像与位置页的佩戴勾选。双击图片或右键菜单负责佩戴／取消，超出八件限制时明确提示并保留原状态；拖动释放不能误触佩戴。拖动改变所在区顺序，跨区拖动不改变佩戴状态。依据已批准的前后分层及层内排序，佩戴区拖动只调整同层的绘制顺序，前后层仍由参数页修改；不隐式把配饰改到另一层。未佩戴库顺序使用清单条目顺序，不新增 Schema 字段。排序保持草稿，应用后重启恢复。

### 12.2 两次确认后的永久删除

第一次确认目标条目，第二次明确确认永久删除；任一步取消都不写盘，也不提交输入缓冲。两次确认后立即删除并持久化，外层取消／Esc 不恢复已删除条目。删除已保存项只从最近保存清单移除目标，不顺带保存其他未应用参数、排序、佩戴状态或新导入图片；当前草稿独立移除同一目标并保留其余改动。删除尚未保存的新项只移除其草稿。

清单写入成功才更新内存保存快照。受保护清单、临时读取失败、有效清单已被外部改变或写入失败应明确拒绝并保留当前状态；保存前快照检查不宣称跨进程原子 CAS。兼容旧帽清单的删除要形成有效新清单，包括合法空列表，避免重启回退。共享图片仍可被副本使用；本轮不增加磁盘孤立资源清理。

### 12.3 输入、低跳和固定纵向镜头

W 不用于跳跃，也不导航；A／D 移动、S 压扁、只有 Space 跳跃。W 的按下／松开不能改变已经按住的 Space。按钮、文本、下拉、模态的输入边界继续适用。纵向镜头在起跳、下降及落地时固定，横向继续跟随无限水平地面；窗口布局变化允许重新构图，不把相机缩放或压缩显示轨迹冒充低跳。

统一 native 世界原地面／支撑跳跃使用固定启动速度，managed 的 JumpImpulse 不控制这条路径。因此本轮采用可选 ABI 1 导出设置单体预览的临时跳跃速度倍率，默认 1，仅在配饰预览设为 0.5；退出、释放 owner 或切宿主恢复 1，重新取得预览 owner 时再次启用。保持世界句柄、实体、帧 owner、原控制槽及旧导出；设置模式和刷新布局不额外推进身体。未启用的默认路径保留原运算，旧模块仍可运行普通场景；缺少低跳能力的模块明确显示预览不可用。新 native 只构建到隔离验收输出，不替换正式 DLL。

可失败门禁使用同条件 native 起跳／下降／落地，配饰峰高为普通峰高的 20–45%，而不是仅检查按键意图。每一实际预览帧保持纵向相机和地面投影固定；原首页／捏脸完整轮廓、头部余量和接地间距门禁保留。默认及恢复倍率 1 后与旧模块的身体轨迹须一致，非法倍率、多体及缺导出不得部分修改模式。

### 12.4 参数端点和导入错误

界面仍显示 0–100。柔软度高端增强图像内部弯曲／拉伸，连接强度低端减小连接恢复频率；常用区间和安全位移边界保留，不增加无碰撞配饰对团子的反作用。实际有界性、网格不翻转和端点效果由专项测试记录，尺寸不同可能先达到位移上限，不承诺统一放大倍数。

用户的选图闪退已由自有日志定位：尺寸校验抛出的 InvalidDataException 没有被创建入口捕获，发生在图片编辑模态打开之前。先用真实超限透明 PNG 和创建点击复现，再补入口捕获并检查错误可见、窗口继续使用、草稿和磁盘不变；合法 PNG 的真实模态确认／取消仍需验证。不增加全局异常吞掉或无原因的图片编辑器修补。
