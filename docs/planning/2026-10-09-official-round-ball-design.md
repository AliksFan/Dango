# 官方圆球单人小样设计

日期：2026-10-09。状态：用户明确回复“可以，设计通过”。随后授权“持续推进直到需要人工协助/验收”，按本设计范围继续计划、隔离技术试验及准入通过后的独立单人小样；具体顺序与门禁见[隔离试验计划](2026-10-09-round-ball-admission-plan.md)。设计批准不代表技术试验或人工验收已通过。来源为[官方家具方向](2026-10-09-official-furniture-design.md)与[已验收的静态平台小样](../verification/2026-10-09-static-platform-prototype.md)。

建议先验证一只原造型团子和一颗官方刚性球。团子可以推动球，球会滚动、落下并有限回弹，也会对团子产生反作用。球在画面中保持正圆，接触位置与可见轮廓一致；无球时保持原团子轨迹。正圆与双向作用的技术准入先于完整验收窗口。

## 首版玩法范围

| 项目 | 已批准行为 |
|---|---|
| 场景 | 独立 Windows 单人验收窗口，一只团子、一颗球及固定地面／左右边界；本批不组合静态平台 |
| 球的形状 | 刚性正圆，固定官方浅蓝球面与弧带标记；标记只用于看清 native 角度，不参与碰撞 |
| 推动与反作用 | 团子从左右推动球，球产生真实位移；较快的球碰到团子时也影响团子，双方同时解算 |
| 滚动与滑动 | 地面切向摩擦产生转动；摩擦不足时允许滑动，角度读取真实物理状态 |
| 落地回弹 | 回弹有界，逐渐衰减；持续接触不会反复添加起跳冲量 |
| 团子动作 | 沿用 A／D 移动、S 下压、Space 原地面起跳及鼠标拖团子；球面接触不授予站立或额外起跳资格 |
| 球的操作 | 首版通过团子接触推动；场景按钮可重新建立初始状态，不提供直接拖球或力度工具 |
| 结束与恢复 | 暂停／隐藏不推进物理，恢复不补跑挂起时间；错误返回球与团子的同一步最后安全状态 |

球顶接触仍是真实碰撞，团子可能短暂压住球并使其滚开；本批不保证可在球上平衡，也不为这种接触增加接地标志。需要球面站立、借球起跳或直接拖球时，另行补充玩法与安全合同。

可压扁的软皮球、多个球、平台与球组合、家具编辑器、玩家 PNG 导入、布局保存、正式房间、账号和多人均不进入本批。刚性球通过不能证明软体家具可用。

## 已核实的能力与缺口

[现有模块](../phase-1-physics-module.md)拥有单一 native 世界、固定步、稳定团子 ID、错误锁存与最后安全帧，算法由 native 层唯一维护。[静态平台 API](../../src/Dango.Physics/DangoStaticPlatformDefinition.cs)仅提供固定矩形与接触诊断，没有动态家具实体、角速度或球的睡眠状态。

[显示轮廓求解](../../eng/native/box2d/dango_display_contact.h)可提供团子样条与对节点的导数，但[平台接触](../../eng/native/box2d/dango_static_platform.h)面对固定边界，只修正团子。圆球需要有质量的双向接触、切向摩擦、球的转矩、地面／墙接触及睡眠唤醒。原始节点圆不能充当可见团子轮廓。

## 正圆与原团子共用的坐标合同

[已验收窗口](../../eng/tools/Dango.JointReview/StaticPlatformWindow.cs)采用世界水平 80、竖直 60 的原始标尺，并对 160×120 团子视觉等比缩放。直接投影同半径的物理圆会得到宽高比 4:3 的椭圆；单独把球画成等宽高会与接触轮廓错位。

建议定义与 DPI 无关的逻辑度量 `q = T p`，其中 `p` 是原世界坐标，`T = diag(4/3, 1)`。它是 native 接触使用的逻辑单位，不是屏幕像素。窗口的 `s` 仅用于缩放：

```text
团子轮廓：qD = T × 原 native 显示轮廓
球轮廓：  |q − qBall| = r
屏幕位置：screen = origin + (60s × q.x, −60s × q.y)
```

由此，团子仍保持原水平 80s／竖直 60s 的投影和原造型，球为半径 `60s × r` 的正圆。球角度在该逻辑度量中定义，纹理随 native 角度旋转；地面与左右边界也从原世界映射到同一度量。DPI 和窗口尺寸不能进入物理求解。鼠标使用窗口 DIP，拖团子的逆变换为 `p.x=(screen.x−origin.x)/(80s)`、`p.y=(origin.y−screen.y)/(60s)`；系统缩放仅由窗口层转换像素与 DIP。

已接受技术选择见 [ADR 0006](../adr/0006-native-round-ball-display-metric.md)：在现有 native 世界的固定子步内增加球的平移／转动状态，与既有团子求解共同处理接触。[隔离技术准入](../verification/2026-10-09-round-ball-admission.md)已通过；正式可选 ABI 和独立窗口按[后续计划](2026-10-09-round-ball-window-plan.md)继续实施与验证。若后续必须改变原团子参数或另建物理世界才能通过，应停止并返回设计评审。

## 推荐参数

以下为设计批准的首轮试验起点，不能写成已实测的稳定参数。参数仅在内部定义，不开放玩家调节。

| 参数 | 初始建议 | 用途 |
|---|---:|---|
| 逻辑半径 | `r = 0.4` | 名义视觉半径 24 DIP，直径 48 DIP，约原静止团子身体高度的三分之二 |
| 质量 | 原团子 core 与 16 节点总质量的 `0.25` 倍 | 提供容易推动的小球；仅为首轮试验起点 |
| 转动惯量 | 均匀圆盘 `I = 0.5mr²` | 使用明确二维模型，避免任意角度动画 |
| 地面摩擦 | `0.45` | 允许摩擦驱动滚动，也能在对照中观察滑动 |
| 团子接触摩擦 | `0.35` | 让斜向接触产生有界转动 |
| 回弹系数 | 地面 `0.25`、团子 `0.15`，低于 `0.5` 逻辑单位／秒的碰撞不回弹 | 避免静置反复跳动；回弹系数不解释成高度比例 |
| 速度边界 | 球线速度不超过 `12` 逻辑单位／秒，角速度不超过 `40` rad／秒 | 超界锁存故障，禁止显示层截断状态伪装正常 |

同样球面材料的滚动阻力、阻尼及睡眠阈值需在技术准入中以停稳时间、能量和唤醒测量冻结，不先任意叠加多种减速机制。团子的参数版本、节点数、重力、原起跳与速度限制保持原值。

## 实体与状态边界

推荐增加可选的球定义、创建／移除、只读状态及接触导出，保留现有 ABI 1 签名和原团子 42 槽状态。旧模块继续支持无球；请求球能力而缺少导出时明确失败。第一批世界最多一只团子、一颗球，不提前引入通用家具注册表或公开任意外力接口。

球定义记录初始中心、逻辑半径、质量、摩擦与回弹。球状态明确使用上述逻辑度量，字段包含世界内独立有效 ID、物理步版本、中心、线速度、角度、角速度及 native 活动／睡眠状态。接触诊断包含接触对象、法线、间距和本步冲量，并标明其逻辑坐标单位；不得混用原世界单位、DIP 和像素。

创建拒绝非有限值、越界、第二颗球及与现有团子／固定边界重叠的初始状态。球与静态平台互斥，已有多团子世界创建球失败，有球时增加第二只团子也失败；无球时保留原容量与平台能力。所有拒绝均不改变有效世界。移除使旧 ID 失效，再创建获得新 ID；Reset 保留存活 ID 和定义，恢复其出生状态，不复活已移除的球。场景切换可以销毁并重新建立整个验收世界。

球与团子按一次成功固定步共同发布。任一实体出现非有限值、速度或形变超界、接触不收敛，均停止普通输入并返回整组最后安全状态；只允许显式重置或退出。读取球状态不能额外推进时间，也不能在失败团子帧旁发布新球帧。

安全快照同时标识场景修订与物理步编号。成功创建、移除或 Reset 时同步更新整组安全快照，失败变更保留原修订；创建后首步故障仍保留新球及其初态，移除后故障不复活旧球，Reset 后故障也不返回重置前状态。物理步编号不单独承担实体拓扑版本。

## 独立验收窗口

窗口复用已接受的团子视觉与操作，增加“无球对照、左推球、右推球、球碰团子、球落地、重置、暂停、隐藏恢复、移除球、显示碰撞轮廓”。预设只是初始状态，后续运动必须来自 native 成功帧。`q` 的逆时针角度 `θ` 在 WPF 对应 `−θ×180/π`；中心与标记来自同一成功步版本，覆盖已知角度、跨周、暂停与故障冻结，不在窗口本地累计转角。

默认显示玩法说明；接触轮廓与诊断可切换。球有清晰弧带，便于比较位移与真实转角。按钮焦点、失焦、捕获丢失、暂停和重置均清空团子输入。拖动只认团子实际填充轮廓，球、装饰标记及覆盖线不参与命中；误点球或透明留白不能捕获团子。场景 Canvas 保留原中文 IME 处理边界，其他控件维持默认输入行为。

本批窗口仍是物理验收场，不预先决定普通房或桌宠房接入，也不修改日常安装。

## 进入完整小样前的技术准入

| 门禁 | 提案要求 | 必须击穿的错误实现 |
|---|---|---|
| 原团子保持 | 无球时 1／2／3 团子各至少 900 步与只读已验模块完整状态零容差相同；原平台专项继续通过 | 改节点、缩放、质量或全局参数使旧轨迹变化 |
| 度量与形状 | 独立重建团子样条与球圆，覆盖左右、上下、四个斜向及采样段内部接触；球中心和至少八向半径与碰撞轮廓偏差不超过 1 DIP，宽高差不超过 1 DIP。覆盖 `s=1`、实际 `s<1` 及本机 DPI；原团子最终投影与相同初态基线一致，不只测组件布局框 | 原世界物理圆加补画正圆、等宽高的错误轮廓，或只有横纵接触正确 |
| 双向接触与功 | 在隔离、无外力的解析夹具检查广义冲量反作用和相对速度；链式导数与独立有限差分吻合，无摩擦／无回弹时不增加动能 | 球单向移动、漏掉团子反作用、法线未经过正确转换 |
| 转动与摩擦 | 圆盘夹具验证切向冲量和 `Δω = τ/I`；无摩擦对照允许滑动，不强制位移推算转角 | 角度按 X 位移编造、没有球惯量、接触点转矩符号错误 |
| 球面起跳限制 | 先证明团子真实接触球顶且未触原地面，接地标志仍为假；Space 和持续按住均不产生额外起跳冲量。与原地面正常起跳对照 | 把球顶接触当作地面支撑，或只改变显示标志却仍授予起跳 |
| 接触预算 | 在统一逻辑度量中，穿入或静止悬空最多 `1/30` 单位，对应名义 60 DIP／单位下的 2 DIP；缩小不放宽。高速左右／斜向用例实测球速度至少 8、不超过 12 单位／秒；另覆盖团子最大合法输入与球反向接近，记录实际相对速度，不将它误限为 12 | 禁用接触、穿越球体、只测核心距离而遗漏节点间轮廓 |
| 回弹与能量 | 球落地恢复系数与隔离夹具一致，低速阈值两侧可区分；连续静置接触不重复注能 | 每个接触子步重复注入同一次回弹、以速度截断掩盖超界 |
| 睡眠与唤醒 | native 明确报告真正停止球积分的休眠，稳定球 10 秒内进入休眠，保持 30 秒后接触唤醒并恢复；球睡眠不停止活动团子 | 仅不绘制、仅报告速度为零，或团子穿过睡眠球 |
| 故障与资源 | 至少 100 次创建／移除／重置／释放循环；覆盖创建后首步、移除后及 Reset 后的真实故障，球和团子按同一场景修订与步号冻结，owner、球状态及 native 分配最终归零 | 错误后球继续移动、丢新球、恢复已移除球、Reset 复活旧 ID、销毁漏资源 |

以上为已批准设计门槛。解析夹具的质量、初态、步数、误差容限与真实故障方式，需在隔离技术准入计划开工前冻结，不能看到结果后放宽。原团子已有弹簧、阻尼、重力和控制力；不得将完整游戏场景冒充无外力守恒实验，或承诺原显示映射下未经证明的普通总角动量守恒。

技术准入及完整小样计划通过后，再制作窗口并检查真实 HWND 的中文 IME 下 A／D／S／Space、拖团子、按钮焦点、松键、失活清输入、缩放、最小化／隐藏恢复及退出。Draw／Resize 不调用 Step，调整尺寸只改变 `s` 与投影，不重建世界；最小化暂停，恢复不补跑。运行观察沿用墙钟至少 600 秒、活动至少 560 秒及 20 次暂停／隐藏恢复的要求，另测新状态绘制、步耗时、CPU／内存和接触误差；本批新候选需自己的运行证据。既有 59 FPS 与其他 DPI／硬件、多屏、睡眠等专项门禁保留，用户人工观感单独确认。

## 审阅与后续授权

设计已批准，用户已进一步授权持续推进。先冻结隔离技术准入计划并验证度量与双向接触；失败则保留证据，在本范围内定位和修复，不降低门槛。通过后记录技术决策并制定完整小样实施计划，再制作独立验收窗口。若需要改变产品范围或已接受团子行为，请求人工决定；窗口造型与手感由用户验收。

本地 main 合并、远端推送、日常安装更新、受保护 DLL 替换、部署和资源删除保持各自独立授权。球面站立／借力起跳、直接拖球、软皮球和与平台组合均需要另行批准范围。
