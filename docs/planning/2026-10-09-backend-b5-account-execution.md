# B5A Windows 账号与配置接入

日期：2026-10-09。用户选择“居中浮层”，承接已批准 B5。先交付账号／配置可独立验证增量，再推进房间管理、正式 Hub／租约与呈现。交互选择通过不代表功能验收；独立任务分支保留既有 B2 草稿，main 与日常安装不变。

## 实现边界

- 固定可信 HTTPS origin，由应用启动配置提供，不接受登录页面输入的服务器地址；未配置仍可使用本地单人，账号面板给出真实不可用原因。
- Client.Sync 的正式账号传输拥有 CookieContainer，禁止重定向，写请求领取新 CSRF。登录、注册、找回请求和绑定 Pet 共享此会话，不共用匿名原型。
- 邀请明确分为 GUID ID 与 43 字符证明。注册 RequestKey、继续秘密与 CompletionKey 跨重试保持；SMTP 接受不等于验证，注册完成后仍需标准登录。
- 默认认证仅内存；主动选择记住登录才通过 Windows Credential Manager 保存认证材料。注册继续信息单独受保护保存，不存密码。固定 origin 分槽，损坏／过期／身份不符不能恢复；恢复必须请求服务端验证。
- 应用单一账号控制器管理请求取消与代际；关闭登录、退出／切账号和销毁后，迟到请求不能改变新界面或复用旧会话。注销网络失败显示撤销未知，本机身份与记住材料仍清除。
- 配置采用 B2 repository／journal／choice，读取不写，显式选择才归档并更新。冲突、保存失败、未知结果不能显示成功；本地外观不因退出登录回退。
- ProductHome 增加居中浮层与门廊独立账号入口，隔离背景点击、Tab 与游戏键；本地两门保持原事件。房间业务尚未接入时不显示虚构目录或在线成功。

## 文件与顺序

1. 独立子工作树实现 `Client.Sync/Accounts/` 及受控 handler 反例测试。
2. 独立子工作树实现 `AccountPanelView` 与布局／输入测试；根实现 Windows secret store、账号编排及 ProductHome／host 接口。
3. 根集中集成两个提交；执行受影响 Client.Sync 与 Desktop STA 回归及 Release 构建，检查敏感日志、配置写入与退出路径。
4. 真实客户端→HTTPS→PostgreSQL 集成需要新的精确数据计划与单独授权；未授权前不启动数据库／正式服务／SMTP。Windows 系统安全存储实写和人工桌面另列门禁，静态 mock 不替代。

## 五项门禁

| 项目 | 本增量反例与后续真实门禁 |
|---|---|
| 正确性 | 不安全 origin、错误／超大响应拒绝；注册密码与状态校验；无配置不能伪登录；真实输入与错误映射后续验证 |
| 一致性 | 重复注册使用相同键；迟到旧身份／错误不污染当前；配置冲突不覆盖；真实提交丢响应与并发后续验证 |
| 安全性 | 凭据不入日志／普通文件；新 CSRF；恢复校验身份；Windows 凭据限定任务 origin／槽；真实 TLS、系统存储与逐次授权后续验证 |
| 可靠性 | 取消／断服保留本地；未知写结果先对账；配置归档失败阻断；真实进程中断、磁盘及备份还原后续验证 |
| 扩展性 | 传输读体／时间有界、单一 UI 请求、取消／销毁清理；长期运行和房间通知／心跳在后续增量验证 |

不新增房间移动协议、好友、私密访客、配饰上传或分布式设施。正式 B4 无移动／动作命令，不能把旧 RoomConnection 接入作为正式在线玩法。当前允许必要代码、局部门禁和本地提交；main 合并、推送、部署、日常安装、DLL 替换及持久数据操作保留原授权边界。
