设计：[DIY 配饰设计](2026-10-07-accessory-diy-design.md)。分支 `codex/accessory-diy`，基线 `8ff78e0`。范围是 Windows 本地导入、编辑、多件佩戴、单支点、图片弯曲／拉伸、旋转／重力参数、保存重载及现有可见宿主接线。无官方分类，无碰撞，无多人／云端／手机实现，不修改正式 native DLL。

用户新增的“配饰可挂在另一件配饰上”已登记到设计第 8 节，为后续候选。A0–A4 只需保持稳定实例身份与连接目标边界，不实现串联挂接、不提供未实现选项，也不将该项列为首版验收要求。

以下是同一个完整交付的增量顺序；A1 或刚性小样完成不代表整个模块完成。每项先建立能失败的验收，再实现。不启动数据库、外部服务或付费资源。

## A0 — 透明图片形变技术门禁

目标模块：新增独立图片／网格表现小样和对应 Desktop 测试，读取当前成功身体帧，不改产品默认入口或 native 模块。

- 验证静态 PNG 解码、透明边缘、非破坏性支点缩放旋转；随后验证统一柔软度下的纹理弯曲／拉伸、连接弹性与重力。
- 比较现有 WPF 能力可实现的绘制路径，优先不新增依赖；记录所选方案的 API、性能与透明质量证据。确有新增依赖需要时，核对官方文档、类型与许可证，并报告相应设计影响。
- 建立刚性距离不变／柔性距离变化的反例，验证固定支点、弹性支点、锁定角度与有界恢复，使用虚构测试图案。
- 在目标 Windows 机器评估 1 件及 8 件显示、合法极端参数组合、接缝、空白边框和非连续图案；保留身体唯一步进与只读宿主消费。

退出条件：透明图片有真实内部形变，运动有界，图片质量与资源预算可满足候选要求。不能通过时保留失败证据，暂停依赖该路径的后续接入并提出具体取舍，不能以整体缩放或预设动画代替柔软度。通过后将实际方案和可复现预算记录到设计补充，必要时新增 ADR；不将未测试候选写为已批准技术。

## A1 — 数据合同、导入与保存会话

目标模块：独立配饰配置／图片资产模块、配饰清单 Store／Session、原子二进制资产写入与提交协调器。当前实现为独立图片资产和包含参数／本地佩戴状态的 `AccessoryItem`，不是独立定义／实例引用结构；第二轮沿用 Schema 1，不进行清单迁移。

- 落实稳定 ID、图像资产与独立配饰副本／佩戴实例、单支点、参数校验、前后层和排序；不增加官方类别。
- PNG 在解码前后校验限额、透明和帧数；保留原画布、不修改原文件、不持久化原路径或元数据。
- 草稿与最近保存值分离，图片先写、清单最后提交；取消、写失败、损坏资产、坏清单和未来版本有可重试／保护边界。
- 读取旧帽时只形成内存兼容配置，第一次显式应用才写新清单；合法空佩戴与旧清单缺失分别处理。

退出条件：故障注入覆盖图片写入、清单提交和损坏路径；取消不写、应用重载一致，删除／移动源图后仍能恢复，修改副本不影响另一件。自身捏脸 Schema 3 与旧主设置回归通过。

## A2 — 统一配饰运行时与共享画面绑定

目标模块：新配饰场景状态／控制器／帧与 Visual；`StackedDangoSceneRuntime`、`DangoHostFrameBinding` 的必要接缝。沿用已有附件生命周期与唯一身体帧。

- 将两个归一化位置映射到当前完整身体帧，任意附着位置取代仅头顶轨道；运行态与持久配置分开。
- 集成 A0 的统一柔软度、连接、旋转锁定／回正／阻尼／摆角及重力，参数彼此独立。
- 每实体组织后配饰、身体／脸、前配饰，应用稳定排序和实体身份；配饰不碰撞、不拦截物理命中、不改变身体轨迹。
- 接入暂停、隐藏、首帧、宿主切换、失败、移除、取消和过期编辑代际保护；增加真实显示范围，不扩展身体碰撞范围。

退出条件：身体输入对照轨迹和步数一致；刚性／柔性、固定／弹性连接、旋转与重力差异可测；快速变更和生命周期恢复没有重复求解、重复显示或过期覆盖。

## A3 — 换装界面与简单图片编辑器

目标模块：`ProductHomeView.xaml`、新 `ProductHomeView.Accessories.cs`、独立图片编辑控件及必要的产品主窗口绑定。按用户后续要求与捏脸 UI 对齐，保留换装左参数／右预览方向、共用团子尺寸及基线。

- 把禁用帽子占位替换为统一配饰库与佩戴列表；支持导入、名称、复制、佩戴／摘下、选中编辑、前后层与上下排序。
- 编辑视图提供透明棋盘格、画布查看缩放、真实配饰缩放旋转、图片支点和身体附着位置；数值、拖动和复位使用同一合同。
- 提供用户可理解的运动参数、实时预览、当前参数复位、取消和显式应用；编辑器确认只回到换装草稿。
- 应用结果分别记录图片／清单保存和画面绑定成功；写失败保留草稿，保存已成功但画面失败时准确报告，不能把已经写盘的状态伪装为取消。
- 输入焦点与拖动不穿透触发团子行为；三档布局与减少动画沿用既有门禁。

退出条件：用户从正式换装入口完成完整操作，磁盘重启恢复；取消及所有离开路径不提交草稿。UI、会话与运行时结果一致，捏脸／换装相互取消不改变另一部分已保存值。

## A4 — 宿主、旧帽兼容与本地验收

目标模块：`DangoApplicationHost`、首页／门廊绑定、Window、Wallpaper／overlay、本地普通房可见实体绑定，以及显示范围与对应回归测试。

- 严格区分清单缺失、有效空列表、单图损坏、坏清单／未来版本：仅缺失时使用旧帽兼容模式，其他状态按设计状态表处理，不叠画或悄悄回退旧帽。三种旧素材作为无类别内置条目，完成资源规范化和明确兼容语义。
- 在上述实际显示路径应用同一配置、同一帧与图层合同；换宿主与返回首页恢复已保存状态。
- 以独立设置根目录及虚构图片开展真实 WPF／native 验收，不覆盖用户日常安装、设置或 DLL。
- 分别验证前后遮挡、透明质量、超出原帽范围、动作、形变、暂停恢复、保存失败与进程重启。
- 运行与改动匹配的 Desktop／Core／Physics 回归、构建、格式与 `git diff --check`。新增失败不降低旧物理门禁。

退出条件：自动门禁、要求的实时路径和本地重启均有证据，并提供用户人工验收窗口。100%／125%／150% DPI 与目标机器性能按实际运行情况记录；未执行项保持“未验证”，不能从一个窗口推定其余宿主通过。

## 已批准的第二轮界面与操作修订 — 候选已实现，待人工验收

本轮依据设计第 11 节。文件所有权分别覆盖配饰编辑面板／主题与图片编辑器、`ProductHomeView` 接线、实时预览／相机与必要的 managed 场景边界；共用代码由集成负责人顺序接线。本轮不实现分享或导出、不引入定义／实例 Schema、不迁移库、不改正式 native DLL，也不新增独立创建事务。

1. **分组与素材网格。** 将“配饰库／图像与位置／柔性与连接／旋转与重力”变为团子左侧竖排的四个图标页签，沿用捏脸主题、尺寸、选中反馈和保存动作锚点。配饰库每行四张真实素材图，显示名称、选中及佩戴状态；分组切换保持当前条目与所有未应用参数，损坏素材保留明确不可用条目。
2. **创建入口及保存说明。** 将入口改为“创建新配饰”，第一步仍选择静态透明 PNG。选择成功后新增草稿，再进入图片模态；模态取消只撤销本次图像编辑，外层取消／Esc 撤销未应用新项及其参数。沿用显式应用提交整套草稿。名称、图像、两个支点、造型、默认前后图层和物理参数形成保存快照，佩戴与排序为本机状态；明确当前条目把这些数据放在一起，未来分享另行设计。
3. **真实控制和无限水平地面。** 换装预览支持 A／D 移动、S 压扁、W／Space 跳跃；Esc 关闭换装并恢复保存值。W 不进入门廊、不导航，两种跳跃按键分别跟踪按住状态，交错松开保持另一键仍有效。复用成功身体帧和唯一 owner；native 局部原点滚动平移与宿主连续世界坐标配合，保留地面、移除水平终点与侧壁，禁止用扩大有限房间替代无限合同。
4. **镜头与输入边界。** 复用普通房默认跟随：水平跟随、低跳保留地面、越过中线后垂直跟随、保护实际身体下方边距。编辑控件及模态输入不穿透，失焦、关闭、取消与宿主切换清空控制。原点平移不能造成世界位置／速度断裂、配饰冲击、支点漂移或新增物理体／步进。
5. **先建可失败门禁，再集成验证。** 对四图换行／图标分组切换、取消的两层边界、全部参数磁盘重载、W 不导航、双跳跃键交错松开、控件输入隔离、越过旧侧边界、多次原点滚动连续性以及镜头中线／下方边距建立能识别错误实现的检查。随后执行改动相关自动门禁、真实 WPF／native 连续操作与重启，提供新的人工验收窗口；既有 A0–A4 的保存、物理、配饰和宿主回归要求仍适用。

退出条件：设计第 11.5 节逐项有证据，未执行项明确为未验证，用户完成本轮人工验收后才标记本轮已验收。原 A0–A4 未人工验收状态、旧性能与 Wallpaper 回归差异继续保留；本轮修改不得把旧记录改写为新通过证据。静态／集成／实时／人工与 Git／推送／安装分别报告，未获授权仍不得合并 main、推送或更新日常安装。
