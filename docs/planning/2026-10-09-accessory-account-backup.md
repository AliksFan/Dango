# 当前穿搭的账号备份与审核：设计和并行实施范围

日期：2026-10-09。用户已确认以下业务规则并明确“可以，那可以开始了”；随后确认只审核图片。

## 已确认规则

- 本地佩戴、编辑和保存自由。未审核、拒审内容可以由本人私有备份和恢复；向任何其他玩家展示前必须审核通过，包括私有房间访客。
- 首版只备份当前已佩戴组合及必要图片。未佩戴素材库继续保留本机，不批量上传。
- “应用”先提交本机；本机成功后自动排队备份。账号或网络失败不撤销本地结果，不能显示已备份。
- 首版由管理员人工审核，提供简单待审列表。
- 可在正式后端合入 main 前并行开发，正式接线依赖冻结且验证过的后端提交。

审核对象已确定为图片本身：同一规范化图片复用内容结论，调整位置、层序和材料参数不重审；组合问题依靠举报复核。初版人工原型以真实图片申请、待审、通过／拒绝和撤销为闭环。私有备份不自动交管理员，申请展示审核是独立动作。原型没有伪造正式管理员鉴权或举报服务。

对其他玩家的当前穿搭投影仅包含图片已获审且当前引用获准展示的实例；混合未审图片时，只隐藏这些图片对应的实例。内置图片无需上传审核。公开投影使用不可变配方，并把本地素材标签替换为通用名称；本人的私有备份和恢复保留原名称。管理员预览只接受已显式申请的图片。内容批准不赋予其他账号使用、私有下载或转发权。组合举报需要后续账号／房间接口和针对被举报组合的处理；除非图片本身违规，不应通过全局撤销无辜源图来代替组合处置。

## 数据与图片合同

`Dango.Protocol.Accessories` 的 Schema 1 独立于捏脸 Schema 3 和旧帽子字段。只传当前已提交且佩戴的最多 8 个实例；实例 ID 与图片 ID 分开，同图可多次佩戴且保留各自参数、层序和名称。内置资源只传已知标识和 64 × 64 逻辑画布。

保存图片沿用已有上限：PNG 32 MiB、最长边 4096、像素数 16,000,000。所有坐标、角度和材料参数保持本地取值范围，必须为有限数字。重复实例、同图不同尺寸、未知版本和路径／库字段被拒绝。`AccessoryOutfitJson` 使用完整 camelCase 配方、32 KiB 清单预算，拒绝重复或缺失字段和数字图层。不得上传原文件路径、元数据、桌面内容、输入、物理网格／速度或逐帧动画。

服务端独立验证实际图片，使用带版本的规范化算法产生内容哈希；客户端必须保留本机哈希到服务端哈希映射，不能假定 WPF 编码器和服务端编码器得到相同字节。规范化不缩图，不偷偷修改尺寸或配饰参数。物理内容按哈希去重，不做感知相似合并。

图片去重不授予权限。正式上传接口必须接收实际受限图片并验证，不以“已知哈希”为由为调用者创建私有引用，也不向用户暴露全局存在性查询。存储原语只管理文件，不负责账号授权。

先完成所需图片上传，再以 `expectedRevision` 和幂等键事务性提交完整穿搭；身份由鉴权上下文裁定，不接受 body 内的账号身份。并发冲突必须返回明确结果；断网导致提交结果未知时，先用原幂等键核对，再决定后续操作。

## 客户端与本机一致性

协调器绑定账号、团子和本次登录代次。串行处理、合并等待中的最新已提交快照；切账号取消旧任务，旧回调不能刷新新账号状态。只响应明确本地提交，草稿预览和取消不备份。

恢复先下载并校验全部必要图片及参数，随后在本机执行一次清单提交。恢复期间草稿变更、磁盘清单变化、图片损坏或写盘失败时保留原配置及库。账号恢复不覆盖未佩戴素材；ID 冲突必须显式失败。图片文件不可变，清单仍为唯一提交点。

本机和账号均有不同内容时，由正式 B5 入口让用户选择使用本机或恢复账号。该 UI 决策入口、真实 HTTP 鉴权与凭据管理由 B5 接线承担；可移植模块不伪装已上线同步。

## 保留与回收边界

正式服务端需要保留当前私有穿搭、有限图片待审引用和有期限上传暂存；公开投影从当前穿搭按图片资格选择，不额外保留上一套公开穿搭。仅替换一个账号的当前私有版本不能删除待审或另一账号仍引用的图片。审核结论记录与图片物理引用分开。

后续回收仅针对无任何有效引用且经过宽限期的对象，删除前重查并发引用。当前增量不操作现有数据库、对象存储或执行持久垃圾清理。撤销后应更新服务端投影并通知客户端重新取快照；不能保证抹除其他设备已经合法下载的字节。

## 能失败的验收

1. 超 8 件、重复实例、同图不同尺寸、未来版本、非有限参数和不匹配内置画布拒绝；合法同图副本完整往返。
2. PNG CRC 错误、动画／恶意结构、展开超预算和伪造 source hash 拒绝；同内容并发只发布一份完整 blob，坏存储不可读。
3. 上传中断和未确定提交保留本地；等待队列仅保存最新已提交快照；旧账号晚回调不影响当前账号。
4. 恢复缺图、hash／尺寸矛盾、未来版本、草稿变化或磁盘变化均不替换原清单；成功恢复保留未佩戴库与全部穿搭参数。
5. 后续正式门禁：只凭 hash 无私有访问权；事务并发无半套穿搭；另一账号只见获准投影；撤销生效；双 Windows 登录真实恢复。

本增量的自动测试仅证明协议和可移植／本机模块。正式数据库、网络账号、管理员审核、多人展示及双机人工验收应独立报告，未经验证不得标记通过。

## 取舍

- 使用独立穿搭清单，避免把多件组合塞入旧帽子字段，代价是必须显式与捏脸和账号版本接线。
- 使用服务器确认的图片标识，避免信任客户端哈希和跨编码器一致性，代价是上传响应映射与恢复校验。
- 保留先本机后云端语义，允许离线编辑，代价是必须展示冲突／失败／未知状态，不能以最后写入覆盖解决。
- 图片审核复用内容结论，减少重复人工审核并允许穿搭自由变化；代价是组合违规需要独立举报复核，图片批准不能证明任意组合合规。
