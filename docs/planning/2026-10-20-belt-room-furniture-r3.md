# F7 家具集合 R3 工程合同

日期：2026-10-20。承接已批准 F7 接入范围，在实现／采样前冻结接口及物理边界。用户要求持续推进完整计划，内部增量检查不再作为等待下一次授权的交接点。原 R1／R2、FAIL 与未触发记录保留。

## 集合与单位

一个真实连续身体和最多 30 件平台／刚性球在同一个 room world、四子步内统一求解。保留原 ABI1、4472 字节身体帧、R1 接触身份及旧单平台路径；新增 capability64／128 和独立 `belt-room-furniture-r3-v1` 集合接口。详见 `eng/native/box2d/dango_belt_room_collection.h`。

新接口全部直接米制，1m＝72 Room 逻辑单位。旧框架 p 的 x80／y60 及球 q 的 4/3 转换不得进入新接口。存档尺寸不变：平台宽272／72m、高21／72m，顶部中心锚点下移半高得物理中心；球半径66／72m，中心直接逆映射，质量0.02，球重力系数0.5；球地面／身体摩擦0.45／0.35，恢复系数0.25／0.15。身体原重力、材料与受力保持。

共享 DTO 显式标记 `LegacyPAndQ` 或 `BeltWorldMeters`，各 binding 拒绝错误空间。旧 Q 字段名在新集合上下文中明确表示米制；不能依据字段名再次缩放。布局文件 schema、roomId、尺寸和保存锚点保持，运动球不写回锚点。

## 原子事务与发布

独立自然 x64 布局：definition112、ballstate88、contact104、item416、collectionframe16968、probe48、token40 字节。新集合帧包含同次 native publication 的身体、完整不可变定义、球状态和 lastAppliedToken，不通过多次独立 read 拼出一帧。

启用集合改变 sceneRevision，不推进物理 tick；与旧单平台模式互斥。probe／prepare／apply／cancel 沿现有家具文件事务：prepare token 绑定 generation、tokenId、sceneRevision、tick、configurationRevision；prepared 时拒绝 step／其他 mutation（busy不锁物理fault）。apply 仅推进 revision，不推进 tick。托管 public token 用进程 OwnerEpoch 防止 DLL 卸载重载后代际复用，私有缓存保留完整 native token。保存已提交而 apply 未确认时继续使用现有“已保存未生效／结果未知”保护和恢复，不改写成从未保存。

求解失败回滚完整身体、球、接触、支撑、布局和版本，另保留故障诊断。对象身份不复用；删移支撑使关联支撑立即失效。现有 session 继续拥有文件操作及 UI 状态，物理唯一推进者仍为现有 scheduler／scene。

## 接触与工作预算

身体接触采用真实 Fourier 几何及 Jacobian，球对身体和身体对球双向作用。球与地、墙、平台、球需要真实运动接触。候选采样／距离根仅定位；曲线与球的 theta×time 区间证书及包含检查裁定成功，球球扫掠按相对线段解析处理。平台继续 R2 最终连续证明。

不放宽：穿透5e-4m、clearance1e-4m、activation1e-3m、32位置／300速度迭代、全帧共享262144几何cell、theta20／time16、shape131072、dt0.0166666f和四子步。球参与联合动能门；增加对象不能重置每件预算或静默截断接触行。

## 后续接入的必要性决定

- 已有产品没有房内身体参数编辑入口。本轮继续验证首页显式应用、暂停交接和重新入房读取完整已应用三参数；不新增房内改参页。未来若开放运行中改参，须另接触状态迁移及配置事务，不能套用单体地面热更。
- 休眠采用保守外物判定：集合中存在任一球就保持求解，覆盖近球／扫掠球可能接触的情况。无球时才允许身体休眠；因此活动球始终推进，不需要本轮新增局部接触岛或远球优化。
- 无球房间沿 visible-deformation-v2 的120连续成功tick稳定窗，最大米到屏幕倍率限定300 DIP/m，二维窗口上限0.0005m对应0.15 DIP。未标定或超范围不睡；投影变化、输入、取消、布局prepare／apply／cancel、边界和宿主变化重置窗口／唤醒。休眠保留原生全部状态，不增加物理tick，唤醒后只走当前固定步，不补墙钟。
- 安全恢复使用当前配置身体的连续保守包络和真实地面支撑，保留原文件格式及无效位置回安全出生点的行为。桌宠沿现有双表面同帧、72等比映射和鼠标输入接入。

真实 DLL 验证 ABI／能力／所有权、版本事务、前置拒绝、完整回滚及负控；再验证双向球接触、场景碰撞和30件实际布局。现有家具 session 验证真实文件成功／失败保护、恢复、同帧呈现、锚点重启、删移支撑。恢复／桌宠／休眠按其实际路径分别验证，后台证据与可见产品／人工验收分开登记。旧保存间歇失败仍 UNKNOWN／OPEN，不能凭定向重跑绿灯关闭。
