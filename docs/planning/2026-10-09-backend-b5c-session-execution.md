## 范围与就绪边界

- 正式 HTTPS 房间准入、公共码解析／确认重置、本人和共享快照；与邮箱账号共用受控会话、CookieContainer 与逐请求 CSRF。
- 仅连接 `/api/v1/room-hub`；Attach、Heartbeat、TakeControl、Leave、EndLease、PersonalSnapshot、Snapshot。禁止接旧匿名 `/room` 原型协议。
- 30 秒业务租约、约 10 秒心跳；本进程实例 ID 稳定，控制／观察区分；关闭浮层只暂停本地连接和心跳，不代表正式离房。
- 原请求键与正文在同会话未知结果恢复时保持；确认回执后读取当前归属，旧回执不能代表当前状态。切换账号释放原连接，旧回调和旧恢复不能影响新绑定。
- 断线停止呈现就绪，有限退避先读本人快照，再 Attach 本实例当前有效租约；不自动 Enter、抢控制或复活旧租约。通知仅合并触发有界读取。
- 状态浮层显示服务器连接、角色、归属与成员快照。正式服务没有 Move／Action 合同，入房位置为 0,0 且尚无批准的场景单位映射；此增量不能宣称可操作的多人场景。宿主就绪仍是显式外部门禁，当前 Windows 不调用场景就绪确认。
- 未选择外观时允许管理及读取状态；明确入房先完成外观选择。进入、接管和离房由用户明确操作，离房先确认。关闭／返回本地不能发广义 Leave。呈现失败补偿只能结束本次捕获的租约。
