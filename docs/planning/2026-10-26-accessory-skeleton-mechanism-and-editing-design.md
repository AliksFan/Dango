## 1. 本轮确定的方向

- 一件配饰使用一个团子佩戴挂点；配饰内部可以有多个图层组，每组绑定一条骨架链。
- 创建图层组时自动创建该组唯一的骨架根；绘制骨架工具不创建根，也不隐式创建图层组。
- 图层组允许为空；图层允许不属于任何组。骨架的连接关系与图层的绘制顺序分别管理。
- 每组独立配置弯曲、形变阻尼、形变恢复、重力响应与伸缩弹性。伸缩弹性为最大长度变化比例 0–50%，默认 0%，拉伸与压缩对称。取消刚性／柔性选择；组重力直接独立设置，不提供继承机制，也不收进高级项；外层另有独立的“整体重力响应”。
- 骨架与配饰根平时隐藏；进入修改骨架或绘制骨架工具时显示。选择、框选、移动使用左键，右键保留给上下文命令。
- 单根拖动靠近有效骨节／骨架根时显示挂接预览，松开左键挂接。根的右键“挂接骨架根”命令进入粘鼠标状态，左键点击挂接。
- 绘制工具左键选择已有骨节，点击新位置追加骨节，新点自动选中；从已选节点开始拖动时自动切换修改工具。
- Delete 删除所选节点；如果删除结果出现漂浮骨节或失效挂接，拒绝整次删除。
- 右侧面板分为可独立展开／收起的上下两部分：上部管理图层及图层组，下部呈现当前组的骨架属性。左侧统一图片／骨架工具栏、折叠与快捷键详见 UI 合同，本轮不重画完整页面。

多个团子挂点、同组分叉／多链、双端钉住、IK、碰撞、自碰撞与主动动画不纳入本版设计。

## 2. 对象、归属与关系

| 对象 | 含义与归属 |
| --- | --- |
| 团子挂点 A | 位于团子身体上，由外层佩戴配置选择，随真实身体表面运动 |
| 配饰根 P | 整件配饰的定位基准，属于配饰，不属于任一图层组，也不必与某个骨架根重合 |
| 图层组 G | 一件配饰中的内容容器；拥有一条骨架及一套骨架属性 |
| 骨架根 R | 创建 G 时自动生成并始终归属于 G，是该组骨架的首点 |
| 普通骨节 J | 组内单链上除 R 外的控制点；相邻两点之间构成骨段 |
| 根挂接引用 | R 指向另一个组的 R／J；引用改变跟随关系，不改变两组身份或参数归属 |

每层至多属于一个组，每组恰有一个 R、至多一条无分叉链。只有 R、没有普通骨节是合法编辑状态。删除骨节不能删除 P 或 R；删除 R 应通过显式删除图层组处理。

未分组图层跟随整件配饰的姿态，不参与任何组的骨架形变。空组也可以拥有骨架并作为其他组的连接结构，不能因没有图层而自动清理。

选中组，或选中属于该组的图层时，下部使用同一套组属性。未分组图层没有组骨架属性，不自动建组。多选跨组时保留一个明确的活动组，暂不提供隐式的跨组批量属性写入；节点多选仍可用于修改工具。

## 3. 定位与挂接机制

### 3.1 A、P 与骨架根

A–P 受外层连接强度与最大行程控制；整体角度、旋转阻尼、整体回正和摆角限制也属于外层佩戴关系。外层“整体重力响应”独立控制 A–P 平移及整体转动的直接重力响应，不作为组参数默认值；各自由度只计一次，不替代组内弯曲或伸缩。

R 未挂接其他组时，以 P 为参考，具有自己的初始局部偏移。该偏移随整件旋转和缩放，P–R 不额外增加弹簧；不同根可并列跟随 P，无需画一条可见主骨架来凑连通。

R 挂接到其他组的 J 时，与 J 同点，跟随其位置和所在骨段的朝向，并保留初始相对角度。若目标是另一个根，则使用目标根的姿态。整件尺寸与基础角度只施加一次，不沿组间依赖重复缩放或旋转。

用户最新明确连接是双向物理连接：组间同点 R/J 在运行时属于同一共享自由度，各组距离／角度／伸缩约束共同作用于整个连接系统，受力可以影响连接另一端。不再按组先后“父带子”求解。编辑时拖动任一端也移动同一个共享连接点。组装引用仍记录根来源与校验无环，不代表物理影响的方向。重力统一世界向下；共享节点按质量贡献合成力，不直接累加两组加速度系数。

### 3.2 挂接不变量

- 每个 R 只有一个有效来源：P 参考，或另一个组的一个骨节／根。
- 不允许连接本组节点，也不允许连接直接或间接后代组的节点；禁止依赖环和悬空引用。
- 父目标节点仍归父组，子根仍归子组。两者空间重合不等于合并身份或共享属性。
- R–J 是同点连接，不提供另一套连接强度、行程或伸缩参数。
- 图层顺序与图层归组不自动改写根的挂接目标。组间挂接不会把子组的图层搬进父组。
- 所有挂接仅发生在同一件配饰内部，不扩大为配饰之间互挂。

### 3.3 创建、改接与解除

普通创建图层组：自动生成 R，补齐默认建议为初始放在 P，以 P 为参考；之后可用修改工具定位。

“从此骨节创建图层组”：创建一个新的空组及其 R，将 R 挂接到上下文目标 J／R；不复制或搬走来源骨架的后缀。新组及其根成为活动对象。绘制工具已激活时，可直接从新根画第一段；修改工具不因创建组自动切换绘制工具。

用户已明确：**拖动自由 R 只移动该根，不自动平移本组普通骨节或子组整条骨架，不移动图像像素。** 要平移整条骨架，框选所需节点或使用“选中所在骨架”再移动。根靠近候选时，虚影与提交均只将 R 移到目标；因此可能改变第一段初始长度／方向，须重新计算初始几何与绑定，不能在松手时突然搬走整条链。

被引用节点及所有与其连接的根构成同点集合；拖动集合中任意 R/J，整个同点集合只移动一次，其余未选普通骨节与图像不隐式平移。受影响链重算初始长度、相对角度和绑定；零长度或无效结构整笔拒绝。此规则同时适用于鼠标与方向键，不再拒绝已连接 R 的普通微调。

解除挂接后恢复以 P 为参考，保持编辑画布中的初始位置与曲线，不从动态试摆位置建立存档。后续普通根移动修改其 P 相对偏移。

## 4. 每组骨架属性与伸缩

| 属性 | 产品语义与边界 |
| --- | --- |
| 柔软度／弯曲幅度 | 允许关节偏离初始相对角度的范围；当前实现本质是角度限幅，不宣称为真实材料刚度。0 禁止内部弯曲 |
| 形变阻尼 | 衰减骨节运动速度，使余晃消退；不主动指定恢复到什么形状 |
| 形变恢复 | 将骨节拉回以当前根姿态为参考的初始曲线；与外层整体回正区分 |
| 重力响应 | 直接配置本组内部自由度的重力响应；各组独立，不继承父组、不与其他组系数叠乘。0 关闭自身直接重力，仍会跟随父目标运动并响应惯性 |
| 伸缩弹性 | 最大长度变化比例，0–50%，默认 0%；拉伸与压缩对称。0 保持骨长固定；非 0 允许在边界内偏离并向初始长度恢复 |

初始骨长来自用户绘制／修改的骨架。编辑初始骨长不受运行时伸缩上限限制，也不能被当成预先拉伸或改变弹性参数。相邻骨节不得形成零长度骨段。

**加入独立伸缩后，弯曲幅度 0 只表示不弯；弯曲与伸缩都为 0 才完全保持内部初始形状。** 不能直接沿用现有 `Softness == 0` 绕过全部内部求解的实现。外层连接与整体转动仍可生效。

令伸缩弹性 e 为 0–0.5，则每段动态骨长 L 必须满足 `(1−e)L₀ ≤ L ≤ (1+e)L₀`。50% 对应 0.5L₀–1.5L₀。这是允许的硬边界，不是自动把骨段拉满。恢复手感、阻尼耦合和稳定策略在 S1 校准；不增加另一套伸缩恢复／阻尼控件，不再把已确定的范围列为待选。

各组重力在共享节点按质量贡献合成力，不重复累计加速度；连接约束的双向传力属于物理连接。A–P 与整体转动使用外层独立整体重力值，组内自由度使用本组值；不能互相替代、相加或作为继承默认。强度到实际加速度／力矩的映射在 S1 验证，产品入口已确定。

## 5. 两工具的共同规则

- 普通图像工具中隐藏骨架、R 与 P；两个骨架工具中显示全部辅助结构，明确区分活动组、选中节点和普通节点。辅助结构不进入成品图像。
- 修改使用静止初始姿态。试摆读取独立快照，不允许对正在动态摆动／伸缩的节点直接修改初始数据；返回修改时恢复初始坐标。几何／参数修订后以新快照重建或重置试摆，拒绝旧修订输出；快照隔离不能使新参数失去预览反馈。
- 左键承担选择、框选、拖动和绘制。普通右键不选择、不框选、不触发绘制，也不把上下文目标暗中加入选择集合。
- 选择集合与活动续画起点分别记录。绘制工具也允许保留多选；空白左拖采用与修改工具一致的框选、Shift 追加，作为本稿补齐建议，不把框选路径误认为落点或自由画线。
- 文本框、数值框、菜单、模态和图片工具保留输入边界；骨架快捷键不能修改正在输入的文字，也不能穿透触发团子动作。
- 拖动、挂接、取消、失焦和关闭须释放指针捕获。临时状态不能在切组或关闭后提交到另一个组。

## 6. 修改骨架工具

### 6.1 选择与框选

- 左键点击节点单选；空白点击清除。补齐建议为 Shift＋点击增选／取消选中。
- 左键从空白处拖出选择框，按节点中心落在框内判定；默认替换选择，Shift＋框选追加。未达到拖动阈值时按点击处理。
- 悬停已选节点显示移动光标；从该节点左键按住并超过拖动阈值后进入移动，不把轻微手抖变成编辑。
- P、R 与父目标可能重合，必须有可辨识的候选切换方法。补齐默认为 Alt＋左击循环同一命中区的候选，悬停标明候选身份；右侧点选根也可定位对应 R。S0 校准命中阈值与提示，不重新占用右键选择。

### 6.2 移动

- 普通骨节：只修改所选控制点的初始位置；按第 3.3 节更新相邻骨段、引用子根及受影响绑定。
- 自由 R：只移动 R；本组普通骨节与图像像素不动。关联子根仍按同点约束更新，不平移其普通骨节。
- P：单独移动 P 时不移动图像或骨架点；重算所有自由根相对新 P 的偏移，保持画布初始坐标。佩戴预览使用新的基准定位。
- 方向键按输出图像坐标微调，补齐建议为 1 图像像素，Shift 为 10 像素，不因视图缩放或 DPI 改变步长。
- 多选按共享连接点去重，各点只移动一次。P 可与节点混选；未选节点不因 P 移动而跟着走。完成后统一重算自由根偏移、初始几何与绑定，一手势一次撤销。
- 多选普通移动保持挂接关系；选择某个已连接 R 时，其连接另一端也移动，不部分移动或静默解绑。若最终几何无效则整笔拒绝。
- 已连接 R 的方向键与普通拖动移动共享连接点；显式解除后才独立移动。单根靠近有效新候选的改接仍以明确预览和原子提交完成。

### 6.3 单根拖动挂接

仅在选择恰好一个 R 时启动自动挂接候选判定；框选／选整条骨架的批量平移不触发批量挂接。

1. 从 R 按住左键拖动，基于拖动前快照显示临时位置。
2. 靠近其他组的有效 R／J 时，显示吸附位置、父目标和挂接后骨架的预览虚影。预览不能只高亮候选，却在提交时突然搬动另一组结构。
3. 松开左键时重新验证候选、组修订及无环性，成功后一次提交根位置、引用与初始绑定。
4. 自由 R 无有效候选时，按普通根移动提交，仍以 P 为参考。
5. 已连接 R 的原引用在提交前保留。无有效新候选时普通拖动移动共享连接点，保持原连接；取消时才恢复快照。有效新候选以明确改接预览提交，不产生隐式解绑。

挂接后的根可以通过该手势重新挂接，覆盖早期“已挂根只能先解除再拖动”的建议。相同目标且无实际变化时不新增撤销项。

## 7. 绘制骨架工具

- 追加只针对当前活动组的有效末端／无骨段根；左击其他组现有节点可以切换活动组和起点。不存在组时先创建组，不允许点击空白直接创建根或组。
- 左键点击已有节点选择它，并确定所属活动组；不在同一位置追加零长度骨段。追加节点须有明确的单点续画起点；多选时不暗取其中某个点，也不批量生长，先单击一个有效末端／根再续画。
- 选中 R 且该链没有骨段时，点击新位置创建第一个普通骨节；选中末端时继续追加下一骨节。新点自动成为选中点与下一次起点。
- 每组只有一条链。选中内部节点点击空白不产生同组分叉，也不截断或覆盖原后缀；提示选择末端，或从该点创建新图层组。已有骨段内加控制点使用“在此插入骨节”命令。
- 鼠标悬停已选节点显示移动光标；从该点开始左键拖动并达到阈值时，自动切换修改工具并承接同一手势，不先追加节点。补齐建议为切换持续有效，松手后不自动回到绘制工具。
- 空白处按下后拖动执行框选，Shift 追加，不视为一次落点；未达到拖动阈值的有效空白点击才尝试追加节点。临时新段只在点击及单链起点校验均通过后进入草稿。
- Enter 结束当前续画；Esc 取消当前未落点段或当前拖动，不删除已完成节点；Ctrl＋Z／重做进入同一工程历史。

## 8. 挂接命令状态

右键根选择“挂接骨架根”后，进入一次性的命令状态，而非第三个常驻工具。R 临时粘连鼠标，原数据保持到提交。

| 状态／输入 | 结果 |
| --- | --- |
| 鼠标移动 | 更新临时根位置；接近有效其他组 R／J 时显示与拖动方式相同的挂接预览 |
| 左键点击有效候选 | 重新校验后提交，一次操作结束；当前活动对象仍为源组及其根 |
| 左键点击空白／非法候选 | 不提交、不创建节点、不改变父目标；保留命令状态并指出原因 |
| Esc 或右键取消 | 恢复进入命令前的坐标、引用与选择，退出命令；本次右键不同时弹出另一个菜单 |
| 切组、失焦、捕获丢失、隐藏、关闭或源／目标修订变化 | 取消未提交操作并恢复快照；不得把旧结果提交给新组 |

拖动挂接在左键释放时提交，命令挂接在左键点击时提交，两者共享候选命中、无环校验、影响范围、绑定更新与撤销路径。吸附阈值和候选优先级按显示坐标校准，不固化未经验证的像素值；多个候选必须能辨认与切换。

## 9. 删除与无漂浮规则

Delete 和右键删除使用同一事务：先对整个待删除集合计算最终图，验证成功后一次提交；失败保留全部节点、图层、引用与选择，并说明阻止原因。

删除后须满足：每组仍有自己的 R，保留节点沿本组链可达 R，所有跨组根引用仍指向存在且允许的目标，组间依赖无环。这里的“漂浮”指失去有效根路径或挂接引用，不是二维图像中没有像素相接。

以 `R—J1—J2—J3` 为例：

- 删除 J3：允许。
- 只删除 J2、保留 J3：按2026-10-28用户新规则允许，J1直接连接J3；保留骨节坐标不变。
- 同时删除 J2、J3：本组结构允许；多删区间连接最近保留的前点。
- 被删J是另一个组的挂接目标：根引用重接该J最近保留前点，相连根移至同点；不移普通保留骨节。最终出现零长度骨段或其他非法结构时整次拒绝，不留下半次修改。
- 删除全部普通骨节：允许退回只有 R 的状态，其他组原本挂在被删J上的根相应重接R；子组本身保留。
- 直接删除 R 或 P：拒绝。R 随图层组管理，P 是整件必需基准。

右键“清空骨节，保留根”明确删除该组普通骨节，仍经过上述验证，不等于自动删除子组。图层组管理按第 12 节默认合同：删除组保留并脱组其图层；若其他组仍引用该组任一节点则拒绝，先由用户改接／解除。不能因组为空而跳过引用检查，也不连带删除图层或子组。

## 10. 右键上下文命令

右键只确定鼠标下的上下文目标，不替换选择、不改变活动组。命令成功后再按该命令更新活动对象。若上下文目标在现有选择中，删除命令可作用于整个选择；否则明确使用“删除此骨节”，只操作该目标。

| 上下文对象 | 建议菜单命令 |
| --- | --- |
| 普通骨节 J | 从此骨节创建图层组；选中所在骨架；删除此骨节／删除所选节点（Delete，同一校验） |
| 骨架根 R | 从此根创建图层组；选中所在骨架；挂接骨架根；解除挂接（已挂其他组时）；清空骨节，保留根 |
| 骨段 | 在此插入骨节；新点保持组内单链、初始骨段非零 |
| 配饰根 P | 从此处创建图层组；选中全部骨架；不提供删除 P 或把 P 挂到骨架上的操作 |

菜单命令的目标和影响范围必须可辨识。无效命令禁用时说明原因，不以菜单隐藏或假成功掩盖结构失败。以上补充项属于本稿建议，不扩大为新的常驻工具。

“选中所在骨架”只选择该组的 R 与普通节点，不自动选中挂接的其他组；“从此骨节创建图层组”是创建新组，不是把父骨架分成两组。

## 11. 草稿、运行时与后续验证边界

- 图像、图层归属、P、骨架根／节点、挂接引用和属性属于同一可撤销工程修订。一次拖动、挂接、创建组或删除集合各为一次操作，不逐帧填满撤销历史；临时预览不写正式数据。
- 编辑器确认仅回传当前配饰定义草稿，不能覆盖外层较新的佩戴配置；模态取消恢复进入前草稿。外层应用仍是正式保存入口，保存失败保留草稿；过期回调不能跨组、跨会话写入。
- 空组／根状态合法不等于全透明整件可作为成品应用；既有成品图像校验、原文件保护和失败恢复继续有效。
- 独立变形的组必须保留独立绘制片及绑定，不能先压成一张 PNG 再声称各组独立运动。未分组层仍参与正确的透明叠放。组合预览图可以合成，但不能取代运行所需的组结构。
- 本版补齐默认为图层组不嵌套、在绘制栈中占连续区间，骨架挂接层级通过引用表达。不连续图层的批量归组直接拒绝并提示先重排；不静默改变遮挡。组管理的完整默认行为见第 12 节及 UI 合同。
- 工程需版本化保存稳定组／节点 ID、图层归属、P、根目标、初始坐标与各组参数；速度、动态伸缩、当前网格和临时鼠标状态不持久化。版本号、格式与旧工程处理策略另行冻结，不复用旧版本号悄悄装入新结构，不自动迁移或删除旧数据。
- 继续复用成功帧、唯一 owner、暂停／隐藏／换宿主合同，不引入额外计时器、物理世界或身体反作用。多组纹理、节点、网格、撤销历史及全部佩戴实例必须有总预算；不能把现有 8 件上限等同于每件可无限加组。

依据[桌面界面规范 v0.1](../desktop-ui-design-v0.1.md)第 2–6 节：后续界面保留暖白、细棕强调、中文辅助名称、必要数值与反馈；两部分内容可分别收起，提交与错误反馈保持可达；参数直接跟手，菜单／模态／拖动输入不穿透，滚动与画布缩放按各自区域消费。图标、游标、候选区分、布局尺寸及过渡手感留给后续界面设计与真实输入验证，本轮没有视觉验收。

后续至少须验证：

- 创建空组自动且只生成一个根；绘制点击不能生成根或隐式分组；未分组层不受组骨架影响。
- 末端续画与骨段插点正确；内部节点空白点击不会悄悄分叉；新点自动选中，拖已选点不误加点。
- 左键单选／Shift 框选／重叠点选择正确；普通右键只出菜单，不改变选择集合。
- 两种挂接方式预览与提交一致；无候选、Esc、失焦、切组、目标删除和过期消息不留下半次连接或输入捕获。
- 拒绝自身组、后代组、双父及循环；父子多选不重复变换；挂接根和父目标在运动与伸缩中仍同点。
- Delete允许末端或中段；保留前后骨节直接相连，多删区间与跨组根引用重接最近保留前点；坐标／引用变化原子完成并可撤销。根和P不可单删，零长度等非法最终结构仍拒绝。
- 各组属性互不串值；重力无继承；弯曲 0／伸缩非 0、弯曲非 0／伸缩 0、两者均 0 有独立反例。
- 保存／取消／撤销／重开保持组和引用完整；透明层顺序、总资源边界、真实宿主活动性能及人工观感分别验证。

以上为验收要求；接续实现和实际检查见统一实施记录，不能以旧 S0 结果代替。

## 12. 补齐建议与尚待冻结项

以下默认规则是为本次明确指令补齐的建议，不能写成用户逐项批准：

1. 自由新根初始在 P。根拖动范围不是补齐建议，已由用户确定为只移动根；同点约束传播、P 偏移重算和混选按第 3、6 节执行。
2. Shift 点击切换增选、绘制工具也支持空白框选／Shift 追加但多选不直接续画、跨组属性采用活动组、单根才自动挂接、多选冲突整次拒绝、绘制拖动后持续留在修改工具。
3. 粘鼠标命令以 Esc／右键取消；已挂根拖到无效位置恢复原连接；上下文目标与选择分离，以及第 10 节菜单补充。
4. 普通骨节删除按2026-10-28用户明确修订搭接保留前后节点并重接根引用；不删子树、不静默丢组，根不单删。删除组仍仅删除该组定义与骨架，原图层按原序脱组；被其他组引用时整笔拒绝，须先改接／解除；删除图像内容仍用独立图层删除命令。
5. 共享连接点双向作用、图层组不嵌套、组在绘制栈占连续区间。新建空组位于当前插入位置，层导入／绘制落入明确活动层，不能把组根当作图像层。批量归组仅接收连续图层，且不得跨越其他组或拆走被选集合外的层；拖入组明确显示插入位置，脱组移动到原组相邻边界并预览最终栈。重排是显式可撤销动作；与挂接关系无关。
6. 组／层重命名、可见性、透明度及上下移使用现有同义操作；选组上下移移动整个连续块，选层仅在允许的所属区间重排。清空组不自动删除骨架；选中所在骨架不包含其他组。

上述补齐默认供后续实施使用，来源是本稿设计而非用户逐项口述；S0／S1 验证发现需要改变用户可见语义时记录具体差异。实现者不自行留空、改为静默重排或重新引入继承选项。

以下影响工程或产品语义，按配套实施计划在依赖该项的正式实现前冻结；不要求先完成全部工程冻结才能验证最小输入样板：

- 伸缩恢复与阻尼耦合的数值映射；范围、默认和对称性已由用户确定。面板采用“弯曲幅度”（原柔软度）以贴合角度限幅语义；现恢复参数展示 rad/s，不把频率输入误标为其平方单位。
- 整体重力与组重力各自的实际加速度／力矩映射和稳定策略；整体独立可调及组无继承已确定。具体初始化值与保留范围见 UI 合同，S1 只校准数值行为。
- 新工程格式、旧工程的保护与重开策略、绑定算法，以及多组总资源与性能预算。由配套实施计划安排评估及接续 ADR 0007 的变更决策，在依赖它的正式实现前冻结；不默默改写已接受 ADR 的历史，也不用本文或计划代替该工程决策。
