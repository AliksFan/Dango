# 团子行走自然感小样设计与验收条件

日期：2026-09-22。状态：**设计及实施已获授权，小样已实现；自动与实时结果见验证记录，人工观感待确认，数值仍为本轮试验候选。**

用户在阅读本设计后回复“我也无法模拟出效果，先试试吧，按上述两点继续制定实施计划”，确认普通单团子同时覆盖自主散步/键盘横移，以及先试贴地、最大新增位移 2 DIP 的候选；已据此形成[实施计划](2026-09-22-gait-sample-plan.md)。文中的推荐方案作为首轮计划依据，数值不等于已验证观感；路线、设计确认、编码授权、人工验收和日常交付分别记录。

## 1. 目标、范围与起点

本批只增加两个相互配合的表现：

1. 行走时轻微“压缩 → 舒展 → 放松”，始终沿用真实地面位置，眼睛与帽子协调跟随。
2. 起步逐渐进入步态，收步平滑回到当前真实身体的自然形状；短按、急停和转向不跳姿态。

推荐覆盖 Product 普通入口、单实体、Window/Wallpaper 两宿主，自主散步和键盘左右移动共用一套规则。键盘并不因此获得新的加速、刹车或速度曲线。DeveloperReview 和多实体场景默认不启用本批步态；后续可在测试夹具中构造异常状态，但不能把它称为多人步态。

不加入脚、跳步、身体整体上下漂移、前倾/扭身新动作、音效、动作性格、完整动作调度系统或用户设置项。不扩展捏脸、联网、岛、真实大小和柔软度；真实快慢节奏仍与多人移动规则共同设计。既有眨眼、面向、跳跃眼动、帽子惯性、轻互动及打盹保留各自语义。

只读起点：本工作树从本地 main 的 `e8938d3` 开始，初始 detached HEAD，工作区干净。已核对路线提交 `75f6b8d` 仅含四份文档，且其父提交与本地起点在相关基线文件上没有差异；在本任务分支 `codex/gait-sample-design` 纳入为 `032809d`。未修改来源工作树，也未合并 main。

主线包含产品闪回修复 `8329397`，其[交付记录](../verification/2026-09-22-transient-spawn-flash.md)登记日常版本 `83293977ad19-63945cc70d88`。设计编写时未检查日常环境；实施后的只读核对和隔离证据见本批验证记录，日常实例与设置保留。Phase 1 仍实施中；第二 DPI、多屏、兼容、GPU 呈现及长测等延期安排见[阶段计划](../development-plan-v0.1.md)。

## 3. 推荐方案与取舍

推荐在**原物理和眼帽求解完成后**，生成一份只读的步态局部变换，随完整呈现帧发布。身体、双眼和独立帽子消费相同结果；宿主只负责绑定，不拥有步态时钟。

| 方案 | 取舍 |
|---|---|
| 原呈现结果之上共用有界局部变换（推荐） | 改动边界小，原物理和眼帽求解保持独立；相同变换保留挂接关系。需明确实际绘制几何、命中和裁切校验。只适合本批的小幅形变。 |
| 先改身体轮廓，再重新解算眼帽 | 可适应更大、更局部的变形，但会改变帽子轨道、形状倾斜和眼睛安全缩减结果，并可能把视觉波形当成真实身体激励。留作小样不足时的独立设计，不同时实现两套。 |
| 周期修改输入、物理力、约束或刚度 | 能产生真实步行起伏，但改变速度、碰撞和停止距离，超出本批；放入多人移动规则共同设计。 |
| 每个部件独立动画或直接套旧下压工具 | 容易产生眼帽脱节、时钟重复和字段丢失，不采用。 |

这是已确认作为首轮小样依据的局部呈现方案，不修改已批准物理架构，不新增依赖或永久技术承诺。本批无需把试验参数另立为已批准 ADR。

### 3.1 单向数据流

每个成功物理步依次处理：

1. 原有手动/自主仲裁照常构造一次物理输入并推进一次物理世界。
2. 使用原始物理快照及原始身体几何完成既有眼帽、反馈和待机计算。
3. 自主移动的可见边界仍读取**未叠加步态的原呈现结果**；保持原随机抽样、驱动起止和边界决策。步态不得消耗自主散步的随机序列。
4. 从该成功步采集实际核心位移、归属和抑制条件，计算本实体唯一的候选变换；仅在呈现侧缩减其幅度以满足几何、安全边缘和命中误差条件。
5. 原始呈现数据与步态描述符作为一个完整结果发布。Window、Wallpaper 和其帽子 overlay 只读应用该结果，不反写 AuthoritativeBounds、RenderOffsets、Core 场景坐标或物理输入。

候选状态只包含实体/代际、上次成功采样、移动归属、相位、当前变换及缓入缓出进度。沿用 runtime 生命周期，不建设通用动作框架，不持久化、不上传、不新增定时器。具体类型及字段在设计确认后的实施计划中确定。

### 3.2 身体、眼帽和脚底统一呈现

先把既有身体曲线、双眼完整轮廓、帽子实际轮廓和挂接点解释到同一 Canvas DIP 空间。在此空间以**当步未叠加步态的可见身体曲线底边**为纵向锚、身体可见宽度中点为横向锚，施加正尺度仿射变换：

```text
x' = centerX + sx × (x - centerX)
y' = bottomY + sy × (y - bottomY)
sx = 1 - 0.5 × (sy - 1)
```

Canvas 的 y 向下。压缩时 sy 略小于 1、横向略宽；舒展时 sy 略大于 1、横向略窄；放松时回到单位变换。没有整体位移、旋转或剪切，也不要求严格守恒面积。锚点须来自同源曲线采样或解析极值，包含采样误差；不能取控件底边 120、出生点或轮廓控制点的最小 Y 代替脚底。

共享变换放在**身体/眼睛的内部绘制组与独立帽子的内部绘制组**，保持外层透明命中控件和宿主定位不变；顺序为先完成既有眼帽局部变换和帽子尺寸，再施加相同步态变换。既有内嵌帽绘制若被启用，也只能消费一次相同结果，防止双重变换。

完整眼睛图形、帽子接触区、角度所对应的几何和全部帽子形状一起变化，不能只平移中心而漏缩放形状。既有面向、眨眼、跳跃眼动和帽子惯性仍由原管线解算，不从步态后的形状推导新的物理速度，不额外给帽子一个周期弹跳。

物理调试骨架、命中边框不跟随假形变，保证能看到视觉与物理的差异；zzz 不属于步态组，打盹期间步态为零。继承的隐藏、回退帧和表情状态不能因构造新帧而丢失。

## 4. 节奏来源与起停连续性

输入意图只说明“谁在尝试行走”；强度和相位需要实际位移证据。只有当前自主驱动或键盘横移拥有者，才可启动步态；被推、拖拽、抛出、原地节点抖动和单纯垂直运动不建立归属。

相邻成功物理步的核心水平差换算到当前场景 DIP，沿归属方向的正向进度累加相位。候选每前进 60 DIP 完成一轮：单位形状 → 轻压缩 → 轻舒展 → 单位形状，各段端点用零斜率曲线连接。相位候选关键点为 0、0.2、0.55、1；0 与 1 处形状及变化率一致。高速时相位最多 2 周/秒，多余路程直接丢弃，不积压到以后追赶；不设置最低播放频率。

实际速度通过有界平滑形成幅度目标，速度趋零时目标也连续趋零。进入/退出速度迟滞只防止噪声反复触发，不是速度一过阈值就跳到满幅。首次采样只建基线，不计算速度、不补走一段相位。

- **起步**：取得稳定地面与移动资格后，从当前显示形状缓入；首步中性起相，不预先下压等候位移。不改变键盘或自主物理输入的生效时机。
- **收步**：撤去驱动后立即冻结相位，从当时实际显示的变换向单位变换单调回收，不继续播放余速半步；物理余速照常存在。这样即使在单位形状处松键，也不会又压下一次。收步期间静止不停止回收，不能定格在压缩或舒展极值；因低速/零进度退出也采用同一规则。
- **快速再起步**：从当前形状及变化趋势过渡，不先清零再播放；若无连续有效样本则先重建采样基线。
- **反向**：物理立即收到新输入，旧方向归属终止。步态先从当前形状收回，新方向确有正向位移才重新进入；不能把旧惯性当新方向步态，也不强制跑完上一轮。

下列数值是**首轮试验候选及拟议失败线，尚未经过真实小样验证**；用户已同意先试 2 DIP 上限，其他数值作为实施起点，不代表逐项冻结。可在不扩大本批范围下根据小样提出修订，但不能通过偷偷放宽失败线接受错误结果。

| 项目 | 首候选 |
|---|---|
| 基础资格 | 单实体、可见健康、无交互抢占；有效贴地几何且竖向速度绝对值不超过 12 DIP/s 连续 100 ms |
| 中性形状参照 | 关闭步态、无占用、低速稳定 500 ms 的原物理可见轮廓；步态/受压中冻结参照，不把被压扁的形状重新学习为中性 |
| 速度迟滞与平滑 | 进入 8 DIP/s，退出 4 DIP/s；幅度速度平滑时间约 80 ms，40 DIP/s 左右达到候选满幅；不得让平滑速度在零进度时继续推进相位 |
| 形变范围 | 满幅 sy 压缩至 0.98、舒展至 1.01，sx 按上式补偿；所有部件的最大新增位移仍受 2 DIP 总上限裁剪 |
| 路程与频率 | 每轮 60 DIP，最多 2 Hz；用成功步时长限制，不读宿主回调次数或墙上时间 |
| 起停 | 起步约 200 ms 缓入；普通撤去驱动后 300 ms 收回，最迟 350 ms 加一个成功步内新增位移不超过 0.1 DIP |
| 普通连续性 | 在同一份原始几何上比较连续两步的变换，10/20/40 ms 成功步下，任何部件的新增跳变不超过 0.75 DIP；不把真实身体位移计作步态跳变 |
| 明显变形抑制 | 相对稳定中性轮廓，高度下降超过 8%，或宽度/面积偏差超过 10%，即视作不适合叠加步态；它是保守几何门槛，不声称识别了碰撞压力 |

若无法取得可靠中性参照、支撑或安全几何，保持原身体表现，待资格恢复再进入。若正常行走持续被上述门槛挡住，应报告假阴性并复核设计；不能用始终关闭的步态通过验收。

## 5. 抑制、退出与恢复

优先级为已有故障/生命周期规则 → 拖动、跳跃、下压及不安全物理状态 → 手动轻互动/打盹 → 步态。步态只管自身贡献，不清物理速度，不释放其他动作的眼睛通道。

| 情境 | 步态行为与恢复条件 |
|---|---|
| 正常自主或键盘横移 | 资格满足且实际有进度时启用；两条路径分别验收，使用相同几何与节奏规则。 |
| 按住键但被阻挡、短暂原地抖动 | 零进度不推进相位；低于退出门槛后收回，持续无进度 350 ms 内归零，即使方向键仍按住。不新增解困、倒退或驱动超时规则。 |
| 松键/自主驱动结束 | 按第 4 节收步；收步期限结束即失去归属，不把长滑行永久包装成行走。 |
| 命中按下、点击/抚摸候选 | 立即让原输入处理；步态停止接纳相位，在仍安全时不超过 120 ms 收回。不等到 3 DIP 起拖或反馈成立才让出。 |
| 拖动或抛出 | DragActive/开始拖动即取消归属；不得因较大横向速度触发行走。落地后重建样本并重新取得资格。 |
| Jump、Squash、离地、落地弹动 | 下一次完整成功帧不叠加步态；低竖向运动、支撑稳定且原下压已释放后再进入。空中不能通过“底边锚定”冒充贴地。 |
| 碰撞受压或几何异常 | 多实体场景整批禁用；单体出现明显压缩/异常面积/无可靠底部时关闭步态，让真实形变可见。不得用累计 ContactStepCount 锁死资格，也不声称完成了多体碰撞检测。 |
| 接近边缘/帽子被裁切 | 根据原始安全余量逐渐缩减共享变换，必要时单位变换；不改变自主方向、原驱动撤销时机、宿主大小或物理位置。 |
| 自主与键盘接管/左右反向 | 旧归属退出，新输入照常立即生效；不跨拥有者或方向累计路程，新有效采样只建立基线，显示从当前形状连续过渡。 |
| 自然眨眼、面向/帽子惯性 | 继续原有求解，不新增对眼帽通道的占用；有手动轻反馈或打盹占用时步态退出。 |
| 隐藏、最小化、切模式、失去宿主 | 丢弃驱动归属与速度/路程历史，停止计时；保留最后完整显示帧和当时变换，不在未显示时补播。恢复时先重绑这一完整帧，首个成功步重建基线并从保留形状收回，随后重新判断资格。 |
| 仍可见但禁用交互 | 不暂停现有物理；禁止新步态及相位推进，已有形变在后续成功步安全收回。计划核对确认此时原宿主仍在 Tick，不能像隐藏一样永久冻结残余形变。 |
| 焦点变化/坐标或 DPI 变更 | 沿用原输入取消；使跨段速度样本失效。坐标迁移不计作行走距离，新的宿主不能重复推进上一宿主的动作。 |
| 实体增减、重置、退出 | 新代际不继承旧相位、速度或归属；实体不存在时不显示旧变换。显式重置沿用原重置后的完整帧语义，不把旧姿态套给新身体。 |
| 物理失败 | 沿用原错误锁存与安全呈现帧冻结/回退，保留随该帧发布的完整步态姿态，不继续推进步态、不重建物理世界。 |
| 附件失败 | 沿用原管线返回的当步身体与冻结附件结果；在同一结果上对身体、双眼和帽子统一撤销步态并禁用至显式重置，不改变后续物理推进策略。步态层不得另取其他帧的部件自行拼接，也不声称原附件故障已经解决。 |
| 仅步态计算失败 | 同一完整帧将身体、双眼、帽子全部回到未叠加步态的原结果，并关闭本次会话步态直至显式重置；原物理与原错误状态不改。仅记录安全错误码，不每帧反复重试或刷日志。 |

普通缓出必须通过连续性门槛。拖动、离地、受压、越界或无效几何的安全退出不为等候缓出而延迟：若残余变换不再安全，整个步态贡献可在同帧归零，最大跳变只允许来自原先不超过 2 DIP 的步态贡献，此项单独记为安全回退，不冒充普通平滑停止。冻结完整成功帧的故障路径仍按原策略保留，不只清其中一个部件。

## 6. 视觉、物理与点击误差边界

1. **物理零变化**：碰撞体、形状节点、硬度、输入、固定步长、随机抽样、驱动起止、停止距离和地面高度保持原值。不重新分配出生点，不调整宿主位置掩盖接触问题。
2. **误差以原呈现为基准**：对同一步原始身体曲线与步态结果比较，包含双眼、全部帽子轮廓及当前 1.35 倍帽子显示。任一对应可见点的新增距离不超过 2 DIP。该上限不是“视觉与碰撞轮廓的总误差为 2 DIP”，既有矩形命中与软体轮廓本来就不同。
3. **脚底**：所用锚点与独立求得的可见曲线底边误差不超过 0.02 DIP；变换前后曲线最低点的宿主 y 差不超过 0.25 DIP（含采样误差）。两项分开检验，不能因形变小而容忍锚点错误；不得新增肉眼可见的离地缝隙或穿地。若原物理已经异常，退回原表现并报告，不借变换修正真实接触。
4. **眼帽安全**：使用变换后的完整曲线检查眼睛仍在有效脸部区域，沿用当前安全边距、最小眼距及帽子接触容差；共享变换保持拓扑关系不等于自动满足绝对 DIP 安全距离。检查不通过时统一减弱全部变换，不单独挪眼或摘帽兜底。
5. **命中**：保留两宿主现有命中矩形与拖动阈值；新增形变不得使原本可点击的身体部分越出既有命中范围。用轮廓边缘样点及矩形边界内外样点验证两宿主输入结果，与关闭步态对照相同；也要人工点压缩/舒展两极时的上下左右轮廓，不接受明显“点在身上却点不中”。不为步态扩张输入代理，也不把帽子变成可点区域。
6. **边缘与裁切**：自主时沿用左右 16 DIP、上下完整可见的原规则；已有 32 DIP 停止预留及目标距离算法不变。独立帽子和 Wallpaper overlay 的实际裁切范围也参与检查。原始帧已越界时不承诺用步态修复，至少关闭新增形变。

上述限制共同决定一份共享幅度；不能对每个点独立 clamp 而扭曲轮廓。正常情况下提前用余量连续减幅；突发不安全状态可以整体回退。实现若因 2 DIP 上限导致观感不够明显，应带小样请用户判断，不能先增幅再放宽验收。

## 7. 能失败的自动验收

以下为本批验收要求；实际执行证据及未验证项见[验证记录](../verification/2026-09-22-gait-sample.md)。测试先构造错误情况下会失败的断言，再接入实现。用确定的虚构输入及显式随机序列；几何/状态测试与真实 native、WPF 宿主验证分别记录。

| 编号 | 输入与观测 | 必须通过的结果 / 应抓住的错误 |
|---|---|---|
| A1 有效果的正例 | 自主与键盘各取稳定地面、开阔空间的实际横移，左右各至少两完整周期 | 每轮同时出现低于和高于原始高度的样本，最终回中；峰值新增位移至少 0.5 DIP 且不超过 2 DIP。完全不做形变不能通过。 |
| A2 依据位移 | 同样方向输入，分别喂正常位移、零位移、原地节点抖动、纯垂直位移、无归属的横向推移/拖动 | 只有有归属且合资格的真实横移进入步态；MaximumSpeed 很高但核心不动不能通过正例。 |
| A3 时间与距离 | 10/20/40 ms 成功步、相同低速总路程，再插入 0 步/重复宿主回调；另测超过 2 Hz 的位移 | 相位低速一致到一个采样步，单位路程决定周期；高速封顶，无路程积压，停后无追赶。若按回调计时、无步仍播放或只按键时长循环即失败。 |
| A4 起停与反向 | 在压缩/舒展极值及单位形状处松键，自主结束、短按、快速重按、旧方向仍有惯性时反向 | 普通变化满足 0.75 DIP 连续性；收步相位冻结，在相同原始几何上观察到的新增偏离单调回收，350 ms 加一步内回到 0.1 DIP；原物理输入同一步生效。强制清零再起、松键后又压下一次、等一轮结束才接管均失败。 |
| A5 脚底与形状 | 原生正常轮廓和通过原几何有效性检查的专门样本；独立解析 B-spline 极值，与所用锚点及变换后曲线比较 | 锚点误差≤0.02 DIP、曲线脚底增量≤0.25 DIP、点位移≤2 DIP、无反转/自交/额外裁切。专门样本须使控制点最低值与真实曲线底边相差超过锚点容差，实际验证错误锚点会失败；不能只靠小幅形变后的脚底漂移断言。 |
| A6 眼帽完整性 | 三种现有帽型、当前帽子尺寸，组合左右面向/眨眼/惯性；检查实际绘制后的眼轮廓、帽沿和挂接 | 身体、双眼、独立帽全部应用同一变换且仅一次，保留绝对安全距离；漏帽、只动眼中心、重复缩放、丢 Attachments/DozeSeconds 均失败。 |
| A7 点击与拖动 | Window 的真实 WPF 命中与 Wallpaper 输入代理，对相同宿主逻辑点执行两相位的命中/按下/拖动阈值检查 | 两宿主结果与原基线一致，新增可见区域不跑出可点范围；把 RenderTransform 加在根控件导致命中移动时失败。 |
| A8 抑制与恢复 | 按住但零进度；Jump+横移、Squash+横移、Drag、离地/落地弹动、受压/无中性参照、轻反馈、打盹 | 按第 5 节退出；残余安全回退同帧覆盖全体部件；稳定后能重新启用。仅见 Grounded 就启动、永久定格或永久关闭均失败。 |
| A9 接触/多体边界 | 历史 ContactStepCount 非零但当前单体正常；实体从 1→2→1，Review 与 Product 对照 | 累计计数不造成永久抑制；多体/Review 单位变换，返回单体重建资格，不恢复旧相位。不得把多体关闭称为碰撞步态已通过。 |
| A10 物理对照 | 步态开/关两次运行相同 native 版本、固定步和随机序列；覆盖自主/键盘左右、停止、跳压拖、近边缘 | 送入物理的逐步输入、步数、随机抽样次数、自主起止步号相同；原始核心、节点、面积、接触结果逐帧相同。若环境本身不能逐值复现，先查基线，不自行放宽至“看起来差不多”。 |
| A11 防视觉反馈 | 构造自主方向选择和撤驱边缘临界样本，同时使步态舒展/帽子接近安全边界 | 驱动决策与关闭步态完全相同；只减弱呈现并满足原可见余量。把增强后的 LastFrame 传给 WanderVisibleBounds 即应失败。 |
| A12 宿主闪回保护 | 扩展 [HostPresentationContinuityTests](../../tests/Dango.Desktop.Tests/DesktopHost/HostPresentationContinuityTests.cs)：先真实移动离出生点超过 20 DIP，再插入半步、重复回调、首次布局和恢复布局 | 零步时 LastFrame、身体/帽子 Canvas 坐标、内部步态矩阵、双眼最终边界和帽子锚全部不变；下一成功步完整更新。只测 Canvas 坐标会漏掉“零步只清步态”的错误。 |
| A13 生命周期 | Window↔Wallpaper、隐藏恢复、暂停/禁用交互、坐标迁移，注入旧代际回调和首次成功采样 | 恢复先显示最后完整帧，首样不累积跨段距离，随后平滑收回/重入；隐藏无计时/补播，旧宿主不能推进。清 LastFrame 或回出生点、身体和帽子不同步都失败。 |
| A14 失败回退 | 无效样本/几何、单独步态异常、附件故障、物理失败、显式 Reset | 不出现 NaN/无限缩放；步态失败统一回到未叠加结果，物理失败沿用原安全帧冻结；附件失败时步态统一归零，原附件冻结且后续物理仍按基线推进。不额外追加/阻断物理步、不重新建世界，重置后不继承旧状态。 |
| A15 既有行为与开销边界 | 关闭步态或不合资格时对照原产品入口、短散步、轻互动、待机/打盹、附件及宿主调度相关测试 | 无新增失败，不增计时器、输入监听或每部件独立采样；无动作时复用单位变换，不重复构建同源几何。完整性能专项结论仍留到原定联合验收。 |

实施时至少实际验证这些反例会被抓住：无条件返回单位变换、用按键计相位、只缩身体不缩独立帽、在零步清变换、把步态边界反馈给自主驱动。可以用局部临时错误实现/测试替身验证断言，修正后保留相应红/绿证据；不要求引入变异测试框架。

受影响构建与回归随实现执行，不能延后。历史旧 DLL 缺失 `dango_box2d_self_bodies_create` 的失败不得通过替换生产 DLL、删除测试或放宽条件“修绿”；本次无测试运行，不引用旧通过数量作为新步态通过数。

## 8. 人工观察与通过界线

设计和实施计划批准、完成受影响自动门禁后，从本任务项目输出启动隔离候选窗口，使用独立虚构设置及现有已验收物理模块；先提供可直接观察的小样，不以 ZIP 或日常安装替代。本次按已批准计划启动隔离候选，保留人工停止点。

| 观察项 | 操作与通过要求 |
|---|---|
| 自主自然感 | 每宿主观察至少 3 次完整自主散步，最终覆盖左右；保留真实等待和距离，不加速计时。轻微压缩、舒展与放松能辨认，像沿地面向前挪动，无上下漂浮、橡皮球弹跳或明显周期抽动。 |
| 键盘起停 | 两宿主各做左右持续移动、短按、在两种形变极值松开、快速重按和反向；没有启动顿一下、收步弹一下或原地踏步，输入响应与原版本一致。 |
| 身体/眼帽 | 三种现有帽子都观察走动与停止，并覆盖面向和眨眼；眼睛始终在脸上，帽根贴合，急停惯性不被新增周期反复拉扯。 |
| 退出与阻挡 | 行走中点击、抚摸、拖动、跳跃、下压；有可用真实阻挡场景则观察顶住，不制造障碍或新增碰撞功能来凑验收。步态及时让出，离地/受压不继续蹦，重新落地后不会永久失去步态。无法真实构造的阻挡另列“未验证”，自动零进度样本不替代它。 |
| 点击与贴地 | 在压缩/舒展两极点击上下左右可见身体，试原拖动阈值；看脚底和帽子边缘，不出现明显点偏、悬空、穿地或裁切。 |
| 双宿主与恢复 | 两宿主都在走动中隐藏/恢复，Window→Wallpaper→Window 往返，并在静止时再做一次；不闪出生点、不出现旧眼帽、恢复后不补播隐藏期间动作。 |

自动门槛满足但人工仍觉得“滑、弹、突兀或看不出变化”，本批仍待调整；人工觉得自然也不能豁免物理轨迹、点击或闪回门禁。只可按“自动 / 实时 / 人工”分别记录结果。
