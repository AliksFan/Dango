## 2. 已通过的场景入口

1. 首页展示自身真实运行时团子。W 收起首页编辑界面，进入二维横向门廊；不增加三维空间或第三人称引擎。
2. 团子在门廊水平移动，镜头跟随其世界位置；房门沿后墙横向排列，门底接地。场景地面、门和团子使用一致的世界到屏幕映射，不能只滑动假背景。
3. 门廊只列出本人获准查看的房间入口，不是公开广场；公共房仍需有效码／定向链接。点击选择或靠近门不等于进入，W 交互或可点击入口发起准入。
4. 正式在线房间的目录、容量和权限由服务端提供并逐次重验，客户端门的显隐不是授权依据。本地单人桌宠入口只走本地场景就绪，不伪造在线准入。
5. 目标显示就绪后，控制界面才隐藏；正式在线入房另须准入成功。桌宠房环境固定壁纸层，同一团子独立显示在普通／最大化应用上方；必须确认同次双表面新健康帧实际呈现、坐标一致和单物理 owner，不能仅见一层就视作成功。共同房默认新独立场景窗口，也允许在壁纸层呈现完整独立场景，不与真实桌面交互。
6. 房间与门廊共享同一团子身份；不同场景的本地位置和相机不是新业务团子或第二个房内占位。门廊移动不得发给仍保留归属的原房。

原型中的相机跟随及转场数值为实施调参起点，不是服务器时间、网络延迟或新的性能承诺。

## 3. 已通过的回门廊入口

| 环境 | 主入口 | 键盘与恢复边界 |
|---|---|---|
| 共同房独立窗口 | 左上角“小门＋房门” | 窗口有焦点且输入控件／弹窗未消费按键时 Esc 返回；不捕获全局键盘 |
| 桌宠壁纸房间＋独立上层团子 | 右键独立团子，精简菜单第一项“房门” | 两表面作为同一场景退出；不要求按 Esc，不抢用户工作输入；托盘同样提供“房门” |
| 共同房壁纸层 | 场景中自己的团子菜单与托盘“房门” | 同样不读取真实桌面，不把壁纸层当成桌宠房型 |
| 隐藏画面 | 托盘打开门廊或恢复画面 | × 只隐藏，不离房、不下线、不解散 |

返回时收起房间画面、恢复控制界面的门廊，采用约 320 ms 柔和转场；减少动画时跳过位移动画。返回不弹确认框；正式在线会话不清空当前归属、不主动断开房间连接。新房准入成功前仍保留原房；有有效原房时可以返回，无房时不显示“返回原房”。恢复在线原房画面必须核对最新权威状态，不重放隐藏期间输入。

本地单人桌宠隐藏时同时收起房间环境和团子、暂停物理与输入、保留会话内状态；恢复重新确认双表面首帧。返回门廊须完成同一场景交接，不能把上层团子遗留在工作应用前。不新增跨重启房间存档或自动入房。

## 4. 已通过的归属修订

本节是正式在线归属和席位规则，不作为本地单人桌宠的运行前置；本次分层修订不重新定义注册初始归属或联机身份接入。

不变量：一名用户仍只有一只主要团子；该团子同一时刻最多归属一个有效房间。`none` 是合法、可持久化和可恢复的无房间状态，不是房间类型，不删除团子身份。

| 事件 | 处理 |
|---|---|
| 桌宠／私密共同房正常正式下线 | 留原房睡眠并占对应名额；本次不改变 |
| 公共房正式下线 | 释放公共占位，进入无房间状态；不回桌宠房睡觉 |
| 被移出／封禁、当前房撤权、房间解散 | 实际在目标房的在线或睡眠团子释放占位并进入无房；旧房会话和迟到动作失效 |
| 非当前房的资格被撤销 | 只撤资格，不清空另一有效当前房的归属 |
| 短暂断线 | 保留原房状态与名额，在容错时间内从权威快照重连 |
| 全部有效会话超过重连容错时间 | 按房型正式下线；公共房进入无房，桌宠／私密留宿 |
| 无房时再次启动 | 首页承接、桌面不显示房间团子；不自动进入自有桌宠房或旧公共房，用户重新选择并准入 |
| 进入失败 | 不主动改变最新权威原房或无房；并发撤权后不恢复失效旧房 |

账号仍自动拥有不可解散的桌宠房、固定房主席位，桌宠访客／私密成员的长期席位不因无房而自动删除。桌宠 2 席、共同房默认 6／最高 12、每人最多 3 间及 7 天恢复规则不变。本轮不改变旧基线的首次注册初始归属规则；首次使用流程及认证方式需专项设计，不能将“无房再次启动”扩大为未经确认的注册行为变更。

## 5. 关键取舍与失败后果

- 选择二维跟随镜头而非三维第三人称：复用二维物理，团子与门都保持可理解的地面关系，不引入三维引擎。
- 选择回门廊而非返回自有桌宠房：返回是导航，尊重不用桌宠房的用户；需要把权威归属与本机视图分开。
- 选择保留原归属到准入提交而非先退出再进入：满员或无权限不能导致丢失原房；并发状态仍以最新服务器事实为准。
- 不将宿主本机回滚当成业务回滚：提交前宿主准备失败不发准入；服务端已确认 B 后若显示失败，归属仍 B，控制界面保持可操作并提供重试。迁回 A 必须另走真实准入，不由客户端擅自恢复。
- 保留短断线容错：不因临时网络波动把用户赶出公共房；具体时长尚未固定，需可控时钟与实际断线验证。
