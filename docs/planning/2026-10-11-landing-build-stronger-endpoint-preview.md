## C 表预览结果与一次补充预设

C 两端均完整完成 3,600 帧及全部下落门槛，中点配置精确相等。瘦端同窗宽高比从旧 B 的 1.333293 降至 1.269144；胖端仅从 1.590411 增至 1.605581，宽度基本不变、高度约降低 1%，不足以兑现用户确认的“明显一档”。这不是健康失败，不修改该真实结果。

为完成本次两端增强方向，再固定一次候选 `landing-build-v2-shape-preview`：胖端径向／外围／面积系数为 **0.50／0.70／1.00**，默认仍为 1／1／1，瘦端保留 C 的 1.60／1.15／1.15。降低外围频率以减弱横向铺开的弹性抵抗，同时保留旧基面积支撑；能否变宽变扁由实际模拟判定。只涉及原三字段，不调整自然几何或硬保护，也不增加其它力。体型 0～50、50～100 分别线性插值，中点直接返回旧配置。

本补充预设只在本轮默认大小／柔软度进行下落外形预览，仍使用原门槛；失败即停止，也不继续添加候选。为适配同一真实工具路径，可以增加明确的 preview 表枚举与版本，不改变冻结 B 或旧诊断语义。成功后报告实际效果；即使落地外形满意，也不能推定运动或长时稳定通过。

补充预设也完整通过下落，但胖端均值宽 1.723638、高 1.082433、宽高比 1.592373，仍没有明显增强。它不作为选定新端点；不继续扫描三项比例。两个外形试验失败的是视觉目标，不是自动健康门禁，原报告全部保留。
