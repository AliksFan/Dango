# 行走受力轮廓：第一步实验计划

日期：2026-10-16。基线：`codex/continuous-belt-lab` 的 `5356b82`；身体实现 `b27fcbd` 已完成本轮拖压稳定性和限速手感人工验收。保持独立实验，不合并、推送、部署或更新日常安装。

## 1. 用户已确认的目标

用户要求仅改变移动时施加的力，使团子行走时略似鲸鱼，并确认：前端饱满、略抬，后端稍收窄，身体轻微拉长；转向交换头尾。第一步仅做A/D行走轮廓，松手恢复静置形状，不加入周期上下摆动，W/S及Space保持现有规则。

材料、质量、自然外形、连续碰撞圈、核心包容、防翻折、原数值门槛与限速不变。所有轮廓变化来自真实动力学受力；不改绘图路径、缩放、直接坐标或目标形状弹簧。正式眼睛和测试配饰只跟随身体，参数不改。

## 2. 最小施力候选

保留原A/D方向半圈驱动力及其合水平力预算。另在连续圈上施加小幅形变力：水平向两侧展开少许，前部上下展开、后部收拢，并对前端加轻微抬起倾向。新增力只在接地行走时作用，拖动、W/S及残余伸展、跳跃和空中抑制，取消输入立即清空。

以64个均匀材料角积分外力。当前包围盒中点与半宽高给出无量纲坐标ξ/η；带符号强度u平滑跟随A/D，起步约0.15秒、松手约0.20秒，反向经过零；u不跟随现有vx限速开关反复切换。候选未投影力密度为：

`Fx = horizontalForce * 0.10 * |u| * ξ`

`Fy = horizontalForce * u * (0.08 * ξ * η + 0.03 * ξ³)`

先去均值，再去绕圈质心的刚体转动分量，使新增净Fx/Fy/力矩均为零，随后通过原Fourier基函数映射为广义外力。它仍可能通过接地摩擦改变实际移动与受压反馈，不能仅凭合力不变宣称手感不变。系数是首个小幅实验候选，不是已经人工验收的最终参数。

形变力功包含于现有外力能量账本，新增诊断只列其子集，不重复记账。独立可选ABI默认关闭、首个成功step前设置；新DLL与应用输出到独立whale目录，原robust模块及打开的稳定版窗口保留。实验复选框支持应用重置后对照原推动。

## 3. 实施与验证

1. 原生新增可选受力模式、完整快照空槽及只读诊断；合成窄合同覆盖合力/力矩、左右镜像、启动/反向/撤力、限速开关独立性、抑制、能量、容量/启用顺序和回滚。默认关闭兼容须能检出轨迹改变。
2. 实验窗口接入明确的“鲸形行走”开关、同帧诊断及故障证据；继续显示原始物理边界、正式眼睛和测试配饰。采用桌面规范v0.1（2026-10-10）§§2–6：沿用暖白/棕色、固定应用区、细滚动条及无虚线焦点，不重做主题。
3. 仍仅运行大小80/120、柔软度0/100、落地体态0/100的八组极值，不加中间材料组合或参数盲搜。沿用同一走停、S/W、Space、拖压/释放时序；检查原安全、恢复、真实起跳和残差门槛，增加形变力净力/力矩与同帧门禁，记录实际轮廓和耗时。
4. 在80/100/0真实WPF窗口检查开关、左右行走/松手及外观跟随，保存来自实际物理帧的截图，再由用户判断鲸形相似程度和形变是否适度。自动通过不能替代此项观感验收；若形变不明显或方向不符，如实记录，不通过改材料补效果。

## 4. 当前状态

已确认目标与范围，第二候选实现、窄合同、26项WPF及唯一一轮八组运行门禁完成，但用户观感反馈“变化太弱，或还不像鲸鱼”，未通过。用户进一步确认主要加强头尾差异，进入单一80/100/0端点的预览修订；先不重复完整八组。具体证据与失败边界见[实验记录](../verification/2026-10-16-force-walking-outline.md)，不把安全门禁通过写成轮廓已整体验收。

## 5. 首候选现场数据与一次修订

首候选`.10/.08/.03`的实际80/100/0窗口已检查左右行走及松手。右行前/后截厚约0.63020/0.64316world，差约−1.91%身体高度；同一材料/相同时序的原推动对照为−2.40%。前部仍略薄，画面变化偏小，尚未达到前圆后收的目标，不能交付为鲸形通过。没有为该候选运行整套八组。

依据上述方向和幅度，将第二候选仅改为`Fx=.10*horizontalForce*|u|*ξ`、`Fy=horizontalForce*u*(.64*ξ*η+.08*ξ³)`，即加强成对形变力，不动材料和净推动力；原候选模块与窗口数据保留。先用同一80/100/0窗口复核，方向和幅度合理后再进行一次八组完整回归。更强局部力可能增加形变和求解负担，所有原安全门槛继续生效，不能以零合力推定其没有物理代价。

用户退回第二候选观感后，进一步确认主要加强头尾差异。新预览只将inflate提高到1.6，stretch0.10/lift0.08不变；同80/100/0的26项WPF与原生合同通过，实测前后截厚差约8.6–9.8%高度，整体宽高相对原推动变化不到1%，松手恢复。已打开“头尾差异预览”等待用户观感，不重复八组，不能把第二候选的八组安全结果迁移为本档通过。
