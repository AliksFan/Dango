# 配饰账号保存与展示审核设计

日期：2026-10-09。状态：用户已确认保存与展示规则；额度、审核执行和存储方案的具体配置待定。当前配饰仍为 Windows 本地功能，本设计尚未实施，不扩大现有邮箱后端批次的编码范围。

## 已确认的规则

用户选择“本地佩戴自由；上传可私有保存，审核通过后才能向其他玩家展示”，随后确认同意本设计。

已佩戴配饰属于团子的完整外观。账号穿搭需要保存图片资源、配饰身份、尺寸、支点、图层顺序、材料形变、连接、旋转和重力参数，不能只保存本机配饰 ID。未佩戴素材库的整体同步另行安排。

| 场景 | 未审或审核拒绝 | 审核通过 |
|---|---|---|
| 本地单人 | 可保存、佩戴 | 可保存、佩戴 |
| 本人账号备份与恢复 | 可私有保存，受存储额度限制 | 可保存与恢复 |
| 其他玩家观看，含私密房间 | 仅展示仍获准公开的穿搭；无可用版本时不展示相关配饰 | 可按当前权限展示 |

私有保存成功、待审核、通过、拒绝和撤销分别记录。审核故障保持原状态，不自动通过，也不阻断本地佩戴。审核撤销停止对外展示授权，保留用户本地作品。

## 图片存储与权限

图片资源与配饰参数分离。同一图片可对应多件配饰及多个账号的合法引用，尺寸、支点、柔软度等参数修改不额外复制图片。

服务器验证图片并按统一规则规范化，对规范化后的文件字节自行计算内容哈希；只对完全一致的内容去重，相似图片不自动合并。规范化规则需要版本化，不能信任客户端声明的哈希或审核状态。服务端重新编码后，云资源 ID 可能与本地 AssetId 不同，上传协议需返回对应标识并保留映射。

全局共用一份图片不改变账号权限。所有私有读取、绑定及公开展示均由服务端校验；知道哈希或已有其他账号审核通过，都不自动获得使用、下载或转发资格。去重接口不得泄露他人私有上传情况。

账号空间按该账号持有的唯一素材计算；同账号重复引用不重复占用图片空间，跨账号分别计算额度。单图体积与像素、账号素材数量与总空间、上传频率及同屏加载预算均需设上限，具体数值待测量后确定。

用户删除自己的配饰先解除自己的引用。图片没有任何有效账号、穿搭或保留版本引用后，进入待清理状态；宽限期结束再次确认无引用后才删除。失败上传的孤立对象同样需要回收，不能用删除一人的记录直接删除共享图片。

## 审核与版本

审核结论绑定不可变内容及对应版本；替换图片形成新版本并重新待审。相同内容可以复用同一规则版本下的内容审核结果，账号使用资格仍独立判断。

素材通过不能证明任意缩放、翻转和叠放组合都合规。公开穿搭需要组合检查及举报复审；哪些纯参数调整需要重新检查、是否进入人工队列，尚未冻结。

服务端生成他人可见的穿搭版本，客户端只能请求，不能自行标记通过。资源缓存需绑定版本及有限展示授权期限；撤销后更新在线可见状态。已经下载的图片字节不能承诺全部远程收回。

## 待细化与实施边界

- 存储提供方、部署环境、上传协议与规范化版本。
- 额度数值、保留期限、清理宽限期和账号注销后的资源处理。
- 人工或自动审核方式、组合复审条件、举报处置及错误申诉。
- 私有穿搭和公开穿搭的预览、版本冲突、恢复及未通过时的用户界面。
- 图片权限、并发去重、引用回收竞争、审核撤销和缓存更新的失败型验收。

本设计不改变已批准配饰不参与碰撞、不给团子反作用的规则。后续实现需独立计划与授权；未执行数据库、对象存储、上传、真实审核、安装更新、main 合并、推送或部署。
