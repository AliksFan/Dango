当前只授权文档工作。建议下一次只授权 **E1 门廊与导航增量**；其后各批先满足依赖再实施。正式认证与账号恢复的技术设计、隔离数据库的具体目标／迁移操作、阶段交叉排期和后续编码范围须分别确认。不会因本计划批准而自动合并 main、推送、部署、更新日常安装或删除任何持久数据。

不包含家具编辑、完整美术资产、注册登录／好友／建房管理页面、情侣功能、完整 DIY、UGC 审核、手机端、窗口内容或屏幕识别。共同房可选壁纸显示列为后续独立增量，不妨碍先验收其默认独立窗口路径。

## 3. 状态与顺序契约

### 3.1 分开保存两类状态

- 权威状态：唯一团子身份、当前归属 `none | room`、归属版本、控制会话与房间快照。客户端只接受服务器确认。
- 本机呈现：`Home / Porch / Entering / RoomVisible / RoomHidden / PresentationRecovery`，以及选中的门、相机和宿主准备结果。状态名称为建议，不是已实现 API。
- 门廊／选门／× 隐藏仅改变本机呈现；不能写权威归属或发正式下线。
- 无房仍可联网读取目录和选择房间；重新进入需要真实准入，不凭旧本地 `roomId` 自动加入。
- 显示失败不改变已提交的权威状态；回门廊保留连接但停止原房动作，门廊位置只用于本地导航。

### 3.2 成功入房顺序

1. 选门后检查必要资源，预准备目标宿主但不对用户显示，也不先隐藏控制界面。
2. 发起有幂等标识和归属版本语义的真实准入，服务端重验身份、房型、权限、容量与当前事实。
3. 接受服务器提交结果及权威快照，拒绝旧请求／旧会话的迟到结果。
4. 暂停首页／门廊的帧驱动，清空动作意图，把同一运行时交接给目标宿主；不得要求两边同时取得帧驱动。交接期间控制界面可保留最后一帧及恢复入口。
5. 目标先进入对用户不可见、输入禁用的暂存激活状态，再核对挂接／场景就绪与当前代际有效首帧，最后揭示房间并隐藏控制界面。现有宿主帧循环依赖 `IsVisible`，不能在完全隐藏窗口上等待不会产生的首帧；已挂接且透明的 surface 或离屏帧绑定是待 E2 验证的候选，技术实现须同时保证不闪现、不抢焦点、不接受输入。就绪信号必须可注入失败、可超时，不以 `Window.Show()` 返回代替；暂存失败仍保持已确认归属并进入显示恢复态。

### 3.3 失败分界

| 失败点 | 权威归属 | 客户端行为 |
|---|---|---|
| 目标宿主预准备失败 | 最新 A 或 none 不变 | 不发准入，保留控制界面并给重试 |
| 准入被拒／事务未提交 | 不由本次请求改变；并发变化以最新快照为准 | 显示满员／无权等真实结果，不能先离开原房或复活失效 A |
| 结果未知，如请求后连接中断 | 不靠超时猜成功或回滚 | 用同一幂等语义查询／恢复权威结果，未确认前不显示假房间 |
| 服务器已确认 B，但激活／首帧失败 | 仍为 B | 保持控制界面可用、进入显示恢复态；重新同步后重试，不擅自写回 A |
| 准入期间被撤权／解散 | 最新服务器状态，可能 none | 拒绝旧成功回调和旧帧，取消显示与输入，回首页／门廊 |

若未来需要自动补偿回旧房，必须另行设计带最新版本、权限和容量复验的业务事务，本计划不默认添加。

## 5. 推荐下一次只开工 E1

### 可见范围

- 把现有侧栏占位门廊换成独立二维场景；首页 W 时原有面板柔和退场，团子进入门廊。
- 世界位置与屏幕位置分离，相机跟随团子，门底与同一地面保持接触；支持窄纵向视口，而不是把横排门挤成卡片列表。
- 门廊 A／D 左右、S 轻压、空格跳跃、W 交互；方向键不恢复。首页 A／D 编辑及 S／空格既有行为不回归。
- 渲染与导航逻辑可先做；正式目录／准入未接入时如实显示空入口或未接入，不模拟成功联网。
- 为“房门”返回、隐藏和宿主就绪建立可失败契约与测试接缝；真实房内按钮／菜单要在 E2／E3 接上真实会话后才能算功能完成。

### 测试与人工验收

自动测试覆盖相机边界／世界映射、门落地／交互距离、重复键限流、焦点／设置／编辑输入优先级、导航不改归属、准入／就绪的迟到回调、none 恢复、单一帧驱动。现有 `ProductHomeInteractionTests`、`UnifiedLiveHomeTests`、`DesktopSceneSessionTests`、`HostFrameSchedulerTests` 增加相关反例，不放宽旧 DLL 缺导出的已知失败。

构建并运行受影响 Core／Desktop 回归，旧失败和缺失产物单列。启动隔离评审窗口，使用真实团子物理运行时，虚构门／空服务接口必须标“场景预览，未接房间业务”。用户验收团子与地面关系、镜头跟随、门排列、首页往返和三档布局；这只验门廊与导航，不标正式房间、同步或 M7 通过。隔离设置与目录不得使用日常 settings 路径，不覆盖 DLL 或更新安装。
