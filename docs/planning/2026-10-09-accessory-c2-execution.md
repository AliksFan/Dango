# C2 当前穿搭正式账号私有保存实施

日期：2026-10-09。用户明确“继续”，沿用[已确认设计](2026-10-09-accessory-account-backup.md)。冻结首批模块 `8eb9351` 和 B5A `d14b22d`，在独立 feature 工作树结合；不是 main 合并或部署。

## 本增量

1. 服务端为全局规范化图片建立独立物理记录，为本人团子建立上传暂存／当前引用；实际接收并验证 PNG 才能获得引用。同内容共用物理文件，哈希知识和图片审核结论不赋予下载权。
2. 当前穿搭、引用转换及幂等回执在 PostgreSQL 同一事务提交。沿用邮箱、用户、会话、团子锁顺序，提交前重查会话有效性。首次版本 0，完整成功递增 1；同键同请求返回原结果，同键异请求、旧版本和缺图明确拒绝。回执缺失只返回未知。
3. 上传暂存期 24 小时，每只团子至多 16 个有效且非当前暂存引用；当前组合仍最多 8 个实例。替换当前组合只变更本团子的当前引用，不删除物理文件。暂存过期不授予下载或提交权。当前不运行持久 GC；回执与过期引用物理保留供后续保留策略和回收实现。
4. 正式 Cookie／CSRF HTTP transport 绑定 origin、身份与登录代次；不把凭据存进穿搭文件。严格完整配方、有界 PNG、明确拒绝与未知写入结果分开。旧登录晚回调不能使用新会话。
5. Windows 接既有本机成功提交事件，再自动排队；恢复来源选择和云状态独立于外观配置。退出／切账号立即阻止旧任务，本机恢复完整校验后一次提交，恢复不再次上传。

私有备份不自动申请管理员审核；正式审核、展示授权、举报、房间投影／通知、GC 和双机人工验收属于后续增量。

## 文件归属

父任务唯一修改 Persistence 实体／EF 模型／migration／snapshot、配置、项目引用、文档及精确数据 runner。服务端代理拥有 Accessories 服务、AccessoryEndpoints、FormalHost 和其反例；HTTP 代理拥有 FormalAccountClient 的会话 seam、配饰 transport 和 HTTP 反例；Windows 代理拥有账号生命周期信号、配饰账号控制器／显示与 STA 反例。各使用独立 worktree，顺序整合到 C2 feature，不在 B5 原树修改。

私有存储必须显式配置 `DANGO_ACCESSORY_BLOB_DIRECTORY`，指向已存在、无链接、位于仓库及密钥目录之外的绝对目录。无配置时配饰 API 明确不可用。运行时不会自行选择开发机目录，不能挂静态文件服务。

## 能失败的门禁

- 非本人、撤销／过期会话、只知哈希均无权下载或提交；每个端点重新裁定本人团子。
- 实际 PNG 验证失败不授予引用；上传成功、穿搭失败不出现半套当前穿搭。
- 同图不同账号各自实际上传后各得独立引用、共用一份物理内容。
- 同版本并发只有一个提交；同键重放返回原版本与完整配方，同键异请求拒绝。
- 事务故障回滚当前穿搭／引用／回执；服务重建能读取原保存，丢响应后查原键核对。
- 旧账号响应、关闭浮层、应用草稿与恢复回传不能干扰新登录或误报成功。

静态及受控 HTTP／STA 门禁可立即执行。真实 PostgreSQL／HTTPS 和迁移必须先完成代码、生成可审查迁移及独立精确资源计划，再按 AGENTS.md 获得数据库操作授权。编译、模型 SQL 生成或受控 handler 不代替真实数据库验证。未授权 main 合并、推送、部署、日常安装、正式 DLL 替换或持久资源删除。
