## 当前状态（2026-10-29，收尾中）

统一编辑器已接入多组／多骨架和组间双向连接、完整图层工具以及中央模拟预览；左侧提供选挂点、平移、缩放、刷新四工具，细调固定展开，输入按焦点归属处理。独立编辑期间后台控制中心暂停，预览侧墙与刷新已有针对性验证。用户对当前版本交互与观感反馈“通过，目前无要改”。详见[收尾验收记录](../verification/2026-10-29-accessory-editor-acceptance.md)。

以下 S0–S7 是实施顺序和历史状态，不再表示当前各批次未开始或无产品验收结论；历史 S0 与旧 E0–E5 的证据仍各自保留。main 集成和发布包验证正在进行；不同 DPI、高对比度、长时内存及正式发布未全面验收。提交、合并、推送和安装状态分别记录。

## 4. 分批实施与退出条件

### S0 — 最小真实交互样板

目标模块：`eng/accessory-editor/` 的几何输入、选择和历史，以及现有本地编辑器测试宿主／夹具。复用最终可接入的命令核心，不新增常驻产品演示入口。该批无正式清单写入，无物理效果或完整图片工具交付声明。

内容：

- 按机制第 12 节补齐默认及 UI-06 快捷键搭建输入样板；自由根只移动根、同点引用根随动、普通子节点不自动平移、P 移动重算自由根偏移和混选规则必须进入用例，其余命中阈值可在合理范围校准。
- 使用两组、一条父子挂接、P/R/J 重合、自由根／已挂根、仅有根和一个未分组层的虚构夹具；只需足够辨识的线、点、游标、虚影和失败反馈，不再先画一轮完整页面。
- 覆盖左单选、空白框选、Shift 追加、方向键；绘制选起点／追加点／自动选新点，拖已选点自动进入修改。
- 覆盖拖根松开提交和粘鼠标左键点击提交、无效候选、Esc、右键取消、失焦、切组、捕获丢失；右键菜单目标与选择集合分开。
- 演示尾节点可删、内部断链拒绝、被引用节点拒绝；一次拖动／挂接／删除对应一次撤销。多选不可暗取续画起点。
- 样板复用现有本地 Runtime 与锁定构建工具，不新增依赖或自动安装系统 Runtime；缺少前置时说明实际缺项。不修改用户数据，不假装已经验证求解、成品质量、真实保存或产品宿主。

验证与失败反例：用真实 pointer／keyboard 事件验证，不只直接调用回调；“点一下就多一个节点”“拖动结束又落一个点”“右键改了选择”“取消后仍残留父引用”“松手提交另一组”的实现必须失败。无屏幕检查先做；真实游标、连续拖动与手感由获准的前台小样验证。

退出：用户对关键交互给出可追溯反馈，补齐行为收口，未通过案例修正并复测；只通过本批输入门禁，不标记产品已验收。无数据库、服务、云端和付费资源。

### S1 — 工程决策、数值与边界冻结

目标模块：本设计的决策附录、接续 ADR、`Rig/` 数值验证、工程／桥版本说明与资源测量记录；当前工程取舍与未测性能见 ADR 0008 和统一实现记录。

内容：

- 收口第 3 节，核对补齐默认的组创建／删除、归组／脱组、相对初始姿态及绑定行为；UI-01–UI-09 是可执行合同，不再留到 S5 重新猜布局。
- 对同一条初始弯曲链做弯曲、速度衰减、位置恢复、重力和长度弹性的独立对照；以 UI-09 范围／默认为起点冻结数值映射、步长、0 端点、硬限制和长帧策略。伸缩 e 的硬边界为 `(1−e)L₀..(1+e)L₀`，e 为 0–0.5；不新增伸缩恢复／阻尼控件。形变恢复展示角频率 rad/s，不能误标为频率平方。
- 明确整体重力独立影响 A–P 平移和整体转动，各自由度只算一次；组重力仅控制各组内部直接重力。外层默认 0、组创建默认 0，均直接存值；不新增继承选项。
- 冻结网页工程、原生工程、桥消息、运行资源和清单的版本关系、稳定 ID／父引用、失败保护；评估旧格式策略并保留原件。
- 建立单件与全部佩戴实例的组数、骨节、网格、纹理、解码、历史和消息总预算；测量来源与未测范围明确。保留已有八件约束，不能据此允许每件无限分组。

验证与失败反例：弯曲 0／伸缩非 0 仍可伸缩，二者均 0 保持内部形状；无界伸长、重复累计重力、参数互相偷用、未知格式被空工程覆盖均须被检出。夹具属于隔离探索，实验代码即使复用也须经过 S3 全部门禁，不能视为成品求解已交付；数值实验通过不代表实时图像和总进程内存通过。

退出：决策和有界合同有记录，改变业务语义的选择已获确认；具体版本号与预算有依据，不以“后续完善”带过。外部资源仅后续授权内的公开资料与已有本地工具，无付费资源或存档迁移。

### S2 — 组、单链、挂接图与编辑命令

目标模块：`AccessoryEditorProject`、`AccessoryProjectContent`、`AccessoryRigConfiguration` 及网页 `project-schema.js`／几何模块中相应数据；按职责增加必要模型与命令。

内容：

- 稳定区分 A、P、组 G、根 R、节点 J、图层归属和挂接引用；每组唯一 R、一条链，根与 P 可不同，空组和 root-only 不造假骨段。
- 建组同时建根；从节点建组是新空组与新根引用，不搬走原链后缀。自由根以 P 为参考，挂接根单父、无环、目标存在。
- 组创建／删除、连续归组、显式拖入／脱组和块重排按 UI-04 实现；删组保留图层，被引用拒绝，空组不清理。不能只有骨节命令而漏掉实际图层组管理。
- 末端追加、骨段插点、选择／移动、改接／解绑、清空普通骨节和删除集合进入统一事务。删除先计算最终图，任何漂浮或失效引用均整笔拒绝，不搭桥、删子树或暗中解绑。
- 维护选择集合、活动组、唯一续画起点和上下文目标；自由根移动只改根及其同点身份，连接任一端编辑均移动同一个共享点，重算受影响链的初始几何／相对角度／绑定；P 与节点混选按同一快照一次提交。编辑图层顺序不自动改挂接。
- 结构变化对所有受影响组做有界校验；原生不只相信网页“成功”标记，双方共享协议和反例夹具，避免两套互相偏离的规则。

验证与失败反例：纯模型测试覆盖重复 ID／根缺失／自身与后代连接／同一根双父／联合后缀删除／被引用末端／根不可单删／空组与未分组层；多组分别引用同一合法目标是允许成功的正例，与同一根同时绑定两个目标的拒绝反例区分。拒绝时比较整个前后快照与修订均未改变。

退出：命令模型、撤销及原生输入校验通过，S0 用同一核心复跑无差异。依赖 S1 对应决定，无数据库、服务或持久库写入。

### S3 — 单链伸缩与多组拓扑求解

目标模块：`AccessoryRigDefinition`、`AccessoryRigSolver`、`AccessoryRigSkin`、`AccessoryMotionSolver` 及根姿态输出。

内容：

- 先实现固定根单链的有界长度弹性，再接依赖图。各骨段围绕初始骨长恢复；0% 固定长度，50% 严格限于 0.5L₀–1.5L₀，不允许负长度或永久漂移；允许区间不是强制拉满。
- 分离弯曲与长度自由度，显式替代 `Softness == 0` 的旧总短路；root-only 不运行退化链内部求解，图像仍跟随 P／父目标的动态根姿态，不是世界静止。
- 各组共同进入整件共享粒子约束求解；R–J 是同一连接自由度，受力双向影响。保留初始相对角度，整件尺寸／角度只乘一次；不以组引用排序代替双向求解。数值选择见 ADR 0008。
- 各组直接使用自己的重力、阻尼与恢复；整体重力只驱动整体自由度，组重力只驱动内部自由度。世界重力方向不随图片旋转，不重复累计父加速度。未分组层使用 P 的整件姿态。
- 保留成功 tick、重复／回退 tick 不推进、长帧重建、暂停／恢复与重绑定重置。明确何种结构／参数变化使哪些实例失效，不残留旧速度。

验证与失败反例：四种弯曲／伸缩组合、重力 0 与惯性、不同组参数互不污染、父子根距离、父组顺序交换、深度预算、整体缩放、重复刷新、暂停和长帧；约束测试须能发现偷偷固定长度或关闭全部形变的实现。

退出：所有数值端点、稳定边界和父子姿态反例通过，冻结可消费的不可变组输出；真实图像观感仍待 S4／S7。依赖 S2 和 S1 数值合同，仅本地无窗口夹具。

### S4 — 独立绘制片、蒙皮与透明顺序

目标模块：`AccessoryRigSkin`、`AccessoryMeshVisual`、`AccessorySceneController`、`AccessoryImageAsset`、`AccessoryProjectContent` 与编辑器分组导出。

内容：

- 从工程产生每个组所需的透明绘制片／绑定及未分组绘制片，组成稳定绘制栈；合成预览 PNG 不冒充多组动态资源。
- 组内仅受所属链影响，空组无图像也可驱动子组；根状态、可见性、透明度与混合顺序只应用一次。
- 分组／脱组遵守 S1 冻结的连续区间和重排规则，不悄悄移动透明层。身体前／后仍是整件佩戴属性，不自动变成每组穿插身体。
- 拉伸／压缩时 UV、透明边缘和边界计算一致；失败保留原草稿，不静默合并组、降画质或减骨节。
- 以实际组数和全部实例测量更新／光栅／绘制／峰值资源，定位必要修正，不能把求解微基准或平均 FPS 当成整个产品性能。

验证与失败反例：重叠半透明层、未分组层夹在两个组之间、跨组交叉固定叠放、伸缩后边缘、裁剪／翻转后的蒙皮与根一致性；对照应能检出提前整图合成、错层、重复透明度及跨组误绑定。

退出：独立组相对运动及透明顺序正确，所选预算有实测证据；空组保留、未分组刚体片有效。依赖 S2、S3，无在线服务和真实素材上传。

### S5 — 正式编辑器装配与属性归属

目标模块：`eng/accessory-editor/`、`AccessoryUnifiedEditorWindow`、`AccessoryUnifiedEditorSession`、`AccessoryBrowserProjectAdapter`、`AccessoryEditorBridge`、`AccessoryEditDraft`、外层面板与共同主题资源。
