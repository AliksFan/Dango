# 团子自身捏脸设计

日期：2026-10-05；当前状态更新于 2026-10-06。**自身捏脸已在本地 Windows 候选实现，最新首页／捏脸／换装布局获用户人工观感确认**。用户明确捏脸只关乎团子本身，帽子作为另一部分单独设计；眼睛取消眼型／大小预设，改为大小、椭圆度、高度和眼距四个滑块。后续“按计划开始实现”授权 F0–F5，生产接线、Schema 3 保存和隔离重启已完成，具体证据见[实现验证](../verification/2026-10-05-face-implementation.md)。此前只在对话中确定的入口、图标、镜像动效、贴影和纵向布局汇总为[当前已确认设计](2026-10-06-home-and-appearance-design.md)。

确认边界：10 月 5 日首次“通过”只属于示意设计评审；10 月 6 日最新“通过”确认已实现候选的当前观感，不关闭完整 F5 专项、整个 Windows 或多人阶段。100%／125% 系统缩放及其它显示器仍未验证；不授权合入、安装或推送。示意与验收预览选择不改为产品默认值。帽子独立设计仍待其自己的评审。

生产映射：用户在实施计划编制时明确选择“保留现有 Windows 默认长相，校准滑块映射”。高度与眼距不直接作为真实身体比例；生产控制以旧默认为锚点增量调节，默认值回到旧完整求解分支。具体合同、分批文件所有权与失败型验收见[Windows 实施计划](2026-10-05-dango-face-implementation-plan.md)。下表记录当前控制范围，不沿用 HTML 的实际身体百分比解释。

## 1. 目标与本轮范围

在现有“我的团子”首页编辑区改变团子自身长相，让用户能预览、取消、应用及恢复默认，同时保留同一团子的真实活动和动态表情。

本轮设计包含身体颜色、眼睛颜色，以及双眼统一的大小、椭圆度、高度和眼距。高度指双眼中心的上下位置，眼距指两眼中心之间的距离；不分别编辑左右眼。帽子、服装、配饰属于独立换装部分；帽子另见[独立选择设计](2026-10-05-hat-selection-design.md)。不把帽子控制项放入捏脸，也不因取消捏脸而重置帽子。真实身体大小、身体形状与柔软度继续留给后续有界物理 DIY；本轮不添加嘴巴、单眼编辑、绘制或上传。

范围依据[已批准路线](2026-09-22-gait-and-customization-roadmap.md)、[产品 DIY 边界](../product-design-v0.1.md#52-团子-diy-参数边界)与明确增加高度／眼距的用户指令。眼睛参数属于外观布局，不改变身体物理；生产值以已批准校准合同为准。

## 2. 当前实现事实

- [首页](../../src/Dango.Desktop/AppShell/ControlCenter/ProductHomeView.xaml)已接通两色、四滑块、比较、整套取消／默认／应用及真实保存反馈；最终横向捏脸为左预览、右参数，纵向参数独立停靠下方。
- [独立颜色成果](2026-10-05-appearance-consolidation.md)是原 Schema 2 整理基线，后续已扩展为严格 Schema 3 和整套外观草稿，并接通实际 Host／Runtime。旧整理记录不作为当前未接线状态。
- 当前 `EyeShape` 描述眨眼、开心、困倦和睡眠等动态表现，不能直接把全部枚举当成可保存的基础眼型。
- [FaceLayoutSolver](../../src/Dango.Desktop/Physics/Presentation/Attachments/FaceLayoutSolver.cs)已消费四项基础请求，叠加原动态注视与安全退让；默认走旧完整求解分支，不能只缩放或移动最终图画。
- [AttachmentMotionController](../../src/Dango.Desktop/Physics/Presentation/Attachments/AttachmentMotionController.cs)将基础请求与动态眼睛指令分开；比较结束回到当前基础参数。长期调用 `SetEyes` 会占用睡眠／表情通道，不能据此实现基础眼型。

## 3. 已确认界面设计

当前横向为左侧团子预览、右侧捏脸编辑区；纵向参数在预览下方独立滚动。颜色／眼睛图标在团子左侧竖排，眨眼／睡眠在对应右侧竖排，不缩小团子，参数区不放“捏脸”标题。切换页签保留同一草稿，不自动保存，也不改变实体、位置或物理参数。保存图标位于团子右下，完整入口、尺寸、动效及纵向锚点见[当前布局合同](2026-10-06-home-and-appearance-design.md)。帽子入口由后续换装设计承担。

颜色页分别显示身体与眼睛的当前色块和只读 Hex，使用系统调色盘选择 RGB；身体保留既有三个快捷色。选择确认只更新草稿；取消系统调色盘保持原值。完整 RGB、黑色和同色合法，不自动改善对比度。

眼睛页直接使用四个连续滑块，移除“圆眼／纵椭圆／横椭圆”与“小／标准／大”预设按钮。不把开心或睡眠作为永久眼型：

| 滑块 | 方向与含义 | 当前控制范围与默认 |
|---|---|---|
| 大小 | 左小、右大；双眼统一缩放，中心位置不变 | 70%～140%，默认 100%，步长 1% |
| 椭圆度 | 左横椭圆，中点圆形，右竖椭圆；连续变化 | -100～100，默认 0，步长 1 |
| 高度 | 左高、右低；双眼一起上下移动，以旧中心为锚点 | 控制值 32～66，默认 51，步长 1；相对变化按身体高度映射 |
| 眼距 | 左近、右远；以脸部中线对称改变中心距离，以旧中心距离为锚点 | 控制值 12～34，默认 24.5，步长 0.5；相对变化按身体宽度映射 |

“椭圆度”在这里是面向用户的双向长宽比例控制，不用数学偏心率命名，因为偏心率本身不区分横向与纵向。示意以圆眼直径为基准：大小统一缩放两轴；椭圆度为负时只缩短竖轴，为正时只缩短横轴，中点两轴相等。短轴倍率为 `1 - |椭圆度| / 200`，两端为 0.5；保持长轴尺寸，让大小与扁长程度可以分别调节。眼距采用中心距离，避免眼睛放大时连带撑远。高度独立于椭圆轴长，不把“眼睛高度”误解为椭圆竖轴尺寸。

选择连续滑块是为保留用户要求的细调空间；固定预设只能覆盖少量长相，已从本轮方案移除。生产映射及默认等价已按实施合同验证，组合、表情、注视和身体受压证据及连续采样的局限见实现记录。示意百分比不表示原生实际身体比例。安全求解的暂时缩小或位置退让不能改写用户请求参数。

预览区提供一次性“眨眼”和“睡眠／醒来”比较，不保存表情、不改变产品中的自动行为。真实实现使用既有 runtime 动态状态，月亮／太阳随比较状态更新；示意仅用页面形状演示，不作为软体、WPF 或安全布局证据。

团子预览右下提供恢复默认／取消／应用三个图标，分别为回转箭头／X／勾；保存反馈保留。恢复默认只是草稿变化；取消回到最近已应用的整套自身外观；应用成功后才成为已保存值。关闭编辑区、去设置／门廊、隐藏或退出时取消未应用草稿，清理临时比较状态。按钮或调色盘有焦点时消费自己的操作，不能同时触发移动、跳跃或 W 进门。

## 4. 草稿、保存与故障

区分已保存自身外观、编辑草稿、逐帧动态表情三个层次。草稿在同一预览实体上展示，不能创建第二个 runtime，也不能用旧模拟帧掩盖故障。动态表情结束后回到当前四项眼睛参数；取消草稿后同时恢复已保存的四项参数与颜色。

| 操作 | 预览与草稿 | 本地保存 |
|---|---|---|
| 选色／拖动任一眼睛滑块 | 对应项即时预览，其他项保留 | 不写 |
| 切换颜色／眼睛页签 | 保留草稿与同一实体 | 不写 |
| 恢复默认 | 全部自身项进入默认草稿；帽子不变 | 不写 |
| 取消／关闭编辑／隐藏 | 回到已保存自身外观，临时表情清理 | 不写 |
| 应用成功 | 整套草稿成为已保存外观 | 原子保存受支持的自身配置 |
| 应用失败 | 保留草稿和最近已保存值，允许重试或取消 | 原文件保持完整，不标已保存 |
| 文件损坏／未知版本 | 安全默认并提示保护状态 | 普通应用不能覆盖；显式备份恢复 |

当前已实现严格外观 Schema 3，保存身体／眼睛 Hex，以及连续大小、椭圆度、高度和眼距；不保存离散眼型或大小档位。字段名、控制单位和范围见实施计划，读取与保存均拒绝非有限数、越界值、缺失／重复／额外字段。旧 Schema 1／2 只读补默认圆眼、标准大小、默认高度与眼距，用户显式应用成功时才升级。旧版软件遇新 Schema 时沿用保护与回退，不能覆盖未知版本。

四项眼睛参数已进入实际 `appearance.json`；兼容保护、写失败／重试和真实隔离进程重启结果见实现验证，不以示意保存冒充磁盘证据。帽子现有设置路径不在本轮重构，未来换装的跨文件保存规则另行设计。正式多人仅同步受支持的版本化配置，服务端校验；本轮不扩展协议或宣称外观已同步。

历史示意聊天状态为 `dango-face-design-v2`，当时为橙色身体 `#DA8D10`、黑色眼睛 `#000000` 的未应用草稿，并非当前窗口或产品默认。旧示意的圆／横／纵与小／标准／大只用于恢复历史预览：分别映射为椭圆度 0／-40／40、大小 85／100／115，默认高度与眼距不变。这个示意状态兼容不属于真实外观文件 Schema 迁移。

## 6. 可失败的验收

- RGB 原值在草稿、文本与保存一致；黑色和同色均不被拒绝、钳制或反色。低对比是用户选择，不作为失败。
- 椭圆度 0 时两轴相等，负值连续变横、正值连续变竖；中点两侧无跳变。大小只改变两轴尺度，高度只改变上下位置，眼距只改变中心距离；双眼对称。
- 四项参数的默认、边界与代表性中间组合均能眨眼、自然闭眼和睡眠，醒后恢复全部请求参数；不能长期锁住动态 `EyeShape`。
- 极端注视、压缩、跳跃与安全退让不使眼睛越出有效脸部、交叉、交换左右或产生非法数值。临时缩小／闭眼／位置退让不改已保存参数；生产范围须以真实求解验证。
- 预览、页签与表情比较不写文件；取消同时回滚身体、眼睛颜色与四个滑块，帽子状态不变。滑块支持键盘方向键，无焦点溢出到移动或房间输入。
- 原子保存、备份、升级或未知字段失败不丢旧文件，不把失败草稿标成已保存；重试和取消仍可用。
- 首页、门廊和后续普通房保持同一实体、同一外观；外观编辑事件不主动调用 Tick 或额外推进物理，既有唯一帧驱动继续负责活动；不重建实体、不新增帧 owner，旧回调失效。
- 输入焦点、关闭、隐藏、托盘恢复、三档首页布局与减少动画不回归；实际 WPF/native、磁盘重启和人工观感分别记录。
