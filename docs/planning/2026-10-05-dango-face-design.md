# 团子自身捏脸设计

日期：2026-10-05。状态：**捏脸交互设计已获用户确认，生产实现未开始**。用户明确捏脸只关乎团子本身，帽子作为另一部分单独设计；随后要求取消眼型／大小预设，改为大小、椭圆度、高度和眼距四个滑块，并在查看新版交互示意后回复“通过”。本页界面、滑块方向、草稿交互与示意范围作为后续实施设计输入；真实布局安全边界和保存扩展仍需实施合同与验证。没有实施生产捏脸界面或眼睛参数保存。

确认边界：本次通过属于捏脸设计评审，不是 Windows 真实运行／磁盘保存的人工验收，不标记产品阶段已验收，也不授权合入、安装或推送。当前预览选择不改为产品默认值。帽子独立设计仍待其自己的评审。

生产映射补充：用户在实施计划编制时明确选择“保留现有 Windows 默认长相，校准滑块映射”。高度与眼距的示意百分比不直接作为真实身体比例；生产控制以旧默认为锚点增量调节，默认值回到旧完整求解分支。具体合同、分批文件所有权与失败型验收见[Windows 实施计划](2026-10-05-dango-face-implementation-plan.md)。以下数值表用于已确认交互示意；生产语义以该校准合同为准。

## 1. 目标与本轮范围

在现有“我的团子”首页编辑区改变团子自身长相，让用户能预览、取消、应用及恢复默认，同时保留同一团子的真实活动和动态表情。

本轮设计包含身体颜色、眼睛颜色，以及双眼统一的大小、椭圆度、高度和眼距。高度指双眼中心的上下位置，眼距指两眼中心之间的距离；不分别编辑左右眼。帽子、服装、配饰属于独立换装部分；帽子另见[独立选择设计](2026-10-05-hat-selection-design.md)。不把帽子控制项放入捏脸，也不因取消捏脸而重置帽子。真实身体大小、身体形状与柔软度继续留给后续有界物理 DIY；本轮不添加嘴巴、单眼编辑、绘制或上传。

范围依据[已批准路线](2026-09-22-gait-and-customization-roadmap.md)、[产品 DIY 边界](../product-design-v0.1.md#52-团子-diy-参数边界)与本次明确增加高度／眼距的用户指令。眼睛参数属于外观布局，不改变身体物理；示意数值不写成已批准的生产参数。

## 2. 当前实现事实

- [首页](../../src/Dango.Desktop/AppShell/ControlCenter/ProductHomeView.xaml)已有右侧编辑区，身体色只有内存预览，眼型与“应用”仍未开发。
- [独立颜色成果](2026-10-05-appearance-consolidation.md)本轮整理了身体／眼睛 RGB、草稿与颜色 Schema 2；未与首页接线。
- 当前 `EyeShape` 描述眨眼、开心、困倦和睡眠等动态表现，不能直接把全部枚举当成可保存的基础眼型。
- [FaceLayoutSolver](../../src/Dango.Desktop/Physics/Presentation/Attachments/FaceLayoutSolver.cs)的基础尺寸与间距目前固定。已有注视、间距、尺寸、闭眼与隐藏的安全退让；新的四项参数需要进入安全求解，不能只缩放或移动最终图画。
- [AttachmentMotionController](../../src/Dango.Desktop/Physics/Presentation/Attachments/AttachmentMotionController.cs)无动态眼睛指令时回到 Round。长期调用 `SetEyes` 会占用睡眠／表情通道，不能据此实现基础眼型。

## 3. 已确认界面设计

沿用首页结构：左侧团子预览，右侧捏脸编辑区。“颜色”和“眼睛”两个局部页签；切换页签保留同一草稿，不自动保存，也不改变实体、位置或物理参数。帽子入口由后续换装设计承担。

颜色页分别显示身体与眼睛的当前色块和只读 Hex，使用系统调色盘选择 RGB；身体保留既有三个快捷色。选择确认只更新草稿；取消系统调色盘保持原值。完整 RGB、黑色和同色合法，不自动改善对比度。

眼睛页直接使用四个连续滑块，移除“圆眼／纵椭圆／横椭圆”与“小／标准／大”预设按钮。不把开心或睡眠作为永久眼型：

| 滑块 | 方向与含义 | 示意范围与默认 |
|---|---|---|
| 大小 | 左小、右大；双眼统一缩放，中心位置不变 | 70%～140%，默认 100%，步长 1% |
| 椭圆度 | 左横椭圆，中点圆形，右竖椭圆；连续变化 | -100～100，默认 0，步长 1 |
| 高度 | 左高、右低；双眼一起上下移动 | 从身体顶端量中心位置 32%～66%，默认 51%，步长 1% |
| 眼距 | 左近、右远；以脸部中线对称改变中心距离 | 身体宽度的 12%～34%，默认 24.5%，步长 0.5% |

“椭圆度”在这里是面向用户的双向长宽比例控制，不用数学偏心率命名，因为偏心率本身不区分横向与纵向。示意以圆眼直径为基准：大小统一缩放两轴；椭圆度为负时只缩短竖轴，为正时只缩短横轴，中点两轴相等。短轴倍率为 `1 - |椭圆度| / 200`，两端为 0.5；保持长轴尺寸，让大小与扁长程度可以分别调节。眼距采用中心距离，避免眼睛放大时连带撑远。高度独立于椭圆轴长，不把“眼睛高度”误解为椭圆竖轴尺寸。

选择连续滑块是为保留用户要求的细调空间；固定预设只能覆盖少量长相，已从本轮方案移除。四项范围作为已确认示意的初始设计输入，不是经真实求解验证的安全数值。最终边界需覆盖四项组合、表情、注视和身体受压；预览中的百分比没有建立与原生实际半径／挂接坐标的已验证映射。未来安全求解的暂时缩小或位置退让不能改写用户请求参数。

预览区提供一次性“眨眼”和“睡眠／醒来”比较，不保存表情、不改变产品中的自动行为。真实实现使用既有 runtime 动态状态；示意仅用页面形状演示，不作为软体、WPF 或安全布局证据。

底部提供“恢复默认”“取消”“应用”。恢复默认只是草稿变化；取消回到最近已应用的整套自身外观；应用成功后才成为已保存值。关闭编辑区、去设置／门廊、隐藏或退出时取消未应用草稿，清理临时比较状态；后续集成需检查现有转场与输入顺序。按钮或调色盘有焦点时消费自己的操作，不能同时触发移动、跳跃或 W 进门。

## 4. 草稿、保存与故障

区分已保存自身外观、编辑草稿、逐帧动态表情三个层次。草稿在同一预览实体上展示，不能创建第二个 runtime，也不能用旧模拟帧掩盖故障。动态表情结束后回到当前四项眼睛参数；取消草稿后同时恢复已保存的四项参数与颜色。

| 操作 | 预览与草稿 | 本地保存 |
|---|---|---|
| 选色／拖动任一眼睛滑块 | 对应项即时预览，其他项保留 | 不写 |
| 切换颜色／眼睛页签 | 保留草稿与同一实体 | 不写 |
| 恢复默认 | 全部自身项进入默认草稿；帽子不变 | 不写 |
| 取消／关闭编辑／隐藏 | 回到已保存自身外观，临时表情清理 | 不写 |
| 应用成功 | 整套草稿成为已保存外观 | 原子保存受支持的自身配置 |
| 应用失败 | 保留草稿和最近已保存值，允许重试或取消 | 原文件保持完整，不标已保存 |
| 文件损坏／未知版本 | 安全默认并提示保护状态 | 普通应用不能覆盖；显式备份恢复 |

当前整理的颜色 Schema 2 不包含眼睛布局参数，本轮不向它偷偷添加字段。后续实现建议另行批准外观 Schema 3，保存现有身体／眼睛 Hex，以及版本化的连续大小、椭圆度、高度和眼距数值；不再用离散眼型标识和大小档位标识。具体字段名、归一化单位和生产上下限应由真实布局合同确定，并拒绝非有限数与越界值。旧 Schema 1／2只读使用默认圆眼、标准大小、默认高度与眼距，用户显式应用时才升级。旧版软件遇新 Schema 时沿用保护与回退，不能覆盖未知版本。

四项眼睛参数不存在当前生产文件里。上述升级方案仍是候选，不能提前写盘或声称已经完成重启恢复；需要专门的兼容与回退验收。帽子现有设置路径不在本轮重构，未来换装的跨文件保存规则另行设计。正式多人仅同步受支持的版本化配置，服务端校验；本轮不扩展协议或宣称外观已同步。

示意聊天状态更新为 `dango-face-design-v2`，保留当前橙色身体 `#DA8D10`、黑色眼睛 `#000000` 的未应用草稿。旧示意的圆／横／纵与小／标准／大只用于恢复历史预览：分别映射为椭圆度 0／-40／40、大小 85／100／115，默认高度与眼距不变。这个示意状态兼容不属于真实外观文件 Schema 迁移。

## 5. 实施顺序候选与文件所有权

1. 本轮先完成独立旧颜色模块整理与聚焦验证，提供捏脸示意供评审。
2. 界面已确认，连续眼睛参数契约和安全布局的[实施计划](2026-10-05-dango-face-implementation-plan.md)已形成，以必败反例锁定动态组合与兼容行为；生产编码尚未开始，不由此次文档交付自动启动。
3. 颜色与自身草稿接线、首页 UI 和 runtime 输入由一名集成负责人处理，避开普通房并行修改同文件；四项眼睛参数按小批独立验证。
4. 在隔离 Windows 候选验收自身外观全闭环后，再单独安排合入、安装或共享交付。

不修改 native、碰撞、软硬度、移动、房间状态或主设置 Schema；不以此次设计批准后续实现、迁移或发布。帽子独立设计不在上述批次中混入。

## 6. 可失败的验收

- RGB 原值在草稿、文本与保存一致；黑色和同色均不被拒绝、钳制或反色。低对比是用户选择，不作为失败。
- 椭圆度 0 时两轴相等，负值连续变横、正值连续变竖；中点两侧无跳变。大小只改变两轴尺度，高度只改变上下位置，眼距只改变中心距离；双眼对称。
- 四项参数的默认、边界与代表性中间组合均能眨眼、自然闭眼和睡眠，醒后恢复全部请求参数；不能长期锁住动态 `EyeShape`。
- 极端注视、压缩、跳跃与安全退让不使眼睛越出有效脸部、交叉、交换左右或产生非法数值。临时缩小／闭眼／位置退让不改已保存参数；生产范围须以真实求解验证。
- 预览、页签与表情比较不写文件；取消同时回滚身体、眼睛颜色与四个滑块，帽子状态不变。滑块支持键盘方向键，无焦点溢出到移动或房间输入。
- 原子保存、备份、升级或未知字段失败不丢旧文件，不把失败草稿标成已保存；重试和取消仍可用。
- 首页、门廊和后续普通房保持同一实体、同一外观；外观编辑事件不主动调用 Tick 或额外推进物理，既有唯一帧驱动继续负责活动；不重建实体、不新增帧 owner，旧回调失效。
- 输入焦点、关闭、隐藏、托盘恢复、三档首页布局与减少动画不回归；实际 WPF/native、磁盘重启和人工观感分别记录。

[交互示意源](../prototypes/dango-face-design.html)的“应用”仅在页面比较草稿与已应用值，聊天恢复状态也仅服务示意；不访问生产设置、外观文件或网络。示意检查不能替代上述真实功能验收。
