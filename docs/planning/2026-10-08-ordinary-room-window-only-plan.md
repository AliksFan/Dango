日期：2026-10-08。状态：用户已批准范围及完整移除方案，并明确“在分支中开始”；代码移除、静态检查及隔离 Release 构建完成，受影响回归仍有一项桌宠到边时限失败及 25 项未执行，人工验收尚未完成。证据见[本轮验证](../verification/2026-10-08-ordinary-room-window-only.md)。

## 决策与边界

普通房只使用独立窗口。桌宠房间继续使用真实壁纸环境和独立透明团子，二者共享一个真实物理实体和唯一帧 owner。普通房壁纸抚摸的多轮失败仍保留为历史事实，不将撤除功能记作修复了原故障。

用户要求不留下冗余代码，因此删除普通房壁纸专用生产实现、入口、事件、状态分支、资格查询及测试，不使用隐藏按钮、关闭开关、空壳或长期兼容层保留该路径。需要重新探索时从 Git 历史取回；旧验证记录和忽略目录中的失败证据保留。

本次同时撤销产品说明中普通／共同房的可选壁纸呈现承诺；正式多人、手机、准入、持久化和权限的阶段安排不变。桌宠、既有基础桌面宿主与设置中的 `DesktopDisplayMode.Wallpaper` 属于仍在使用的能力，不按名称批量删除。

普通房呈现偏好仅为应用进程内状态，进入普通房始终选择窗口，没有独立的磁盘呈现设置。因此不增加设置迁移、fallback 或 schema 变更，不清理用户设置。
