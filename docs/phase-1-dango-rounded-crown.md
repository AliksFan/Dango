# 顶部轻圆拱局部试验

> 历史机制：用户已批准用[单一顶部内收力](phase-1-dango-top-inward-force.md)取代顶部柔软度及顶部圆润度。下文保留旧试验与失败证据，不再代表当前参数设计。

## 用户确认与范围

用户已确认 Window 修复后的桌面表现和操作手感通过，但顶部仍尖，即使调高顶部柔软度也不满意；目标是保留一点圆拱，不做平顶。已批准先测量实际轮廓、再做顶部局部试验。

保留[满意参数基线](phase-1-dango-parameter-baseline.md)中的 16 项、鼠标和 WASD 参数、16 个轮廓节点、两组等长初始骨架、90°～180°硬范围、地面和已修复的宿主坐标映射。本次人工验收只新增顶部外形目标；改后手感仍需确认无退步。

## 实测问题

用当前原生物理运行 600 帧后，顶部柔软度为 0、0.5、1 时，最高节点转角分别约为 38.226°、36.836°、39.788°，相邻节点平均转角约为 24.778°、24.891°、24.011°。顶部高度降低不等于弯曲分布更均匀，因此继续整体加软不能直接解决尖顶。

以上数值来自可重复的测试场景，而非读取用户现场鼠标或桌面信息。节点会随运动转动，顶部不能固定为某个节点编号。

## 局部机制

新增独立 `CrownRoundness`（顶部圆润度），范围 0～1、候选默认 0.5，放在“结构与伸缩”。参数实时生效，不重建 world；0 完全关闭新增力，用于回到已验收机制做对照。现有 `TopSoftness` 默认仍为 0，压缩范围与弹性公式保持不变。

对当前世界坐标中位于核心上方的节点，比较其内角与左右相邻节点内角的平均值，使用转角解析梯度施加三节点成对平衡的力：

- 上方权重为 `max(0, dy / radialLength)^4`，侧面与下半部平滑趋零；左右相邻节点承受局部反作用。
- 力强度随角度差和顶部圆润度增加，并沿用既有最大力上限。系数采用 `48 × roundness / (1 + roundness)`，范围内从 0 平滑增加到 24，减缓高档位增长；每个节点力受限，不取消联合约束。
- 三节点合力和合力矩为零；不指定目标节点坐标、静止长度或一套预制圆弧，不修改渲染轮廓。
- 尖的顶部向内调整，相邻区域承担反作用，使弯曲分散；平坦区域不以固定“向下压”处理，以保留圆拱。

新增 native 配置字段，ABI 11 升为 12，同步托管布局、版本校验和构建元数据。未修改 Box2D 依赖版本。

## 可失败验收

先加入测试验证旧版本确实失败：顶部转角不超过两侧平均值 5°，同时最高点高于左右相邻点平均值至少 0.01 个局部坐标单位。旧版本在三个柔软度取值下全部失败。

候选需满足：

1. 三个柔软度取值下，连续稳定帧满足上述曲率与拱起要求；没有内凹、自交或冻结。
2. 圆润度为零可复现原机制数值；运行中开关不重建 world，开启后曲率集中程度有可测改善。
3. 圆润度与柔软度各取 0、0.5、1 的组合，逐帧验证落地、拖拽释放和 WASD 下的硬角度范围与无锁存。
4. 原有下宽上窄、顶部柔软度高度对照、局部角度均衡、大小切换及模式切换/重新生成测试继续通过，不降低门槛。
5. 原生长期模拟分别覆盖圆润度 0、0.5、1，检查长度、地面、角度和静置漂移。
6. 全量构建、格式、测试通过后替换正式桌面候选，旧可运行版本备份；进程运行检查不代替人工观感。

本文件记录实施中的候选；最终测试结果与正式桌面替换状态以本节后续记录为准，不把试验方向当作已验收结果。

## 已取得的自动证据

- 线性系数 36 的高档位试验中，圆润度 1 的长期静置位移范围约 0.0123，超过 0.003 门槛，因此未交付。采用上述饱和增幅后，圆润度 0、0.5、1 各 36,000 帧模拟的末段位移范围分别约 0.000488、0.000355、0.000358，全部低于同一门槛。没有放宽稳定性判定。
- 原生几何、守恒、长度、地面和退化拒绝测试通过；三个档位的实际 Box2D world 都持续运行而不是冻结取样。加速模拟不等于真实桌面持续观察。
- 单体定向测试 24/24 通过。默认圆润度 0.5 时，柔软度 0、0.5、1 在第 900 帧的顶部转角约 30.001°、30.078°、30.311°，相邻平均转角约 25.525°、25.502°、25.532°，拱起高度约 0.0674～0.0685；第 480～899 帧逐帧满足局部角差不超过 5°和拱起大于 0.01 的要求。
- 关闭圆润度可复现旧机制第 600 帧约 13.448°的顶部曲率差；运行中重新开启后差距减少超过 5°，不需要重建 world。截图中的 16 项参数测试继续通过。
