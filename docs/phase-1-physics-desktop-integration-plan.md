## 2. M2 API 与不变量

- 创建时传入明确 native 路径和参考逻辑矩形，真实创建世界及第一只实体；加载错误直接返回可识别异常，不启动旧物理 fallback。
- `Add(x,y)` 添加到同一个世界，默认容量三；`Remove(id)` 不重建幸存者，拒绝移除最后一只。`Select(id)` 选定键盘实体并清理旧输入。ID 只在本场景有效。
- `BeginDrag/MoveDrag` 将宿主 DIP 目标转换为世界坐标；`EndDrag` 正常释放拖动而不伪造新的跳跃边沿；`CancelInput` 用于失焦、捕获失败与 Esc，停止所有持续输入。
- `Step(dt)` 只推进一次，共享全部有效实体输入。返回原始物理帧以及按 ID 标识的显示帧；显示控件应按 ID 绑定，而不是固化数组顺序。
- 原点为参考矩形中心，X 比例为宽度的一半、Y 比例为高度的一半并反向；`Rehost(center)` 只变更平移，保留世界和附件平滑状态。DPI 是宿主最终变换，不进入这里。
- `SetPaused` 清空输入，不销毁世界；暂停时禁止 Step，不积累隐藏时间。恢复由宿主时钟提供新的一次固定步。
- `Reset` 保留当前 ID/出生锚点，清除锁存并重置显示适配器；不恢复已移除实体。
- native 帧错误可通过 `Physics.ErrorCode/LastErrorCode` 识别；下一帧不继续求解、不重建世界，保持安全帧。宿主必须显式展示该错误，不能只看视觉适配器的历史诊断。
- 创建线程操作及释放，重复 Dispose 幂等；失效/跨线程操作拒绝。没有后台线程、网络连接或持久输入记录。

## 3. M3/M4 接线前必须处理的真实缺口

接线前已核实：Window 的第二/三只视觉为 `IsHitTestVisible=False`；WorkerW 的 hit-test policy、桌面鼠标代理和 `dangoAboveWindow` 只覆盖第一只。以下是本轮接线解决的缺口，保留其验收依据。

实施 M3/M4 时先补齐以下宿主详细契约和对应红灯测试，不能直接把旧数组接到新场景后称完成：

1. 场景 ID 到视觉控件、帽子、捕获对象及桌面代理的绑定表；移除实体时释放对应捕获/窗口/代理，保留幸存者。
2. 两种宿主与“图标上/下”层级下的多体命中优先级；一次指针操作只能绑定一个稳定 ID，不能事件冒泡导致多次 BeginDrag。
3. 所有操作目标都用场景坐标，统一设备像素→DIP→世界转换；代理增量以本次抓取起点累计，禁止重复乘 DPI。
4. 当前控制中心只有无 ID 的移除命令；接线需要明确它作用于选中实体，失败理由区分最少数量、故障和宿主不可用，不能一律显示数量上限。
5. 隐藏/退出、全屏抑制、Explorer 恢复和宿主切换时，额外覆盖窗与代理须跟随相同生命周期；场景仍只保留一个 world。
6. 控制中心错误应反映真实 native 加载/帧故障；默认单体、数量上限三，不能静默切回旧 DLL。

这些属于 A 的宿主实现准备，不授权 B 的自主动作、点击/抚摸识别、爬岛、静态平台或四体扩容。

### M3/M4 接线细则（本次继续实施）

- 继续由 `DangoApplicationHost` 唯一持有 runtime。现有 Window/Wallpaper 的可见性判断和切换先隐藏旧宿主的顺序保持；暂停不释放 world，退出才释放。测试直接传入已验收模块路径；应用从自身输出目录加载新模块文件名，缺库显式失败，不搜索旧 DLL。
- 帧携带 EntityIds 和每个实体的显示色槽；视觉控件每帧绑定 ID。数组只用于本帧布局，不作为持久实体标识。选中实体接受键盘输入，“移除团子”移除选中实体；移除后清空键盘桥/鼠标捕获，选中最早存活实体。
- Window 三个视觉均连接相同输入处理器，捕获对象为实际命中的控件；鼠标失捕获、Esc、失焦、隐藏、重置/移除均清理输入。捕获失败必须撤销 BeginDrag。
- Wallpaper 图标下按 ID 创建/复用 `WorkerWInputProxy`，保持现有桌面图标优先策略；删除只释放对应代理，隐藏/恢复释放并按当前存活 ID 重建代理，不重建物理世界。
- Wallpaper 图标上采用一个共享、无激活的透明场景覆盖窗，所有身体先绘制、所有帽子后绘制，避免独立身体窗口遮住另一只帽子。覆盖窗只包围当前场景，空白区域 `HTTRANSPARENT`；命中返回实际 ID。它不含第二个计时器/world，不通过拖动窗口伪造物理位移。
- 覆盖窗指针使用屏幕设备坐标，经 WorkerW 的 `PointFromScreen` 转为场景 DIP；代理局部设备坐标除一次宿主 DPI，加本实体的显示位置。宿主移动/迁移只改变显示原点，取消进行中的拖动。
- 先写数量开放的失败测试，再接 runtime；随后分别验证实体路由、生命周期、真实 native 等价、compiled WPF 事件绑定及隔离发布。两种宿主仍须用户分别验收，自动测试不提升为人工通过。
- 构建仅通过显式 `DangoPhysicsModulePath` 内容项把新模块复制到隔离输出；不调用 native 重建脚本，不覆盖旧 DLL 或已验收对照。
- 实际窗口不能直接复用实验场景的固定左右出生偏移。新增实体从当前可见区域的空位出生，控制矩形保留 8 DIP 边缘余量；出生锚点按模块既有 DropHeight 换算，不修改参数。宿主迁移/窗口缩放只对整组显示做一次平移适配，不重建或缩放物理；若整组跨度大于视口，明确提示放大或重置，不承诺无限边界或偷偷传送实体。
- 人工入口使用 `--physics-host-review`，单实例标识与普通应用分离，设置及验收草稿保存到隔离构建目录的 `physics-review-state`，不覆盖已有个人设置或旧验收草稿。首次进入普通窗口并开启 WASD；之后使用本测试目录保存的设置。
