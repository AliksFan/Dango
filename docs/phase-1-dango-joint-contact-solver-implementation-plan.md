## 1. 交付目标

在现有 16 节点＋动态核心 self rig 上建立默认关闭、测试专用的联合求解候选：最多 3 只、共 51 个动态刚体使用同一份小步状态，位置和速度分别在最多 96 次**全组扫描**中收敛；单体长度/角度、地面、跨体节点—线段接触及摩擦使用统一停止条件和小步内累计预算。

本计划只回答联合求解器能否在不改变已批准形状与门禁的前提下，通过单体回归、双/三体 5% 稳定、承重和支撑释放。首轮输出仍是隔离原生证据，不直接接入 `dango_box2d_bridge.c` 的正式导出、`Box2DNativeLoader.cs`、`Wallpaper/Window` 或生产 DLL。

必须保持：

- 每只 16 个轮廓节点＋1 个动态核心，既有质量、弹簧、内部力、满意默认参数和 `TopInwardForce=0.5`；
- 90°～180°硬角度边界、长度比例、二次 B 样条外形及已接受的单体静态/动态体验；
- 地面摩擦 `0.72`，跨体首轮只运行 `0` 与 `0.3`；
- 居中及左右 `5%W` 为稳定必过范围，`W` 为固定无负载初始渲染轮廓宽度；`10%W` 只探索；
- 原位置误差、速度、能量、动量、漂移及资源门槛，不用调高摩擦、放宽容差、增加 96 扫描预算或强制休眠换取通过。

## 3. 目标内部接口

以下名称在实现中可做不改变语义的 C 风格微调；若职责或容量发生变化，先更新计划。

### 3.1 固定状态

`dango_joint_state` 固定包含：

- `body_count`（1～3）、每只 17 个稳定 body identity；
- 51 项位置、速度、逆质量和上一小步位置；
- 每只径向/外围静止长度、长度范围、节点半径和地面高度；
- 每节点 Box2D 已施加的地面法向/切向冲量及是否真实接触地面；
- 跨体 `skin`、地面 `mu=0.72`、跨体 `mu=0/0.3`；
- 接触、约束行、扫描次数、约束访问次数、接触重建次数、耗时和最大残差诊断。

适配接口分为 `read_rigs`、`solve_positions`、`build_velocity_rows`、`solve_velocities`、`validate`、`write_rigs`。候选数组全部通过后才批量写回 Box2D；任何失败都不部分写回。

### 3.2 单体行

从 `dango_self_constraints.h` 提取可独立调用的：

- 径向长度、外围长度、原始角度、显示角度的位置投影与只读残差；
- 相同梯度和逆质量权重的活动边界速度投影；
- 地面非穿透位置行及地面法向/切向速度行。

旧入口仍可调用同一原语恢复现有“位置＋速度”行为。新位置入口必须逐位保持速度数组不变；新速度入口必须逐位保持位置数组不变。不得维护第二份满意参数或第二套角度数学定义。

### 3.3 接触与容量

接触键由 `{pointRig, pointNode, edgeRig, feature}` 组成；边中部 feature 使用有向边起点和量化前的稳定端点身份，端点命中规范成顶点 feature。双向扫描命中同一顶点对时按规范键只保留一项。

固定容量及失败规则：

- 最多 96 个有向跨体候选、48 个地面接触，共 144 个接触槽；
- 最多 384 个单体上下限速度行、288 个接触法向/切向行，共 672 行；
- 退化边、非法索引、非有限几何、重复键冲突或容量溢出返回具名错误，不截断、不覆盖旧槽；
- `b2Body_GetContactCapacity` 先读取实际数量，再用足量缓冲提取；不得继续固定 `contacts[8]` 后把截断结果当完整地面预算。

每次位置扫描开始时，从同一份当前几何快照重建最近特征，规范化、去重和容量检查通过后物化行身份；本轮访问中不改选特征，按当前候选位置重算该特征的几何和梯度。下一轮允许重建身份。轮末从最终几何独立重建接触做只读残差检查，包含本轮中新出现的接触；不追加修正。最终位置冻结后再固定速度阶段的法向、切向、插值 `t`、雅可比和行身份。速度迭代期间不再漂移接触身份。

### 3.4 累计速度预算

每个活动速度行保存本小步累计值，重复扫描只施加差量：

- `Jn=max(0, oldJn-vn/K)`；
- `Jt=clamp(oldJt-vt/K, -mu*Jn, +mu*Jn)`；
- `Jn` 回落时立即收紧 `Jt`，分离或失去支撑时累计量回到零；
- Box2D 地面法向/切向冲量只作为“已经施加的预算基数”，不再次加到读入速度；候选额外冲量单独累计；
- 跨体每小步从零开始，不跨帧预热。

内部行和跨体接触必须守恒全组线动量；地面外力单独记账。速度求解前后动能正增量不得超过既有 `1e-6` 地面门禁，单次跨体冲量动量/能量误差继续不超过 `1e-5`。

### J1 — 状态适配与单行等价

**修改**

- 在 `dango_self_constraints.h` 提取共享单行原语；
- 建立 1～3 rig 到连续 51 项状态的读取/写回适配；
- 增加位置只改位置、速度只改速度的接口和测试。

**通过条件**

- 径向/外围上下限、原始/显示角度、地面正反例逐行与旧公式在 `1e-7` 数值误差内等价；
- 零逆质量、退化长度、非法角度、NaN/Infinity 得到受控失败；
- position-only 后 51 项速度逐位不变，velocity-only 后 51 项位置逐位不变；
- 旧 `dango_self_constraints_tests` 全部通过，原 `dango_constraint_solve` 的 96 轮包装输出不变。

**停止点**

必须改变角度/长度定义、单次位移上限或满意参数才能共享原语时，回到设计评审。

### J2 — 完整可重放 fixture

旧节点日志只含公开位置/速度，不能称为 Box2D 动态检查点。本阶段建立两层重放：

1. **完整自然重放**：从 world/config/锚点/输入/摩擦/厚度和确定性步数重新创建真实 3 rig，跑到 46/47 帧失败小步；这是 Box2D 路径的权威复现。
2. **求解边界 fixture**：冻结该小步 `world step` 之后、任何外部投影之前，保存联合求解器实际读取的 51 项位置/速度/逆质量/上一位置、每节点地面冲量、所有配置、接触厚度和参与者顺序；它是完整的**求解器输入**，不冒充包含 Box2D 内部 joint/contact cache 的 world checkpoint。

**通过条件**

- 自然重放再次产生同一失败分类、帧/小步及门槛两侧相符的残差；
- 边界 fixture 的 schema 版本、元素数量、有限值、质量和校验摘要均通过；缺字段、重复身份、错误容量必须失败；
- 独立 fixture 重放与自然路径在首轮求解输入和旧求解残差上等价；
- fixture 只含虚构物理数据，不含本机绝对路径、PID 或环境凭据。

**停止点**

若 Box2D 非公开缓存使自然重放不确定，保留自然重放为权威红灯，fixture 仅用于求解边界单测，并明确记录差异；不得伪称完整 world 恢复。

- 每轮只访问每条活动位置约束一次，不在扫描内调用完整 `dango_self_solve_constraints` 或另一个 96 轮循环；
- 保留原两份完整输入及校验摘要，J3R 新结果单独命名；记录扫描数、每类行访问数、接触重建数、最大修正、耗时及 J2.5 的逐轮诊断；
- 轮末独立从最终几何检查所有残差和拓扑门禁，遗漏新生接触、跨体交叉或穿心的错误实现必须被测试拒绝；
- 求解前后所有速度逐位一致。

**停止点**

96 次全组扫描仍不收敛时保留 fixture、末态和残差曲线，停止；不启用 1.25、不增加轮数、不放宽 `1e-5`。

### J4 — 最终几何上的速度行与生命周期

**修改**

- 在 J3R 通过后的最终几何上复用 J2.5 的规范 contact key、端点归一化与接触槽，构建固定速度行；
- 复用真实地面 shape 身份及实际 capacity 检查，不另建一套接触身份规则；
- 增加速度行容量峰值、水位及失败码诊断。

**通过条件**

- 边中点、两端点、双向扫描、相邻边端点、镜像/反序、分离重接触正反例通过；
- 去重前后的几何覆盖一致，同一支撑不重复，同一真实端点支撑不丢失；
- 3 rig 人工构造达到 96 跨体＋48 地面槽不越界，第 145 项明确失败；
- 384 单体行、288 接触行、总 672 行的边界和第 673 行溢出均有可验证结果；
- 移除/reset/destroy 后不保留 body 指针或旧接触行。

**停止点**

若一个节点必须同时保留多条邻边特征才能不丢支撑，停止并修订候选生成和容量设计，不静默扩大数组。

### J5 — 统一速度与累计冲量

**修改**

- 最终位置上固定活动单体、地面和跨体行；
- 实现每小步累计 `Jn/Jt`、差量施加、法向回退时摩擦锥收缩和地面已施加预算基数；
- 统一最多 96 次速度扫描及全部行的最终残差验证。

**先失败测试**

- 同一接触重复访问不得重复花费预算；
- `Jn` 下降、支撑撤销、端点切换、零摩擦、无支撑、不同质量和镜像顺序；
- 一组速度行修好后让另一组重新违规的耦合用例；
- 错误地把 Box2D 地面冲量再施加一次时，测试必须因动量/能量账目失败。

**通过条件**

- 活动长度/角度/法向行不继续闭合，沿用 `1e-5` 速度精度；
- `Jn>=0`、`abs(Jt)<=mu*Jn`，同一小步重复扫描只施加差量，下一小步清零；
- 内部与跨体冲量全组线动量误差 `<=1e-5`；地面外力账目闭合；
- 候选前后动能正增量 `<=1e-6`，并分别输出最大单次差量和最终总量；
- 最大速度变化 `<=1e-5` 只能作为附加停止量，不能代替逐行残差。

**停止点**

出现不可解释增能、摩擦无支撑仍生效或需要跨帧 warm start 才通过时停止，不进入 J6。

### J6 — 真实单 rig 回归

**输入**

使用 `configuration()` 的满意默认值和现有单体完整动作序列；新路径必须真实经过联合状态、位置和速度阶段，不能在 `body_count=1` 时绕回旧入口冒充兼容。

**通过条件**

- 默认五位置、三档压力、历史三档 36,000 帧、A/D/S/W、最高节点拖动/释放、快速甩动两档、地面下移/支撑释放、碰撞唤醒、非有限/非法几何锁存和资源归零通过；
- 16 节点、动态核心、长度、90°～180°、面积、自交、`TopInwardForce=0.5` 和同比例限速不变；
- 实际渲染轮廓协议 v2 的 512 点距离/宽高面积结果单独报告；旧数值失败不删除，已通过的隔离静态/动态人工结论不被改写；
- 候选单体若产生新轮廓或动态差异，先进入隔离 WPF 对照，不以历史人工通过自动豁免。

**停止点**

单体自动门禁或已接受桌面手感发生回归时停止；不进入多体矩阵。

### J7 — 双/三体 5% 稳定、承重与释放

**固定矩阵**

- 数量 `2/3` × 接触厚度 `0.020/0.045` × 偏移 `0/-0.05W/+0.05W` × 跨体摩擦 `0/0.3`；
- `W` 仍取无负载初始轮廓 512 点宽度，不随受压变化；
- `mu=0` 是物理对照：不要求不滑落，但必须几何、能量、自然分离和资源合法；
- `mu=0.3` 承担居中及左右 5% 的稳定必过目标；`+/-0.10W` 另行输出探索结果，不计必过率。

**先行统计冻结**

第一次出现真实稳定支撑窗口后，先用只读诊断记录核心高度、相邻层接触、节点漂移、各层平均垂向压缩和实际法向反力。在继续任何求解调整前，把压缩统计窗口、计算式和最小层间差写入验证记录并加入测试；后续失败不得降低。若始终没有稳定窗口，则以“不具备冻结统计门槛”失败停止。

**通过条件**

- 自然落下而非预制静态堆叠；`mu=0.3` 的 12 个必过场景各运行 36,000 帧；
- 最后 600 帧相邻上下层持续接触，上层不直接接地，非相邻层无直接承重；
- 底层平均垂向压缩显著大于顶层，实际法向反力沿相邻层传递，轮廓/几何全程合法；
- 稳定窗口节点漂移 `<=0.003`，整体平移与轮廓形变分开统计，不靠多体睡眠归零；
- 失去有效支撑后允许并要求自然下落；移开底层时上层开始下落，跨体累计接触在完全分离后 120 帧内归零；
- 每组资源归零、无非有限值、无锁存、无接触容量溢出；
- 同向与交错三体偏心分别报告；未覆盖方向明确列为未验证。

**停止点**

任一必过场景达到 96 扫描上限、滑落、穿心、互锁、增能、容量失败，或只有提高摩擦/修改形状/放宽门槛/支持链冻结才能通过时，保存完整状态和成本后停止。不得继续调参消除红灯。

### J8 — 结果收口与人工验收路径

**若 J0～J7 未全部通过**

- 在验证记录和评估文档追加失败分类、fixture、残差、预算、成本和明确未验证项；
- 保留候选默认关闭，不修改生产 bridge、ABI、DLL 或宿主；
- 回到设计评审，不自动开始第二候选。

**若 J0～J7 全部通过**

1. 先完成隔离 WPF 多体预览计划：真实 native 候选快照进入现有二次 B 样条渲染，展示 1/2/3 只、居中/左右 5%、轻贴、承重、支撑移除和骨架；不替换正式 DLL。
2. Agent 先核对窗口启动/退出、同帧三色与真实骨架、接缝 DIP、无假动画和资源释放。
3. 用户人工观察单体是否仍自然、双体接触是否局部、三体承重是否柔软、偏心/失撑是否自然滑落；关闭窗口不代表批准。
4. 隔离人工通过后，另行制定并批准 plural ABI、左右墙、正式 `Wallpaper/Window`、任意团子拖动和生产 DLL 替换计划；本计划不越过该批准点。

因此本计划结束条件是“隔离联合求解候选通过或按停止点失败并留证”，不是 P2D-007C、P1-004 或 Phase 1 整体验收完成。

## 6. 证据与交付状态

每个 J 阶段完成后按以下层次报告：

- **静态门禁**：C17、MSVC `/W4 /WX`、受影响原生测试、文档链接、`git diff --check`；
- **集成门禁**：自然重放、冻结 fixture、51 刚体、144 接触槽、672 速度行、1～3 rig、资源归零；
- **实时行为**：本计划默认未验证；只有 J8 另获批准并运行隔离 WPF 后才记录；
- **人工验收**：本计划默认未进行；既有单体静态/动态通过不等于新候选或多体通过；
- **交付状态**：默认不提交、不合并、不推送、不部署、不替换正式 DLL。

所有失败使用非零退出码并保留输入、末态和诊断。无法运行的项目写“未验证”，不得从局部代数测试推断完整堆叠通过。

## 7. 计划批准后的执行节奏

修订后的顺序为 `J0 → J1 → J2 → J2.5 → J3R → J4 → J5 → J6 → J7 → J8`。当前 J3R 已触发停止点，下一步为设计评审；原 J3 红灯作为历史对照。J2.5 前提门禁、J3R、J5、J6、J7 各自是硬停止点。任一硬停止点触发，本轮即收口留证并向用户报告，不自动换算法、参数、范围或进入正式集成。

计划批准只授权上述隔离实现和验证，不授权提交、正式 DLL/ABI、宿主、多体休眠、左右墙、清理历史文件或开始下一阶段。
