### 3.2 输入与输出

`AttachmentBodySample`（新增）只持有归一化显示轮廓、facing、固定步编号和 reset generation；不传 native 角度、角速度、世界位置差分、可写节点或 world 引用。身体平移不得激励附件。控制器由实体路由持有，Core 命令无 `DangoEntityId`；Desktop 路由以 scene 实例+实体 ID 校验目标，跨世界相同数字 ID 不通用。

`AttachmentPresentationFrame` 不可变：Version、StepIndex、Generation、ShapeTilt/Confidence、左右 EyeFrame（中心、宽高、局部角、Openness、Round/Soft、Strength、Visible）、HatFrame（s、有效区间、非零贴合宽度、平移/角度、b/c、Visible）、Diagnostics。诊断含置信度原因、眼安全级别、轨道重投影、贴合间隙/穿入、预算占用/削减、事件状态及降级原因；不记录真实桌面/按键内容。

位置使用两种明确单位：旧 `PresentationPoint` 不变；附件内部采用参考画布的等尺度局部坐标 `u=(DIPx-80)/160, v=(66-DIPy)/160`（Y 向上，数值均按参考宽 160 归一化）。所以身体点为 `(72*x/160,58*y/160)`。轨道 s、宽度、速度和贴合误差都用此单位；最终还原参考 DIP 后整体映射到宿主尺寸。角度在这个等尺度空间求，不能在旧 x/y 不等比例坐标求完直接当 WPF 角。眼动作比例独立于这些单位。旧范围类型只用于旧字段，帽尖可超身体边界但须在专用素材包围限值内；不得放宽全局类型救局部异常。

`Update(sample, dt, mode)` 只在成功固定步调用；dt 必须 (0,100ms]，非法值拒绝且不改变状态。额外 Render/ApplyFrame 不推进状态。首次有效帧直接建立合法中立挂接，不从旧默认 (0,0.82) 弹入。重置 generation 区分同一 ID 的新生命周期，旧队列不复活。

### 3.3 命令与仲裁

保留设计全部语义：`SetGaze(Left/Right/Both,x,y)`；`SetEyes(eye,openness,Round/Soft,strength)`；`Blink(eye,close,hold,open)`；`SetHatSlide(offset)`；`PulseHat(velocityDelta)`；`BounceHat(direction,strength)`；`Release(token,mask)`；内部 `ResetAttachments`。没有 `SetHatPose` 或任意角度入口。

持续目标默认无限期直到替代/Release；Blink 三段严格正时长，候选各段最大 2 秒，总和最大 6 秒；参数越界/非有限明确 Rejected，不静默修正命令。Left/Right 各自保存目标、速度、开合、事件和状态；Both 先检查两侧并在同一步原子入队，任一 Busy/拒绝则全拒绝，不移动另一侧序号水位。序号按当前已注册 token 单调递增；无效请求不推进水位。合法旧序号重发拒绝。token 注册优先级由入口确定：生命周期 > 显式预览 > 保留动作入口 > 默认朝向；本轮不实现未来动作调用者。

同优先级新有效命令覆盖对应通道；高优先级接管删除被抢占通道的低优先级意图，不排队复活。Release 只作用于 token 当时拥有的通道，入队顺序处理；同 token 的新命令不会被逆序 Release 删除。暂停/停止时拒绝新外部命令，保留已运行状态以便恢复；移除/Dispose 清队列、token 和结果。

Blink 包络乘当前有效开合，闭眼目标不会被眨眼打开；同眼忙返回 Busy，另一眼独立；取消从当前开合平滑返回。Pulse/Bounce 冷却各候选 150ms，暂停不走冷却时间；冷却内 Busy，不排队。轴向实现前 Up/Down 返回 Unsupported，UI 同步禁用。

一次事件 Accepted 只表示已接纳。Blink 完成三段回目标后 Completed；Pulse/Bounce 在其激励之后相应运动连续 200ms 低于位移 1e-4、速度 1e-3（参考宽单位；b/c 用各自归一化幅度）时 Completed。被新事件替代、抢占、Release、Reset 或移除则 Cancelled，不能假报完成；持续外部激励可能延迟完成，不用固定计时宣称已稳定。每实体候选最多 8 个注册 token、64 条待处理命令、128 个待消费事件结果；耗尽返回 Busy/Capacity，不丢失未消费结果冒充完成。事件消费后释放记录，销毁后全部清理。

## 4. 几何及运动算法候选与可失败标准

本节选定首轮可实现候选及理由，先锁测试阈值再实现；发现不适用时记录失败、理由和替代候选，不随着失败放宽阈值。数值通过自动门禁也不等于用户认可观感。

### 4.1 同一显示曲线与形状倾斜

共享闭合二次 B 样条定义：第 i 段从 `(p[i-1]+p[i])/2` 经控制点 p[i] 到 `(p[i]+p[i+1])/2`，在等尺度视觉坐标求值。抽出纯数值段计算供渲染和附件使用；不重新拟合身体，不移动原控制点。自适应细分误差候选 ≤0.0005 参考宽，最大 1024 样本，超限降级；现有 128 点物理接触采样完全不变。用独立公式与 compiled WPF 展平结果交叉校验，不能只让两个消费者调用同一错误函数便算等价。

形状包围高 H，自底向上取 0.45/0.55/0.65/0.75/0.85H 截线，半开区间处理顶点避免重复交点。取包含脸部中轴的连续内区间，至少 3 条有效；计算中心 cx(y) 的加权线性回归。主要角 `atan(dcx/dy)`，正号定义为上部中心向右。辅助角使用中央上冠的宽区间走势（排除最顶端 5% 高度的尖峰），只用于信号一致性与镜像校验，不叠加角度。

置信度候选 `C=Ccoverage*Cresidual*Cagreement`：coverage 为有效截线数/5；residual 为 `clamp(1-rms(center-fit)/(0.04*W),0,1)`；agreement 在两信号差 ≤5° 为1、≥15°为0，中间线性。辅助不可用时 C=0，明确回中立而非猜朝向。主信号死区 |dcx/dy|≤0.02 为0，之后连续扣除死区；目标为 C 乘限幅 ±10° 的主要角。对称圆形/压扁/拉长应精确中立（数值误差≤1e-8 rad）；非对称左右镜像反号且置信度相同。近圆带微小噪声以死区和低置信度回零，不采用可能翻转的主轴，也不依赖节点编号。

视觉角用独立弹簧 4Hz/ζ0.9。正角表示向右歪，WPF 显示旋转须按 Y 翻转显式转换。对主/辅冲突、冠顶换序、循环移位全部设置正反例；几何不变而伪造不同物理方向元数据，结果必须完全不变。真实几何旋转后形状变了可响应，不要求旋转不变。

### 4.2 双眼布局与联合安全

脸部起始中心取旧 y=-0.05 附近，换算进等尺度空间；在相邻 3 条截线寻找能容纳图形的中心内区间。候选中心只允许在中部高度 0.35～0.65H 内温和调整，不追逐远离中心的孤立宽区间。共享视觉角只转双眼基准连线，各眼的 gaze 响应在共同脸部坐标中独立积分，再作联合约束。

中立优先保留当前眼尺寸/间隔。Round 为原 12 DIP 圆；Soft 用同一局部图形的上下弧连续变化，strength=0 还原 Round。闭合为有厚度曲线，候选 1.5 DIP；openness 不导致零尺寸布局。安全边界包含图形完整旋转包围范围和笔画半宽，内边距候选 1 DIP（均先转参考宽单位）。以解析弧极值或有误差界的细分轮廓检查整个眼图形在身体内部，不能仅检查中心或四个顶点。

每步按固定顺序寻找可行布局：共同缩减两眼 gaze 系数从1到0（保留两眼各自目标，不互相覆盖）→眼间距缩至中立的80%→两眼尺寸缩至中立的70%。每阶段做最多12次二分可行搜索；最小左右净间距候选2 DIP，强反向 gaze 也不交换左右身份。仍不合法则显示安全闭眼线；闭眼线也放不下时隐藏对应眼并记录失败。安全投影只清朝非法方向的速度，不把投影反馈进意图目标；恢复空间后自然恢复。双方安全约束只耦合最终布局，不共用眨眼计时或 gaze 弹簧。

失败反例：只检查中心、共用计时器、交换左右目标、先做安全检查再旋转、严重挤压扩大身体，均必须被夹具检出。

### 4.3 头顶轨道、底座标定与整段贴合

先对当前叶芽标定候选虚拟底座：参考素材 y=25，x∈[77,83]，宽6 DIP；茎的最下缘到y=26纳入穿入评估；整个 y≥25 区域是零形变底座。它是现有素材几何的试验起点，EH-02 compiled 图验证后冻结，不能把原 (80,15) 变换原点当帽根。叶片/茎外形和颜色零形变时保持原值。

沿真实显示闭合曲线提取中央连通上冠：以包围盒中线为中立搜索基准，候选限制 x 在中心±0.35W、y≥底部+0.65H，选择包含中央垂直截线最高合法交点的连续外边界；不能跨凹陷缺口拼接轨道。转折处按真实弧段走向处理；每候选贴合区在 x 上须左右有序，不能走到侧脸。按弧长等距重采样，曲线求值仍落在原 B 样条上，不用无约束平滑把轨道移出表面。

中立中心为中央±0.15W 上冠区间的弧长加权 x 中心在冠线的投影，避免选择最高单点。滑动 s 以中立为0、沿轨道向右为正，最大左右各0.08参考宽，再与足够容纳底座的区间及角度/误差合法集合求交；只取含中立或最邻近中立的连通合法分量，不跨跳到另一侧。帧间根据上一贴合中心/区间的最近几何位置映射，等距并列优先保持前帧侧别；无前帧时选择距中轴最近者。节点循环换起点不能改变结果。

每个候选 s 取非零宽6/160的贴合弧段，9个等弧长样本；以端点权重1、内部权重2作二维最小二乘直线拟合，切向强制左到右，不出现180°翻转。沿拟合切向放置底座的左右端点，法向平移由整段最大间隙和最大穿入的 minimax 平衡决定；同时优化s邻域内的位置使误差最小。底座长度按素材标定，不通过缩到0解决曲率。

9点只用于拟合，验收要对区间自适应密集采样并包含茎底外缘：轨道到原显示曲线距离≤0.0005，底座最大正间隙≤0.005参考宽、最大穿入≤0.007（包含素材底缘1 DIP的候选预算）。角度绝对值≤0.35 rad；超过则缩小合法s区间/重拟合，不能到渲染端 clamp。若这种6 DIP底座与既有外观不相容，停止标定并报告，不改身体或假称已贴合。

轨道缩短先投影到最近合法区间，消除朝外速度并重建形变差分基线；不对最终世界挂点再作滞后平滑。无合法区间时隐藏帽子并报告降级；不悬浮或跨头瞬移。平顶滑动必须有平移、角度近零；变曲率弧面上必须同时调整平移/角度。专用测试将拟合替换成单点切线、固定支点旋转、只检查帽底中心时应失败。正常连续非退化序列相邻贴合中心变化≤0.01参考宽、角度≤0.03rad/60Hz；突发约束投影另列，不拿平滑阈值要求故障瞬变，也不允许正常序列频繁降级来过关。

### 4.4 弹簧、时间与轨道目标

采用分段常目标的解析二阶阻尼更新，分别处理欠阻尼/临界阻尼和零dt内部查询；配置仅开放0<ζ≤1、0<f≤10Hz，拒绝其他参数。EH-03先验证公式。外部只允许合法正dt；内部按命令时间/眨眼相位边界分段，最大1/240秒以便一致执行几何与预算约束。它是附件内部步，绝不调用物理 Step。

候选初值：gaze 5Hz/1，开合跟随 8Hz/1，共享角4Hz/0.9，轨道3.5Hz/0.8，弯曲5Hz/0.75，轴向6Hz/0.85。相位三段70/40/120ms为预览起点；眨眼包络采用端点导数为0的 smoothstep，乘该眼有效开合，事件取消保留当下输出再回目标。

自然轨道目标 `sShape=(theta/10°)*0.04`；显式offset按当前左右可用s距离分段映射，再加sShape并投影合法区间。镜像夹具和预览确认正负协调；不把theta再次加到帽角上。轨道状态 s、v；Pulse只给v有界增量，候选速度上限0.3参考宽/秒。触边消除朝外分量；Release保留s/v，只换目标。匀速宿主平移无激励。

纯弹簧常目标无约束分段应满足解析半群一致性≤1e-10；整体30/60/120Hz比较用同一240Hz虚构输入时间轴、同一命令时间，局部终值≤0.002参考宽、角度≤0.005rad。另测最大100ms、交替dt、长时间静止、阶跃/反向；不要把不同物理采样率产生的不同身体帧混进此门禁。

### 4.5 帽身变形及自然反馈

局部素材以底座中心 (80,25) 为原点，向帽尖高度 h；参考帽高 Hh=23 DIP。y≥25不变，h>0令 `t=clamp(h/Hh,0,1)`、`w(t)=3t²-2t³`。弯曲 `x'=x+b*Hh*w(t)`，轴向 `h'=h+c*Hh*w(t)`，再应用整段贴合姿态。底座处w及导数为0，茎和两片叶子使用同一连续变形场；不对控件整体缩放，不加叶片独立弹簧。

候选 |b|≤0.06、|c|≤0.05；c正伸长、负压缩，Left/Right 对b速度负/正，Up/Down 对c速度正/负。检查雅可比 `1+c*w'(t)>0`、路径无翻折/自交、底座所有点完全不变。原路径含曲线，不能仅变换Bezier控制点假装精确变形：自适应细分原曲线再变形，素材空间误差≤0.05 DIP；零b/c直接使用原曲线，逐点/像素基线比较。预算、几何都在绘制前验证，两种帽路径用同一结果。

自然激励只读取轨道平滑速度变化及形状描述子（H/W、主截线中心偏移）的变化，不读核心位置/物理转角。候选100ms指数低通；轨道加速度死区0.05参考宽/秒²、形状变化率死区0.02/秒，扣死区后限幅并乘dt注入形变速度。符号：向右滑动急停时帽尖继续向右、身体高度减少时压缩；用正反例固定。恒定形状、匀速轨道滑动应不持续注入。首次/Reset/恢复/重投影/故障重建差分基线，禁止安全修正制造冲击。先只开弯曲；EH-07通过才支持轴向。

### 4.6 统一强度预算（首轮明确公式）

预算采用“每通道硬状态界 + 共享激励功率”，避免只在末端截断图形。轨道几何/有效动作目标优先；不为给帽身让空间移动底座或改变sTarget。

对轨道、弯曲、轴向定义归一化占用：`qS=max(|s|/S, |vS|/VS)`，`qB=max(|b|/B, |vB|/VB)`，`qC=max(|c|/C, |vC|/VC)`。S为当前侧合法范围（零范围时s/v必须0），VS=0.3，B=0.06，C=0.05，VB=2π*5*B，VC=2π*6*C。各q≤1；轴向未支持时qC=0。

组合状态指标 `Q=0.5*qS+0.25*qB+0.25*qC≤1`，因此任意通道同时达到独立上限也不突破已定义组合最大；这不是额外放大许可。共享激励上限再随当前轨道占用收紧：每内部步剩余形变速度额度 `R=max(0,1-qS)*max(0,1-max(qB,qC))`。对自然与显式待注入量按绝对值合计 `D=(|ΔvB,n|+|ΔvB,e|)/VB+(|ΔvC,n|+|ΔvC,e|)/VC`；统一缩放 `λ=min(1,R/max(D,epsilon))`，四项都乘同一λ后再按方向合成。相反事件不能用抵消释放预算、同帧人工不能再叠一倍自然冲击。Pulse先过轨道速度/几何界再算qS，不与Bounce自动联发。R是本步上限；自然注入本身乘dt，显式事件只消费一次，子步不能重发。

已有b/c不随R缩小瞬间缩放，而继续有阻尼衰减；候选解析一步若越独立位移界，在首次到界时分段推进并清朝外速度，余下时间继续回弹，保持位置连续。极端几何失效才可确定性重置并显式降级，不能把这种重置算自然恢复。总状态仍受Q硬界约束。该公式不是机械能守恒模型，是保守视觉强度契约；EH-07必须用连续脉冲和组合人工对照验证是否仍过强，失败时降低候选配置并保留失败证据，不能在渲染端偷偷改数值。
