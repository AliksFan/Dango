## 1. 背景

当前候选通过预制椭圆目标、径向弹簧、外围弹簧和多体接触修正叠加形变。连续调参后仍容易出现轮廓骨架交叉、Z 字形折返、接触粘连以及异常重建等问题，难以继续作为正式团子的物理基础。

本轮放弃当前团子自身的形变机制，从单只团子的内部结构重新设计。现有 Windows 桌面宿主、控制中心、渲染组件、输入桥、帽子和眼睛图层、16 节点数量及完整骨架显示框架继续保留。团子间碰撞不在本轮实现。

## 2. 目标与范围

### 2.1 本轮目标

1. 用明确、可解释的 16 节点软体结构生成团子自身形变。
2. 初始状态下 16 根径向骨架彼此等长，16 根外围骨架彼此等长；两组长度可以不同。
3. 骨架允许在受控范围内轻微压缩和拉伸，限制与弹性参数可调。
4. 团子自由落到地面后，由真实重力、地面接触和内部约束形成“下宽上窄”的稳定轮廓。
5. 径向骨架之间具备排斥机制，外围相邻骨架有向内夹角必须处于 90°～180°，避免尖角、内凹反角、节点越序和 Z 字形轮廓。
6. 鼠标拖动与 WASD 全部改为对物理体施力，不再强制修改团子坐标。
7. 新机制参数可在控制中心实时调整，并能恢复默认值或显式重新生成团子。
8. 帽子、眼睛沿用既有物理跟随特性；帽子没有碰撞且始终处于最高绘制层。

### 2.2 明确排除

- 本轮只允许一只活动团子；控制中心保留数量框架，但禁用添加和移除按钮并注明“团子间碰撞阶段开放”。
- 不实现团子与团子之间的碰撞、堆叠、承重、滑落或多人同步。
- 不修改账号、房间、网络、持久化或服务端协议。
- 不恢复独立预览窗口；全部实验继续发生在正式 `Wallpaper/Window` 桌面场景。
- 不把物理结果写成已经完成的 Core、服务端或多人权威状态。

## 3. 结构模型

### 3.1 节点和骨架

每只团子由以下物理对象组成：

- 1 个动态核心体；
- 16 个按固定顺序编号的动态轮廓节点；
- 16 根“核心—轮廓节点”径向骨架；
- 16 根“相邻轮廓节点—轮廓节点”外围骨架，首尾闭合；
- 1 条静态地面碰撞边界。

骨架模式完整显示上述 1 个核心点、16 个轮廓节点、16 根径向骨架和 16 根外围骨架。骨架只用于诊断，不额外参与碰撞，也不能改变模拟结果。

### 3.2 初始几何

- 16 个轮廓节点按等角度分布，初始相邻方位角为 22.5°。
- 所有径向骨架使用同一个初始静止长度 `RadialRestLength`。
- 所有外围骨架使用同一个初始静止长度 `PerimeterRestLength`。
- 控制中心只提供一个“团子大小”参数，对应径向静止长度；外围静止长度固定按 `2 × 团子大小 × sin(π/16)` 计算，不能与径向长度分开调整。
- 初始拓扑顺序固定。模拟期间节点不能交换编号、轮廓不能翻面、外围骨架不能自交。

初始轮廓为规则、近圆的软体结构，而不是预先写死“下宽上窄”的椭圆。团子落地后的下宽上窄必须来自物理形变。

## 4. 骨架伸缩机制

### 4.1 有限伸缩

径向和外围骨架分别具备：

- 静止长度；
- 最小长度比例；
- 最大长度比例；
- 恢复弹性；
- 阻尼。

骨架在正常受力时以弹簧方式轻微伸缩；接近最小或最大长度时，限制力非线性增强；达到硬边界后不允许继续缩短或拉长。这样既保留软弹感，也防止节点被冲量拉散或挤到核心另一侧。

### 4.2 面积保持

仅依赖长度弹簧会在落地时整体塌陷，因此增加弱面积保持力：

- 以初始有向面积为目标；
- 面积减小时沿轮廓法线向外施加有限恢复力；
- 面积保持只抵抗整体坍塌，不直接指定各节点位置；
- 强度可调，并受最大力限制。

地面压缩下部节点后，面积保持与有限拉伸把体积向两侧重新分配。接地期间再施加一组守恒的水平形变力：下半轮廓向外、上半轮廓向内，合力的反作用施加给核心，不能凭空推动整体。该力不指定节点坐标、不改变渲染比例，并可在控制中心调至零做对照实验。

## 5. 防交叉与排斥机制

### 5.1 径向骨架排斥

16 根径向骨架共享核心点。为避免共享端点导致持续发散，排斥计算采用以下规则：

1. 每根径向骨架靠近核心的内侧一小段不参与距离计算。
2. 对骨架有效段计算最近距离；低于 `BoneRepulsionDistance` 时施加成对、方向相反的排斥力。
3. 排斥力随距离缩短非线性增强，并限制在 `BoneRepulsionMaximumForce` 内。
4. 相邻径向骨架同样参与排斥，以维持节点顺序；所有力成对施加，不能凭空推动整体重心。
5. 排斥强度为零时可关闭该机制，用于控制中心对照实验。

### 5.2 外围角度范围

每个轮廓节点连接两根外围骨架。以团子内部一侧的夹角为准：

- 固定硬范围为 90°～180°，不作为普通调参项；
- 接近 90° 时施加渐增强的张开纠正力；超过 180°、形成内凹反角时施加守恒的三节点凸性恢复力；
- 纠正强度可调；
- 数值积分误差允许极小容差，但任何稳定帧不得超出验收范围；
- 180°屏障在接近边界前提前介入；默认参数和最大拖动力压力测试中的每个可见轮廓帧都必须保持在范围内。

在硬范围之内，额外使用局部角度均衡力抑制尖角。每个节点比较自身内角与左右相邻节点内角的平均值；偏差越大，沿相邻节点弦线的法向施加越强的恢复力。当前节点承受主力，左右节点各承受一半反向力，因此三节点合力为零。该机制只平滑局部曲率，不要求所有节点回到规则圆的 157.5°。

### 5.3 外围自交保护

除角度限制外，对不共享端点的外围骨架执行线段最近距离检查和有限排斥。每步结束验证：

- 有向面积为正；
- 节点环顺序不变；
- 不相邻外围线段交点数为零；
- 骨架长度与角度均在硬边界内。

若无法在有限迭代中恢复合法状态，冻结最后一个合法帧并记录安全诊断；不得清空 world 后自动从出生点重新出现。

## 6. 地面、重力与落地形变

- 核心体和 16 个轮廓节点均受统一重力影响。
- 轮廓节点负责与地面发生实际接触；核心体不使用大尺寸外壳替代轮廓接触。
- 地面摩擦和恢复系数可调，默认恢复系数较低，避免持续弹跳。
- 接触求解不得使用预制“落地压扁动画”覆盖物理轮廓。
- 从规定测试高度自由落下后，团子必须经历下落、首次接触、下部扩宽、有限回弹和稳定收束。
- 稳定状态下轮廓底部应比顶部明显更宽，同时骨架不交叉、节点不越序、核心不穿过地面。

## 7. 输入受力设计

### 7.1 鼠标拖动

1. 鼠标按下命中团子时，选取当时屏幕位置最高的轮廓节点作为本次抓取节点。
2. 从按下到释放始终使用该节点，拖动途中不因其他节点变高而切换。
3. 每个物理步对抓取节点施加朝向鼠标的弹簧力：
   `F = DragStiffness × displacement - DragDamping × nodeVelocity`。
4. 力受 `DragMaximumForce` 限制；鼠标不能直接设置节点、核心或权威边界坐标。
5. 松开后立即停止拖动力，团子保留物理系统自然产生的有限速度并受阻尼、重力和地面约束。
6. 失焦、鼠标捕获丢失、宿主切换或退出必须取消拖动力，不能留下持续拉拽状态。

### 7.2 WASD

- `A`：按住时向核心持续施加向左的水平力。
- `D`：按住时向核心持续施加向右的水平力。
- `S`：按住时向核心持续施加向下力，使团子贴地压缩；松开后由骨架自然回弹。
- `W`：仅在确认接地时施加一次向上的瞬时冲量；按住不会逐帧持续上推。
- 同时按 `A+D` 时水平输入抵消；失焦立即清空全部输入。
- 跳跃保留防重复触发间隔；重新接地且间隔满足后才能再次起跳。
- 水平力、向下力、跳跃冲量、水平速度上限、空中控制比例和跳跃冷却均可调。

输入桥仍只产生意图，不记录或持久化真实按键和鼠标轨迹。

## 8. 帽子与眼睛

### 8.1 眼睛

- 沿用既有双眼独立挂点、有限延迟和阻尼跟随。
- 眼睛位置由合法轮廓和核心姿态计算，不作为碰撞体。
- 眼睛不得因节点交叉、朝向变化或落地压缩移动到轮廓外。

### 8.2 帽子

- 沿用顶部语义挂点、有限旋转、延迟和阻尼跟随。
- 帽子没有 body、shape、joint 或任何碰撞质量，不承重、不阻挡节点。
- 帽子始终在所有团子身体、眼睛和骨架诊断图元之后绘制，保持最高可见层。

## 9. 控制中心参数

面板中可调参数仅在本次运行中有效；重启恢复批准后的默认值。本轮不写入正式设置文件。

### 9.1 结构与形变

| 参数 | 作用 |
|---|---|
| 团子大小 | 16 根径向骨架共同的初始长度；外围长度按固定 16 边形弦长比例联动 |
| 径向弹性 | 径向恢复速度 |
| 外围弹性 | 外围恢复速度 |

径向与外围压缩/拉伸限制、两组阻尼、面积保持和落地形变力恢复为可调参数。五个参数分类使用独立折叠面板，默认只展开“结构与伸缩”，其余保持收起。

### 9.2 防交叉

| 参数 | 作用 |
|---|---|
| 骨架排斥距离 | 径向或不相邻外围骨架开始排斥的距离 |
| 骨架排斥强度 | 距离不足时的排斥力度 |
| 骨架排斥最大力 | 防止近距离数值爆炸 |
| 核心排除比例 | 径向骨架靠近共享核心、不参与排斥的长度比例 |
| 外围角度纠正强度 | 接近固定 90°～180°边界时的恢复力度 |
| 局部角度均衡力 | 减小一个外围节点与左右相邻节点之间的角度差，平滑局部尖角 |

### 9.3 环境与输入

| 参数 | 作用 |
|---|---|
| 重力、节点质量 | 整体下落和惯性 |
| 地面摩擦、恢复系数 | 滑动和回弹 |
| 整体阻尼 | 自由运动的衰减速度 |
| 拖动弹性、拖动阻尼、拖动最大力 | 鼠标拉动手感和安全上限 |
| A/D 水平力、水平速度上限 | 横向移动手感 |
| 空中控制比例 | 离地后的水平控制程度 |
| S 向下力 | 贴地压缩力度 |
| W 跳跃冲量、跳跃冷却 | 跳跃高度和重复节奏 |

### 9.4 控件行为

- 所有数值控件同时提供滑块和精确数值输入，并显示单位或无量纲比例。
- 参数输入必须限制范围，非法值不能进入 native 层。
- 力、阻尼等运行参数在下一物理步实时生效。
- 静止长度、质量等结构参数改变后执行一次平滑重建；重建是明确的用户操作结果，不冒充连续物理状态。
- “恢复默认参数”恢复本轮批准默认值；“重新生成团子”使用当前参数重建。
- “显示骨架”是独立开关，实时切换完整骨架，不改变模拟。
- 添加、移除团子按钮在本轮禁用并注明后续碰撞阶段开放。

## 10. 架构边界

- 替换范围限于 `Dango.Desktop` 物理表现世界、native bridge、物理输入映射、表现帧适配和控制中心实验参数面板。
- `Wallpaper` 与 `Window` 继续共享同一个正式场景运行时，不能各建一套物理状态。
- 物理状态只输出轮廓、核心表现偏移、挂点、接地状态和诊断，不修改账号、房间或服务端事实。
- 本轮保留现有 Core 实体与状态机接口；需要移动正式视觉与命中区域时，通过受限的表现偏移统一更新渲染和命中测试，不允许渲染位置与交互区域分离。
- native 错误冻结最后合法帧；只有用户显式重新生成、结构参数重建或正式生命周期重置才能新建 world。

## 11. 分步实施顺序

设计批准后仍按以下顺序实施，每步先建立可失败验收：

1. **P2D-007B-1 初始结构**：单只、16 节点、两组等长骨架、完整骨架显示、拓扑诊断。
2. **P2D-007B-2 有限伸缩与地面**：重力、地面、长度限制、面积保持、下宽上窄落地形变。
3. **P2D-007B-3 防交叉**：径向排斥、外围非相邻排斥、90° 角度屏障、非法帧冻结。
4. **P2D-007B-4 受力输入**：固定抓取节点的鼠标力、A/D/S 持续力、W 接地跳跃冲量。
5. **P2D-007B-5 控制中心**：实时调参、默认恢复、显式重建、骨架按钮、单体阶段数量禁用。
6. **P2D-007B-6 正式桌面验证**：两种宿主、焦点/拖动取消、长期稳定性和人工观感。

只有 P2D-007B 完成自动门禁、真实运行验证并由用户人工验收后，才另行设计团子间碰撞；不得在本任务中顺手恢复多体碰撞。

## 12. 可失败验收

### 12.1 自动验收

1. 初始 16 根径向骨架长度在统一容差内相等；16 根外围骨架长度在统一容差内相等。
2. 受压和受拉测试中，所有骨架长度保持在各自最小/最大比例内。
3. 自由落地后稳定轮廓的下半部宽度明显大于上半部，且形变来自物理节点而非渲染缩放。
4. 任意稳定帧有向面积为正、节点顺序不变、非相邻外围骨架交点为零。
5. 外围相邻骨架有向内夹角保持在 90°～180° 的求解容差内。
6. 径向骨架排斥启用时，高冲量测试不得出现径向节点越序或穿过相邻骨架。
7. 拖动期间只对按下时选定的最高节点施力；鼠标位置不得直接写入节点或核心 Transform。
8. A/D 对核心产生有界水平加速度；A+D 抵消；S 产生向下力和可恢复压缩。
9. W 只在接地时产生一次跳跃冲量，按住不逐帧叠加，空中不能重复起跳。
10. 帽子和眼睛跟随合法、帽子零碰撞且绘制层最高。
11. 参数越界被托管层拒绝；实时参数下一步生效；结构参数只触发一次显式重建。
12. 数量保持一只，隐藏的测试参与者不存在活动 body 或 contact。
13. native 异常连续步进不自动回出生点，而是保持最后合法帧。

### 12.2 实时行为

- 正式 `Wallpaper` 和 `Window` 均只出现一只团子，无独立预览窗口。
- 从空中落地时能够看出下部先接触、向两侧变宽、顶部相对收窄、回弹后收束。
- 骨架模式下没有 Z 字形折返、节点换序、外围自交或高频闪烁。
- 鼠标拖动表现为从最高节点拉起，身体其余部分有延迟和形变；松手后自然下落。
- A/D 具有受力加速和惯性，S 能贴地压缩，W 是清晰的一次性起跳而非脚本抛物线。
- 失焦、切换宿主和丢失鼠标捕获后不残留输入。
- 连续运行至少 10 分钟不自动重生、不无限加速、不持续抖动，CPU 和工作集无明显无界增长。

### 12.3 人工验收

用户重点确认：

1. 静止外形仍像团子，而不是规则球或僵硬多边形。
2. 落地的下宽上窄形变自然、柔软但不过度塌陷。
3. 鼠标拉动、A/D、S、W 的力量感和响应速度合适。
4. 眼睛和帽子的延迟、角度与遮挡关系自然。
5. 参数面板足以快速定位满意手感，骨架显示能明确解释形变来源。

## 13. 失败与停止条件

### 顶部柔软度试验（2026-09-07，尚未通过验收）

以下保留联合约束实施前的失败证据。后续经用户批准已按[角度硬约束修订方案](phase-1-dango-angle-constraint-design.md)实施并通过自动门禁，顶部开启对照测试随之通过，但默认仍关闭，桌面人工验收待完成。当前默认以[用户满意参数基线](phase-1-dango-parameter-baseline.md)为准，不以本节历史候选数值为准。

已按用户批准方案接入 `TopSoftness`（0～1，候选默认 0.5）：按当前世界方向的上半部权重 `max(0, dy/length)^2`，把径向压缩下限最多降低 18.75%，抗压刚度最多降低 60%；静止长度和拉伸上限保持不变。该参数放在“结构与伸缩”中并实时生效。native 配置增加字段，ABI 升为 11。

测试发现顶部压低与外围凸性未能同时通过。将力更新细分到 240Hz 后，关闭/开启时顶部局部高度约 0.7842/0.7850，未达降低 0.005 的对照目标，拖动前还测得约 181.61°的内角。细分步进试验已撤除，候选源码保留用于后续设计，不替换正在运行的旧 Release。需要重新评估顶部所受向外拉力与向内压力，不能仅靠放宽压缩限制宣称尖头解决。

后续经用户批准，增加与同一柔软度参数联动的径向向内压力：单节点力为 `0.3 × TopSoftness × max(0, dy/length)^2 × clearance`，单位沿用 native 力单位；距压缩下限不足静止长度的 10% 时线性减弱，到下限归零。核心承受所有节点力的等量反作用，静止长度不变，柔软度为零时关闭此力。本次只增加 native 力及测试、更新构建元数据，没有改动宿主或输入行为。

验证结果：native Release 编译成功；Debug 单体物理定向测试 10 项中 6 通过、4 失败。关闭/开启时顶部局部高度为 0.786717/0.808605（反而升高）；落地上下宽度关系未通过；强拖动第 0 帧最大内角约 248.264°；局部相邻角差约 52.450°，超过 35°门槛。落地和强拖动测试补充 `IsRestartBlocked` 检查，防止冻结被误报成稳定；这些检查未触发。未降低任何形状验收阈值。

此候选保留为未通过的实验源码，不替换正式桌面 Release，不声称完成尖头修复。当前外围角度实现是纠正力，不是可保证 90°～180° 的硬约束；需要另行评审约束求解方式后再继续，不能用持续叠加力掩盖这个差距。全量门禁和新候选桌面实时、人工验收未执行。

出现以下任一情况时不得继续叠加调参掩盖问题：

- 两组等长结构无法在落地后稳定形成下宽上窄；
- 需要取消 90° 下限或允许外围自交才能保持轮廓；
- 排斥力导致持续注入能量、核心附近爆炸或明显高频抖动；
- 物理视觉位置与鼠标命中区域无法保持一致；
- 必须改写 Core、服务端权威或提前实现团子间碰撞才能继续。

此时应停止当前增量，报告冲突证据并回到设计评审。
