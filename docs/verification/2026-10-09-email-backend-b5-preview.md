# B5 交互候选局部验证

日期：2026-10-09。范围是[交互候选](../planning/2026-10-09-backend-b5-interaction-proposal.md)的虚构数据可点击预览，正式 Windows 接入等待交互确认。本次没有修改应用或服务端代码，也没有运行数据库、正式服务或 SMTP。

## 检查方式与证据范围

用 Codex 浏览器操作沙箱内预览，逐次检查可见结果及必要的 DOM 边界。源码为会话预览 `dango-account-rooms.html`，SHA256 为 `DC6270C35CC7AA24BD67A62E1A82FF431BB283B2FC1FC9327D4035A2B8D9ED56`；临时渲染包装位于忽略目录 `artifacts/backend-b5/`。交互状态只演示界面，不构成正式接口或持久状态证据。

| 局部检查 | 实际结果 |
|---|---|
| 登录与配置选择 | 登录后进入显式选择；配置冲突阻止采用，重新读取后再选择；保存失败保留选择页；未知结果要求先检查保存结果 |
| 外观保留 | 采用奶油色账号配置后退出并重新登录，本机来源仍显示奶油色；再次采用本机配置不会重置为白色 |
| 注册输入 | 空登录密码、空邀请、短注册密码不能进入成功页；两次密码不同显示错误并清空密码；符合长度且一致时才显示虚构注册完成 |
| 邮件状态 | 未验证时只有刷新／重发冷却操作，没有完成注册按钮；发送失败与验证完成分别显示 |
| 房间管理 | 虚构公共房创建、编辑冲突保留草稿、刷新后修改、解散与恢复路径可操作；无本次签发码时只提供生成新码 |
| 公共码与离房 | 解析页只显示容量；满员在确认进入时失败；准入后仍等待窗口就绪；公共房离房取消返回当前连接页 |
| 断服反例 | 确认页面切断服后，解散、重置访问码、就绪检查、正式离房均被阻止；访问码未被签发，离房失败仍保留上次归属 |
| 本地入口与焦点 | 断服仍可打开本地入口示意；本地面板打开时背景与导航具有 inert 属性；Tab 从末项回到首项，Escape 回到门廊并恢复在线入口焦点 |
| 布局边界 | 两种布局可切换；1024 宽检查右侧布局；320 宽浏览器包装内实际可用宽约 273，配置、登录及建房面板约 252，面板 scrollWidth 不超过边界，配置选项纵向排列 |
| 运行错误 | 最终浏览器 error 日志为空；临时 viewport 已恢复 |

独立只读审查发现两类错误：断服时部分确认操作仍改变虚构状态，以及注册未核对密码长度和两次一致性。已修正并用上表反例复验。预览源码没有网络调用、浏览器存储或凭据日志；widgetState 仅保存布局、页面、场景与配置来源元数据，输入凭据不写入其中。

## 五项质量与未验证项

- 正确性：局部输入与状态反例已检查；完整服务端规范化、异常响应映射和 Windows 输入尚未验证。
- 一致性：已检查界面冲突、未知结果和失败反馈；真实并发、请求重放、切账号旧响应隔离尚未验证。
- 安全性：原型无网络／凭据持久化边界已审查；正式 Cookie、CSRF、安全存储、逐次授权和日志脱敏尚未验证。
- 可靠性：局部保存失败、断服与焦点恢复已检查；真实磁盘写入、服务重启、场景失败补偿、备份还原尚未验证。
- 扩展性：候选保留有界目录与快照的正式实施门禁；本预览不证明资源上界、长期订阅清理或负载能力。

B5 正式客户端→API→PostgreSQL、真实多客户端、Windows 人工、SMTP 投递及用户交互确认均未验收。没有运行 .NET 构建或回归：本次只改变设计与验证文档及仓库外交互预览，不沿用 B4 测试数字声称 B5 通过。
