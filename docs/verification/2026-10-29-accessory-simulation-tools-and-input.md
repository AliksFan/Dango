# 模拟工具栏、固定细调与物理输入

日期：2026-10-29；工作区分支 `codex/accessory-editor-rig`，HEAD `c91e5f4` 上保留原有未提交修改。范围为用户本轮指定的三个 UI／输入变化及按对话约定重开本轮进程。未改默认用户库、物理力模型或保存合同。

## 需求与实现证据

1. **三个工具移到右侧专用栏。** `dynamic-preview.js` 将选挂点、平移、缩放移出右上表单，新建独立竖向 `simulation_tools`；`canvas-layout.css` 复用绘画栏的暖白、细边界、32 DIP 图标命中和8 DIP间距。中央原生视口让出整栏，栏随右侧参数收起后移；返回绘画时隐藏。原选挂点虚影、点击／Esc和再次点击退出工具的语义保留。
2. **形变细调始终展开。** `index.html` 将 details／summary 改为普通 section／标题，删除收起和基础／细调翻页逻辑。五项骨架值在编辑和模拟模式同时显示；短窗口采用横向紧凑行，右上模拟参数高度调整为200 DIP，为下方留足空间。旧绘画 SVG 在模拟时隐藏，防止标签露在原生视口边缘。
3. **自动焦点与正式身体输入。** `AccessorySimulationView` 绑定原有 `HomeBodyPreviewSession`，复用 WASD、空格跳跃和键盘／拖动混合输入。Window 在进入、激活和普通按钮操作后恢复物理空间焦点；真正执行前重新核对自身 HWND 为前台、窗口活动／可见／启用、非最小化、模拟有效且无参数／菜单占用。没有全局键盘钩子或 Activate 操作。
4. **输入与释放边界。** `simulation-input.js` 通过有身份且只允许0/1的 `simulation-focus` 消息报告必要输入占用；参数、下拉菜单及弹窗保留操作，数字 Enter 完成后归还焦点，退出／失活／隐藏／关闭清按键与拖动。重新取得焦点抑制此前按住的键。Enter 后 blur 可能再次触发 change，表单按相同待提交参数去重，避免重复撤销动作；错误回传后仍可重试。

## 实际验证

- 原生相关 **31项通过**：15项 SimulationView＋既有 HomeBodyPreviewSession、15项 UnifiedEditorSession、1项真实离屏 Window／WebView2 集成。覆盖正式 native 输入、实体位置前进、W/S命令、空格重复不再跳、键盘＋拖动、释放抑制、切模式停止、故障清输入及原有草稿事务。
- 离屏集成不激活窗口，不发送 OS 输入；用真实 WebView→native bridge 验证焦点占用／释放门禁，用本地 WPF D down/up 事件验证正式 owner 输入1→0。默认非前台资格不能聚焦；测试资格与恢复意图的注入仅用于避免测试占屏。
- 浏览器 **26项通过**：独立右侧竖栏、视口避让、面板收起、最小尺寸、五项参数固定展开、参数仍能编辑、输入焦点占用与 Enter／菜单关闭释放、统一历史及原画布回归。最终隐藏绘画 SVG 并补强普通按钮点击后的焦点归还后，预览＋佩戴历史11项再次通过，包含“占用状态未变化仍归还焦点”的断言。独立 transport 回归通过。首轮 Enter 重复请求断言失败后定位为 blur 的第二次 change，修正后原单次提交断言保留并通过。
- Web build／verify通过：精确6项资源清单与SHA256、本地CSP、依赖允许列表。最小内容区784×548的布局检查和截图用于核对图标栏、间距和参数；它不呈现原生团子，不能作为物理显示证据。物理帧及身体像素由真实离屏原生集成覆盖。
- 最终独立 Debug 构建0警告0错误；打包内6项Web资源SHA256与源manifest一致。测试构建仍有既有NU1903依赖告警，未升级依赖。`Dango.Desktop.dll` SHA256：`db6d160f038c774117730512dbce7d7b7659a32ecfa2e983ac06205ea8f9a9f3`。
