# P1-002A Dango 控制中心验证记录

> 状态：实现与自动门禁完成，待人工验收
>
> 验收对象：正式控制中心壳层、图形化 P1-002 验收入口和本地诊断，不代表桌面宿主候选已经通过

## 1. 范围

本任务实现：

- 普通 WPF 控制中心窗口，包含概览、桌面体验、实验与验收、诊断四个页面；
- 托盘菜单和双击打开同一个控制中心，关闭控制中心后继续托盘驻留；
- 第二次启动向主实例发送激活请求，不创建第二套宿主和托盘；
- 由宿主确认的显示与交互开关，失败时保留或恢复观测状态；
- 版本化 P1-002 验收定义、人工结论、备注、本地草稿和分层 Markdown 导出；
- 原子本地写入、非敏感窗口尺寸保存、隐私字段拒绝和高对比度切换；
- 原有覆盖层托盘和单实例职责迁移到统一 App Shell。

以下内容不在本任务中：WorkerW、正式动画、降低动画实现、账号、好友、房间、网络、数据库、最终宿主选择和 Phase 1 人工验收结论。

## 4. 本地数据边界

控制中心只在用户主动保存或关闭已显示窗口时使用：

- `%LOCALAPPDATA%\Dango\settings.json`：只保存控制中心宽度和高度；
- `%LOCALAPPDATA%\Dango\verification\p1-002-draft.json`：只保存版本化验收环境摘要、人工结论和用户备注。

本次自动与进程验证结束后，上述目录、设置文件和草稿文件均不存在；没有写入用户本地验收数据。

诊断、草稿和导出模型不包含用户名、窗口标题、窗口内容、桌面文件、剪贴板、原始输入、访问令牌或连接串。导出路径只在用户选择后显示给用户自己，不写入报告正文。
