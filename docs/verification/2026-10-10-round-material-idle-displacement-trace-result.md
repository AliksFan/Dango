# 圆形材料：静置水平漂移观测结果

2026-10-10。用户明确批准[被动观测方案](../planning/2026-10-10-round-material-idle-displacement-trace.md)，本轮实施隔离观测并完成实际 DLL ON/OFF 固定运行。**实际对照、最终精确账本、19 个语义反例与独立审查通过；漂移定位到材料＋Box2D 执行边界，尚未确定该边界内部的唯一根因。原漂移门槛仍失败，没有修改物理模型或恢复后续验收。**

## 已定位的执行边界

固定默认世界从初始化运行至第 6,301 帧，包括全部 100,816 小步。沿用原采样规则，第 601 帧末是第一个采样点；从此至第 6,301 帧末的静置区间包含 91,200 小步。

| 静置区间阶段 | 核心水平位移 | 17 体实际质量加权质心水平位移 |
|---|---:|---:|
| 材料＋Box2D | `-0.004094499861821532` | `-0.0030126596162236537` |
| 位置校正 | `+0.0010790773667395115` | `+0.00003207308538276163` |
| 连续性、施力前后、耗散、接触 float、cap、实际写回差额 | `0` | `0` |
| 合计 | `-0.0030154224950820208` | `-0.0029805865308408924` |

核心从 `-0.0007009438704699278` 移至 `-0.0037163663655519485`，精确合计等于原第 6,301 帧的超限跨度。表中量为物理世界坐标；公开绘制轮廓前 32 项是相对核心、加了节点半径的局部坐标，几何 centroid 没有当作物理质心。

证据将直接产生位移的边界定位在材料＋Box2D 段；后续位置校正反而向右补回一部分。该边界同时包含材料力、重力、Box2D 接触／关节／缓存及 float 积分，**不能从这份观测直接认定其中某项为唯一根因**。

耗散和接触裁定虽不直接移动位置，仍持续改变下一小步的速度。该静置区间核心的有符号速度变化累计分别为：材料＋Box2D `+5.435772787583168`、耗散 `+2.5080507656493864`、接触 double `-7.943823553232554`；它们相互抵消，不是最终速度或位移。独立账本保留全部 17 体、double→float 差额及质量加权动量，不能因位置贡献为零就排除速度路径的作用。

全部 101,283 个实际模式事件中，98,472 次有效选择的 α 都为零；另外 2,811 次是真正满秩、未执行选择，分开统计。静置区间 91,200 次均为 9 维／秩 8／一维零空间，α=0。首次非零 α 未出现；这不免除特解反力及后续速度路径的影响。

## 观测实现和实际验证

新增私有 `DANGO_MATERIAL_IDLE_TRACE` 构建，关闭观测时仍保留每小步物理整数成本和每帧公开输出；开启时流式复制 8 个位置／float 速度边界、接触 double 速度、实际质量、receipt 和全部已执行模式事件。阶段可用性在实际赋值点记录，不用 `phase=4` 推定块构建或反力选择完成。

- `/W4 /WX` Release 构建通过；默认无宏模块受影响兼容 **11/11**，含认可模块 900 帧逐位对照。历史三体模块缺失的其它 6 项仍未验证。
- 实际 DLL ON/OFF 各完成 6,301 帧，所有世界操作经 `GetProcAddress`，没有源码等效世界 fallback。**264,642 个公开 float 位型、1,209,792 个物理成本整数逐值一致**；共 96 个原采样点，两者首超限都为第 6,301 帧。
- 布局 72 bytes、配置 164 bytes、原诊断 87,016 bytes，匹配当前私有宏和源；布局及诊断 canary 完好。保留全部 256 个固定窗口小步；没有非零 α 或原生故障，因此额外窗口未触发。
- 原始 ON 证据 `360,239,784` bytes，OFF `14,119,560` bytes；两份 JSON 各 `177,095` bytes。锁定的保守最坏上限 `499,083,504` bytes，低于 512 MiB；反例在小夹具或稀疏内存副本中运行，没有复制大型证据。
- 最终精确复算涵盖全期及静置区间的逐体位置／速度、质量加权质心／动量，并重建原首次超限。C 汇总与精确账本最大差为 **0**；按累计次数和数值尺度推导的最大误差界约 `4.54426e-11`，不是物理门槛。实际 float 端点到 double 的减法均精确。
- 实际测试世界已销毁，DLL 已卸载；按本轮构建目录过滤的原生进程残留为 0。没有服务、端口或持久业务数据操作。

## 独立审查与复核工具修正

C 钩子及实际读取器经独立审查，确认原求解调用和短路顺序保持、写回差额不重复计入候选校正、每个实际模式均记录、错误或写入失败停止，以及公共销毁路径关闭文件和清理 TLS。实际源码／DLL／工具／受保护模块的 13 项运行前哈希与运行后相同。

初次 Python 全期复核通过后，独立审查用纯内存夹具证明两类错误记录仍可能通过：位置-only 校正误抄速度、健康一维零空间模式将已选择的 α 抹成缺失。它们是复核工具遗漏，不是物理实现失败；初次日志／JSON 保留。

最终工具增加 34 个位置校正前后速度原位一致检查，并严格核对健康分解／维度／零空间／选择状态合同。有效夹具和 19 个语义反例通过，覆盖缺失阶段、漏小步、重复校正、错帧／模式／质量、错公开 float、错误窗口、删除阶段累计、错速度和抹掉真实选择等；反例维持合法二进制格式，不靠校验和错误拒绝。独立审查重新执行原两项漏洞夹具，均被新门禁拒绝；随后根任务对原完整实际证据重跑最终工具，退出 0、`allChecksPassed=true`。实际世界仅执行原 ON/OFF 两次，没有因复核工具修正重跑物理或改变门槛。
