## 1. 范围与结论

本检查点在无 WPF 环境中建立真实 Box2D 单团子软体环：一个运动学核心、12/16 个动态外圈节点、相邻与径向距离弹簧、静态接地代理、2/4 子步、休眠以及异常熔断。native bridge 使用 opaque handle 管理 world/body/joint，.NET 只接收局部轮廓和受控指标，不接收或持有 Box2D 类型。

四个候选均通过相同的长时空闲、单次落地冲量、拖动和 100 ms 时间尖峰序列。默认暂选 `12 节点 × 2 子步`：它是所有通过候选中确定性求解工作量最低的一组；16 节点是否具有足以抵偿成本的轮廓观感，留到 P2D-005 可视预审，不凭本轮无渲染测试决定。

本轮未接入 `StreamGeometry`、WPF、WorkerW 或真实桌面动画，也未开始 P2D-005。

## 2. 物理模型与硬限制

| 项目 | 当前值/行为 |
|---|---|
| 核心 | 运动学 body；目标变化每步最多 `0.015` 局部单位，防止权威位置跳变直接撕裂轮廓 |
| 外圈 | 12 或 16 个 dynamic circle；只与接地代理碰撞，不自碰撞 |
| 弹簧 | 核心到节点径向弹簧 + 相邻节点周长弹簧 |
| 接地代理 | 静态矩形，仅参与表现碰撞，不决定 Core 落点 |
| 固定步长 | 正数且不超过 100 ms；Box2D 2 或 4 子步 |
| 轮廓方向 | signed area 必须至少 `0.45`，否则 `SimulationUnstable` fallback |
| 最大半径 | `0.98` 局部单位 |
| 最大质心偏移 | `0.25` 局部单位 |
| 最大节点速度 | `8.0` |
| 能量代理 | 节点速度平方和不超过 `节点数 × 64` |
| 重放容差 | 同一构建、配置与输入逐点差异不超过 `0.00001` |

任一采样出现非有限数、翻面/面积不足、半径越界、质心越界或速度/能量超限时，native 返回固定错误码；adapter 释放实例并切到 authored fallback，不修改 Core。

## 3. 先失败验收与修正

实现前新增稳定性测试，首次因 `SoftBodyConfiguration` 等契约不存在产生 `CS0246`，退出码 1。

初版实现后，19 项相关测试中 18 项通过；统一压力序列在拖动开始时触发 native `-24`（轮廓半径超过 `0.98`）。保留半径门禁不变，根因是表现核心在单帧内直接跳到新权威位置。修正为 adapter 内部的有界核心跟随，每步最多移动 `0.015` 局部单位；它只影响表现核心，不写回输入或 Core。修正后四候选和极端 100 倍宽度权威跳变测试均通过。

## 4. 四候选统一输入结果

每组依次执行 3,600 步空闲、600 步落地、600 步拖动和一次 100 ms 尖峰；下表为全序列极值。计时只保留为诊断，受测试顺序和机器调度影响，不用于选择。

| 节点 | 子步 | 最小面积 | 最大速度 | 最大半径 | 最大质心偏移 | 最大能量代理 |

| 12 | 2 | 1.770190 | 1.107037 | 0.828380 | 0.067877 | 11.996379 |
| 12 | 4 | 1.770148 | 1.148897 | 0.828712 | 0.066286 | 12.958902 |

四组均保持有限、正向、有界，并在空闲序列末进入睡眠。相同输入重放逐点通过 `0.00001` 容差。
