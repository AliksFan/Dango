# 配饰统一编辑器与骨架 E1 原生合同记录

日期：2026-10-23。状态：原生工程、素材、编辑草稿与 Schema 2 保存合同已实施；网页工程适配开始，正式统一编辑窗口及双运行链接线尚未完成，未作产品或人工验收。

范围依据：[设计](../planning/2026-10-23-accessory-editor-and-rig-design.md) C2／C5、[实施计划](../planning/2026-10-23-accessory-editor-and-rig-implementation-plan.md) E1。实现位于 `codex/accessory-editor-rig`，不修改主工作区的用户 `AGENTS.md`，不合并、推送、安装或操作用户配饰库。

## 已实施合同

- 静态 PNG／JPEG 按文件头读入，允许不透明或空白创作源；解码前验证大小和尺寸，执行 EXIF 方向变换，再去除元数据与原 DPI。工作素材有界缩小一次，最终透明 PNG 严格校验且不静默缩图；源文件不变。
- Dango 版本化工程保留 image／brush／text／空图层、受控内部图片、画布、输出引用与修订。列表和图片数据防御复制；未知字段、重复字段、外部引用和超预算结构拒绝。全部嵌入 PNG 的尺寸与累计像素先于任何像素解码预检。
- 条目保存刚性／单链模式、全量共同参数及静止 rig；休眠链同样验证数值、根部一致与蒙皮可绑定性，不保存速度或当前变形。
- 选图成功即建立“待完成”外层草稿。模态编辑以会话、代际、稳定条目和修订票据确认，工程／PNG／参数一次回传；模态取消保留进入前草稿，外层取消撤销未应用项。待完成项禁止整套应用，复制后编辑互不污染。
- 独立 `accessories-v2.json` 是唯一提交点。图片和工程先不可变写入并回读验证，随后原子替换清单；保存返回本次提交文本的精确散列，外部后续写入不能变成本会话的已知基线。结果不确定时须散列与配置都一致才确认成功。
- Schema 1 原文件只识别并提示未载入；未来／坏的新清单写保护，已保存损坏资产继续隔离保留引用。失败保留旧清单与可重试草稿；先写成功但未提交的资产不自动清理。永久删除仅提交已保存快照减去目标，不夹带其它草稿。

## 实际验证与修复

Release 无窗口选择集 `e1-final.trx` 为 **87／87 通过**；既有 `AccessoryStorageTests` 迁移 Schema 2 后，在 `storage-browser-interchange.trx` 中另有 **16／16 通过**。E1 合计 103 项，0 失败、0 跳过。证据在忽略的 `artifacts/accessory-editor-rig-e1-evidence/`。E2 工程适配与隐藏浏览器最终另有 9 项通过，不计入本表。

独立复核关闭了三处问题：保存后重新读取外部修订造成丢更新基线；累计图层像素检查晚于解码；合法中心线不一定具有可用蒙皮绑定。均有针对性反例。

另一个复核发现是旧公开 PNG 导入入口解析 eXIf 却未旋转像素。扩展测试先复现方向 6 的预期宽 16、实际宽 24（`png-orientation-before-fix.trx`）；修复为共享方向变换并使用变换后尺寸，随后上述 87 项通过。

测试项目沿用既有 SignalR 10.0.11 的 NU1903 告警，仅本次命令使用 `WarningsNotAsErrors=NU1903` 执行；未更改仓库警告策略或无关依赖。

## 未完成与验证边界

原生工程与 miniPaint 的字段、图层 ID、资产 ID、透明度单位不同，E2 通过显式适配转换。`browser-interchange-final.trx` 的 7 项适配器检查与 2 项隐藏 WebView 四种图层往返通过，涵盖唯一与相同排序值。独立复核发现同排序值在网页绘制与原生稳定升序排列之间遮盖顺序不同；先用真实浏览器复现重开 PNG 改变（`layer-order-before-fix.trx`），再按浏览器稳定降序后反向绘制的顺序修复，最终 9 项通过。此结果验证可编辑图层与合成像素往返，仍不构成正式编辑窗口接线。

正式窗口、图片变换与连接点／链坐标的一致撤销、真实输入、运行时试摆、双 owner 正式接线和旧消费者退役仍依 E2–E5 进行。E1 与本次 E2 选择集共覆盖 112 项，不能推定整个桌面套件或产品验收已通过。

既有存储测试原运行 16 项中 6 项因旧清单路径或旧字段夹具失败，迁移新合同后 16 项通过，通用失败、锁、缓存、预算、线程、隐私和运行态排除断言保留。迁移前仅有控制台结果，没有生成 TRX；不把整个桌面测试集标记通过。旧临时参数字段与 `ImportPng` API 为后续统一替换点保留，不提供 Schema 1 柔性兼容。

系统性性能优化放在 E4／E5 真实场景接通后；当前资源边界、正确性与数据安全仍作为前置。未运行可见窗口、全局输入或人工验收；隐藏控制器结束后未发现本轮 profile 的 WebView2 进程残留。本轮仅有隔离虚构素材与测试资产残留，没有新增服务、端口或用户库迁移。
