# DIY 配饰第五轮：更宽材料端点、翻折与两个行程上限

本轮依据用户“柔软度的上限再高，连接强度的下限再低，大胆搞就行”“翻折……作为一个可选的选项”“最高允许形变量”“连接的最大行程也要加上”实施。范围及理由见[设计第 14 节](../planning/2026-10-07-accessory-diy-design.md#14-更宽材料端点可选翻折与用户形变连接行程上限)和[计划](../planning/2026-10-07-accessory-diy-plan.md)。本地候选待人工验收，延续[第四轮](2026-10-08-accessory-ui-v4.md)的输入、镜头和资源合同。

## 结果与边界

- 柔软度／连接强度仍显示 0–100；最高材料响应 gain 从 3 扩至 18，最大弯曲 .90、伸长 .75、压缩 -.35。最弱连接恢复频率从 .35 降至 .18 Hz，恢复更慢。
- “允许翻折”默认关闭。关闭时按实际旋转、应变及支点投影材料场，保留有向面积安全余量；开启时允许真正反向三角和自身重叠，按稳定网格顺序合成透明像素。
- “形变上限 %”：0–200，默认 100；限制图片各点相对同一位置及整体角度下的刚性原造型的偏移。0 保持图片刚性，不限制连接弹性及整体旋转。
- “连接行程上限 %”：0–200，默认 75；限制图片支点与身体附着点的实际径向距离。0 使支点重合；斜向移动受完整向量半径限制，边界去掉向外速度，保留切向及向内速度。
- 两个百分比均以当前配饰显示尺寸的对角线为 100%。连接强度控制弹性及恢复速度，行程控制可移动距离；中段频率映射保留，但新默认行程替代旧隐藏限制，不声称中段全部动态行为不变。
- 三项新字段随配饰应用、保存、复制、取消、复位及重载。Schema 1 缺少可选字段的旧清单取默认值，读取不重写；非法类型、范围、未知及重复字段仍保护原文件。
- 配饰不参加碰撞，不反作用于团子；材料、连接、旋转仍独立。保留第四轮普通窗口插值、W 不跳、Space 低跳、固定纵向镜头和无限水平地面。配饰间挂接和分享仍属后续范围。

五项旧像素失败的原因是夹具使用新的材料求解生成了不同几何。新增 `AccessoryMaterialV4ReferenceSolver.cs` 冻结 `5bc3215` 的原始求解，48 帧光栅对照和五种完整位图继续使用原几何与原像素摘要；没有更新 hash 放宽门禁。原 930 帧整体配饰输出相等是优化阶段的历史门禁，本轮故意改变材料，不将其作为当前相等结论；测试和历史录制保留。真实 bare／dressed native 对照扩为翻折关／开，每种 550 步，仍要求 native、身体、眼帽、步态和计数相同。

混合朝向接缝原实现按世界 top-left 规则归属，正反两面位于共享边同侧时会得到透明裂线。新 `FoldCoverage` 按原材料索引分配共享边及顶点的唯一 owner，退化三角不抢占归属；重叠内部仍按 source-over 合成。门禁明确区分接缝 alpha 128 和真实重叠 alpha 192，并覆盖退化面和像素中心共享顶点。

第二次功能中，行程夹具每 .1 秒来回瞬移产生高频正负力，.18 Hz 连接的真实慢响应会将其抵消，不能检验达到行程边界。改为持续对角加速度，保留实际径向上限、到达至少 95% 上限、图片形状及角度独立的全部断言；增加球面精确边界的外向／切向／向内速度检查。原失败保留。

第二次宽回归的呈现失败发生在 `current.X > previous.X` 前置条件，未产生预期向右 native 位移。独立呈现组及最终完整相关组均复测通过，尚不足以解释原失败；补充原位置、Home／Runtime 意图及对齐状态诊断，没有放宽断言或改产品镜头代码。第四轮持续按键性能红灯、人工视觉抖动和其他 DPI 未验证矩阵继续保留。

364 项包含参数／保存、真实 WPF 编辑、图片资源、native 低跳／无限水平、无碰撞对照、零步／多步呈现、原像素摘要、首页接地布局以及既有眼睛／帽子／步态优化对照。性能、持续按键测量和故意改变材料后不适用的完整配饰轨迹等价不计入本轮通过数；进程组单独验证。随后真实进程补查发现辅助操作的翻折开关未进入草稿，因此该轮通过不能证明辅助操作保存已通过。初次新增测试格式差异仅修正排版，最终静态结果随最终代码记录。
