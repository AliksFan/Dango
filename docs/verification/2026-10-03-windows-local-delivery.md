## 诊断脚本失败与修复

原始失败全部保留，产品包和测试基线未修改：

- 最初额外备份检查在任何写入前拒绝 OneDrive Desktop 的 Microsoft Cloud_6 标记（`0x9000601a`）；快捷方式叶文件本身普通且目标精确匹配。仅本机诊断允许读取此类已有 Cloud 祖先，安装根、真实设置、evidence 与快捷方式叶文件仍严格拒绝重解析点。产品安装器保护未放宽。
- 首次 StageOnly 实际使用既有安装包装脚本，两个快捷方式前后 SHA 相同。审查指出已有链接并发消失时包装器仍有新建路径；之后诊断 helper 改为直接 `Install-DangoPackage -StageOnly`，避免此路径，没有重跑一次性迁移。
- 首次新 UI 脚本因 PS5.1 解码 UTF-8 无 BOM 中的非 ASCII 字面量而在启动前解析失败；改用 ASCII Unicode 转义，不修改产品。
- `b-window-first-02.json` 为 1 pass / 1 fail：把所属 `Popup` 内的 `ToolTip` 误算为桌面宿主。精确 PID 32344 正常退出后，修正检测并完整冷启动重跑通过；未改写原失败。
- `a-window-01.json` 为 4 pass / 1 fail：确认正常退出后，UIAutomation 读取已消失的 HWND。原记录当时仍有 PID 3756，随后正常退出；不推定该轮 ExitCode。改用精确 PID/class/title 的原生退出提示检查，完整重跑实际 ExitCode 0。
