# 普通房壁纸移除验证

日期：2026-10-08。任务分支：`codex/ordinary-room-window-only`，基线 `1c47930`。用户批准普通房只保留独立窗口，要求完整删除专用代码，并授权在分支中开始。范围见[实施计划](../planning/2026-10-08-ordinary-room-window-only-plan.md)。代码移除及隔离 Release 构建完成；受影响回归仍有一项桌宠失败，人工验收未完成。

## 已实现范围

- 删除普通房壁纸宿主、壁纸菜单窗、玩法／滚轮输入桥、资格 policy、普通房独有的桌面前台／全屏扫描、Shell 焦点恢复和诊断查询。
- 删除普通房窗口／托盘“显示方式”、回调／事件、`Wallpaper` 房间状态和应用切换、隐藏、恢复、失败与释放中的对应分支；移除失去调用者的菜单协调方法和无有效赋值的菜单交接字段。
- 桌宠仍需的鼠标 Hook、输入样本和旧 WorkerW 图标查询 helper 提取到仍在使用的模块；窗口前台判定和桌宠壁纸定位保留。房间物理、场景、外观、镜头、滚轮累计和唯一 owner 保持。
- 删除普通房壁纸专用测试；迁移共享菜单合同，外观链路改为窗口 → 门廊 → 桌宠双表面 → 门廊 → 首页。桌宠和既有基础桌面设置不增加兼容层或配置迁移。
