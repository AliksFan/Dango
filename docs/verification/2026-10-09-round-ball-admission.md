## 首轮失败与定位

r1 数学／几何入口运行 906 个场景、10135 项检查，35 项失败。全部来自测试将接触点速度雅可比 `+Jᵀn` 直接与球到团子间距的导数比较；固定球心时，间距对团子自由度的导数为 `−Jᵀn`。实测与独立中心／单侧差分符号相反、大小在原容差内。测试已按该数学约定修正，未改算法或误差门槛；后续完整批次需实际重跑，不能据定位推定通过。

原合法 rig 的径向约束与节点外扩使显示归一化分支不可达。归一化及边界因此使用 test-only 17 点强形变几何夹具，经同一轮廓函数验证，独立稠密 oracle 与有限差分门槛不变。这些夹具不代表稳定可玩姿态；正常 rig 场景保留原约束。

## 完整合同与边界反例批次

第二轮完整入口运行 1026 个场景、217100 项检查，0 失败。后续独立审查补充双步长切向材料雅可比差分、真实冲量时刻的高速到达证据、三方夹球，以及可恢复出生状态与旧能力交叉的边界用例。

`round-ball-boundaries-red-r1` 从冻结源码快照构建，1030 个场景、220386 项检查，13 失败。实际复现：清除宽界会遗落外侧真休眠球；球创建错误使用原点地面范围；当前无重叠地创建球后，Reset 的团子出生姿态与球重叠，实际 gap 为 `−.34749642059218344`，超出 `−1/30` 门槛。

修复仅新增球场景的预检及元数据：地面读取真实 native ground 位置；保存只读团子出生节点；球创建同时检查当前与共同出生几何；球激活时，set／clear 校验当前与双方出生状态，非法变更原子拒绝；Reset 发布前验证真实几何和边界。移除球后平台 Reset 继续使用原平台解算／刷新／快照分支。未改变团子参数、出生位置或旧无球 Translate 的 anchors 规则。既用球的 world 仍明确拒绝整体横移，窗口使用固定场景；切换场景新建 world。

平移地面“有效创建”夹具同时要求共同出生状态合法：旧 Translate 保留原 reset anchors，平移后应先移除旧团子并在真实地面重新 Add，才建立有效新球。另有独立用例要求保留旧出生位置、无法一起 Reset 的场景原子拒绝。这是有效初态前提澄清，地面、接触、睡眠及误差门槛未降低。

## 最终准入结论

`round-ball-final-admission-r1` 冻结完整源码运行 1037 个场景、244495 项检查，0 失败。新增真实自由飞行 `vx=0／ω=3` 以及 μ=0 滑动中的角度独立性检查；旋转不由水平位移推算。七种错误路径只进入独立合同 exe，正常 module 固定变体 0；没有生产故障或任意初速入口。

额外错误变体成功运行并退出 1：单次先法后切 267 失败（耦合冲量及法向残差），伪滚动 300 失败（真实无摩擦滑动与自由飞行角度），伪休眠 1801 失败（native 实际积分计数）。四个原指定反例结果保留；最终正常 module 哈希与绿候选相同，仍为 `4C7F94B507BD80A87B7FB518880DA31EEDFF930E931CADD502119AFC64CB3332`。

最终原路径 64／64 通过，0 跳过；平台 native 合同 0 失败；1／2／3 团子各 900 步完整帧与已接受 r3 零容差完全相同。纯数据 probe 的 70／70 自检及 58／58 真实旧帧投影保持。正式 DLL 哈希再次相同。每个构建的 source snapshot、逐文件 SHA、命令、退出码、正常／错误 exe 与 module 哈希均保存在独立忽略目录。

准入只证明冻结范围内的算法、合同与保留性。继续按窗口计划实施可选 ABI、托管不变帧与独立 WPF 场景；真实 HWND、实际 s<1、十分钟新候选观察和人工手感不能由上述离屏／native 结果推定通过。未合并 main、推送、安装、替换正式 DLL 或部署。
