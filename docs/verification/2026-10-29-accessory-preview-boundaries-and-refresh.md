# 模拟边界、刷新与后台暂停

日期：2026-10-29；`codex/accessory-editor-rig`，HEAD `c91e5f4` 上的既有工作区。范围为用户指定的左侧模拟工具栏、刷新团子、独立配饰编辑期间暂停控制中心，以及走到预览边缘后卡住的修复。保留已有未提交修改和独立虚构验收库，不改默认用户库。

## 实现与根因

- `dynamic-preview.js`／`canvas-layout.css` 将模拟工具栏移至左侧，保留选挂点、平移、缩放并增加刷新；中央原生视口避让左栏和右侧参数。刷新是普通动作，不成为另一个选中工具，也不改图像／佩戴历史。
- 原问题通过真实 native 复现：640×480 预览持续向右行走151 tick，CoreX约1.692828，返回 `-605/site14`，owner停止。原 `SetBounds` 定义越界保护，未实现侧墙碰撞，因此正常走到可视边缘也触发故障。
- 新可选 `dango_belt_set_solid_walls` 仅由模拟场景显式启用，使用真实位置投影及耦合的法向／Coulomb接触冲量；越界、形状和速度保护保留。SPD投影度量从room已有算法提取共用，room dispatch和默认guard-only路径不变，capabilities仍为127，旧加载身份不放宽。侧墙接触补齐动量、角动量与能量诊断。缩窗时对真实身体状态进行经验证的共同平移，而非仅夹显示坐标。
- `AccessorySimulationView.RefreshBodyAsync`、原生session／runtime接线复用同一owner，重建初始物理姿态、清输入和摆动，保留素材、骨架、佩戴值及相机。重复刷新合并，失败owner可恢复，重建保留侧墙模式，退出后的异步刷新不能重新激活；真实reset首帧立即消费，不额外推进物理。Window通过既有身份白名单调用，失败不发成功状态。
- `AccessoryEditorPanel` 在独立窗口打开／关闭时成对通知；Home复用原有可见性、暂停和清输入路径。绘画及模拟期间，后方控制中心均不步进；取消、异常或确认退出后按当前页面资格恢复。隐藏／设置页不误恢复，迟到configure也不恢复被暂停owner。外层换装页自身的可视预览继续保留。
