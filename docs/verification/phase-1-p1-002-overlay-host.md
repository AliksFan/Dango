## 3. 启动

从仓库根执行：

```powershell
dotnet build .\Dango.slnx -c Release
dotnet run --project .\src\Dango.Desktop\Dango.Desktop.csproj -c Release --no-build
```

启动后应看到静态占位团子与悬浮岛，控制中心未打开时任务栏不出现普通应用按钮，通知区域出现 `Dango 控制中心` 图标。第二次启动同一程序应激活已有控制中心后退出，不创建第二个覆盖层或托盘。
