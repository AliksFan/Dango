## 1. 范围

本记录只验证静态占位团子和悬浮岛的覆盖层宿主：透明区域穿透、显式交互区域命中、焦点、拖动捕获与取消、托盘显示/隐藏、诊断和安全退出。

以下内容不在本次验收中：WorkerW/Shell、正式动画、爬岛/落地规则、账号、网络、房间、同步、数据库和正式美术。

## 3. 启动

从仓库根执行：

```powershell
dotnet build .\Dango.slnx -c Release
dotnet run --project .\src\Dango.Desktop\Dango.Desktop.csproj -c Release --no-build
```

启动后应看到静态占位团子与悬浮岛，任务栏不出现普通应用按钮，通知区域出现 `Dango P1-002 覆盖层` 图标。第二次启动同一程序应立即退出，不创建第二个覆盖层。

## 6. 结论

- 自动门禁：占位资产校验通过；Release 构建 0 警告/0 错误；真实发现并执行 32 项测试（Core 19、Desktop 13），全部通过；`win-x64` self-contained 发布成功，`--smoke-test` 退出码 0
- 真实 Windows 行为：默认非任务栏覆盖层进程已在 Windows 11 Build 26100 启动并保持响应，随后停止；可见性、穿透、命中、焦点、拖动、托盘和 DPI 结果按用户要求留待人工验收，因此不记为通过
- 人工体验：P1-002 只验宿主干扰和输入边界，不验正式生命感
- 已知问题：自动测试不能证明分层窗口在真实桌面上的透明像素穿透、焦点和全屏层级；这些项目保留为人工验收缺口
- 仍运行的进程 / 端口：任务启动的 Dango 进程已停止，无 Dango 监听端口；保留 3 个 .NET SDK 可复用 MSBuild 工作进程和本地 `bin` / `obj` / `artifacts` 构建产物
- 是否允许继续 P1-003：待用户根据本记录决定

透明窗口能够显示不等于覆盖层候选通过。只有透明区域、焦点、桌面操作、拖动回收、托盘退出和两种缩放配置均有真实结果后，才能形成 P1-002 宿主结论。
