日期：2026-10-06。用户确认「按现有需求完善并验收」，暂停壁纸实现与实体测试，保留既有工作和失败证据。本记录只收尾普通房窗口；不改变桌宠房拖动或增加家具、账号、网络、持久化与多人范围。

## 已批准体验与可失败验收

| 范围 | 窗口验收目标 |
|---|---|
| 初始场景 | 纯色墙与连续地面；不可达侧区有不同材质及明确边缘；地面视觉抬高，原生碰撞高度保持。 |
| 玩法 | 窗口焦点下 A/D 移动、S 轻压、空格跳跃；普通房不发生物理拖动，Shift+左键横移产生真实抚摸反馈。 |
| 视角 | 焦点窗口场景内滚轮调整视距，保留默认视距、上下限及横向跟随；不改变物理、实体或帧 owner。 |
| Esc 菜单 | 全窗蒙版与居中菜单，暖白/棕灰风格；操作说明替代继续游戏与三档视角按钮；Esc 收起恢复场景焦点；菜单期间不接受玩法。 |
| 控制中心 | 房间内可打开；外出首页不显示团子和捏脸换装入口，显示「团子去玩拉！回来才能换衣服哦」；明确返回后恢复首页能力与已保存外观。 |
| 生命周期 | 失焦、菜单、隐藏、缩放、resize/DPI 变化取消旧手势；不补播旧输入、不出现持续移动；隐藏可恢复，返回门廊保持同实体与单 owner。 |
| 流畅度 | 检查实际窗口动作、视角与菜单操作的手感；自动测试与进程响应不代替用户体验结论。 |

壁纸已有入口暂不删除；本轮不点击、不验证，不将其视为完成交付。壁纸玩法资格、性能、抚摸与 Esc/Shell 焦点恢复待重新梳理后再继续。
