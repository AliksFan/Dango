# 捏脸右侧工具布局验证

日期：2026-10-05。用户已批准推荐分组并授权直接实现，随后要求删除左侧捏脸标题以释放空间。本次在 `codex/appearance-face-design@a3fc1c9` 的干净工作树上开始，只改首页布局、输入焦点及直接测试；不改变外观参数、保存合同、帽子或物理。

## 最终布局

- 左侧只放颜色或四个眼睛滑块；捏脸标题与整个标题行隐藏，行高为零，参数区从顶部开始。换装保留自己的标题和关闭入口。
- 右侧顶部为颜色／眼睛选择与收起按钮，中间为团子预览，下方为眨眼／睡眠比较；保存反馈、受保护文件恢复入口及默认／取消／应用固定在底部，不随参数列表滚动。
- 编辑捏脸时收起原捏脸／换装入口，退出后恢复。比较按钮采用轻背景，应用以暖色边框强调；高对比模式使用对应系统文字色。
- 横向预览按工具之间的实际空闲区域缩放。纵向为顶部预览与比较、中部滚动参数、底部保存。长错误提示按真实测量高度保留空间；进入和退出捏脸均重新计算舞台尺寸。
- 右侧工具纳入外观输入焦点边界，聚焦后 A/D/S/Space/W 不进入游戏输入。退出、换装或进入设置后，工具立即失去输入和焦点能力。
