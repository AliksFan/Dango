## 实施前冻结的验证合同

- 产品入口为 `--belt-body-review --belt-body-review-settings <owned-directory>`，目录必须有恰好三字段的虚构数据所有权标记；禁止日常／包目录和重解析点。使用实际 `ProductHomeView` 与草稿／持久化组件。普通启动和旧房间继续使用原路径。候选未接入的房间／换装编辑必须明确说明范围。
- 物理身份 `continuous-belt-v1`，标定 `C455-F-v1`；`dango_belt_product.dll` 独立产物。固定参数关闭休眠时与冻结 C455 成功状态逐字节比较。形状保护、受力、质量和既有材料门不变。
- 热更新同 native handle 和物理 tick；普通编辑保持运行 epoch 与 FIFO，完整三元组在下一合法步生效，尚未开始的请求可被更新三元组明确替代。不重建／重下落。保存绑定模型、完整三元组、配置 revision、身体 epoch 与实际显示确认。旧快照不覆盖滑块草稿。
- 取消／隐藏／设置切页／关闭作生命周期屏障，输入及旧快照作废计数；有限在途调用交还 owner 后恢复／关闭。恢复期间保存仍受阻，失败锁存并可显式恢复。
- 实时性能测量使用 Release、实际产品窗口、同一机器、60Hz 显示回调、默认与 120/100/0 负载，保留正式眼睛和配饰。先测记录后判断，不按结果更改门：目标配置到成功 WPF 显示确认 P95 ≤150ms、松手最终配置 ≤250ms；连续显示的新物理帧目标 ≥57/s。WPF 回调和视觉树确认不等于 GPU present。实际 OS 输入另列。
- 休眠候选门在采样前冻结：至少120个连续健康接地 tick，每个内部 q 的单步变化 ≤1e-5 world、全部内部速度 ≤5e-4 world/s，核心／曲线单步变化 ≤1e-5 world，窗口参考几何位移 ≤1e-4 world；无输入占用、拖动、跳跃、取消、待处理配置或故障。任一相反键组合仍阻止休眠。门的实际可达性须自然落稳、走停、跳跃／拖压释放后分别验证。
- 睡眠保持 native q/v/contact，不调用 solver、读回或重新创建不变身体几何；owner 无轮询超时地等待事件。输入／改参／边界／取消／关闭均唤醒；判睡到等待间事件不能丢。唤醒第一成功帧目标 ≤100ms（本机正常负载），不得补算睡眠墙钟。故障不记成休眠。
- 休眠收益必须在同配置、相同外观负载、相同墙钟区间开关对照：自然落稳、走停后、拖压后分别采样，至少10秒有效静置，报告进程 CPU 时间、native 次数／耗时、线程等待、分配／GC。收益门为休眠段 native 调用减少 ≥99%、进程 CPU 时间减少 ≥30%。未测功率，不能宣称节电百分比。未达到门、误睡或破坏唤醒则默认关闭并保留失败。
- 桌面规范采用 v0.1（2026-10-10）第2～6节：暖白／棕色资源、固定保存区、三项合法范围和默认值、常驻细滚动条；最小正式／横向／纵向、真实拖动、键盘、失焦与重启分别验证。人工观感及支持 DPI 未测项明确保留。

### F6a 测量后的独立合同与明确失败

最初的绝对 v 门失败：所有九组都存在接触约束后的非零广义速度残量，默认最大约 .00278，软小胖角约 .05289，而 q／真实几何几乎不变。首次 worker 同时有把 elapsed since jump 误读成 remaining 的实现错误，已根据 native 创建／子步／跳跃源码修正；不能把首次不睡唯一归因于阈值。

测量后新立的 F6a 合同使用全部36维 v 的逐 tick 差及120tick逐分量 max-min 趋势包络，均 `<=5e-4`；q、256点曲线、核心仍保持原单步 `1e-5`／窗口 `1e-4`，支撑、完整输入、故障和120tick要求不变。允许保留稳定的接触残量，绝不清零 v。理由、每角数据、反例、睡眠字节冻结与同状态下一步对照见[Runtime／休眠合同](2026-10-19-belt-runtime-sleep-contract.md)。初始绝对门 FAIL 保留，不回写通过。

原生九角实际有7组入睡，两组大身体在60模拟秒仍有缓慢形变，正确拒睡，不能列为这两组节能通过。原生拖动后3600tick，以及实际产品走停／拖压后60秒观察均未达到严格几何门，短观察的节能目标 **FAIL**。独立延长原生观察至释放后12000tick仍拒睡（末窗q约.000230／curve约.000212，均大于1e-4）；实际产品独立延长至180秒，两工况也未入睡。旧失败不被长观察覆盖；长观察明确说明严格合同在这些状态下仍不能获得节能。F6默认关闭，后续取舍见[待确认方案](../planning/2026-10-19-belt-body-sleep-followup-options.md)，新可见位移门未实现／未批准。
