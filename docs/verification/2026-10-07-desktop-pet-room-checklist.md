## 真实 WorkerW 生命周期

专项应独立标记 `DesktopPetRealShell`；只有明确设置 `DANGO_RUN_DESKTOP_PET_REAL_SHELL=1` 才操作真实桌面。没有条件时记为未验证，不以虚构 WorkerW 或缓存 LastFrame 替代。专项使用隔离临时设置、明确的候选 native 模块和当前用户会话；不要停止 Explorer 或改日常安装。

| 检查 | 失败标准 | 状态 |
|---|---|---|
| 门廊 → 桌宠 | 当前代际的新身体帧尚未实际应用，来源就已隐藏；或空白目标开放输入 | 真实 WorkerW 自动通过，视觉待验 |
| 运行健康 | 没有物理推进、身体无有效面积、外观错误，或出现第二实体／第二 owner | 新物理帧／单实体／owner 自动通过，观感待验 |
| 进入失败／超时 | 控制界面及恢复入口一起丢失；或过期成功回调隐藏了已恢复来源 | 首入取消／物理不可用／隐藏恢复超时后重试自动通过 |
| 隐藏／恢复 | 隐藏改变所选房间、留下输入或 owner、继续步进；恢复复用旧 readiness | 真实 WorkerW 自动通过，保留本次 X |
| 返回门廊 | 新门廊首帧前桌宠已隐藏；返回失败后所选房间或恢复入口丢失 | 正常返回及首入取消自动通过，实际返回故障待验 |
| 普通房互斥 | 普通房窗口、壁纸和桌宠同时有活动 owner；换房生成另一个团子 | 窗口／桌宠自动通过，普通房壁纸仍搁置 |
| 显式物理恢复 | 恢复后团子复制、旧输入继续执行或边界错误 | 未验证 |
| 宿主失效 | 失效仍继续采样／运行，或失去托盘恢复入口 | 失败 timer／旧回调自动通过，Explorer 实际失效未验证 |

## 人工验收

1. 从隔离候选首页上 W 到门廊，看见「普通房／本地单人」及「桌宠房／本地单人」两个独立入口；走近桌宠门，分别用 W 和点击进入。
2. 确认桌宠只呈现团子及已有外观，没有普通房地面／场景背景。桌面图标、任务栏、其它应用鼠标及键盘操作正常。
3. 对团子点击、轻抚、Shift 手势及自身右键菜单逐项验收；打开控制中心后不出现第二只可操作团子，也不能在团子离开时打开外观编辑。
4. 团子移动及跳跃不越过本机安全区域；测试可选键盘开／关、焦点丢失、切换应用。禁止捕获全局 Esc 来返回房门。
5. 用自身菜单与托盘分别隐藏、恢复和返回门廊；反复 3 次，观察手势是否结束、画面是否空白、位置映射是否漂移及是否累积第二实体。
6. 从门廊进入普通房，再回门廊进桌宠房，确认普通房窗口原有行为和捏脸已保存外观仍有效。
7. 在当前显示器／缩放核对遮挡与边缘；其它缩放、多屏、长期运行和 Explorer 重建没有证据时保持未验证。

状态：待用户实际操作验收，不能因自动用例通过标记已验收。
