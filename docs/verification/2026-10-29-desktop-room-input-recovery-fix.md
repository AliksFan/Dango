# 桌宠候选输入失活与重试挂接失败修订

日期：2026-10-29。基线：`codex/desktop-room-single-desktop@9f85974`。状态：**R2 的 110 项后台／离屏回归通过，但用户前台反馈仍会在操作其它界面后失去输入；该版人工复验未通过。同步消息中的 COM 查询根因与 R3 修正见[后续记录](2026-10-29-desktop-room-focus-independent-input.md)。以下保留 R2 历史验证范围；未合并 main、推送或更新日常安装。**

## 用户反馈与复现

首版候选用户反馈：进入桌宠房后左键拖动和右键菜单均无反应；点击重试弹出“桌宠房间挂接失败，请返回门廊重试。请从托盘恢复房间或返回房门。”该版人工体验未通过。用户本次负责实际鼠标与 Win＋Tab 验证，代理继续仅做后台／离屏检查。

1. **输入禁用后无法恢复。** 新增真实宿主、驱动、物理帧的离屏回归，在一次鼠标 `WM_NCHITTEST` 归属采样中确定性返回不可交互。修复前复现 `Ready=True; Input=False; Suspended=False` 并一直超时；`MessageHook` 关掉输入，但宿主仍宣称就绪、没有走恢复链。这会同时阻止左右键。
2. **真实呈现后的重试准备失败。** 使用同一真实宿主、公开 COM、驱动和物理帧，按正式重试顺序停止、重新生成并重建宿主。72% 初次通过，100%／200% 在第二次进入时均复现 `GetWindowDesktopId` 首次返回空 GUID，`Attach` 立即抛出 `InvalidOperationException`。仅空像素宿主的连续重建不能覆盖这个触发条件。

复现证据包括 `tests/Dango.Desktop.Tests/TestResults/desktop-room-input-repro.trx`，以及 `artifacts/desktop-room-single-desktop/uncertain-hit-test-repro/uncertain-hit-test-repro.trx`。保留红灯，不将原 104 项后台通过当作真实鼠标验收。

## 修正

- `DesktopPetRoomHost.AllowsInteraction` 在鼠标或手势先于健康检查发现非当前桌面时，立即进入同一个 `SuspendForDesktop`：标记暂停、取消就绪回调、停止输入与物理、释放手势并隐藏。归属重新确认后恢复同一实体，等待新健康帧后才重新启用输入。
- 新建透明 anchor 后，在初始准备期最多等待 1500 ms，以公开接口每 10 ms 重新查询真实非空 GUID。等待不泵 WPF 队列，避免重入导航；不激活、不移动桌面、不把空 GUID 当成功、不缓存旧归属。COM 错误及超时仍失败清理，运行期校验不放宽。
- 准备失败保留固定阶段、异常类型和数值原生错误码，应用层将其保存到既有有界故障快照。COM 异常也进入可恢复边界。异常消息、堆栈、外部窗口、桌面标识及输入内容不写入记录。
- 为后台复现引入可替换显示几何读取边界；生产默认仍采用真实主显示器。测试显式使用不与任何显示器重叠的离屏区域，执行真实宿主／驱动／帧和自身消息资格检查，不操作全局鼠标、原生捕获、前台菜单或虚拟桌面。

## 验证

Release 测试项目构建与 `git diff --check` 通过。完整定向回归 **110/110** 通过，结果为 `tests/Dango.Desktop.Tests/TestResults/desktop-room-input-fix-full-final.trx`，包含：

- 原共享映射、背景、配饰实际像素、大小、存储与手势桥回归。
- 72%／100%／200% 的真实帧、命中资格、驱动拖动及原顺序重试。
- 一次不确定采样后的新健康帧恢复。
- 同一真实宿主连续八次重建、完整 owner 树清理。
- 失败阶段记录、异常消息不落盘及未显示窗口释放。

注册修复中曾有重复测试在“整个测试前后前台句柄必须相等”的断言失败；该观测不能区分测试激活与用户自行切换应用，未将失败改称通过或断言其原因。后台焦点门禁改用 Windows 原生进程过滤，仅监听测试进程的 `EVENT_SYSTEM_FOREGROUND`，记录自有窗口是否曾取得前台，并在结束时确认无自有前台窗口；覆盖全过程，不保存外部句柄／标题。相关生命周期与原生测试已统一使用该门禁，最终整组通过。

构建命令仍仅针对已有 NU1903 使用 `-p:WarningsNotAsErrors=NU1903`；已知 SignalR 依赖告警未修复，未改变仓库门禁。修正版使用普通产品入口独立 Release publish，位于 `artifacts/desktop-room-single-desktop/candidate-r2/`。
