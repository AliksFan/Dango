## 1. 范围与结论

本检查点建立普通 WPF 单团子调参窗口、动态纯色 `StreamGeometry` 身体、独立眼睛与帽子挂点、真实 Box2D 落地形变、无效轮廓 fallback、实时参数说明与 JSON 预设。用户导出的参数已固化为新启动和“恢复默认”的候选值；精确快照测试防止默认值静默漂移。

用户于 2026-09-03 确认当前团子表现合格。P2D-005/B5 据此完成普通 WPF 动态轮廓与落地人工预审。按照已批准的[落地调参台设计](../phase-1-soft-body-tuning-design.md)，本检查点不接 WorkerW；正式动作和桌面宿主组合留在 P2D-006，不能据本记录声称 P1-004 整体完成。

## 2. 先失败验收与缺陷修正

- 首个渲染测试因动态轮廓命名空间不存在产生 `CS0234`，随后实现轮廓校验、周期 Catmull-Rom 到 Bézier 的闭合填充几何和分层视觉。
- 调参 UI 完整性测试先因缺少 `ParameterPanel` 失败，随后补齐实时调参、重新下落、暂停、慢动作、对比、辅助线、重置和 JSON 保存/加载。
- 子步滑块曾在真实操作中闪退。Windows `.NET Runtime` 事件确认根因是把 `double` 反射赋给 `int`；新增离散参数回归测试后，节点数/子步改为合法值下拉框，并对 UI 参数错误作受控处理。
- 稳定态轻微抖动来自每帧调用 `b2DistanceJoint_SetLength` 清空累计冲量；修正为只在目标形状实际变化时更新，并为接触/离地限制增加死区。

## 3. 默认候选验证

- `SoftBodyTuningParameters` 的默认实例与用户导出值逐字段相等；JSON 往返保持相等，未知字段和越界值被拒绝。
- 全新 Release 进程启动后，UI 显示体型宽 `1.4197`、高 `1.192`、顶部圆度 `0.1766`、下半部鼓度 `0.2009`、底部平坦度 `0.1173`、常态压缩 `0.0925`、下落高度 `0.5`、撞击速度 `1.7372`、瞬间压缩 `0.273`、瞬间外扩 `0.1092`、回弹 `0.06`、稳定速度 `0.75`。
- 稳定采样指标：面积 `1.294`、宽高比 `1.204`、最低点 `-0.580`、最大速度 `0.000`、质心 `(-0.000, -0.059)`、16 节点，无 fallback。
- 自动物理验收确认空中首帧近圆，落地稳定轮廓宽高比大于 `1.12`。
