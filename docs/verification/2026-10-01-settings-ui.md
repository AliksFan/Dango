# 设置页（Settings UI）验证记录

> 状态：专项自动验证已核实；正式物理桌面实时行为与设置页人工验收待补。
>
> 日期：2026-10-01

## 本批范围

本记录覆盖产品首页壳层内的设置页：导航/返回、显示与交互、显示模式、图标层级、键盘控制、三种现有帽型、诊断可见性以及设置保存失败和重试。它不证明多人功能、正式物理桌面行为、日常安装更新或发布状态。

## 已核实的专项自动验证

已核实 `ProductSettingsPageTests` 与 `ProductControlCenterLayoutTests` 合计 **17/17** 通过，覆盖：

- 设置页在已验收壳层内打开，返回和 Escape 恢复首页/焦点；
- 宽度 320、480、940 DIP 的单列与按钮边界；宽度 320、940 DIP 的诊断展开可见性；
- 虚构宿主成功、拒绝、执行后失败，以及观察状态回写；
- 会话偏好保存、首次写入失败、失败提示、只重试写入及恢复；
- 壁纸恢复单次操作不会二次保存掩盖失败；编辑器转入设置时焦点落在可见内容；
- 选中状态、高对比度可读性及开关的读屏状态文本。

这些是针对 UI、命令边界和虚构宿主的专项证据，不是正式桌面宿主或用户体验证据。

Release 构建通过，0 警告、0 错误；`git diff --check` 通过。受影响范围回归（首页交互、产品控制中心与布局、设置页、应用宿主、设置存储/会话、命令控制器）为 **58/58**；其中应用宿主专项验证了真实帽型事件不会在同次点击中二次保存，外部帽型变更仍会延迟保存。完整 Desktop 套件最终实跑 **575 项：403 通过、172 失败**；失败日志仍能观测到旧物理 DLL 缺少 `dango_box2d_self_bodies_create` 导出。与本批修正前的一轮完整套件相比，172 个失败测试名称逐项相同；不把专项通过当作完整门禁通过，也不推断所有失败同属一个根因。

## 隔离界面实时检查

从本批 Release 产物以 `--settings-ui-review` 启动同一个 `ProductHomeView` 的设置页隔离窗口；进程有有效窗口句柄，标题为“Dango · 设置页视觉预览”，且保持响应。此入口不连接物理宿主、托盘、网络或用户设置，操作按钮保持禁用；供用户查看设置页、返回首页和滚动。它只支持布局与导航的人工验收，不能证明正式桌面设置操作。
