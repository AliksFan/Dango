## 本批范围

本记录覆盖产品首页壳层内的设置页：导航/返回、显示与交互、显示模式、图标层级、键盘控制、诊断可见性以及设置保存失败和重试。用户已决定移除设置中的外观入口；这不删除首页换装或底层既有帽型能力，它们的归属和后续验收待实际功能实现时再定。

本记录不证明多人功能、正式物理桌面行为、首页换装、日常安装更新或发布状态。

## 修订前候选的历史专项证据

移除设置中外观入口前，曾核实过下列候选证据：`ProductSettingsPageTests` 与 `ProductControlCenterLayoutTests` 合计 **17/17**；受影响范围回归 **58/58**；完整 Desktop 套件 **575 项：403 通过、172 失败**。这些数字只保留为修订前候选的历史记录，**不得**作为本次修订后的测试结果或门禁结论。

该候选曾覆盖：

- 设置页在已验收壳层内打开，返回和 Escape 恢复首页/焦点；
- 宽度 320、480、940 DIP 的单列与按钮边界；宽度 320、940 DIP 的诊断展开可见性；
- 虚构宿主成功、拒绝、执行后失败，以及观察状态回写；
- 会话偏好保存、首次写入失败、失败提示、只重试写入及恢复；
- 壁纸恢复单次操作不会二次保存掩盖失败；编辑器转入设置时焦点落在可见内容；
- 选中状态、高对比度可读性及开关的读屏状态文本。

其中涉及设置中帽型选择、帽型事件保存的旧候选断言，不是修订后设置页的有效门禁，必须删除或改写后重新执行。

在真实 Product 控制中心用 UI Automation 操作设置页，并核对隔离设置文件及窗口状态：

- 鼠标互动关闭/开启、键盘控制关闭/开启、方向键/WASD 往返，界面状态与持久化值一致；
- 键盘关闭时执行 Window → Wallpaper → Window，以及团子位于图标上/下层往返，界面状态与持久化值一致；
- Window 模式下隐藏/恢复团子，真实场景窗口的可见状态依次为可见 → 不可见 → 可见；
- 诊断可展开；返回首页后换装入口仍可见，再进入设置页未发现三个帽型按钮。
