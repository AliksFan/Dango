# 桌宠真实桌面、单一虚拟桌面与显示大小候选验证

日期：2026-10-29。分支：`codex/desktop-room-single-desktop`，基于本地 `main@425b9df`。依据：[已批准设计](../planning/2026-10-29-desktop-room-single-desktop-design.md)与[实施计划](../planning/2026-10-29-desktop-room-single-desktop-plan.md)。状态：**首版及 R2 人工反馈未通过；最新 R3 的 111 项后台／离屏回归及用户人工验收通过，代码已纳入本地 `main@5bde536`，见[R3 修订与集成记录](2026-10-29-desktop-room-focus-independent-input.md)。以下保留首版验证范围。**

用户明确本次自己测试 Win＋Tab 与实际观感，要求代理后台验证后打开候选。代理未切换虚拟桌面、未操作全局输入、未截图或记录真实桌面内容。

## 范围与实现

- 桌宠房不再创建 WorkerW／壁纸源，场景健康校验挂在唯一透明团子窗口；桌宠不绘背景、墙面或地板。普通房环境绘制保留。
- `DesktopPetVirtualDesktop` 使用公开 Windows COM 与自有普通窗口的 owner 关系核对归属；单独管理桌面暂不可见、手动隐藏和故障。切走停止物理与输入，回来重新确认健康帧；手动隐藏保留所属桌面，重试不会主动迁往另一个桌面。首帧握手超时随桌面暂停，隐藏时归属故障也进入正式恢复链。
- 设置增加 50%–200% 的桌宠大小，默认 100%；独立本机偏好原子保存，非法文件保护原件并显示真实失败／重试。投影、身体／帽子／配饰、命中与显示平移一致；不更改物理参数，不重建物理实体。必要横向回收保留原地面参考，竖直显示回收采用共同显示偏移。
- 旧壁纸故障字段、双宿主测试 fixture 及其坐标预期已迁移；保留单实体、单 owner、真实帧、像素和输入断言。

离屏绘制先确认测试区域不与任何显示器重叠，使用不激活窗口和自身渲染目标；测试要求实际新物理帧、健康帧及非空像素，未把遮挡／最小化暂停时间当作有效呈现。空像素归属检查核实原生区域为空、anchor alpha=0、无输入／手势监听及前台焦点未变；不构成跨桌面视觉验收。

测试项目的首次标准构建被已有 `Microsoft.AspNetCore.SignalR.Common 10.0.11` 的 NU1903 阻断。验证命令局部使用 `-p:WarningsNotAsErrors=NU1903` 保留该告警后完成构建；未改依赖版本或仓库门禁。桌面产品独立 Release publish 成功。该已知依赖告警仍未修复，属于本轮范围外问题。

## 问题复核与修正

后台验证实际发现并修正：EnsureHandle 时视觉源尚未挂载导致空引用；WPF HwndTarget 剥除 layered 样式；DeleteTab 移除 app-view 导致空归属；非法版本／重复字段的 InvalidDataException 未进入偏好保护分支。自审同时修复隐藏期间失效恢复、重试迁移和握手超时，以及实际配饰包络／显示偏移和物理地面参考问题。失败记录保留在本地历史 TRX，最终检查不通过放宽断言获得。

## 未验证与交付

- 未由代理执行：真实两个或更多 Windows 虚拟桌面的切换与删除、Win＋Tab／Alt＋Tab／任务栏观感、真实前台鼠标互动、不同 DPI／显示器配置、完整产品导航及用户人工体验。由用户在隔离候选中测试，不能用上述后台结果替代。
- 界面遵循规范 v0.1 第 2、4、4.1、6 节：复用暖白／棕色共同资源、现有参数滑条、百分比和必要失败文字、图标＋短文字的重试操作。桌宠表面的透明背景按批准业务规则采用；普通房主题保留。真实布局／DPI／高对比观感仍未人工验收。
- 候选位于 `artifacts/desktop-room-single-desktop/candidate/`，测试数据单独位于同批次手动测试目录，保留给用户测试；本轮不开数据库、网络服务或个人端口。所有自动测试进程及其窗口结束并释放，打开供用户测试的候选进程另行保留。
- 本轮不合并 main、不推送、不更新日常安装或删除任何已有保存数据，不标记整个桌面阶段为已验收。

人工建议路径：进入桌宠房，确认原有系统壁纸可见；切到另一个虚拟桌面再切回；分别拖动和轻抚；在设置调整大小，再测试隐藏／恢复及重新打开候选后的百分比；最后返回门廊并在另一桌面重新进入。
