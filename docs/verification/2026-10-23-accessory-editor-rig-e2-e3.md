# 配饰统一编辑器 E2／E3 实施与验证

日期：2026-10-23。分支：`codex/accessory-editor-rig`。本记录承接 [E1](2026-10-23-accessory-editor-rig-e1.md)，依据 [实施计划](../planning/2026-10-23-accessory-editor-and-rig-implementation-plan.md) 和 [设计](../planning/2026-10-23-accessory-editor-and-rig-design.md)。状态为本地实现与选择性验证，未作阶段或产品验收；无 main 合并、推送、安装、发布或部署。

## 实施范围

- 正式配饰入口打开 `AccessoryUnifiedEditorWindow`，通过本地 WebView2 编辑图片、文字、根部、中心线和全部参数。原生会话校验分块工程与 PNG，再一次返回外层草稿；只有外层应用提交清单。缺失或损坏的工程不得静默退回扁平图。
- 网页整图翻转、旋转、裁剪与撤销同步变换根部／中心线；裁掉绑定时要求重新绑定。橡皮与恢复保留真实像素及工程重开来源，文字和笔画继续可编辑。
- 共享配饰求解改为单链、固定骨长、静止曲线与蒙皮；消费所属 owner 的成功推进，重复刷新不得增加时间。Belt 接收真实 Core 位移，Stacked 接收身体位置变化，暂停恢复清除残速；配饰不反作用于身体。
- 桥接区分小坐标通知与完整快照声明。请求忙碌时不允许小通知打断已有传输或延长超时；过期代际、损坏散列、次序与预算越界均拒绝。
- 复核修复了共享 PNG 的已完成条目被传入另一条目待完成 source 的问题，保留每件配饰的可编辑工程归属。

## 获准前台交互与界面问题

用户授权约 5 分钟前台交互。本次仅启动隔离构建、独立数据目录与虚构素材，通过实际鼠标／键盘和 UI Automation 操作正式入口。文字 `DangoTest` 与三点中心线经确认、外层应用后可重开；子窗口修改名称后取消，再开仍为保存名称。截图包括 `ui-text.png`、`ui-cancel-reopen-ready.png`。这些是 Agent 前台操作结果，不是用户人工观感验收。

外层取消的前台连续操作受到异步窗口关闭／页面切换时序影响，部分命令未找到目标控件，未完成全部参数逐项对照；不得把最后截图作为全参数恢复的前台通过证据。该合同随后由上表新增确定性测试验证，前台完整流程仍待复测。独立静态复核未发现可证实的阻断缺陷；真实 WebView 焦点下 Enter／Escape 与宿主默认确认／取消的完整输入矩阵尚未验证。

按桌面界面规范 v0.1 第 2–6 节检查：暖白棕色、图标短文字、固定确认／取消区、参数独立滚动与画布输入分区已有实现；配饰参数在窗口右侧是统一图片编辑窗口的业务布局。前台发现网页缩放按钮仍蓝色、部分辅助英文外露、数字框按钮挤压。根因为上游主题类覆盖 CSS 变量、缺少 `.sr_only`、通用按钮最小高度覆盖半高 spinner。已修正语义色覆盖、中文短标签、辅助文本裁切、数字框空间和 toggle 标记，并重新打包；修正后的前台外观尚未复测。

本轮测试窗口与进程已关闭，检查时无对应 Dango／WebView2 残留；没有新增常驻服务或端口。隔离虚构数据、截图及测试 profile 保留为证据，不清理用户库。

## 后续与验证边界

- E2：继续核对完整手动去背／填充／图层工具闭环、滚轮与键盘焦点隔离、修正后真实窗口及最小／纵向窗口和 DPI；隐藏浏览器或静态测量不能代替这些验收。
- E3：单链机制和两个正式消费者的自动反例已有结果，自然跟随、静止曲线观感与实际图片可编辑性仍需人工验收。
- E4：已有接线改动，仍需覆盖切页、试摆、桌面宠物交接、暂停／故障恢复，清理旧简单编辑器及失效旧路／测试，不将类型仍留仓库等同已退役。
- E5：正式发布包／离线与缺 Runtime 恢复、8 件佩戴真实负载、Windows 视觉及人工验收待完成。系统性性能分析与优化继续留在正式场景，不提前引入新渲染后端。
