# 单机性能与稳定性采样计划

本批已获验证授权；用户选择真实持续运行 **60 分钟**。代码基线 `6e3266de4044e877a0077ae3c25b1c6f5b4d9f81`，独立分支 `codex/performance-stability`。不更改产品行为、物理库、容量或日常安装。主代理负责验证工具和结果报告；并行审计只读，分析器代理仅负责 `eng/performance/analyze_samples.py` 和对应测试。

## 可失败验收与时间

- 使用既有干净 Release/self-contained 包的原样程序集和 DLL；先核实 `333ec9c` 与本次基线的 `src/`、`native/` 无差异，记录实际二进制 SHA-256。工具独立进程构造原有 Product `DangoApplicationHost`，通过既有构造参数传入虚构设置；不走日常单实例激活入口。此差异必须保留在结果限制中。
- 默认 Wallpaper 宿主、单团子、sprout 帽型、交互开启、键盘控制关闭。日常实例保持运行，记录其并存影响。没有捕获桌面图像、窗口标题或真实输入，也不驱动全局鼠标键盘。
- 预热至少 60 秒；随后连续观察至少 3,600 秒墙钟，保留自然空闲、自主活动和真实打盹状态。之后 20 次隐藏/恢复（各至少 3 秒）、持续隐藏至少 180 秒、恢复至少 180 秒、宿主释放后观测至少 30 秒。正常总时长约 70 分钟；调度延迟只延长，不缩短。
- 每秒读取本进程 CPU 累积时间、工作集/私有字节、句柄、线程、GDI/USER 对象、运行状态；CPU 除以真实墙钟和逻辑处理器数。记录成功产品计时器回调之间的原始间隔、帧数、打盹状态和必要错误。混合状态秒单列。
- 单个稳定状态累计有效样本至少 180 秒才给该状态 CPU 结论；短窗口、无效/缺失数据不得通过。连续观察出现超过 5 秒采样缺口、场景错误、提前退出或 UI 心跳丢失均不能宣称该时段稳定通过。15 秒无 UI 心跳时验证进程自行失败退出，只影响自身。
- 空闲沿用整机平均 CPU ≤1%、工作集峰值 ≤250 MB（保守按十进制 250,000,000 字节，并另报 MiB）；普通活动平均 CPU ≤5%，报告相对 **60 FPS** 目标的实际偏离。平均/P95 帧间隔无额外批准数值线。应用更新 FPS 不是 GPU 呈现 FPS；GPU 无可靠计数器则未验证。
- 隐藏转换后第二秒起要求计时器禁用、runtime 停止、回调数为零；CPU与释放后的进程噪声对照。恢复要求继续有有效帧、无场景错误。重复循环和长期资源比较相同状态/阶段的首末窗口与趋势；没有批准的统一泄漏增量线，不能凭一个数值宣布无泄漏。
- 退出检查宿主 Dispose、计时器、scene/attachments/tray 引用释放及进程退出。隐藏只是暂停，不能要求每次隐藏把物理 world 释放。

## 语义与未覆盖

打盹等待300–600秒按成功固定物理步累积，低实际 FPS 时墙钟可能更长；按真实 Sleeping 状态分段，不加速、不改随机数。打盹仍运行物理和 zzz；隐藏才停动画。不会触发系统睡眠或重启 Explorer。

本机 OS、显示配置和 DPI 只读记录；未实际运行的 Windows 10 22H2/第二 DPI/多屏热插拔/系统睡眠恢复明确未验证。当前容量上限3，6/12压力矩阵未实现；隐藏的“降低动画”选项不算正式能力。位置持久化、岛、房间、联网、平台扫描和新开关均不在本批范围。

已知旧 DLL `dango_box2d_self_bodies_create` 缺失导出继续保留；不替换、不删测、不通过跳过制造全绿。不重做安装回退、单实例和整套陪伴体验人工验收。最终报告分开列出静态/集成/真实运行/人工验收/Git状态。
