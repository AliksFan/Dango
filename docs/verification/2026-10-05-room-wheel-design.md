# 普通房滚轮视距设计检查

日期：2026-10-05。状态：**用户已通过两层环境与视角方案；滚轮补充已纳入设计，生产实施未开始**。

## 范围与结果

用户要求“用滚轮调视角”：普通房窗口获得焦点时可调；壁纸呈现须无应用窗口占焦点且无全屏应用。更新[视角方案](../planning/2026-10-05-room-view-mechanism-proposal.md)、[房间设计](../planning/2026-10-05-local-single-room-design.md)、[候选计划](../planning/2026-10-05-local-single-room-plan.md)与[视角示意](../prototypes/dango-room-view.html)。三档快捷入口保留，普通滚轮向上拉近、向下拉远，支持档间倍率；首轮建议每刻度相对标准倍率加减10个百分点，夹紧至全景下限／近景与顶部安全上限。窗口和壁纸分别保留本次运行内的选择。

设计核对把“没有焦点窗口”解释为桌面Shell前台，空前台句柄不视为允许。壁纸的全屏条件覆盖所有显示器，必须独立判定；不读取窗口标题、内容或保存输入记录。该设计批准不自动批准其余隐藏策略、位置恢复或生产实施。

## Windows只读接缝与未验证项

代码核对：`WorkerWDesktopFocusPolicy.cs:12–21`对空句柄拒绝并允许已识别桌面Shell；`NativeMethods.IsForegroundFullscreen():80–115`只看前台，不能证明副屏无全屏应用；`FullscreenGeometryClassifier.cs`已有整屏覆盖几何规则；`WorkerWInputProxy.cs`尚无滚轮路由。后续需核对所有显示器的可见、未最小化、未cloaked非Shell顶层窗口，使用必要的临时关系与几何信息；每个事件及应用命令前重新过滤。仍不能用浏览器条件开关替代Windows证明。

原型采用DOM累计100px近似一刻度、250ms断开累计，仅为示意；真实Windows输入须按`WHEEL_DELTA=120`和高精度设备验证。预览没有真实Shell检测、全屏扫描、WorkerW滚轮输入桥、真实物理或WPF首帧。当前原型固定虚构参考视口，不证明真实窗口高度安全上限。设计人工评审已通过；产品实时行为和产品人工验收未执行。
