# 圆形材料：有限活动块候选结果与复核

2026-10-10。对应[已批准方案](../planning/2026-10-10-round-material-contact-block-candidate.md)第 1／2／3／5 项。**独立夹具和私有集成审查通过，真实候选在第 147 帧初次落地失败，停止于设计复核。** 未通过长期稳定或新物理人工验收。

## 固定实现及独立验证

`dango_material_contact_block.h` 保留整个几何活动集合，最多 16 行，包括释放行；每小步最多 32 次线性裁定及模式检查。采用完整 pivot 的一般消元、原行／列 ID 平局规则与原定缩放及秩门槛，显式处理单边启用／释放、粘着、两向滑动及零累计预算。没有补对角线、删选约束、退回逐行算法、增加预算或修改物理门槛。

原第 29 帧夹具保留全部 17 体、93 个 float、4 条真实 receipt 和小步 dt，与原报告逐位一致。原 384 扫描候选仍失败；新候选在 8 行、1 次裁定／完整 double 检查／float 检查内通过。角度闭合／互补残差为 `5.544784304010314e-12 / 3.128240397673683e-11`，能量由 `0.0617119538525049` 降至 `0.043582422732563714`。

独立夹具最终通过 **30,158 项检查、29 个固定正例、16 个拒绝负例**，覆盖不同质量、单边释放／重启、正负滑动／粘着／锥边界、零摩擦／零预算切换、receipt 差量／实际锥余量／失去支撑、恰好 16 行及 17 行拒绝、秩／非有限／float 发布失败、重复模式、预算及输出保持。梯度、全行 rate 和账本另行重算。

一组合法三行几何会出现 ZERO→STICK→释放 N→ZERO→启用 N 的重复模式，并正确拒绝发布。因此夹具通过不证明所有合法物理状态都受支持。滑动转粘着与 32 个不同模式耗尽另有明确标注的决策／守卫单元覆盖，不冒充真实世界轨迹。

末态检查包括全 160 行、当前模式、摩擦锥、耗能、逐体反力账本与总动量／角动量，转换 float 后再次验证。审查又发现：原统一限速的旧全行检查允许零乘子行开离，但新 ENABLED 模式要求 rate≈0；极小尺寸的真实 float 缩放可使它超出模式门槛。因此补充限速后原模式检查，使用临时报告，保留未限速接触账本。固定反例必须证明旧 cap 检查接受而新模式检查拒绝，没有改变限速公式或求解结构。

## 真实私有连接与失败

私有宏 `DANGO_MATERIAL_CONTACT_BLOCK_CANDIDATE` 仅属于新候选目标。默认无宏模块保留原路径，旧逐行候选保留。每小步真实世界推进一次，副本依次执行原位置阶段、原耗散各一次、新块裁定、原统一限速及独立末态验证，通过后才批量写回。

默认请求 36,000 帧；正向及镜像各请求 6,000 轨迹帧加同一世界 36,000 零输入帧。三条源码诊断均只完成 146 个合法帧，尝试第 147 帧失败。实际私有 DLL 的两向报告同样为 146 个轨迹帧、0 个静置帧；拖动在第 600 帧后才开始，当前故障属于自然初次落地。不能称已执行甩动或完整长时门槛。

## 独立数学复核

从固定捕获几何独立重建梯度及矩阵，最大梯度／raw 矩阵残差分别为 `8.881784197001252e-16 / 2.842170943040401e-14`。两个接触节点 y 相同、边水平，存在精确关系：

`J55 − J155 + J156 = 0`，且 `rhs55 − rhs155 + rhs156 = 0`。

因此 9 行初始粘着矩阵的秩是 8；最小奇异值约 `5.49429e-17`，下一个约 `0.0115056`。原秩门槛正确检出冗余；它没有证明物理不可行。

在固定帧上取解析反力坐标 `λ55=0`，求得另八行的一个解；其余六个单边乘子为正，两个切向累计冲量严格在各自摩擦锥内。完整解族为：`λ55=α`、`λ155=λ155(0)−α`、`λ156=λ156(0)+α`，其他反力不变。区间 `0≤α≤0.005079772720584183` 保持单边和摩擦合法；该方向合成冲量为零，速度相同。

独立 native harness 对这个固定诊断解执行原 double／float 全 160 行及账本／cap 验证，均通过；能量由 `3.7284536070118325e-6` 降至约 `2.17814023e-6`，float 最大角度闭合 `2.7905826360513805e-12`。它没有重放世界、修改候选、扫描模式或增加预算，也不证明下一方案能完成长期轨迹。候选仍按批准的 rank 失败规则拒绝此帧。

## 锁存与恢复

真实回归精确要求第 147 帧、`-96`、phase 4、rank、9 行、2,345 小步及上述成本／可用性字段；没有故障会使测试失败，不能跳过。

失败副本没有写回：实际 17 体位置／速度仍与该小步的世界输入逐位相同；公开输出保持第 146 帧合法快照。故障后移动、下压／跳跃、拖动三类输入不推进世界或改变原始状态、计数及完整诊断。显式 reset 清锁存／接触计数／诊断、恢复初始运动状态，再次完整恢复 146 个合法帧，并在第 147 帧重现同一故障。

首轮测试错误要求跨 reset 保留内部 Box2D body ID，实际 reset 会销毁重建物理体，generation 合法变化。按现有契约修正为运动状态逐位恢复、旧 ID 失效、新 ID 有效且不同；锁存期间及重现运行中的内部身份仍严格保持。首失败日志保留，未改候选代码或故障门槛。修正后的真实锁存回归通过 **1,355 项检查**；这是故障处理通过，物理候选仍失败。测试世界已销毁。
