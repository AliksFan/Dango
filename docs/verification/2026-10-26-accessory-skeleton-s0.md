## 实施范围

- `eng/accessory-editor/skeleton-commands.js`：可复用、无 DOM 的移动、挂接、解除、续画、插点、删除、建组和内存历史；每次提交重新校验几何／引用，无环检查及同点约束传播。几何快照重算根偏移、长度和相对角度，只提供未来绑定输入，不声称已实现正式蒙皮／绑定。
- `eng/accessory-editor/skeleton-input.js`：真实 DOM pointer／keyboard 事件、选择与活动组、两种骨架工具、单手势快照、候选预览、上下文目标、取消与捕获释放；外部历史修订使临时状态和旧菜单失效。
- `eng/accessory-editor/s0/`：独立最小消费者和精确静态文件白名单服务器。两组虚构链、一条父子挂接、P/R/J 重合、固定图像夹具和一个未分组层；新组为空且只有根。草稿只在当前页面内存中，刷新即重建夹具。
- package 脚本及局部 README 提供启动／验证入口。未改正式网页编辑器入口、生成包、原生桥、工程格式、求解器、运行宿主或正式存储。

技术延续：用户再次确认优先基于此前选定的 miniPaint。已只读核对 [ADR 0007 决策第 1 项](../adr/0007-accessory-editor-and-rig.md)：固定版本 miniPaint 本地定制资源，由 WPF WebView2 承载。图片工具／图层／历史优先复用现有集成，Dango 增加组骨架、挂接、伸缩和原生桥／求解。S0 消费者是临时输入验证，S5 必须接回 miniPaint 并保持统一工程历史；当前内存样板历史不作为另一套永久产品历史。

启动：在 `eng/accessory-editor` 执行 `npm run s0`，使用打印出的本机临时 URL；不会自动开浏览器。Ctrl+C 关闭。无依赖安装、无数据库或云资源。

## 自动验证

`npm run test:s0`（现有 Node v24.18.0、锁定 Playwright Core 1.56.1、现有无头 Edge）：**29 项通过，0 失败**，其中核心 9 项、DOM 输入 20 项。浏览器输入使用 Playwright 的真实鼠标／键盘事件，不只调用编辑回调。

| 范围 | 反例与实际覆盖 |
| --- | --- |
| 移动和约束 | 自由 R 只移根；P 单动不带节点；父 J 只传播子根；整链与 P／父节点／子根混选不重复位移；二级同点传播；冲突及传播后零长度整笔拒绝 |
| 选择和绘制 | 左击现有点不添点；空白框选与 Shift 追加；Alt 重叠轮选；只从单个末端／空根续画；新点自动选中；拖已选点持续切换修改且不误落点 |
| 两种挂接 | 拖动松手和命令点击；候选预览与提交相同；Alt 切换不随移动／复核抖动；无效命令点击不提交；已挂根无效拖动恢复；自身／后代拒绝 |
| 取消和修订 | Esc、右键取消、真实捕获释放、切组；DOM blur 通知；外部修订取消拖动／粘鼠标；外部删除菜单目标／选择末端不留下无效 ID |
| 删除和历史 | 尾删、联合后缀、内部后缀拒绝、跨组引用拒绝；失败保留全部草稿；一次移动／挂接／删除一次撤销；过期修订和无变化不进历史 |
| 输入边界 | 文本框保有文字／方向键／Delete；骨架键和文本键不向宿主冒泡；Enter 仅结束续画；缩放和平移不改几何；微调使用输出图像像素 |
| 页面资源 | 实际请求限本机源、无 JS pageerror；静态文件白名单，不开放任意仓库文件 |

失焦用 DOM 生命周期事件注入检查取消处理，未把它冒称真实 Windows 切换验收。修订变更通过独立消费者夹具的 History 边界注入；指针手势仍用浏览器事件执行。宿主穿透探针检查 DOM 冒泡，不代表原生 WPF／WebView2 已接线验收。

静态资源门禁：`node verify.mjs` 的 6 项正式资源精确清单和散列检查通过；本轮不重建包。`git diff --check` 及新增文本的空白／冲突标记／机器路径检查通过。后台样板无 CSP 违例，未分组斜纹实际生效。真实中文输入法与原生 WPF 输入桥未验证。

## S0 临时交互值与差异

- 命中半径 11 CSS px、拖动阈值 4 CSS px、骨段菜单命中 7 CSS px；均是可校准样板值，不冻结为 S1／S5 产品尺寸。
- 普通重叠点按 Alt+左击轮选。挂接中按一次 Alt 切换当前候选；Alt 按住时粘鼠标左击只更新预览，无修饰左击提交；拖动松手按当前候选提交。此细节用于避免复核轮选和预览跳变，属于 S0 补齐默认，待用户反馈。
- 临时防御上限为 12 组、96 节点、40 步内存历史，不是正式资源预算；不接收用户工程或写正式库。
- 按规范第 2、4 节复用暖白／棕强调语义变量、线图标＋短字、键位提示和可辨焦点；第 3 节保留固定反馈／历史操作，第 5 节侧栏常驻细条；第 6 节的正式窗口、DPI、高对比、减少动画及人工观感门禁仍待对应阶段。本样板没有折叠参数面板或装饰动画。
- 页面差异仅为 S0 的最小画布、活动组列表和两工具入口；无完整图像工具、参数面板或正式保存动作，不当作 UI-01–UI-09 全部完成。

## 原前台反馈清单（历史范围，未获通过）

需按 AGENTS 第 4 节取得当前屏幕授权，预计约 5 分钟；显示独立本地样板窗口，先由用户操作，不自动占用全局鼠标键盘。

1. 点击／Shift／框选与整链移动是否自然；重合 P/R/J 身份、根单独移动和混选反馈是否清楚。
2. 绘制选点、续画、拖点转修改、Enter／Esc 是否符合预期，是否出现误落点。
3. 拖根松手挂接、右键粘鼠标点击挂接、Alt 候选切换和失败／取消反馈是否易懂。
4. 删除拒绝原因、单步撤销、切组取消、持续拖动和布局辨识是否可接受。

用户已用新的统一实现授权替代此 S0 门禁；本记录不再阻断 S1/S2，也不构成通过声明。正式求解、伸缩、组绘制片、保存／重启、两条宿主运行链及产品人工验收均未验证。
