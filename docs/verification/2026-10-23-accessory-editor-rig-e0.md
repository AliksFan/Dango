# 配饰统一编辑器与骨架 E0 工程记录

日期：2026-10-23。状态：**E0 有界合同已实施，未达到本轮 60Hz 工程对照目标；系统性能留待 E4／E5 正式场景。后续 E1 原生合同结果见 [E1 记录](2026-10-23-accessory-editor-rig-e1.md)。**

目标来源澄清：批准的设计、计划及 ADR 0007 要求 E0 测量并冻结预算，没有规定「8 件、200% DPI、p95 ≤ 16.67ms、60 FPS」为本功能的硬验收线。60Hz／16.67ms 与具体 2× DPI 样本由本轮实施选择，用于工程风险对照；16.67ms 是 60Hz 的整帧时间，不能全部分给配饰。此前将该对照直接称为已确定的性能门禁、并据此宣布后续必须停止，表述过于绝对。本次纠正目标和授权的归属，实测数据与未完成事项保留。

依据：[设计](../planning/2026-10-23-accessory-editor-and-rig-design.md)、[实施计划](../planning/2026-10-23-accessory-editor-and-rig-implementation-plan.md)、[ADR 0007](../adr/0007-accessory-editor-and-rig.md)。后续实施对话的用户授权覆盖本地生产代码、依赖获取、相关测试与本地提交，不覆盖安装、日常 DLL 替换、main 合并、推送、上传或部署。

实施从 `6f8c83b58998da768617282662cd8370c81c1e8a` 建立独立受管工作树与 `codex/accessory-editor-rig` 分支；文档来源工作树只读。主工作区 `main@d929a8e` 的用户 `AGENTS.md` 修改保持原样。实施采用主工作区最新规则；桌面界面以规范 v0.1 第 2–6 节及 §4.3 为依据。

## 已覆盖的工程机制

- 新 managed 链式原语与皮肤绑定尚未替换正式旧求解器。2–17 节点；最多 1,089 顶点、2,048 三角形；每顶点最多相邻两段权重，固定根部，保留初始曲线。拒绝退化／交叉／明显折返或非相邻歧义绑定。
- 新参数候选单位：柔软度 0–1；阻尼 0–30/s；恢复频率 0–30 rad/s；重力加速度 0–4 图高/s²。每次最多 8 个 1/120s 子步；超过 1/15s、尺度改变或根部过大跳变重建；不追算隐藏时间。柔软度 0 精确保持内部初始几何。
- 独立审查复现极小正时间步产生 Infinity／NaN；已拒绝小于 1µs 的正步长，回归覆盖极小步后正常帧。重复／回退 tick、只读刷新、暂停／恢复与重置有可失败用例。
- native 浏览器宿主验证本地资源散列、来源和资源清单，禁止外部导航、子框架、弹窗、下载、任意权限与 host object。使用独立 InPrivate 控制器；不接收文件系统对象，不记录图片／工程／源路径或输入内容。消息桥有协议／会话／请求／修订校验，256 KiB 消息、128 KiB 原始分块、64 MiB 单传输、60s 操作上界；编辑等待本身不设 60s 限制。E2 仍须接入主动超时通知、完整数据校验和关闭生命周期。
- 原生隐藏 HWND 没有 WS_VISIBLE；未调用 ShowWindow、激活、置顶或全局输入。真实 WebView2 已验证本地载入、合成 PNG→工程→重开逐字节相同、外部导航拒绝、隔离页面 renderer 崩溃与重试。初始化还检查网页 API 实际可用，不能仅凭导航成功判定成功。

## 测量与当前结果

设备：Intel Core i7-12700H，20 逻辑处理器，Windows 10.0.26100，.NET 10.0.12，Release；实际 WebView2 Runtime 155.0.4283.62。数值测量只含链式求解、不可变快照与蒙皮输出；不含 WPF 光栅／上传或产品 compositor。

| 工况 | 中位 / p95 / 最大 ms | 每帧分配 |
|---|---|---|
| 默认分层 JIT，1 件最大拓扑 | .2618 / .3434 / .6871 | 18,320 B |
| 默认分层 JIT，8 件最大拓扑 | .4344 / .5841 / 5.4302 | 146,560 B |
| 关闭分层 JIT，1 件 | .4825 / .5677 / 1.0715 | 18,320 B |
| 关闭分层 JIT，8 件 | 3.6775 / 4.8739 / 11.0909 | 146,560 B |

隐藏 WebView2 的 4000×4000 工作画布、4 个独立图像层（64,000,000 图层像素）加载／导出：初始化 895.7ms，操作 1680.5ms；采样浏览器进程私有字节峰值 683,618,304 B。样本是虚构的透明边框／实色内容，尚不代表高熵 PNG／满撤销压力或 native 源解码的联合峰值。1.5 GiB 浏览器测量门槛是当前测试边界，不是已证明的所有操作进程硬配额。

### 本轮 60Hz 工程目标下的光栅性能风险

`AccessoryRigRasterTests` 使用真正的 `AccessoryMeshVisual.ApplyBatch` 和 `WriteableBitmap.WritePixels`，无窗口、无合成或输入。1024² 虚构 Pbgra32 纹理，256 DIP 基础几何，17 节点；120 帧预热、120 帧采样。静止图对独立四角网格和原始像素采样的最大通道差均为 1/255，透明边缘与支点正确。正确性通过不消除下列性能风险。

| 件数 / DPI | 总耗时中位 / p95 / 最大 ms |
|---|---|
| 1 / 1× | 2.985 / 4.475 / 4.693 |
| 8 / 1× | 9.437 / 11.540 / 13.775 |
| 1 / 2× | 9.886 / 11.858 / 14.568 |
| 8 / 2× | **26.899 / 33.913 / 42.482** |

8 件 2× 时，各阶段 p95：准备 7.718ms、光栅 22.479ms、上传 3.651ms；UI 线程每帧分配约 2.629MB。总耗时未包含身体绘制、WPF compositor 与输入，已经超过 60Hz 对应的 16.67ms；不能冻结为满足该目标的生产预算。各阶段分位数并非同一帧，不能相加推算总 p95。

另外执行了一次明确的低密度对照：仅测试采样完整网格的隔行／隔列，并保留精确支点与端点，18×17＝306 顶点、544 三角形。生产网格未改变，未引入按负载静默降画质。相同 8 件 2× 工况总耗时仍为 **19.721 / 23.259 / 25.803ms**；光栅 p95 17.231ms，准备 2.787ms，上传 3.353ms，每帧分配 787,630B。对照动态观感未验收；该结果仍未达到本轮 60Hz 工程目标。

这些是 CPU 光栅／上传机制数据，不是屏幕 FPS、桌宠／房间实测或人工效果。测试中计时记录方法的通过只表示样本确实发生动态光栅、纹理非空且无异常；按本轮 60Hz 工程目标评估未达到，不能据此宣布违反了已批准的具体性能标准。

初轮已通过：9 项链机制用例、1 项极小步回归、6 项 native 边界用例、1 项隐藏原生控制器用例（含 crash／retry）、1 项最大工作画布测量。网页独立 smoke 覆盖实际画笔输入和工程重开，属于后台浏览器验证；最终联合结果如下，性能判定独立。

最终同一源码联合回归 **25/25**：上述 18 项，加 2 项静止图光栅正确性、4 组实际动态光栅记录与 1 组低密度对照。报告保留在 `artifacts/accessory-editor-rig-e0-evidence/final.trx`。该轮完整网格 8 件 2× 总耗时中位／p95／最大为 **21.922 / 25.645 / 28.753ms**；低密度对照为 **17.593 / 20.969 / 22.006ms**。与首轮数值存在 JIT／机器时况差异，两轮均不满足 16.67ms。最终浏览器工作画布样本初始化 1094.8ms、操作 3069ms、采样私有字节 632,193,024B；所有源解码／高熵／历史压力联合峰值仍未验证。

最终独立复审再次执行 `verify.mjs`、`budget-tests.mjs`、`smoke.mjs`，全部通过且资源清单散列未变。已关闭的反馈包括：畸形 brush 图层破坏原文档、16 层配额拒绝后仍修改旧笔画、遗留外部颜色片段来源；九类畸形图层拒绝保留 PNG／工程／撤销，满图层笔刷拒绝保持工程／历史，独立替换外部片段并检查实际闭包。保留历史失败与修正，不将这些审查项通过写成性能通过。

测试恢复遇到基线已有 `Microsoft.AspNetCore.SignalR.Common` 10.0.11 高危公告 NU1903；测试命令单独使用 `-p:WarningsNotAsErrors=NU1903` 保留警告，未修改仓库错误策略、关闭审计或升级范围外依赖。正式桌面项目本身的 build／publish 未依赖该测试工具链例外。

## 未完成门禁与边界

网页输入、图层／矢量内容与历史资源反例已覆盖当前 E0 受控子集；全量内存压力与正式 E2 输入仍未验证。项目预算为最多 16 层、64M 图层像素、64 MiB 工程字符、20 次／64 MiB 保留撤销载荷、32,768 画笔点、65,536 文字字符；载荷计账不能冒充整个进程的内存硬配额。未运行产品前台窗口，未证明整套 E1–E5 功能。

最终工程源码提交 `97e55f890bc42c82250f6d66a2d2301c2a29d25c` 的干净正式 publish 通过，包清单为 `sourceDirty=false`，位于 `artifacts/desktop-entry/accessory-editor-rig-e0-final/package`。直接从 Git 提交导出后的 6 个网页资源散列也全部匹配；第三方许可与生成模板采用局部 Git attributes 保留原字节和原始空白，不以改动许可文件修复检查。

分发脚本已实际运行 SDK 依赖白名单、nupkg SHA256、LICENSE／NOTICE 与已审核来源一致性检查；其余包依赖仍默认拒绝。由该包生成的本地许可核查 ZIP 位于 `artifacts/preview-releases/accessory-editor-rig-e0-license-check`，SHA256 `719177bbab1612f4bc43a2908fa83aabe12694490b101218a7055b85f31cd49f`。它是 E0 内部包证据，未接通统一编辑功能，不能作为新功能发布或人工验收材料。未启动此包或修改日常安装。

实施计划 §4 的停止条件针对无法满足明确预算的情况。当前具体性能预算尚未冻结，不能把本轮自定对照目标直接当作该停止条件已成立。已有本地实施授权继续有效；当前记录的是性能风险与预算待确定，E0 尚未完成，后续方向的差异如下：

| 方向 | 保留的合同与代价 |
|---|---|
| 继续优化现有 WPF CPU 光栅与网格提交 | 保留当前渲染后端和 8 件／原始纹理，可在已授权范围内继续定位与优化；优先测准备分配、三角覆盖和采样热点；当前尚无优化后证据，不能承诺达标 |
| 调整渲染边界，以 GPU 纹理网格承担动态形变 | 保留图片／骨架／成功帧合同，但改变当前渲染实现边界，需先补相应 ADR、依赖许可及 Windows 分发验证 |
| 调整产品能力或质量 | 减少已批准的 8 件佩戴能力或降低图像质量属于范围变化；帧率目标则应先明确，不能把本轮对照自动视为已批准的质量承诺；本次未实施此类调整 |

原统一编辑与骨架方向已经获批，无需重新批准；尚待明确的是正式性能预算、适用设备和场景，以及实际绘制成本的分配。

用户随后指出优化可等主要模块开发后再做，当前顺序已澄清为：有界性、正确性与失败恢复作为前置，系统性性能优化及验收留待 E4／E5 真实接线场景。后续 E1 的 Schema2／工程／成品原子保存已形成原生合同，E2 工程适配开始；正式统一编辑窗口、E3 骨架制作、E4 双运行链与旧路退役、E5 Windows 和人工验收仍待完成。原有图库／旧文件未被清空、迁移或删除。正式旧入口暂存至计划 E4 的同步替换点，不作长期 fallback。

本轮隐藏测试结束后已确认对应 WebView2 进程残留 0；临时虚构测试数据与包位于忽略的 artifacts 目录并保留，无监听服务或新端口。未安装 Runtime，未替换保护 DLL，未合并／推送／打标签／部署。
