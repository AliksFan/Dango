# 普通房窗口镜头设置

日期：2026-10-06。用户要求新增三种镜头设置，并反馈镜头静止时平滑、移动时出现抖动。沿用已授权的窗口体验实施范围，壁纸继续暂停。用户明确确认停止后缓慢归中、右键允许横纵拖动、Esc 菜单选择、本次运行记忆，并追加未来纵轴设计也应跟随。纵向构图已询问，先采用已说明默认：平地保持当前地面构图，升降柔和追随，落地恢复；如用户补充答案，以新答案为准。

## 初版行为与约束（3bac659；纵向跟随后续修订见下）

- 跟随：初次入房横向居中，纵向记录平地构图；移动时保留位置滞后，镜头两轴用保留速度的阻尼追随；横向静止后缓归中，纵向升降后落地缓恢复。世界边缘受限时允许不居中。
- 不积极跟随：中心区域不追随；团子进入画面左右、上下约 20% 的边缘区时更新相应轴目标并柔和追随，停止后保持目标。
- 不跟随：不自动追随；右键按住空白场景横纵拖动，方向如抓住场景；左键保持点击/抚摸，不恢复普通房的物理拖动。
- 设置只在窗口 Esc 菜单显示，默认跟随；滚轮视距独立，缩放/resize 保留二维观看中心并夹边界，全景时水平不能拖出世界。纵轴在默认地面构图上下各一房间高度内有限移动，不改变实际物理世界；当前墙本来延伸到世界零点上方，不能以零点硬夹导致纵向跟随永远不动。未来更高场景可按 WorldHeight 扩展范围。
- 右键手势在菜单、失焦、隐藏、捕获丢失、模式/视距/尺寸/DPI/健康帧变化时取消，不补播旧位移；正常右键抬起不清 A/D。
- 不改变原生位置、碰撞、步态、实体身份、物理步数或单帧 owner。不新增依赖、网络、数据库或桌面输入记录。

## 已核实原因与取舍

当前窗口相机只在 ApplyFrame 推进。HostFrameScheduler 采用约 60Hz 固定物理步，无物理步的呈现回调直接返回；多步只应用最后一帧。原相机使用一阶指数插值，没有速度状态。身体、帽子、环境共用世界 Projection，目标来自物理核心，未发现步态轮廓作为相机目标。

仅提高镜头频率会新增相对锯齿：同速情况下，60Hz 团子位置 0→8→16 与 120Hz 镜头 0→4→8→12→16 相减，会得到 0→−4→0→−4→0。因此窗口在同一唯一呈现回调同时插值身体/帽子的共同位置和镜头目标，约延迟一固定步；轮廓与步态仍使用最新健康物理帧。命中减去同一呈现偏移；环境只使用相机投影。多步采样使用实际累计成功步的时间跨度，不把两次 Applied 默认当相邻物理步。隐藏恢复、错误、时钟重置/丢步重建基线，不补播旧样本。

这些源码与数学证据支持修正呈现时序，但尚不能证明真实合成/DPI/显示设备上的全部抖动根因。真实手感仍由用户验收。

## 实施顺序与可失败门禁

1. RoomViewController 与纯算法测试：三模式、运动/停止/反向、不同呈现频率、边界和手动视角缩放保持。
2. SceneView/Driver 与位置插值测试：零物理步继续呈现、重复回调不推进、实际多步时间跨度、生命周期重建、身体/帽子/命中与同一中心一致；保持单 owner 和原生步数。
3. Window/Menu 与输入门禁：三选项、默认隐藏壁纸设置、下拉 Esc、右键取消、正常 Up 保留方向、最小窗口所有动作可用。
4. 串行受影响窗口测试、隔离 Release 构建；保留保护 DLL。替换本任务旧候选，保留其他任务进程。分别报告自动证据、人工待验和 Git 状态；不合回 main、推送、日常安装或部署。

## 纵向中线修订

用户追加要求「团子在超过中线之后再实行垂直跟随」，反馈旧版有时把团子放到屏幕下边缘。已询问向上跨线与上下跨线的区别，先按已说明默认向上跨线处理；普通房窗口 Follow 纵轴使用此修订，其他模式和横轴保持各自合同，壁纸仍暂停。

两个新门禁在修改生产代码前实际 **2/2 失败**，见 `window-camera-midline-red-20261006-r1.trx`：下半屏内的微小上升已使相机移动；高处停稳后下落轨迹将 core 推到 570.36 DIP（600高视口，已侵入32 DIP下缘区）。原目标是地面锚点加相对初始 core 的全部纵位移，阻尼下降时会滞后；仅限制到世界范围不能保证屏幕可见性。此为受控轨迹复现，不冒称真实桌面同一输入的精确根因。

修订设计：Follow 的纵向目标为地面锚点与「已校准身体中心位于屏幕中线」两者中更高的视角。团子处于下半屏时小跳不移动镜头，向上越线才启动柔和跟随；落回时柔和恢复地面构图。目标取同一插值物理中心加固定中性地面对齐，不追随步态轮廓。另将实际已绘制身体底部（含步态与共同呈现偏移、笔画余量）作为每帧下缘安全约束，留出32 DIP；仅 Follow 使用，Manual 不强行拉回镜头，EdgeFollow 规则不变。安全约束修正越界的相机位置，必要时截断向上的旧速度；不改身体、碰撞或物理世界。

验收范围：低跳不触发、高跳越线缓跟随、静止高处收敛到中线、落地恢复原地面、临界小波动不产生明显抖动、初始高度不固化构图、下落全过程身体底部保留余量；实际 Native 绘制路径与逆命中保持一致。
