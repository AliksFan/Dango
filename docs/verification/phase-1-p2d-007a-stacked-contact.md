## 1. 范围与结论

本检查点验证 1–3 只不同颜色的虚构团子在同一个本地 Box2D world 和同一地面上的重力、堆叠与滑落。恢复候选直接替换正式 `Wallpaper/Window` 桌面团子的表现路径，两种宿主共享同一个 stacked runtime；启动时只有主团子，控制中心可在本次运行中添加或按最后添加优先移除另外两只。主团子仍是唯一 Core 权威实体，另外两只只属于本地物理验证。它不创建账号、好友、房间或网络连接，也不代表多人同步或 P2D-008 的 1/6/12 性能验收完成。

P2D-007 paired session 保持原有双体横向共同 cue、强挤压与释放行为。恢复后的主团子消费 P2D-006 `DirectionalControlIntent` 产生的 Core 权威边界，stacked native 不再消费预览专用二维 WASD 力；另外两只动态核心继续受重力。三体输出只进入局部轮廓、诊断、帽子挂点和 `RenderOffsets`，不能回写 Core 权威位置。

恢复范围与已批准参数见[团子物理特性统一与 P2D-007A 恢复方案](../phase-1-dango-physics-characteristics-restoration-design.md)。下文中关于独立预览、`0.02` 摩擦和零连线骨架的内容只作为上一失败候选证据保留，不代表当前实现。

## 2. 上一候选的先失败验收（历史证据）

`Box2DStackedContactWorldTests` 首次运行因 `Box2DStackedContactPresentationWorld` 与 `StackedPhysicsPresentationFrame` 不存在而以 `CS0246` 失败。实现后覆盖：

- 三个软体环共享真实 Box2D contact，且上下两组相邻层都实际接触；
- 返回帧逐项保留三份原始 Core 权威边界；
- 底层承重压缩大于顶层，远侧宽度变化和轮廓面积保持有界；
- 接触地面前的自由落体持续加速，偏心上层团子会沿另一只团子滑落并继续受重力下落；
- 第一只团子接受有界 WASD 二维控制力，移动底层后上层会侧移并失去原堆叠 contact；
- 底层被移开后必须在 60 帧内解除与中层的接触，并持续分离至少 30 帧，不能拖拽粘连；
- W 方向控制力能够克服重力抬升受控团子，停止输入后重新受重力影响；
- 失焦清空按键状态，输入白名单只接受 WASD，`R` 单独用于重置；
- 稳定保持期间无非有限数、无界能量或持续抖动；
- reset、fallback、Dispose 完整释放共享 world；
- 现有 P2D-007 paired world 仍可加载并保留权威边界；
- 帽子在 stacked native 中没有 body、shape 或 joint，且三个独立帽子在 XAML 中全部声明于身体之后；
- stacked 契约不含账号、好友、房间或网络语义，且按键内容不记录、不持久化。

## 3. 上一候选的实现边界（已退役）

- bridge ABI 升至 v9，Box2D 版本继续固定为 3.1.1；paired 导出与行为保留，stacked step 新增二维表现控制输入并返回动态核心位置。
- stacked session 固定承载三个 16 节点软体环、三个动态表现核心、一个静态地面和左右边界；所有团子受真实重力。团子间平滑防穿透层与轮廓节点统一使用 `0.02` 低摩擦，移除原先强制至少 `0.75` 的摩擦下限；地面仍只与轮廓节点接触并保留独立摩擦。
- 三份 Core 权威边界只用于出生和重置；Box2D 动态核心位置转换为表现层 `RenderOffsets`，原始 Core 边界逐帧原样返回，物理结果不能推动或修改 Core。
- 预览用暖杏、浅蓝、浅紫三色区分层次，中层与顶层从相反方向的明显偏心位置落下，避免默认形成不易观察的垂直粘连链；窗口焦点内用 WASD 控制暖杏色底层团子，`R` 或按钮重置场景，失焦立即清空控制状态。
- 预览保留“显示物理骨架”开关，只显示虚构标识、表现帧和受控物理诊断。
- 骨架调试层彻底取消所有连线，只显示一个核心点和 16 个轮廓节点，避免辐条聚集后仍形成 Z 字或扇形结构。
- stacked native session 不创建帽子 body、shape 或 joint；三个 `DangoHatVisual` 与身体分离，并在 XAML 中统一位于全部身体之后，保证帽子始终绘制在所有身体最上层。身体纵向尺寸按控件实际高度换算，使真实 contact 与屏幕轮廓一致。
- `Reset`、fallback、关闭窗口和 `Dispose` 都销毁整组 stacked native world；销毁时验证 Box2D 分配回到创建前基线。

## 5. 证据分层与停止点

- **静态门禁**：ABI v9 native Release 重建、格式、Release solution 构建、Core 36/36、Desktop 150/150 及差异检查均通过。
- **集成门禁**：三体共享 Box2D world、真实重力、严格居中承重、偏心滑落、WASD 有界控制、34 帧内解除接触并持续分离、Core 权威边界不变、帽子零碰撞、reset/fallback/Dispose 释放及 P2D-007 回归已由测试覆盖。
- **实时行为（历史）**：上一独立 WPF 预览 PID `19516` 已停止；独立预览不再是本轮验证入口。当前恢复候选必须以正常启动的正式桌面场景重新验证。
- **人工验收待完成**：WASD 手感；移开底层后上层是否自然滑落；重力、碰撞、压缩与收束是否自然；帽子是否始终在所有身体上层；骨架是否不再出现 Z 字结构。
- **人工反馈与恢复方向**：首轮截图确认轮廓折线形成 Z 字、身体间留缝且帽子看似承重；第二轮截图确认滑落不明显且接触后粘连。用户随后批准恢复 P2D-007 完整骨架、暂不处理 Z 字，并要求直接替换正式桌面团子。当前实现不再采用零连线骨架、独立 `0.02` 摩擦或预览专用 WASD。
- **交付状态**：当前改动未提交、未合并、未推送、未部署。
- **延期项**：正式 CPU/GPU/帧时间及 1/6/12 只采样属于 P2D-008/P1-005；账号、好友、房间、网络同步和正式群体动作不属于本任务。

人工观感通过后，才能把 P2D-007A/B7A 标记为完成。不得据此开始 P2D-008。

## 6. 2026-09-05 正式桌面恢复候选

- `Wallpaper` 与 `Window` 共同持有一个 `StackedDangoSceneRuntime`；宿主切换只重映射显示坐标，不复制或重建当前多体物理状态。
- 初始数量为 1，本次运行内边界为 1–3；添加启用下一只并从其出生锚点开始，移除禁用最后添加者，隐藏 body 不参与 contact，重启恢复 1。
- native 非稳定帧会冻结最后一个有效表现帧并阻止自动重建，避免第二、第三只自动消失后又回出生点；显式数量操作或正式生命周期重置才允许重新初始化。
- 主团子仍由 P2D-006 Core 方向控制器驱动；stacked 托管契约已删除 `StackedPresentationControl`，native 的预览二维力固定为零。
- stacked 碰撞恢复 `10%` 轮廓节点半径和正式 `0.55` 节点材质；内部防穿透代理使用零摩擦圆角代理，避免制造表面粘连。接触时通过表现层接缝补偿把相邻身体收敛至约 `-2 px`，帽子不参与补偿或承重。
- 正式两种宿主只绘制当前活动身体，并在全部身体之后绘制对应独立帽子；stacked native 中仍不存在帽子 body、shape 或 joint。
- 完整骨架恢复为一个核心点、16 条核心径向线、按 `(i, (i+1) mod 16)` 闭合的 16 条轮廓线和 16 个节点。控制中心“桌面体验”开关默认关闭；Z 字只观察、不隐藏。
- `--stacked-contact-preview` 和对应独立窗口已删除；本轮不创建 P2D-007A 控制中心验收会话、草稿或导出记录。
- 本轮先失败验收覆盖初始一只、1–3 数量命令和异常帧不得自动重生；实现后定向回归通过。最终静态门禁：native Release 重建 SHA-256 `75BBDA12A039FA3444B33D4CC16A87938484DCDFC43E96E9434F7A7D9F316052`，格式验证通过，Release 构建 0 警告/0 错误，Core 36/36、Desktop 156/156，`git diff --check` 通过。
- 正式 Release 程序从工作树启动，PID `27816`；30 秒存活检查 `Responding=True`，CPU 增量 5.11 秒，工作集由 183.0 MiB 到 185.8 MiB。按钮操作后的桌面观感、添加后的滑落与移除顺序仍需用户人工验收。
- 正式桌面实时行为与用户人工观感仍需正常启动 Dango 后确认；这一步不使用独立预览，也不写入控制中心验收记录。
