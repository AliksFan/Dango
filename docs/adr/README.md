# Dango 架构决策记录

本目录保存 Dango 已批准的重要技术决策。ADR 记录决策当时的背景、选择、后果和重新评估条件，不替代产品设计、阶段计划或专项调研。

## 状态

- **Proposed**：已形成提案，尚未批准。
- **Accepted**：已经批准，当前工作应遵循该决策。
- **Superseded**：已被后续 ADR 替代；原记录保留用于追溯。
- **Rejected**：明确不采用，但保留评估理由。

已接受的 ADR 如需改变，应新增 ADR 并链接原记录，不直接抹去历史结论。
