# ADR 0007：配饰本地图片编辑与链式骨架表现

> 状态：Accepted（用户已确认方向；工程门禁、依赖版本与数值预算待执行）
>
> 决策日期：2026-10-23
>
> 范围：Windows 本地配饰制作与表现；当前仅文档准备

## 背景

配饰第一版只能导入静态透明 PNG，并以单支点整图弯曲／应变场产生柔性。用户要求增加手动抠图、简单绘图，把连接点和运动参数并入编辑器，并能在一张完整猫尾／彩带图片上设置多节链条。用户确认使用 miniPaint，保留重力影响，并明确无需承担已有柔性配饰的继承成本。

[ADR 0001](0001-windows-client-foundation.md) 保持 WPF／Win32 客户端基础，[ADR 0003](0003-animation-assets-and-rendering-validation.md) 延后完整骨骼／角色引擎并要求独立版本化资产。本决策只为配饰增加有限链式结构与制作工具，不替换身体物理、客户端框架或正式渲染后端。具体产品合同见[设计](../planning/2026-10-23-accessory-editor-and-rig-design.md)，增量见[实施计划](../planning/2026-10-23-accessory-editor-and-rig-implementation-plan.md)。

## 决策

1. 采用固定版本的 miniPaint 本地定制资源，通过 WPF WebView2 承载图片编辑；连接点、单链控制点和配饰参数属于同一编辑会话。它是制作端依赖，运行中的配饰不依赖网页计时器或在线服务。
2. 使用刚性和骨架柔性两种制作方式。骨架柔性以单根无分叉链、图片网格与蒙皮为首期边界，响应真实挂点运动和每件重力参数。managed 约束求解优先验证 PBD／XPBD 路线；精确算法、预算、版本与端点经 E0 验证冻结。
3. 每件同一时刻只运行一种内部形变。接线完成时退役旧整图材质场和旧简单图片窗口，不建立旧柔性兼容、自动骨架转换或永久回退开关。可复用的刚性连接、整体角度、纹理光栅化与身体映射保留其职责。
4. Belt 和 Stacked 复用配置、求解和不可变网格合同，各自沿现有 owner／成功帧推进。编辑器、渲染和布局刷新不能新增物理世界、额外推进或合并 native ABI／工作线程。
5. Dango 以版本化工程包装编辑内容，以静态 PNG 供运行时使用；工程、根部、骨架与参数通过同一草稿／清单提交。miniPaint 内部对象和任意网页 JSON 不作为唯一持久事实。
6. 不为旧柔性效果或旧库安排迁移；旧存档只识别并保护，明确未载入，不自动删除、重写或清空。新格式通过显式应用建立独立清单；坏／未来的新格式不能被空库覆盖。
7. 固定并核查真实 miniPaint commit、依赖、素材和构建来源，保留 MIT 及第三方声明。WebView2 SDK／Runtime 单独按微软条款核查和分发，不能把 miniPaint 的 MIT 推广为整个运行环境许可。具体 Runtime 分发方案由 E0 确定，缺失时提供可恢复错误，不自动安装。
8. 浏览器只访问受控本地编辑资源。消息验证来源、会话、修订和大小；native 持有文件选择、校验与正式写盘。用户图片和工程不上传，未授权网络、任意文件系统桥接及非必要本地信息采集不纳入。

该决策为 ADR 0003 中配饰工具／表现的有限增补，原身体、多人动作语义、资产独立性和渲染验证规则继续有效。没有批准完整骨架角色引擎、Spine／Live2D／Rive 或 Godot／SkiaSharp 渲染迁移。

## 替代方案与取舍

| 方案 | 取舍 |
|---|---|
| 继续扩展旧 WPF 图片窗口并自建全部绘图工具 | 避免浏览器依赖，但绘图、选区、撤重和图层维护工作较多；用户已选择 miniPaint |
| 骨架后再叠加旧整图柔性 | 可能扩展局部材质表现，但本批没有该需求，会重复控制内部弯曲，增加参数和测试耦合 |
| 长期保留旧柔性兼容／迁移 | 用户明确无需承担此继承成本；只保留原存档的安全边界 |
| 每节骨节使用单独图片 | 对分段素材可行；不满足本批整张图片连续弯曲的主要制作方式 |
| 专业动画运行时或完整引擎 | 增加授权、分发和宿主整合成本，超出单链需求及当前 ADR 范围 |

## 后果与门禁

- 图片编辑、参数和链条制作形成同一产品流程，PNG 与动态结构相互独立，首批不用用户手工切图或绘制复杂权重。
- 增加 WebView2 Runtime 前置、本地网页依赖维护、桥接安全、工程格式与资源预算；网页可嵌入不代表已满足 Dango 主题、输入或无障碍合同。
- 单链不能覆盖任意宽布片、分叉和真实三维扭转；首期没有碰撞或反作用，自动绑定失败要明确反馈。
- 网格绘制可复用接口基础，具体拓扑、透明质量及 1／8 件实时负载仍需实测，不能用旧 8×8 网格或历史性能结果推定通过。
- E0 依赖／安全／资源门禁未通过，依赖它的实现不可视为可交付；整体门禁包含正式入口、保存重启、两个 runtime、离线、失败恢复与人工验收。

## 重新评估条件

若受支持素材无法得到可接受的单链绑定或弯曲、WPF 光栅化不能满足已冻结预算、WebView2 依赖／许可不可接受，或用户需要分叉、布料、自碰撞、主动动作，再新增相应决策。不得通过忽略图片质量、停用真实响应或退回已退役路径隐藏失败。
