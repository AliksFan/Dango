# ADR 0006 原团子与正圆家具的逻辑度量

> 状态：Accepted（隔离技术准入；完整窗口与人工验收待完成）
>
> 提案日期：2026-10-09
>
> 所属范围：官方圆球独立单人小样

用户于 2026-10-09 通过圆球设计，并授权持续推进至需要人工协助／验收。[隔离技术准入](../verification/2026-10-09-round-ball-admission.md)现已实际通过，以下候选成为本批技术选择；这不等同于真实窗口、性能或人工验收通过。

## 背景

[静态平台小样](../verification/2026-10-09-static-platform-prototype.md)恢复并验收了原 160×120 团子造型。其世界标尺水平 80、竖直 60；物理正圆在该映射下成为 4:3 椭圆。为球单独画正圆会使可见轮廓、接触位置和滚动角度失配。圆球设计需要保持原团子、正圆外观和双向真实接触，详见[产品提案](../planning/2026-10-09-official-round-ball-design.md)。

[ADR 0005](0005-box2d-visual-soft-body-presentation.md)确立 Box2D 3.1.1 和 native 表现层边界。当前团子已经使用 Box2D rig 与 native 显示轮廓接触求解；静态平台并非通用有质量刚体家具。本提案只讨论新增圆球的坐标、自由度与接触边界，不替换团子内核或扩大到服务端。

## 准入后的技术选择

定义逻辑接触度量 `q = T p`、`T = diag(4/3, 1)`。原团子的位置、节点、质量和 Box2D 步进不变；其显示轮廓进入圆球接触时映射到 q。圆球在 q 中保持正圆，拥有中心二维平移与一维旋转三个自由度。屏幕仅以 `60s` 等比投影 q，得到原团子投影与正圆球，DPI 与窗口尺寸不参与 native 求解。

首选试验候选是在现有 native 世界的固定子步内维护球状态，按同一成功物理步发布球与团子。球仍受同一重力、真实地面／墙接触、质量、圆盘惯量及有界摩擦／回弹约束。它不另建 Box2D 世界，也不在 WPF 中积分、搬动物体或推算滚动。

接触在 q 中测量团子显示样条与球圆。若 q 中的接触法线为 `n`，作用到原团子自由度的导数必须包含 `Tᵀn` 及既有样条导数，球在自身度量中接收对应的反作用和接触转矩。法线、间距、速度与冲量的单位必须显式定义，不能仅交换两个不同空间的数值。最终冲量、摩擦、位置修正和睡眠方案需由解析夹具与真实 rig 试验证明。

圆球法向作用线经过球心，不产生自转；切向作用按实际接触点与圆盘惯量计算。候选法向有效逆质量为 `Σ(|gᵢ|²/mᵢ) + 1/m`，切向还需计入球转动项；这里 `gᵢ` 已包含完整映射与显示轮廓导数。接触点在采样段内部时，段参数、最近点和导数必须一致，不可只对最近节点施力。

球的休眠由其实际 native 积分与接触状态定义。如果候选没有 Box2D 球 body，就不能将自己的睡眠字段称为 `b2Body_IsAwake` 结果；必须记录积分停止、再次接触唤醒及睡眠期间的碰撞检查。仍活动的团子世界继续正常步进。

## 替代方案

| 方案 | 后果与当前取舍 |
|---|---|
| 原世界直接新增 Box2D 正圆，按原标尺如实投影 | native 结构最简单，但画面得到椭圆，不满足正圆设计目标 |
| 原世界 Box2D 正圆，显示层另画正圆 | 可见边缘与接触不一致，不满足本提案 |
| 全场景改成等比标尺或重建团子 | 会改变已接受的团子映射／接触，超出圆球最小范围 |
| 在同一 Box2D 世界把不同物体位置解释为不同坐标空间 | 需要绕过所有自动跨体接触并集中处理映射，容易误用地面、墙及查询，暂不推荐 |
| 球状态在 native 固定子步中用明确逻辑度量求解 | 保留原 rig，但需要维护新增球动力学、接触和睡眠；作为受停止门禁约束的首选试验候选 |

Box2D 的标量质量与惯量不能直接表达仿射变换后的完整质量矩阵。因此“使用原生圆形 body”本身不证明两个坐标空间下的力学已经一致。本提案不默认整场景的普通总角动量严格守恒；无外力解析夹具要验证定义明确的冲量反作用、功、球转矩与能量边界。

## 代价与准入

新增的球自由度只服务该官方刚性球，不建设通用自研刚体引擎。已有团子、无球和平台路径必须保持原行为，原模块 ABI 签名和 42 槽团子帧保留。球与团子共同冻结最后安全步，创建、移除及 Reset 同步更新含场景修订的整组安全快照，普通动作不得越过故障锁存；所有权和资源由同一 native 世界管理。

该技术尚未实现或试验，不能记为 Accepted。进入完整小样前必须通过产品提案中的度量／轮廓、有限差分、双向冲量与功、转动、接触预算、休眠唤醒、无球零容差对照及资源门禁。具体试验夹具与误差容限在实施计划中冻结。

若无法在原 rig 不变、单一固定步和可接受维护成本下通过，应停止并重新比较方案；不得用显示层补偿、改变团子参数、静态演出或第二物理世界绕过准入。用户设计批准与后续编码／交付授权仍分别记录。
