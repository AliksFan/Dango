# ADR 0009：配饰编辑器中央模拟模式

状态：Accepted（2026-10-29用户批准本地实现；人工交互验收另计）。补充[ADR 0008](0008-accessory-shared-joints-and-unified-project.md)，不改变已有工程／清单schema、骨架求解或正式保存边界。

## 背景与决定

用户确定在同一编辑器中点右上预览Tab，把中央画布切成只含团子和当前配饰的物理空间；左工具收起，直接拖动团子。右上放挂点／相机工具和连接、行程、前后显示层等佩戴值，不需要播放器及配饰间排序。

1. **正式引擎、独立临时场景。** 每个编辑器模拟场景复用 `BeltBodyRuntime` 和正式 `BeltBodyAppearancePresenter`，只有一个native owner推进物理；WPF视图消费已发布帧，不另行积分。外层当前外观通过装配工厂传入，临时姿态不改变外层团子位置或持久设置。
2. **直接原生显示。** WebView仍持有图像／骨架工程、历史与表单；按当前有效中央矩形裁出HWND区域，WPF原生视图负责身体、当前配饰和鼠标交互。原生再次按实际DIP视口裁界并转换物理像素；收起面板仍可扩大模拟空间，切回后恢复完整browser region。旧小PNG逐帧传输与播放器入口退役。
3. **明确启动与退出。** 构造和编辑模式不创建native world；有有效显示尺寸且进入模拟才创建／配置。空白配饰允许仅身体运行，首次完整定义到达不重置身体或相机。异步configure／bounds／resume按代际拒绝迟到继续，退出清输入并暂停，关闭同线程释放owner。
4. **单份草稿与统一撤销。** 现有13项佩戴字段使用严格有限值、布尔与前／后枚举白名单；不允许借参数更新修改资产、P、组、佩戴开关或排序。前端佩戴动作进入原miniPaint历史，但不发图像Changed／不导出PNG。身体选点经同一动作回传，图像／骨架快照接受时采用最新native佩戴值，Busy期间不回退参数。
5. **原提交合同。** 模拟不保存；确认返回项目、图像与佩戴参数到外层草稿，外层应用才原子持久化。取消、故障和失败导出保留现有恢复语义；其他配饰不受临时场景影响。现有兼容数据保护和资源边界继续有效。

## 替代与后果

- 外层控制中心实时截图复用简单，但小图帧限制大画布清晰度，且混入其他配饰与外层位置；旧产品调用退役。
- 独立预览窗口增加窗口切换；用户已选择同窗口模式，不实施新独立预览产品入口。
- 新场景多占一个受生命周期约束的本地物理owner；其正式场景内仍只有一个推进者，退出即停止计算，不能用第二计时器重复步进同一world。
- 编辑器模式切换、13字段校验、历史与HWND region需跨层验证；离屏真实WebView2／native检查可证明覆盖的集成行为，前台手感和DPI观感继续由人工验收。

没有新依赖、远端服务、付费资源、用户库迁移、安装或发布授权。

2026-10-29 后续用户调整：模拟三工具移入独立右侧竖栏，骨架细调固定展开。模拟输入复用既有 `HomeBodyPreviewSession` 绑定当前唯一 runtime，避免复制 WASD／跳跃／混合拖动规则；WebView只传必要输入焦点占用，原生按自身窗口实时前台资格恢复焦点。参数和菜单保留输入，失活释放，返回时抑制旧按键；不引入全局键盘钩子或跨应用激活。

2026-10-29 最新用户调整：工具栏改到左侧并增加“刷新团子”，保留相机和配饰草稿，只重置临时身体的位置、速度与摆动；独立编辑窗口打开期间暂停外层控制中心owner，退出后重新核对页面资格恢复。刷新是用户对先前不提供复位控制的明确后续调整，不增加播放器。

同轮边界故障已真实复现：原单身体 `SetBounds` 只定义越界guard，到可视边缘会返回 `-605` 并停算，不能充当墙。模拟显式启用新的可选侧墙能力，复用room已有的SPD投影和耦合接触冲量方法，保留原guard／shape／speed保护；默认单身体和门廊仍不启用侧墙，现有capabilities与room dispatch不变。刷新复用原临时owner的重建入口并清失败状态，不通过吞错、显示端夹坐标或另建计时器恢复。侧墙能力在重建时保留，缩窗时让真实身体安全进入新边界；关闭及快速模式切换仍受代际约束。
